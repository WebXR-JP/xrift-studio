# モデルの取り込み設定

初回の取り込みでは、読み込みメニューのテクスチャ設定が使われます。モデルごとに変更したい場合は、Inspector の「読み込み設定」で「テクスチャの最大解像度」を選び、再インポートしてください。選択肢は「読み込み設定に従う」「原寸のまま」、および 256〜8192px です。内蔵画像の縦横比と原本はそのまま維持され、個別に保護したテクスチャ設定は上書きされません。

メッシュ最適化と Draco 圧縮の設定は素材に保存され、再インポート時にも適用されます。Inspector での最適化と公開前の Draco 圧縮には共通の変換処理を使います。公開前に Draco 圧縮を選ぶと Draco が有効になり、メッシュ最適化にはモデルに保存された設定が適用されます。

原本はそのまま残るため、圧縮のチェックを外して再インポートすれば原本から読み直せます。ただし、原本自体が最初から Draco 圧縮されている場合は、その圧縮が残ります。

「配置時にMesh Colliderを追加」のチェックを外して再インポートすると、そのモデルを参照しているシーンとプレハブから Mesh Collider が取り除かれます（手動で追加した Mesh Collider も対象です）。Box Collider など他の形状、他のモデル、編集済みの階層や位置・回転・大きさは変更されません。再インポートに失敗した場合も、現在の素材と Collider はそのまま残ります。

MCP から変更する場合は、`update_model_asset` の `patch.importSettings` に `compressWithDraco` と `textureMaxSize` を指定します。`textureMaxSize` に指定できる値は `"default"`、`"original"`、または 256・512・1024・2048・4096・8192 です。設定を保存したあと、`reimport_model_asset` を呼んで適用します。

Draco 圧縮はモデルの転送サイズを抑えるための機能です。描画時のテクスチャメモリを減らしたい場合は、テクスチャの解像度縮小と KTX2 圧縮を併用してください。
