# 空の背景シェーダー Library v3

## カタログと選び方

11 カテゴリ・全 40 プリセットを収録しています。従来の 9 プリセットの ID を維持しつつ、24 プリセットを追加しました（これに後述の 7 つの時間帯プリセットを含めて全 40 プリセットです）。テクスチャ、リモート画像、追加モデルは不要です。

各プリセットは複数の GLSL 表現とパラメーター設定を組み合わせています。ワールド制作向けに調整した表現であり、フォトグラメトリや観測データに基づく物理大気モデルには対応していません。

## 一日の空・7つの時間帯

Skybox Creator 由来の 7 つの時間帯（夜明け・朝・昼・黄金時・夕暮れ・薄明・夜）を追加しました。アセットストアの「Skybox Shader」で「一日の空・7つの時間帯」を選ぶと、`creator-dawn` / `morning` / `day` / `golden` / `sunset` / `twilight` / `night` に絞り込めます。プレビューを選んで「Skyboxに設定」を押すと適用され、空の色・雲の影・光の縁は追加後も編集できます。

これら 7 種類は静止した空のマテリアルであり、Web エディターの時計・鳥・飛行機は含みません。雲の連続的な方向サンプリングと、表示色から線形光への変換を同じシェーダー内に実装し、通常の色管理とポストプロセスを通して描画します。品質設定によるサンプル数の変更はない軽量な表現です。

## 品質と負荷

| 設定 | 新規ノイズの階層 | 新規ボリューム雲 | 新規オーロラ | 従来ボリューム雲 / 光サンプル |
|---|---:|---:|---:|---:|
| 軽量 | 3 | 10 | 10 | 12 / 2 |
| 標準 | 4 | 18 | 18 | 24 / 3 |
| 高精細 | 5 | 28 | 28 | 40 / 4 |

表の数値は 1 ピクセルあたりの上限やループ回数です。内部で別のノイズや光の計算も行うため、単純な FPS 換算はできません。巻雲や霞はボリュームのレイマーチを行わず、サンプリング数を使わないシンプルなプリセットでは、品質を変えても見た目や負荷が変わらない場合があります。「描画量」はアルゴリズム上の目安であり、実測の性能ランクではありません。

既定の品質は「標準」です。ストアでの品質選択は通常のマテリアルの Variants / `defines` に保存されます。追加後に品質を変更したい場合は `defines` を直接編集するか、同じプリセットを追加し直してください。追加し直すと独自の GLSL や Uniform 編集が上書きされる点に注意してください。

従来の volumetric 系プリセットのストア既定値は 40/4 から 24/3 へ下げています。「高精細」を選べば 40/4 に戻せます。なお、すでにプロジェクトへ保存済みのマテリアルのサンプル数は自動で変更しません。

## 見た目とプレビューの変更

- 星は立体グリッドから球面方向の 6 面グリッドへ変更し、1 ピクセルより小さい星の明るさを補正しています。太陽・月の輪郭には角距離に応じたアンチエイリアスをかけ、地平線とノイズの補間も見直しました。新規の自然系プリセットでは山並みの初期値を 0 とし、不要な地形が自動的に表示されないようにしています。
- オーロラは高さごとに変わる模様を単純に重ねず、縦筋を共有したうえでサンプル間隔に合わせて光の幕をフィルターしています。環を持つ惑星は球と環の交差判定を行い、前後関係と影を計算します。
- 下半球のシンセウェーブの格子は背景であり、歩ける床ではありません。水中プリセットも実際の水面・集光・水中フォグを生成するものではありません。
- 一覧では `public/visual-editor/sky-shaders/v3/*.webp` を遅延読み込みします。詳細欄だけ 1 つのライブ Canvas を使い、カード数に比例して WebGL コンテキストを増やしません。サムネイルが読み込めない場合は案内を表示し、別の Canvas へフォールバックしません。
- 詳細欄ではドラッグや矢印キーで見回し、再生・一時停止、視点リセットができます。タブ非表示や画面外では連続描画を止め、端末の「視覚効果を減らす」設定を初回の停止状態に反映します。Uniform 編集時は既存の `ShaderMaterial` を更新し、品質やソースが変わったときだけマテリアルを作り直します。

## 開発者向け

実装の入口は次のファイルです。

- `src/lib/visual-editor/sky-shader-catalog.ts`: カタログ統合、既存 9 種類、パラメーター適用
- `src/lib/visual-editor/sky-shader-extended-catalog.ts`: 新規 24 種類と GLSL 表現のテンプレート
- `src/lib/visual-editor/sky-shader-glsl.ts`: 共通の頂点段階、ノイズ、星、天体など
- `src/lib/visual-editor/sky-shader-quality.ts`: 品質による `defines` の上書き（Uniform は変更しない）
- `src/components/visual-editor/SkyShaderStore.tsx`: 検索、カテゴリ、品質、追加 UI
- `src/components/visual-editor/SkyShaderCatalogPreview.tsx`: 静止カードとライブ表示

新規プリセットを追加する際は、安定した ID、カテゴリ、GLSL、Uniform の初期値、有効なパラメーター、タグ、既定の視点を定義してください。

- 球の内側から描画するため、variant は `side: back`、`transparent: false`、`depthWrite: false` とします。
- 方向は `vDirection`、回転は `uRotation`、露出は `uExposure`、中心は `uCenter` に従います。アニメーションには `animatedTimeUniform: uTime` を使います。
- GLSL の出力は線形色として扱い、末尾に Three.js の `tonemapping_fragment` と `colorspace_fragment` を入れます。色の Uniform は既存のマテリアル生成処理で sRGB から線形色へ変換されます。
- 空を追加しただけで環境照明や反射まで変わらないようにする前提を維持してください。

ブラウザ側で任意の URL から GLSL を取得する新しいインポート API は追加していません。既存の「アセットストア」に同梱カタログを増やした改修であり、編集可能な通常マテリアル、MCP、ワールド出力の既存経路をそのまま利用します。

## 再現用コマンド

既存の依存関係をインストールした環境で実行してください。追加の npm パッケージは不要です。

```sh
# カタログの整合性検査と、自己完結型ギャラリー生成
node scripts/sky-shaders/check.cjs ./sky-check

# PlaywrightのChromiumで3品質・視点・境界値を検証
node scripts/sky-shaders/verify-webgl.mjs ./sky-check

# 検証に通った後、ストア用WebPサムネイルも再生成
node scripts/sky-shaders/verify-webgl.mjs ./sky-check --thumbnails

# アプリ全体の型検査と既存fixture群は別途実行
pnpm typecheck
pnpm e2e:typecheck
pnpm exec playwright test e2e/sky-shaders.spec.ts e2e/water-shaders.spec.ts
```

- `check.cjs` は Vite で TypeScript を変換してカタログを読み込み、整合性を検査します。アプリ全体の型検査は別途必要です。生成されるギャラリーはデモ・検証用の独立した WebGL2 実装であり、R3F の結合テストや実機 FPS 測定の代わりにはなりません。
- Playwright の Chromium が未導入の場合は既存プロジェクトの手順で導入してください。システムの Chromium を使う環境では `SKY_CHROMIUM_PATH`、ソフトウェア描画では `SKY_SOFTWARE_GL=1` を指定できます。Linux 環境によっては Xvfb などのディスプレイが必要です。
- `verify-webgl.mjs` は実装と同じ品質 `defines` をカタログから生成して検証します。`ShaderMaterial` の仕様検証を含むアプリのフィクスチャテストには、全プリセットの品質・インストール・再インストール・JSON 保存の検査も追加しています。空の背景用フィクスチャテストは取り込み時に実行済みですが、すべてのフィクスチャテストや VR 実機検証を代替するものではありません。
- ストア用サムネイルは `--thumbnails` から Playwright の Three.js 描画テストを呼び、本体と同じ `createClassicR3fMaterial` で生成します（標準品質、時刻 6.5 秒、640×400）。`manifest.json` にシェーダーのハッシュを記録しているため、プリセットの GLSL・初期値・既定視点を変更した場合はサムネイルと確認用 HTML を再生成してください。なお、確認用 HTML の表示変換は ACES フィットと sRGB 出力で、アプリの Three.js チャンクとは独立した実装です。
