# OpenXRで部屋を取り込む

WindowsのStudioで、Questに保存された部屋の床・壁・家具を取り込みます。必要な機能をPC側で利用できる環境が対象です。実機動作は未検証です。

## 手順

1. Quest本体でRoom Setupを済ませます。
2. Meta Air LinkなどでPCへ接続し、ヘッドセットでLinkが使える状態にします。空間データの利用を許可してください。
3. Play中なら「Stop」を押し、Scene Viewの「部屋を取り込む」を開きます。「Meta Quest」を選ぶと準備の手順を確認できます。
4. 接続環境が自動で確認されます。接続や設定を変えた場合は「接続を確認し直す」を押してください。この確認だけでは、端末の接続や部屋の取得成功までは分かりません。
5. 必要な機能がそろったら「保存済みの部屋を取り込む」を押します。
6. 完了後は「取り込んだ部屋を表示」で配置したEntityを選択して表示します。寸法・向き・床位置を確認し、プロジェクトを保存してください。

床・壁の平面、家具の寸法・分類、対応Runtimeが提供するMeshを取得します。取得できた形状をGLBとして配置し、形状がない物体には基本サンプルを使います。実物と同じ製品モデルを生成する機能ではありません。

取得中はヘッドセットの表示が一時的に切り替わる場合があります。画面を閉じても取り込みは続き、Scene Viewのボタンに進行状態が残ります。「取得を取り消す」はデータ取得中だけ使えます。素材の保存が始まった後は完了を待ってください。

完了後も配置・除外件数と警告を確認できます。追加で取り込むと、前回の部屋を残したまま新しいEntityが配置されます。同じ部屋を取り込むと重複するため、結果を確認してから追加してください。

取得できない場合は、画面に表示される準備や再試行の手順を確認してください。詳しいエラーは折りたたみから開けます。取得中にシーンが変わった場合は編集を保持し、再取得を案内します。取得を取り消した場合も、既存のシーンは保持されます。

## 接続環境と制限

| 接続環境 | 部屋の取り込み |
| --- | --- |
| Meta Air Link + Meta Runtime | 必要な部屋取得機能が利用できる場合に読み取ります。実機未検証です |
| SteamVR Runtime | 必要な拡張がない場合は、不足項目を表示して取得を止めます |
| PICO 4 Ultra + PICO Connect | 現在は未対応です。「PICO」を選ぶと対応状況を表示し、取得操作は表示しません |

この操作で新しくルームスキャンを始めることはできません。Questに部屋が未設定の場合はLinkを切断し、本体でRoom Setupを済ませて再接続してください。

データはローカルプロジェクトへ取り込みます。公開前には部屋の形状を含む内容を確認してください。
