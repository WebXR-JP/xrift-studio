# OpenXRで部屋を取り込む

WindowsのStudioで、接続中の端末に保存された部屋を取り込みます。実機動作は未検証です。

## 手順

1. Quest本体でRoom Setupを済ませ、Meta Air Link等でPCへ接続します。空間データの利用を許可してください。
2. Playを停止し、Scene Viewの「OpenXR」を開きます。「再診断」で接続環境を確認できます。
3. 「保存済みの部屋を取り込む」を押します。
4. 取得後に選択されたEntityの寸法・向き・床位置を確認し、プロジェクトを保存します。

床・壁の平面、家具の寸法・分類、対応Runtimeが提供するMeshを取得します。取得できた形状をGLBとして配置し、形状がない物体には基本サンプルを使います。実物と同じ製品モデルを生成する機能ではありません。

取得中はヘッドセットの表示が一時的に切り替わる場合があります。「取得を取り消す」はデータ取得中だけ使えます。素材の保存が始まった後は完了を待ってください。取得中にシーンが変わった場合は編集を保持し、再取得を案内します。

## 接続環境と制限

| 接続環境 | 部屋の取り込み |
| --- | --- |
| Meta Air Link + Meta Runtime | 必要な部屋取得機能が利用できる場合に読み取ります。実機未検証です |
| SteamVR Runtime | 必要な拡張がない場合は、不足項目を表示して取得を止めます |
| PICO 4 Ultra + PICO Connect | 現在は未対応です |

この操作で新しくルームスキャンを始めることはできません。Questに部屋が未設定の場合はLinkを切断し、本体でRoom Setupを済ませて再接続してください。

ブラウザのページを開く操作や、部屋ファイルの手動転送は不要です。データはローカルプロジェクトへ取り込みます。公開前には部屋の形状を含む内容を確認してください。
