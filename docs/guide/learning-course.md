# 制作から公開まで、順番に学ぶ

XRiftとXRift Studioの関係、作り方の違いを知るところから始めます。小さなワールドを一つ作り、XRiftで確かめ、人を招くまでのコースです。各レッスンを「準備 → 操作 → できたかの確認 → 困ったとき」の順に進めます。

## このコースの使い方

- 初めてなら第0章から、作成済みの作品があるなら必要な章から始めます
- 動画ありの教材は、既存19本の動画と詳しい文章を一緒に使います
- 「文章・動画未収録」の教材も、手順を読んで進められます。未完成の再生枠はありません
- 公開や認証は、アカウントの持ち主が公開先・内容・権限を確認して操作してください。APIキーやパスワードを会話や共有文書へ貼り付けないでください

## 先に知っておくこと

基本の配置にはログインやAPIキーは必要ありません。ブラウザ版βでも始められますが、スクリプトを含むワールドとアイテムの公開はデスクトップ版で行います。スクリプトの「回転」教材は追加練習として飛ばせます。保存先と端末ごとの違いは、最初のレッスンで確認します。

最初の公開を目指す場合、MToon、Prefab、Bloomなどの表現は必要に応じて追加してください。床、開始位置、保存、テスト、公開確認は省かず進めます。

## 00 XRiftと作り方を知る

作品を体験するサービスと制作ツールの関係を知り、作りたいものに合う方法を選びます。

   ワールドとアイテムの違い、画面での配置、Node Graph、TypeScript／TSX、GLSLでできることを確認します。

1. [Hierarchyで選ぶ・視点を動かす](./lesson-01-03.md)（動画あり）

3. [複製とUndo・Redoを使う](./lesson-01-04.md)（動画あり）

## 06 見た目と動作を確認する

仕上げを加えたら、同じ条件でテストし、必要な素材だけ軽くします。

1. [Bloomで光をにじませる](./lesson-04-08.md)（動画あり）
   Bloomを使い、光のにじみを調整します。
2. [テクスチャの解像度と容量を確認する](./lesson-04-09.md)（動画あり）

4. [容量を調べ、必要な画像だけ軽くする](./course-optimize-world.md)（文章・動画未収録）
   端末ごとの確認場所から大きい素材を探し、見た目と容量を比較しながら画像を変換します。

## 07 XRiftへ送り、公開状況を確認する

作品情報、アカウント、送信、審査を一つずつ確認します。

1. [公開前のバックアップと作品情報を整える](./course-publish-prepare.md)（文章・動画未収録）
   公開前にタイトル、説明、サムネイル、素材の利用条件とバックアップを確認します。
2. [公開用のアカウントを確認する](./course-publish-account.md)（文章・動画未収録）
   公開先のアカウントと端末別の認証方法を確認し、秘密情報を安全に扱います。
3. [ワールドを一度だけ送信する](./course-publish-upload.md)（文章・動画未収録）
   公開先を確認して一度送信し、処理中・完了・結果不明のときに取る行動を区別します。
4. [審査と一覧への公開を確認する](./course-publish-review.md)（文章・動画未収録）
   送信後の審査状態、現在使用中の版、ワールド一覧への掲載を別々に確認します。

## 08 同じ作品を更新し、人を招く

更新先と参加範囲を確認してから、実際に入れることを確かめます。

1. [同じワールドを更新する](./course-publish-update.md)（文章・動画未収録）
   公開済みの元プロジェクトから更新先と変更内容を確認し、新しい版を送信します。
2. [ワールドに入り、友達を招く](./course-publish-invite.md)（文章・動画未収録）
   ワールドとインスタンスを区別し、参加範囲やゲスト許可を確かめてから共有します。

## 一通り終わったら

- 元のプロジェクトを開き直し、バックアップの保存先が分かる
- 床、開始位置、仕掛け、音をテストし、実機で確認が必要な項目も控えてある
- 公開先と審査状況、使用中の版、一覧掲載の状態を区別できる
- インスタンスの参加範囲を確認し、相手が使える案内を渡せる

公開したら終わりではなく、実際の端末で確かめて修正します。ひとつずつ変え、元の作品を残しながら更新してください。
