# 制作から公開まで、順番に学ぶ

XRiftとXRift Studioの関係や作り方の違いを知るところから始めて、小さなワールドを一つ作り、XRiftで公開して友達を招くまでを順番に学べるコースです。各レッスンは「準備 → 操作 → 確認 → 困ったとき」の流れで進めます。

## このコースの使い方

- 初めての方は第0章から順番に進めてください。すでに作りかけの作品がある場合は、必要な章から読み始めても構いません。
- 「動画あり」のレッスンでは、19本の短い動画と文章の手順をあわせて確認できます。
- 「文章のみ」のレッスンも、手順に沿ってそのまま進められます。
- 公開やログインの操作は、必ずアカウントの持ち主ご自身で行ってください。APIキーやパスワードは、チャットや共有メモに貼り付けないよう気をつけてください。

## 先に知っておくこと

基本的な配置や見た目の調整は、ログインやAPIキーなしですぐに始められます。ブラウザ版βからそのままワールドやアイテムを公開することもできます。

ただし、スクリプトを含む作品の公開にはデスクトップ版を使います。第5章にあるスクリプトの「回転」レッスンは追加練習なので、まずはNode Graphだけで進めたい場合は飛ばしても大丈夫です。保存先や端末ごとの違いは、第1章の最初に確認します。

最初の公開を目指すときは、MToon・Prefab・Bloomなどの表現は必要に応じて取り入れてみてください。一方で、床・開始位置・保存・テスト・公開の確認は、飛ばさず順番に進めるのがおすすめです。

## 00 XRiftと作り方を知る

作品を体験する場であるXRiftと、制作ツールであるXRift Studioの関係を知り、作りたいものに合う方法を選びます。

1. [XRiftとXRift Studioでできること](./course-introduction.md)（文章のみ）
   ワールドとアイテムの違いや、ビジュアルエディター・Node Graph・TypeScript／TSX・GLSLでできることを確認します。

## 01 準備して、ワールドを開く

制作に使う環境と保存先を決めて、練習用のワールドを一つ開きます。

1. [制作する環境と保存先を決める](./course-start-here.md)（文章のみ）
   ブラウザ版、デスクトップ版、iPadの中から使う環境を選び、自動保存とバックアップの仕組みを確認します。
2. [新しいプロジェクトを作る](./lesson-01-01.md)（動画あり）
   新しいプロジェクトを作成し、編集を始める準備を整えます。

## 02 選んで、動かして、保存する

操作している対象を確かめながら、やり直しや復元ができる状態で編集する基本を身につけます。

1. [Hierarchyで選ぶ・視点を動かす](./lesson-01-03.md)（動画あり）
   Hierarchyから対象を選び、作業しやすい角度に視点を動かします。
2. [オブジェクトを移動・拡大縮小する](./lesson-01-02.md)（動画あり）
   位置と大きさの数値を変えて、オブジェクトの配置を調整します。
3. [複製とUndo・Redoを使う](./lesson-01-04.md)（動画あり）
   複製やUndo・Redoを使って、気軽に試しながら編集します。
4. [保存して開き直し、バックアップを残す](./course-save-backup.md)（文章のみ）
   自動保存の完了を確かめて開き直し、`.xriftstudio`ファイルでバックアップを残します。

外部モデルを取り込んで配置し、色・模様・陰影を整え、よく使う組み合わせを再利用します。

   外部のGLBモデルを取り込み、シーンに配置します。
2. [PBRの色と光沢を調整する](./lesson-02-03.md)（動画あり）

4. [MToonでアニメ調の陰影を作る](./lesson-02-07.md)（動画あり）
   MToonを使って、アニメ調の陰影や輪郭線を作ります。
5. [Prefabを作って再利用する](./lesson-02-08.md)（動画あり）

## 04 歩ける空間と光を整える

歩ける床と開始位置を確認したうえで、ライト・空・環境光を使って空間の雰囲気を整えます。

1. [床Collider・SpawnPoint・Playを確認する](./lesson-01-05.md)（動画あり）
   床の当たり判定と開始位置を確認し、Playで歩いて確かめます。
2. [ライトの明るさと影を調整する](./lesson-01-06.md)（動画あり）
   ライトの明るさや向き、影の見え方を調整します。
3. [Skybox Shaderで青空を作る](./lesson-01-07.md)（動画あり）
   Skybox Shaderを使って、背景に青空を設定します。
4. [HDRIを背景と環境光に使う](./lesson-01-08.md)（動画あり）
   HDRI画像を背景やIBL（環境光）に設定する方法を確認します。

「始まったとき」「押したとき」「待ってから」というきっかけの違いを順番に試します。

## 06 見た目と動作を確認する

仕上げの効果を加えたら、決まった手順で動作をテストし、必要な画像だけ容量を軽くします。

1. [Bloomで光をにじませる](./lesson-04-08.md)（動画あり）
   Bloomを使って、光る部分のにじみを調整します。
2. [テクスチャの解像度と容量を確認する](./lesson-04-09.md)（動画あり）
   テクスチャの解像度とファイルサイズを確認します。
3. [公開前のワールドを同じ順番でテストする](./course-test-world.md)（文章のみ）
   開始位置・床・仕掛け・音を毎回同じ順番で確認し、公開後に実機で確かめる項目を整理します。
4. [容量を調べ、必要な画像だけ軽くする](./course-optimize-world.md)（文章のみ）
   容量の大きい素材を見つけ、見た目と容量を見比べながら画像を変換します。

## 07 XRiftへ送り、公開状況を確認する

作品の情報・アカウント・送信・審査を、一つずつ確かめながら公開します。

1. [公開前のバックアップと作品情報を整える](./course-publish-prepare.md)（文章のみ）
   公開前にタイトル・説明・サムネイル・素材の利用条件とバックアップを確認します。
2. [公開用のアカウントを確認する](./course-publish-account.md)（文章のみ）
   公開先のアカウントと環境ごとの認証方法を確認し、APIキーなどの秘密情報を安全に扱います。
3. [ワールドを一度だけ送信する](./course-publish-upload.md)（文章のみ）
   公開先を確認してから一度送信し、処理中・完了・結果が分からないときの対応を身につけます。
4. [審査と一覧への公開を確認する](./course-publish-review.md)（文章のみ）
   送信後の審査状態、現在使われているバージョン、ワールド一覧への掲載設定をそれぞれ確認します。

## 08 同じ作品を更新し、人を招く

更新先と参加条件を確認したうえで、実際にワールドへ入って友達と試します。

1. [同じワールドを更新する](./course-publish-update.md)（文章のみ）
   公開済みの元プロジェクトから更新先と変更内容を確認し、新しいバージョンを送信します。
2. [ワールドに入り、友達を招く](./course-publish-invite.md)（文章のみ）
   ワールドとインスタンスの違いを押さえ、参加条件やゲスト許可を確認してからURLを共有します。

## 一通り終わったら

コースを終えるころには、次のことができるようになっています。

- 元のプロジェクトを開き直し、バックアップの保存先を把握できます。
- 床・開始位置・仕掛け・音をテストし、実機で確認すべき点も整理できます。
- 公開先・審査状況・現在使用中のバージョン・一覧掲載の違いを区別できます。
- インスタンスの参加条件を確認し、相手が迷わず入れる案内を渡せます。

公開したあとも、実際の端末で動きを確かめながら少しずつ直していけます。元のプロジェクトとバックアップを大切にしながら、ワールドを育ててみてください。
