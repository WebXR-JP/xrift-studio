# ワールドを一度だけ送信する

動画：未収録（文章で進められます）

## このレッスンでできること

公開する内容と送信先を確認し、ワールドをXRiftへ一度だけアップロードします。送信が完了したら、結果に表示されたワールドIDとバージョンを手元に控えます。審査や一覧への公開確認は次のレッスンで行います。

## 始める前に

- [公開前のバックアップと作品情報を整える](./course-publish-prepare.md)と[公開用のアカウントを確認する](./course-publish-account.md)を済ませておきます。
- 公開する素材の中に、秘密情報や公開してはいけないファイルが混ざっていないか確認しておきます。
- 公開済みのワールドを更新する場合は、複製やファイルから取り込み直したプロジェクトではなく、前回公開した元のプロジェクトを開いてください。

ここから先は実際にデータをXRiftへ送信します。確認だけで止めたい場合は、最後の公開ボタンを押す前に画面を閉じてください。

## 手順

### 1. 新規公開か更新かを確認する

1. 「XRiftへ公開」を押します。
2. タイトルと説明を読み、これから公開したい作品であることを確認します。
3. デスクトップ版は「公開先」、ブラウザ版は「公開する作品」の下に表示される内容を確認します。
4. 新しいワールドとして公開されるのか、既存ワールドの更新になるのかを確かめます。更新先のIDが表示された場合は、前回の控えと見比べてください。

更新するつもりなのに「新しいワールドとして送信」と表示されている場合は、ここで一度止めて[同じワールドを更新する](./course-publish-update.md)を確認してください。

### 2-A. デスクトップ版で確認して送信する

1. 「公開情報」「サムネイル」「XRiftアカウント」がすべて整っているか確認します。未完了の項目があれば先に直してください。
2. 「読み込み容量・VRAMの目安」が表示されたら、「詳細を見る」から容量の大きな素材がないか確認します（数値は目安であり、すべての端末での快適な動作を保証するものではありません）。
3. 「公開チェック」が終わるまで待ちます。「変換時の注意」に指摘があれば、内容を確認して対象を修正します。
4. 「公開前の確認が完了しました」と表示され、問題がなければ「XRiftへ公開」を一度だけ押します。
5. 保存・変換・検査・アップロードの進捗が終わるまで待ちます。送信前の準備段階ならキャンセルできますが、送信が始まったあとは結果が出るまで画面を閉じられません。

検査で`REJECT`などが表示されて止まった場合は、表示された原因を直してからもう一度公開してください。

### 2-B. ブラウザ版βで確認して送信する

1. ワールド名・説明・サムネイルのプレビューを確認します。
2. 「XRift APIキー」欄に、用意したキーを入力します（画面共有や録画をしているときは、キーが見えないように気をつけてください）。
3. 初回は「ワールドをアップロード」、更新時は「このワールドを更新」を一度だけ押します。
4. ファイル準備・送信・結果の受信が終わるまで待ちます。途中でタブを再読み込みしたり、同じ作品を別のタブから送信したりしないでください。

アイテムを公開するときは、`write:items`権限付きのAPIキーを使って「アイテムをアップロード」または「このアイテムを更新」から送信します。スクリプトを含むワールドを公開したい場合は、スクリプトを消すのではなく、[パソコンへ引き継ぐ](./ipad.md#プロジェクトを保存してパソコンへ渡す)手順でデスクトップ版に移してから公開してください。

### 3. 完了画面の内容を控える

1. デスクトップ版では「XRiftへの送信が完了しました」、ブラウザ版では「XRiftへのファイル送信が完了しました」と表示されるのを待ちます。
2. 画面に表示されたワールドIDとバージョンを確認し、あとで照合できるよう作品名と一緒にメモへ控えておきます。
3. デスクトップ版で「XRiftで結果を開く」が出たら、そのリンクからXRiftを開きます。ブラウザ版では「ワールド一覧を開く」から進みます。
4. 結果のURLが表示されない場合は、[XRift](https://app.xrift.net/)の「ワールド」から「マイワールド」を開いて確認できます。

**送信が完了した時点では、審査の通過やワールド一覧への掲載はまだ完了していません。** 次のレッスンで、XRift側の状態を確認しましょう。

## できたか確認する

- 作品内容と公開先を確かめてから、一度だけ送信できました。
- 完了表示とワールドIDを確認し、バージョンが表示された場合はそれも控えました。
- XRift側で公開結果を確認する場所が分かりました。

## うまくいかないとき

### 送信結果が分からない

通信の切断やエラーが起きた場合でも、XRift側にはすでに届いていることがあります。まずはXRiftの「マイワールド」と「バージョン履歴」を確認し、状態が分かるまで再送しないでください。

デスクトップ版の「未公開を確認して送信保留を解除」は、前回の送信が反映されていないと確認できた場合だけ使います。すでに反映されているときや、判断がつかないときは解除しないでください。

### ファイル送信後、ブラウザへの保存だけ失敗した

「ファイル送信は完了しました」と「公開結果をこのブラウザに保存できませんでした」の両方が表示された場合は、画面を閉じずに「公開結果を保存し直す」を押してください。これは結果の記録だけをやり直すボタンなので、ワールド自体を再アップロードする必要はありません。

### 容量・権限・検査のエラーが出た

画面に表示された原因を確認し、内容に応じて[容量と描画負荷を減らす](./performance.md)、[公開用のアカウントを確認する](./course-publish-account.md)、[復旧と問い合わせ](./recovery.md)へ進んでください。問い合わせを送るときはAPIキーを含めず、どの段階で止まったかを伝えます。
