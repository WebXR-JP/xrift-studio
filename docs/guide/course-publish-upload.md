# ワールドを一度だけ送信する

動画：未収録（文章で進められます）

## このレッスンでできること

公開内容と送信先を確認して、ワールドをXRiftへアップロードします。送信後は、結果のワールドIDとバージョンを手元で確認します。審査と公開状態の確認は次のレッスンです。

## 始める前に

- [バックアップと作品情報](./course-publish-prepare.md)、[アカウントの確認](./course-publish-account.md)を済ませてください
- 公開する素材に、秘密情報や公開できないファイルが含まれていないか確認してください
- 更新の場合は、複製や取り込み直したプロジェクトではなく、前回公開した元のプロジェクトを開いてください

ここから先は、実際に作品のデータをXRiftへ送ります。練習だけで止める場合は、最終ボタンを押す前に閉じてください。

## 手順

### 1. 新規公開か更新かを確認する

1. 「XRiftへ公開」を押します。
2. タイトルと説明を読み、公開する作品を確認します。
3. デスクトップ版は「公開先」、ブラウザ版は「公開する作品」の下の表示を確認します。
4. 初回の作品なのか、既存ワールドの更新なのかを確かめます。更新先のIDが表示されたら、前回の結果と見比べてください。

更新するつもりなのに「新しいワールドとして送信」と出る場合は、ここで止めます。[同じワールドを更新する](./course-publish-update.md)に戻ってください。

### 2-A. デスクトップ版で確認して送る

1. 「公開情報」「サムネイル」「XRiftアカウント」を確認します。未完了の項目を先に直してください。
2. 「読み込み容量・VRAMの目安」が表示されたら、「詳細を見る」で容量の大きな素材を確認します。数値は目安であり、すべての端末で快適に動く保証ではありません。
3. 「公開チェック」の確認が終わるまで待ちます。「変換時の注意」に問題があれば、内容を読み、対象を修正してください。
4. 「公開前の確認が完了しました」と表示され、内容に問題がなければ「XRiftへ公開」を一度押します。
5. 保存・変換・検査・アップロードの進捗を待ちます。送信前の準備は取り消せますが、送信開始後は結果が出るまで閉じられません。

`REJECT`などの理由で検査が止まったら、表示された原因を解消してからやり直します。検査を飛ばして送る手順は使いません。

### 2-B. ブラウザ版βで確認して送る

1. ワールド名・説明と、サムネイルのプレビューを確認します。
2. 「XRift APIキー」欄に、本人が準備したキーを入力します。画面共有や録画中は、キーが見えないようにしてください。
3. 初回は「ワールドをアップロード」、更新は「このワールドを更新」を一度押します。
4. ファイル準備・送信・結果受信が終わるまで待ちます。タブの再読み込みや、同じ作品を別タブから送信する操作はしないでください。

アイテムやスクリプトを含むワールドは、ブラウザ版から送信できません。スクリプトを消して見かけ上通すのではなく、[パソコンへ引き継ぐ](./ipad.md#プロジェクトを保存してパソコンへ渡す)手順を使ってください。

### 3. 完了画面を確認する

1. デスクトップ版は「XRiftへの送信が完了しました」、ブラウザ版は「XRiftへのファイル送信が完了しました」を確認します。
2. 表示されたワールドIDとバージョンを確認します。後から照合できるよう、作品名と一緒に手元のメモへ控えてください。
3. デスクトップ版で「XRiftで結果を開く」が表示されたら、そのリンクを使います。ブラウザ版は「ワールド一覧を開く」からXRiftへ進みます。
4. 結果のURLが表示されない場合は、[XRift](https://app.xrift.net/)の「ワールド」から「マイワールド」を開いて確認します。IDからURLを推測して入力する必要はありません。

**送信完了は、審査通過や一覧への掲載まで確認できたという意味ではありません。** 次のレッスンで、XRift側の状態を確かめます。

## できたか確認する

- 対象と公開先を確かめてから、一度だけ送信した
- 完了表示とワールドIDを確認した。バージョンが表示された場合は、それも控えた
- XRift側で確認する場所が分かる

## うまくいかないとき

### 送信結果が分からない

通信切断やエラーが起きても、すでに送信されている場合があります。まずXRiftの「マイワールド」と「バージョン履歴」を確認し、結果が分かるまで再送しないでください。

デスクトップ版の「未公開を確認して送信保留を解除」は、前の送信が反映されていないと確認できた場合だけ使います。すでに反映されている場合や、判断できない場合は解除しません。

### ファイル送信後、ブラウザへの保存だけ失敗した

「ファイル送信は完了しました」と「公開結果をこのブラウザに保存できませんでした」が出た場合は、画面を閉じずに「公開結果を保存し直す」を押します。これは結果の保存をやり直す操作です。同じワールドを再アップロードしないでください。

### 容量・権限・検査のエラーが出た

表示された原因を読み、[容量と描画負荷](./performance.md)、[アカウントの確認](./course-publish-account.md)、[復旧と問い合わせ](./recovery.md)へ進みます。問い合わせにはキーを含めず、どの段階で止まったかを書いてください。
