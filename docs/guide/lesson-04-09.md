# テクスチャの解像度と容量を確認する

[動画を再生する：テクスチャの解像度と容量を確認する](./media/tutorials/lesson-04-09.mp4)

テクスチャの解像度と容量を確認します。

## 操作の要点

1. Assetsでテクスチャを選び、解像度と容量を確認します。
2. 必要な画像だけ、縮小や圧縮の設定を調整します。
3. 変換を適用したら、編集画面とPlayで見た目を確認します。

## 試すときのポイント

文字や細かな模様は縮小すると読みにくくなります。元画像を残し、容量だけでなく見た目も比べてください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./performance.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
