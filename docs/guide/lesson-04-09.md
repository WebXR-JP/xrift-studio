# テクスチャの解像度と容量を確認する

[動画を再生する：テクスチャの解像度と容量を確認する](./media/tutorials/lesson-04-09.mp4)

## このレッスンでできること

容量の大きいテクスチャを見つけ、必要な一枚だけ設定を見直します。

## 始める前に

- [バックアップ](./course-save-backup.md)を残します。
- 縮小前の見た目を控えます。文字や細い模様のある画像は、特に慎重に扱います。

## 操作の要点

1. Assetsでテクスチャを選び、Inspectorで解像度と容量を確認します。
2. 実際に表示する大きさに対して、過大な画像がないか見比べます。
3. 必要な画像だけ、解像度や圧縮の設定を選びます。設定しただけで終わらせず、適用対象を確認してください。
4. 「この設定で画像を書き出す」で変換を適用します。
5. 編集画面とPlayで、元と同じ角度・距離から文字や模様を比べます。悪くなった場合は、保持された原本があれば「元の画像に戻す」で戻します。
6. ほかの画像も一括で変える前に、[容量を調べて軽くする](./course-optimize-world.md)手順で効果を確認します。

## できたか確認する

- 変更した画像と、変更していない画像を区別できる。
- 容量の変化だけでなく、文字や模様の読みやすさも確認した。

## うまくいかないとき

- 設定したのに変わらない：変換の適用操作と完了表示を確認します。
- 画質が悪くなった：元画像へ戻すか、縮小を弱めて再確認します。公開時に自動で画質を直す処理はありません。
