# テクスチャの解像度と容量を確認する

[動画を再生する：テクスチャの解像度と容量を確認する](./media/tutorials/lesson-04-09.mp4)

## このレッスンでできること

容量の大きいテクスチャを見つけ、必要な1枚だけサイズや圧縮を見直して、見た目と容量のバランスを確認します。

## 始める前に

- 変換を試す前に、[保存とバックアップ](./course-save-backup.md)を残しておきます。
- 縮小や圧縮を行う前の見た目を覚えておきます。看板の文字や細い模様が入った画像は画質変化が目立ちやすいため、特に注意して見比べてください。

## 操作の要点

1. Assetsでテクスチャを選び、Inspectorで解像度とファイル容量を確認します。
2. シーン内で実際に表示される大きさに対して、必要以上に解像度が大きい画像がないか見比べます。
3. 軽くしたい画像だけを選び、解像度や圧縮方式を設定します。
4. 「この設定で画像を書き出す」を押して変換を適用します。設定を選んだだけでは変換されないため、必ず書き出しまで進めてください。
5. 編集画面とPlayの両方で、変換前と同じ角度・距離から文字や模様を見比べます。画質が気になる場合は、原本が保持されていれば「元の画像に戻す」で元に戻せます。
6. ほかの画像にもまとめて適用する前に、[容量を調べ、必要な画像だけ軽くする](./course-optimize-world.md)の手順で全体の効果を確認しておくと安心です。

## できたか確認する

- 変換した画像と、元のまま残した画像を区別できました。
- ファイル容量の変化だけでなく、文字や模様の読みやすさも画面上で確かめました。

## うまくいかないとき

- **設定を変えたのに容量が変わらない**：「この設定で画像を書き出す」を押して変換が完了したか確認してください。
- **画質が粗くなった**：「元の画像に戻す」で一度戻し、縮小の幅を控えめにするか、その画像は変換せずに残すことを検討してください。
