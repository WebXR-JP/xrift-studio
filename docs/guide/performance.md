# 容量と描画負荷を減らす

動画で操作を確認する：[テクスチャの解像度と容量を確認する](./lesson-04-09.md)

ファイルの容量は読み込み時間に、描画の負荷は表示の動作に関わります。どちらが問題か確認してから、対象の素材や設定を調整してください。

## 公開前の見積りを見る

「XRiftへ公開」の確認画面では、初回読み込みの容量、回線別の推定時間、素材の内訳、実行時VRAMの目安を見られます。実際の時間や使用量は、端末や利用条件によって変わります。

容量や負荷の大きい順に内訳を確認し、調整する素材を選んでください。上位の素材から見直すと、改善の大きい対象を見つけやすくなります。

## 画像とモデルを調整する

公開前の最適化では、解像度の縮小、KTX2圧縮、Draco圧縮などを個別に選べます。適用後は、変換結果と見積りを確認してから公開画面に戻ってください。

文字が入った画像などは、縮小すると読みにくくなる場合があります。容量と見た目の両方を確認してください。

テクスチャのInspectorで設定を変えたら、「この設定で画像を書き出す」を押して適用します。元画像は残り、変換後の画像が編集と公開に使われます。公開時に自動で縮小・圧縮されることはありません。適用後は、編集画面とPlayで見た目を確かめてください。

## 表示が重いとき

影を出すライト、重なる半透明の面、パーティクルの数や大きさ、Post Processing、表示するモデルの数を見直してください。

設定は一つずつ変え、変更前と同じ位置から比べます。複数の設定を同時に変えると、どの変更で軽くなったか判断しにくくなります。

## 編集画面だけ軽くする

エディターの描画品質を下げると、編集中の負荷を抑えられます。この設定は、公開した作品の品質には影響しません。

軽量表示では影やBloomが省略されます。完成前には、高品質表示とPlayでも確認してください。

## 実際の端末で確かめる

端末が変わると、読み込み時間や動作の重さも変わります。公開後は、利用する端末でも読み込み、操作の反応、見た目を確かめてください。
