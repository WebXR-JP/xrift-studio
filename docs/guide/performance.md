# 容量と描画負荷を減らす

動画で操作を確認する：[テクスチャの解像度と容量を確認する](./lesson-04-09.md)

ファイル容量が大きいと読み込みに時間がかかり、描画負荷が高いと表示が重くなります。まずどちらが原因かを確認してから、対象の素材や設定を調整してください。

## 公開前の見積りを見る

「XRiftへ公開」の確認画面では、初回読み込みの容量、回線別の推定読み込み時間、素材ごとの内訳、実行時VRAMの目安を確認できます。実際の時間や使用量は、端末や通信環境によって変わります。

容量や負荷の大きい素材から順に見直すと、効果的に軽くできます。

## 画像とモデルを調整する

公開前の最適化では、解像度の縮小、KTX2圧縮、Draco圧縮などを素材ごとに選べます。適用したら、変換結果と見積りを確認してから公開画面に戻ってください。

文字が入った画像などは、縮小すると読みにくくなることがあります。容量だけでなく見た目も合わせて確認してください。

テクスチャのInspectorで設定を変えたら、「この設定で画像を書き出す」を押して適用します。元画像はそのまま残り、変換後の画像が編集画面と公開先の両方で使われます。公開時に自動で縮小・圧縮されることはありません。適用後は、編集画面とPlayで見た目を確かめてください。

## 表示が重いとき

動作が重いときは、次の設定を見直してください。

- 影を落とすライトの数
- 重なり合う半透明の面
- パーティクルの数や大きさ
- Post Processingの効果
- 表示するモデルの数

動かない物を照らすライトは、[ライトベイク](./light-bake.md)で「ベイク」にしておくと、実行時の光と影の計算を省けます。

設定は1つずつ変え、変更前と同じ位置から見比べてください。複数の設定を同時に変えると、どの変更が効いたのか判断しにくくなります。

## 編集画面だけ軽くする

エディターの描画品質を下げると、編集中の負荷を抑えられます。この設定は、公開する作品の品質には影響しません。

シーンの「表示 → 描画品質」にある「自動」は、高品質から始まります。重い状態が続くと、描画75%・50%・25%へと段階的に下がります。別の設定から「自動」へ戻すと、高品質から判定をやり直します。

軽量表示では影やBloomが省略されます。完成前には、高品質表示とPlayでも見た目を確認してください。

## 実際の端末で確かめる

端末が変わると、読み込み時間や動作の重さも変わります。公開後は、実際に利用する端末でも読み込み速度、操作の反応、見た目を確かめてください。
