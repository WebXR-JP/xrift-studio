# ライトの明るさと影を調整する

[動画を再生する：ライトの明るさと影を調整する](./media/tutorials/lesson-01-06.mp4)

## このレッスンでできること

一つのライトで明るさと影の違いを確認します。

## 始める前に

- 床とBoxのあるワールドを開きます。
- 表示モードを「シーン」、描画品質を「高品質」にします。

## 操作の要点

1. Hierarchyでライトを選びます。まず種類がDirectional Lightなど、影に対応するものか確認します。
2. Intensityを一つだけ変え、Boxの明るさを比べます。
3. Directional LightやSpot Lightは「照らす方向」を調整し、明るい面が変わるか確かめます。
4. 影を使う場合はcastShadowを有効にします。ライトと床・Boxの位置関係を見ます。
5. 縞や浮いた影がある場合は、shadow.biasとshadow.normalBiasを少しずつ調整します。元の値を控えて比較してください。

## できたか確認する

- 同じ視点でIntensityの変更前後を比較できる。
- 影を使う場合、Boxと床の位置関係が読み取れる影になっている。

## うまくいかないとき

- 影が出ない：軽量表示では省略されます。「シーン」「高品質」とライト側の設定を確認します。
- 金属だけ暗い：ライトを増やす前に、[HDRIとIBL](./lesson-01-08.md)による反射環境を確認します。
