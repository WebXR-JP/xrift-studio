# ライトの明るさと影を調整する

[動画を再生する：ライトの明るさと影を調整する](./media/tutorials/lesson-01-06.mp4)

## このレッスンでできること

一つのライトを使って、明るさ・向き・影の設定で空間の印象がどう変わるかを確かめます。

## 始める前に

- 床と`Box`があるワールドを開きます。
- 影や光の調整が正しく見えるよう、表示モードを「シーン」、描画品質を「高品質」に切り替えておきます。

## 操作の要点

1. Hierarchyでライトを選び、種類が`Directional Light`など影を落とせるライトになっているか確認します。
2. まず`Intensity`だけを変えて、`Box`の明るさがどう変化するか見比べます。
3. `Directional Light`や`Spot Light`では「照らす方向」を調整し、光が当たる面と影の伸び方を確認します。
4. 影を表示したい場合は`castShadow`をオンにし、ライト・`Box`・床の位置関係を見ます。
5. 影に縞模様が出たり影が浮いて見えたりするときは、元の値を控えながら`shadow.bias`と`shadow.normalBias`を少しずつ調整します。

## できたか確認する

- 同じ視点のまま、`Intensity`を変えた前後の明るさを見比べられました。
- 影を有効にしたとき、`Box`と床の位置関係が自然に分かる影になりました。

## うまくいかないとき

- **影が表示されない**：軽量表示では影が省略されます。表示モードを「シーン」、描画品質を「高品質」にしたうえで、ライト側の`castShadow`を確認してください。
- **金属の質感だけ暗く見える**：ライトを増やす前に、[HDRIとIBLの設定](./lesson-01-08.md)で周囲の反射環境を用意すると自然に見えやすくなります。
