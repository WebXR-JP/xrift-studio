# ライトの明るさと影を調整する

[動画を再生する：ライトの明るさと影を調整する](./media/tutorials/lesson-01-06.mp4)

ライトの明るさと影を調整し、空間の見え方を整えます。

## 操作の要点

1. HierarchyでライトのEntityを選びます。
2. Inspectorで位置、向き、Intensityを一つずつ調整します。
3. 影を使う場合はcastShadowを有効にし、見え方を確認します。

## 試すときのポイント

影が見えないときは、表示モードを「シーン」、描画品質を「高品質」にしてください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./lighting.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
