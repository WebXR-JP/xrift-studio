# 画像を貼って、模様の大きさを変える

[動画を再生する：画像を貼って、模様の大きさを変える](./media/tutorials/lesson-02-04.mp4)

画像を貼り、模様の大きさを調整します。

## 操作の要点

1. PNGやJPGをAssetsに取り込みます。
2. マテリアルのBase Color Mapに画像を割り当てます。
3. テクスチャの繰り返し、位置、回転を調整します。

## 試すときのポイント

画像の色にはBase Colorが掛け合わされます。画像の色をそのまま確認する場合は白にしてください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./textures.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
