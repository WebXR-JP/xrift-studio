# 画像を貼って、模様の大きさを変える

[動画を再生する：画像を貼って、模様の大きさを変える](./media/tutorials/lesson-02-04.mp4)

## このレッスンでできること

色の画像を貼り、模様の繰り返し方を調整します。

## 始める前に

- 利用条件を確認したPNGまたはJPGを用意します。
- [マテリアルを作って割り当てる](./lesson-02-03.md)ところまで済ませます。

## 操作の要点

1. 画像をAssetsへ取り込み、マテリアルを選びます。
2. Base Color Mapに画像を指定します。
3. 画像の色をそのまま確かめるため、Base Colorを白にします。
4. テクスチャ設定の繰り返し、位置、回転を一つずつ変え、模様の見え方を比べます。
5. 別の角度から見て、継ぎ目や極端な引き伸ばしがないか確認します。

## できたか確認する

- Base Color Mapに指定した画像が、目的の面に表示される。
- 模様の大きさを変える設定と、Entity自体の大きさを変える設定を区別できる。

## うまくいかないとき

- 画像より暗い・色が違う：Base Colorが画像に掛け合わされるため、白に戻し、照明も確認します。
- 一部だけ伸びる：UVの配置による可能性があります。画像の差し替えだけで直らない場合は、モデル側のUVを確認してください。
