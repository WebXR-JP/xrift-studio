# 画像を貼って、模様の大きさを変える

[動画を再生する：画像を貼って、模様の大きさを変える](./media/tutorials/lesson-02-04.mp4)

## このレッスンでできること

マテリアルに画像を貼り付け、模様の繰り返し回数や位置・向きを調整します。

## 始める前に

- 利用条件を確認したPNGまたはJPG画像を一つ用意します。
- 先に[PBRの色と光沢を調整する](./lesson-02-03.md)を済ませ、マテリアルを割り当てたオブジェクトを用意しておきます。

## 操作の要点

1. 用意した画像をAssetsへ取り込み、対象のオブジェクトに割り当てたマテリアルを選びます。
2. Inspectorの`Base Color Map`に、取り込んだ画像を指定します。
3. 画像本来の色を確認するため、`Base Color`を白にしておきます。
4. テクスチャ設定にある繰り返し・位置・回転の数値を一つずつ変えて、模様の見え方を見比べます。
5. 視点をぐるりと回して別の角度からも見て、継ぎ目のずれや不自然な引き伸ばしがないか確認します。

## できたか確認する

- `Base Color Map`に指定した画像が、狙った面に正しく表示されました。
- テクスチャの繰り返し設定と、Entity自体のサイズ（`Transform`）の違いが分かりました。

## うまくいかないとき

- **元の画像より暗い・色味が違う**：`Base Color`の色が画像に掛け合わされています。`Base Color`を白に戻し、ライトの明るさもあわせて確認してください。
- **一部の面だけ模様が引き伸ばされる**：3Dモデル側のUV設定が原因のことがあります。画像を差し替えても直らない場合は、モデル側のUVを見直してください。
