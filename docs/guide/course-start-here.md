# 制作する環境と保存先を決める

動画：未収録（文章で進められます）

## このレッスンでできること

使う環境を一つ選び、プロジェクト一覧を開きます。作品がどこに保存されるかを確認してから、最初のワールド作りへ進みます。

## 始める前に

- XRiftとXRift Studioの関係や作り方を知りたい場合は、[最初の紹介](./course-introduction.md)を読んでください。
- パソコン、またはSafariを使えるiPadを用意します。
- ブラウザ版の読み込みやデスクトップ版のセットアップには、インターネット接続が必要です。
- すでに制作中の作品がある場合は、保存状態を確認します。新しい練習のために既存の作品やサイトデータを削除する必要はありません。

## 手順

### 1. 今回使う環境を選ぶ

| 環境 | この講座の始め方 | 保存と引き継ぎ |
| --- | --- | --- |
| パソコンのブラウザ版β | インストールせず、配置、色、Playなどを試す | 使用中のブラウザに保存。別の環境へは`.xriftstudio`で渡す |
| デスクトップ版 | アプリをインストールして使う。Scriptを含むワールドやアイテムの公開にも使う | パソコン上のプロジェクトに保存。別端末へは`.xriftstudio`で渡す |
| iPadのSafari | ブラウザ版βをタッチで操作する | そのSafariに保存。区切りごとに`.xriftstudio`を「ファイル」などへ残す |

ブラウザ版βからもワールドを公開できます。ただし、アイテムとScriptを含むワールドの公開、MCPでのAI接続、コードエディターへの書き出しにはデスクトップ版を使います。最初の配置の練習に、XRiftへのログインやAPIキーは必要ありません。

### 2. プロジェクト一覧を開く

**パソコンのブラウザ、またはiPadの場合**

1. [ブラウザのビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開きます。
2. プロジェクト一覧に「新規プロジェクト」と「ファイルから取り込む」があることを確認します。
3. このURLをブックマークしておきます。同じ作品は一つのタブで編集してください。

**デスクトップ版の場合**

1. [インストールの案内](./installation.md)から、使うOSに合う配布ファイルを選びます。「Source code」のZIPはインストーラーではありません。
2. アプリをインストールして起動し、初回画面の「セットアップを開始」を押します。
3. 準備が終わり、プロジェクト一覧が表示されるまで待ちます。

起動時の警告で止まった場合は、[インストールで困ったとき](./installation-problems.md)を確認してください。保護機能を一括で無効にして進めないでください。

### 3. 保存先とバックアップ先を分ける

ブラウザ版の自動保存先は、使用中のブラウザの保存領域です。「ブラウザに保存済み」と表示されても、iCloud Driveやダウンロードフォルダーにファイルができたわけではありません。サイトデータを消すと、そのブラウザの作品も失われます。

デスクトップ版では、パソコンに保存したプロジェクトを一覧から開き直せます。どちらの環境でも、制作の区切りに`.xriftstudio`ファイルを書き出しておくと、変更前の状態や別端末へ渡すデータを残せます。

「作品のバックアップ」など、自分で見つけられる保存先を決めておいてください。書き出しの練習は[保存とバックアップのレッスン](./course-save-backup.md)で行います。エディターのURLだけを渡しても、作品は渡りません。

### 4. iPadならタッチ操作の入口を確認する

iPadでは、Hierarchy、Assets、Inspectorをボタンで切り替えます。シーンは1本指で視点を回し、2本指で視点をずらし、ピンチで近づいたり離れたりできます。上部の「ファイル」からプロジェクトを開いたり書き出したりします。

詳しい操作は[iPadの案内](./ipad.md)で確認できます。マウスやキーボードの操作が書かれたレッスンでは、こちらも参照してください。

## できたか確認する

- 使う環境を選び、プロジェクト一覧を開けた
- 自動保存の場所と、`.xriftstudio`の保存先を区別できる
- 既存の作品を消さず、新しい練習を始める準備ができた

## うまくいかないとき

- **ブラウザを変えたら作品がない**：元の端末・ブラウザで一覧を確認します。自動で端末間同期される前提にはせず、元の環境から`.xriftstudio`を書き出して渡してください
- **別のタブで編集中と表示される**：もう一方のタブで紹介ページへ戻るか、そのタブを閉じてから開き直します
- **セットアップが失敗した**：表示されたエラーを読み、「セットアップを再試行」を使います。既存作品を消すリセット操作は行わず、[復旧の案内](./recovery.md)を確認してください
