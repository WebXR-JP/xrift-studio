# 制作する環境と保存先を決める

動画：未収録（文章で進められます）

## このレッスンでできること

制作に使う環境を一つ選び、プロジェクト一覧を開きます。あわせて、作品がどこに保存されるかを確認してから最初のワールド作りへ進みます。

## 始める前に

- XRiftとXRift Studioの関係や制作方法の全体像を知りたい場合は、先に[XRiftとXRift Studioでできること](./course-introduction.md)を読んでおくとスムーズです。
- パソコン、またはSafariが使えるiPadを用意します。
- ブラウザ版の読み込みやデスクトップ版のセットアップにはインターネット接続が必要です。
- すでに制作中の作品がある場合も、練習用の新しいプロジェクトを作るだけなので、既存の作品やブラウザのデータを消す必要はありません。

## 手順

### 1. 使う環境を選ぶ

| 環境 | このコースでの始め方 | 保存先と引き継ぎ方 |
| --- | --- | --- |
| パソコンのブラウザ版β | インストール不要で、配置・色・Playなどをすぐ試せます | 使っているブラウザの中に保存されます。別環境へは`.xriftstudio`ファイルで渡します |
| デスクトップ版 | アプリをインストールして使います。Scriptを含む作品の公開にも対応しています | パソコン上のプロジェクトとして保存されます。別端末へは`.xriftstudio`ファイルで渡します |
| iPadのSafari | ブラウザ版βをタッチ操作で使えます | そのSafariの中に保存されます。区切りごとに`.xriftstudio`ファイルを「ファイル」などへ残します |

ブラウザ版βからでも、ワールドやアイテムを公開できます。ただし、Scriptを含む作品の公開、MCP接続、コードエディターへの書き出しにはデスクトップ版を使います。最初の配置練習の段階では、XRiftへのログインやAPIキーは必要ありません。

### 2. プロジェクト一覧を開く

#### パソコンのブラウザ、またはiPadの場合

1. [ブラウザのビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開きます。
2. プロジェクト一覧に「新規プロジェクト」と「ファイルから取り込む」があることを確認します。
3. いつでも開き直せるよう、このURLをブックマークしておきます。なお、同じ作品は必ず一つのタブだけで編集してください。

#### デスクトップ版の場合

1. [インストールの案内](./installation.md)から、お使いのOSに合う配布ファイルを選びます（「Source code」のZIPはインストーラーではないのでご注意ください）。
2. アプリをインストールして起動し、初回画面の「セットアップを開始」を押します。
3. 準備が終わり、プロジェクト一覧が表示されるまで待ちます。

起動時にOSの警告が出て進めない場合は、OSのセキュリティ機能を無効にせず、[インストールで困ったとき](./installation-problems.md)の手順に沿って対応してください。

### 3. 自動保存先とバックアップ先を分ける

ブラウザ版の自動保存先は、今使っているブラウザの保存領域です。「ブラウザに保存済み」と表示されていても、iCloud Driveやダウンロードフォルダーにファイルが書き出されたわけではありません。ブラウザのサイトデータを消去すると、保存していた作品も一緒に消えてしまいます。

デスクトップ版では、パソコン上に保存したプロジェクトを一覧から開き直せます。どちらの環境でも、作業の区切りごとに`.xriftstudio`ファイルを書き出しておくと、変更前の状態を残したり別の端末へ渡したりできて安心です。

「作品のバックアップ」など、自分ですぐに見つけられるフォルダーを決めておきましょう。書き出しの手順は[保存して開き直し、バックアップを残す](./course-save-backup.md)で練習します。なお、エディターのURLを共有しても作品データ自体は渡りません。

### 4. iPadの場合はタッチ操作を確認する

iPadでは、Hierarchy・Assets・Inspectorを画面のボタンで切り替えて使います。シーンの視点は、1本指ドラッグで回転、2本指ドラッグで平行移動、ピンチ操作で拡大・縮小ができます。プロジェクトを開いたり書き出したりするときは、上部の「ファイル」を使います。

詳しい操作方法は[iPadの案内](./ipad.md)にまとめています。マウスやキーボードの操作が出てくるレッスンでは、こちらもあわせて参照してください。

## できたか確認する

- 使う環境を一つ選び、プロジェクト一覧を開けました。
- 自動保存される場所と、`.xriftstudio`ファイルで残すバックアップの違いが分かりました。
- 既存の作品を残したまま、新しい練習を始められる状態になりました。

## うまくいかないとき

- **別のブラウザや端末で開いたら作品が見当たらない**：ブラウザ版のデータは自動で端末間に同期されません。元の端末・ブラウザで一覧を開き、`.xriftstudio`ファイルを書き出してから移してください。
- **「別のタブで編集中」と表示される**：もう一方のタブで一覧へ戻るか、そのタブを閉じてから開き直してください。
- **セットアップに失敗した**：表示されたエラーメッセージを確認し、「セットアップを再試行」を試します。既存の作品を消すリセット操作はすぐに行わず、[復旧の案内](./recovery.md)を確認してください。
