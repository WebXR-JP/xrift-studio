# GLSLでマテリアルを編集する

色や質感をコードで作るには、マテリアルのカスタムシェーダーを使います。MToonの陰影や輪郭線を使う場合は、[マテリアルの種類からMToonを選ぶ](./materials.md#mtoonマンガのような陰影と輪郭線を付ける)手順を参照してください。

## カスタムシェーダーを作る

Assetsでマテリアルを選び、「Inspector → カスタムシェーダー」を開いてください。スマートフォンでは、この項目を開くために折りたたみを展開します。「カスタムシェーダーを作成」を押すと、コードを編集できます。

「シェーダーコード」で、「頂点シェーダー GLSL」か「フラグメントシェーダー GLSL」の「編集」を押してください。頂点シェーダーは頂点の位置などを、フラグメントシェーダーは描画する色などを扱います。最初は生成されたコードを少しずつ変え、プレビューで結果を確かめてください。

## 編集と保存を確認する

GLSLエディターの変更は自動保存されます。表示が「保存待ち → 自動保存中 → 保存済み」と変わることを確認してください。保存に失敗した場合は、「自動保存を再試行」を押します。

保存した変更は、同じマテリアルを使うすべての場所に反映されます。一つのEntityだけを変える場合は、先にマテリアルを分けてください。画像やuniformの値は、Inspectorで確認できます。

## uniformの種類と入力

Inspectorの「シェーダーの調整値」には、シェーダーが持つuniformが並びます。数値、色、ベクトル、テクスチャのほかに、次の種類を編集できます。uniformの追加や種類の変更は、AIクライアントの`update_custom_shader`で行います。

| 表示 | GLSLの宣言 | 入力する内容 |
|---|---|---|
| mat3、mat4 | `mat3`、`mat4` | 9個か16個の数値。列ごとに、カンマで区切って並べます |
| 12個の数値など | `float`、`vec2`〜`vec4`、`mat3`、`mat4`の配列 | 1〜4096個の数値。`vec3 uPoints[4]`には12個を並べます |
| 3Dテクスチャ | `sampler3D` | スライスを左から右へ並べた画像と、「スライス数」 |
| キューブマップ | `samplerCube` | +X、-X、+Y、-Y、+Z、-Zの各面に使う6枚の画像 |

3Dテクスチャには、高さがスライスの一辺、幅が「一辺 × スライス数」の画像を使います。「スライス数」が空欄のときは、正方形のスライスが並んでいるものとして数えます。一辺とスライス数は256までです。GLSLでは、スライス内の横がx、縦がy（画像の上端が0）、スライスの番号がzになります。

キューブマップの6枚は、同じ大きさの正方形にしてください。3Dテクスチャとキューブマップには、PNGやJPEGなどの8bitの画像を選びます。KTX2へ圧縮したテクスチャとEXRは選べません。

`sampler2D`のテクスチャにはEXRも選べます。EXRは浮動小数のまま渡るため、1を超える値や、位置などの数値を読めます。精度はファイルに合わせ、16bitか32bitになります。32bitの値をなめらかに補間できない端末があります。数値の表として読むEXRは16bitで保存するか、`update_custom_shader`で`filter`を`nearest`にしてください。HDR（.hdr）は選べません。

## 合成とカリングを設定する

Inspectorの「描画設定」では、バリアントごとに描き方を選べます。バリアントは、Meshの名前に応じて切り替える設定の組です。

| 項目 | 効果 |
|---|---|
| Blending | すでに描かれている色への重ね方です。Normal（通常）、Additive（加算）、Multiply（乗算）、Subtractive（減算）から選びます |
| Transparent | 不透明なものを描いた後に、奥から順に描きます。Normal以外のBlendingでは有効にしてください |
| Depth Write | 深度を書き込みます。光や煙のように重ねて見せるものでは切ります |
| Frustum Culling | 画面の外にあるMeshの描画を省きます。頂点シェーダーでMeshを別の場所へ動かす場合は切ってください |

Frustum Cullingを切ったマテリアルを割り当てたMeshは、画面の外にあっても描かれます。別のマテリアルへ替えると、Meshは元の設定に戻ります。数が多いMeshで切ると描画の負荷が増えるため、必要なマテリアルだけで切ってください。

## モデルの属性を読む

頂点シェーダーでは、割り当て先のメッシュが持つ属性を`attribute`で宣言して読めます。GLBの独自属性は、小文字の名前で宣言してください。たとえば`_AMAT`は`attribute float _amat;`と書きます。

同じ形を並べたGLB（`EXT_mesh_gpu_instancing`）では、インスタンスごとの独自属性も同じ書き方で読めます。値は頂点ごとではなく、インスタンスごとに1つ届きます。各インスタンスの位置には`instanceMatrix`を使います。

```glsl
attribute vec3 _aoffset;

void main() {
  vec4 local = vec4(position + _aoffset, 1.0);
  #ifdef USE_INSTANCING
    local = instanceMatrix * local;
  #endif
  gl_Position = projectionMatrix * modelViewMatrix * local;
}
```

値はGLBから読み込みます。外部のファイルを参照する`.gltf`は取り込み時にGLBへ変換されるため、インスタンスごとの独自属性は残りません。必要なデータを含むGLBを取り込んでください。

## PBRへ戻す

「PBRへ戻す」を押すと、カスタムシェーダーの割り当てが解除されます。コードを編集する前に[プロジェクトをバックアップ](./save-and-open.md#バックアップする)しておくと、変更前後の状態を比較できます。

空や水の見本を使う場合は、[Skybox Shaderと水の使い方](./sky-and-water.md)を参照してください。カスタムGLSL、MToon、標準のPBRマテリアルでは、それぞれ描画方式が異なります。
