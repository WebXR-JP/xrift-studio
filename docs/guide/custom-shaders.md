# GLSLでマテリアルを編集する

色や質感をコードで作る場合は、マテリアルの**カスタムシェーダー**を使います。MToonの陰影や輪郭線を使いたい場合は、[マテリアルの種類からMToonを選ぶ](./materials.md#mtoonマンガのような陰影と輪郭線を付ける)手順を参照してください。

## カスタムシェーダーを作る

1. **Assets**で編集するマテリアルを選びます。
2. **Inspector → カスタムシェーダー**を開きます。スマートフォンでは折りたたまれた項目を開きます。
3. **カスタムシェーダーを作成**を押します。
4. **シェーダーコード**にある**頂点シェーダー GLSL**または**フラグメントシェーダー GLSL**の**編集**を押します。

頂点シェーダーは頂点の位置などを、フラグメントシェーダーは描画する色などを扱います。最初は生成されたコードを少しずつ変更して、プレビューで結果を確認してください。

## 編集と保存を確認する

GLSLエディターでは、変更後に自動保存されます。**保存待ち → 自動保存中 → 保存済み**の状態を確認してください。保存に失敗した場合は**自動保存を再試行**を押します。

保存すると、そのマテリアルを使うすべての場所に反映します。一つの物だけを変えたい場合は、先にマテリアルを分けてください。使用している画像やuniformの値もInspectorで確認します。

## PBRへ戻す

カスタムシェーダーの**PBRへ戻す**で、カスタムシェーダーの割り当てを解除します。コードを調整する前に[プロジェクトのバックアップ](./save-and-open.md#バックアップする)を残すと、試した状態を比較できます。

空や水に用意された見本から始める場合は、[Skybox Shaderと水の使い方](./sky-and-water.md)を参照してください。独自のGLSLとMToon、標準のPBRマテリアルは、それぞれ異なる描画方式です。
