# GLSLでマテリアルを編集する

色や質感をコードで作るには、マテリアルのカスタムシェーダーを使います。MToonの陰影や輪郭線を使う場合は、[マテリアルの種類からMToonを選ぶ](./materials.md#mtoonマンガのような陰影と輪郭線を付ける)手順を参照してください。

## カスタムシェーダーを作る

Assetsでマテリアルを選び、「Inspector → カスタムシェーダー」を開いてください。スマートフォンでは、この項目を開くために折りたたみを展開します。「カスタムシェーダーを作成」を押すと、コードを編集できます。

「シェーダーコード」で、「頂点シェーダー GLSL」か「フラグメントシェーダー GLSL」の「編集」を押してください。頂点シェーダーは頂点の位置などを、フラグメントシェーダーは描画する色などを扱います。最初は生成されたコードを少しずつ変え、プレビューで結果を確かめてください。

## 編集と保存を確認する

GLSLエディターの変更は自動保存されます。表示が「保存待ち → 自動保存中 → 保存済み」と変わることを確認してください。保存に失敗した場合は、「自動保存を再試行」を押します。

保存した変更は、同じマテリアルを使うすべての場所に反映されます。一つのEntityだけを変える場合は、先にマテリアルを分けてください。画像やuniformの値は、Inspectorで確認できます。

## PBRへ戻す

「PBRへ戻す」を押すと、カスタムシェーダーの割り当てが解除されます。コードを編集する前に[プロジェクトをバックアップ](./save-and-open.md#バックアップする)しておくと、変更前後の状態を比較できます。

空や水の見本を使う場合は、[Skybox Shaderと水の使い方](./sky-and-water.md)を参照してください。カスタムGLSL、MToon、標準のPBRマテリアルでは、それぞれ描画方式が異なります。
