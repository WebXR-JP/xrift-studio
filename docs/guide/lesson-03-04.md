# テンプレートでBoxを回転させる

[動画を再生する：テンプレートでBoxを回転させる](./media/tutorials/lesson-03-04.mp4)

テンプレートを使い、Boxを回転させます。

## 操作の要点

1. スクリプトのテンプレートから「回転」を選びます。
2. 回転させたいBoxに取り付け、回転軸と回転速度を確認します。
3. Playで回転を確認し、Stopで編集に戻ります。

## 試すときのポイント

「回転」テンプレートはスクリプトです。Node Graphとは設定方法が異なるため、動画で取り付け先を確認してください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./interactivity.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
