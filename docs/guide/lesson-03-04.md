# テンプレートでBoxを回転させる

[動画を再生する：テンプレートでBoxを回転させる](./media/tutorials/lesson-03-04.mp4)

## このレッスンでできること

スクリプトの「回転」テンプレートを使って`Box`を回し続け、回転する速さや軸の向きを調整します。

## 始める前に

- 回転させたい`Box`を用意し、Hierarchyで選んでおきます。
- これはスクリプトの追加練習です。ブラウザ版βからそのまま公開したい場合は、まずはNode Graphだけのワールドで進めても構いません。スクリプトを含むワールドの公開にはデスクトップ版を使います。

## 操作の要点

1. Assetsパネルを右クリックし、「新規スクリプト」を選びます。
2. テンプレート一覧から「回転」を選び、スクリプト名と保存先を確認します。
3. 選択中の`Box`にスクリプトComponentを自動で追加する項目がオンになっていることを確認し、「作成して開く」を押します。
4. `Box`のInspectorで、回転速度と回転軸の項目を確認します（初期設定では軸が`X: 0 / Y: 1 / Z: 0`、速度が`1`です）。
5. Playを押して`Box`が回る様子を確認します。Stopで編集画面に戻り、速度を変えてもう一度試してみてください。
6. 動きを止めたいときは速度を`0`にします。スクリプト付きワールドを公開したいときは、[XRiftへ公開する](./publishing.md)のデスクトップ版手順へ進みます。

## できたか確認する

- Play中に`Box`が回転し、Inspectorで速度を変えると回る速さも変わりました。
- スクリプトを作っただけでなく、対象の`Box`に正しく取り付いています。

## うまくいかないとき

- **まったく回転しない**：回転速度が`0`になっていないか、回転軸がすべて`0`になっていないか確認してください。
- **ブラウザ版βから公開できない**：スクリプトを含むワールドは`.xriftstudio`ファイルに書き出し、デスクトップ版で開いてから公開してください。
