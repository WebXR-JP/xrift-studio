# テンプレートでBoxを回転させる

[動画を再生する：テンプレートでBoxを回転させる](./media/tutorials/lesson-03-04.mp4)

## このレッスンでできること

「回転」テンプレートでBoxを回転させ、速度と軸を調整します。

## 始める前に

- Boxを用意し、Hierarchyで選びます。
- これはスクリプトの追加教材です。ブラウザ版βから公開したい人は、先にNode Graphだけのワールドで進めても構いません。スクリプトを含むワールドの公開にはデスクトップ版を使います。

## 操作の要点

1. Assetsの右クリックメニューで「新規スクリプト」を選びます。
2. テンプレートの「回転」を選び、名前と保存先を確認します。
3. 選択中のBoxへスクリプトComponentを追加する項目を確認し、「作成して開く」を押します。
4. BoxのInspectorで回転速度と回転軸を確認します。初期の軸はX:0 / Y:1 / Z:0、速度は1です。
5. Playで回転を確認します。Stopで戻り、速度を変えてもう一度試します。
6. 動作を止めたい場合は速度0を試します。公開するときは[デスクトップ版の手順](./publishing.md)へ進みます。

## できたか確認する

- PlayでBoxが回転し、速度を変えると回る速さが変わる。
- スクリプトを作成しただけでなく、目的のBoxに取り付いている。

## うまくいかないとき

- 動かない：回転速度が0、回転軸がすべて0になっていないか確認します。
- ブラウザ版から公開できない：スクリプトを含むワールドは.xriftstudioで書き出し、デスクトップ版から公開します。
