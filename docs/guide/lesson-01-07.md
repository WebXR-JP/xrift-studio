# Skybox Shaderで青空を作る

[動画を再生する：Skybox Shaderで青空を作る](./media/tutorials/lesson-01-07.mp4)

Skybox Shaderを使い、空間の背景に青空を作ります。

## 操作の要点

1. シーン設定からSkyboxの設定を開きます。
2. Skybox Shaderを背景に指定します。
3. 空の色や動きの設定を変え、シーン全体の見え方を確認します。

## 試すときのポイント

Skybox Shaderは背景の表現です。物を照らすライトやIBLは別に設定します。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./sky-and-water.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
