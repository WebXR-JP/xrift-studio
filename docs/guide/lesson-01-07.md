# Skybox Shaderで青空を作る

[動画を再生する：Skybox Shaderで青空を作る](./media/tutorials/lesson-01-07.mp4)

## このレッスンでできること

`Skybox Shader`をシーンの背景に設定し、空の色を一か所調整してみます。

## 始める前に

- 練習用のワールドを開き、Play中ならStopで編集画面へ戻ります。
- 背景が表示されるよう、表示モードを「シーン」にしておきます。

## 操作の要点

1. 「Assets → 外部から追加 → Skybox Shader」を開き、用意されている空のプリセットを見比べます。
2. 「追加後にSkyboxへ設定」をオンにして追加し、シーンの背景が切り替わったか確認します。
3. Assetsに追加されたマテリアルを選びます。
4. Inspectorの「調整できる値」で、空の色など一つの項目だけを変えてみます（表示される項目はプリセットによって異なります）。
5. 変化を見比べたあと、元に戻したいときは「既定値へ戻す」を使えます。気に入った設定を残したいときは、戻す前に保存やバックアップを済ませておきましょう。

## できたか確認する

- 物体に貼られた画像ではなく、シーン全体の背景として空が表示されました。
- 選んだプリセットの調整場所が分かり、色を変えたり元に戻したりできました。

## うまくいかないとき

- **Assetsに素材が増えただけで空が変わらない**：カタログの「Skyboxに設定」を押すか、シーン設定のSkybox欄から割り当ててください。
- **空は明るいのに置いた物が暗い**：背景の見た目と照明は別の設定です。ライトやIBLを別で調整してください。
