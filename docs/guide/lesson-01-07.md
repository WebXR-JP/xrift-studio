# Skybox Shaderで青空を作る

[動画を再生する：Skybox Shaderで青空を作る](./media/tutorials/lesson-01-07.mp4)

## このレッスンでできること

Skybox Shaderを背景へ割り当て、空の色を一か所変えます。

## 始める前に

- 練習用ワールドを開き、Stopで編集へ戻ります。
- 表示モードを「シーン」にします。

## 操作の要点

1. 「Assets → 外部から追加 → Skybox Shader」で、プリセットの見本を確認します。
2. 「追加後にSkyboxへ設定」を有効にして追加します。背景が変わったか見ます。
3. Assetsで追加されたマテリアルを選びます。
4. Inspectorの「調整できる値」で、色など一つの値だけを変えます。項目はプリセットごとに異なります。
5. 背景を確認し、必要なら「既定値へ戻す」で比べます。今の設定を残すときは先に保存・バックアップしてください。

## できたか確認する

- 画像や物体の面ではなく、シーンの背景に空が表示される。
- 変更した値を戻せ、選んだプリセットの調整場所が分かる。

## うまくいかないとき

- 素材だけ増えて空が変わらない：カタログの「Skyboxに設定」かシーン設定で割り当てます。
- 空は明るいのに物が暗い：背景とは別にライトやIBLを設定します。Shaderの追加だけでは照明は用意されません。
