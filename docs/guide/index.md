# XRift Studio 使い方ガイド

XRiftは、ブラウザでワールドに入り、人と交流できるサービスです。XRift Studioでは、そのXRiftで使うワールドやアイテムを作れます。このガイドでは、画面で素材を配置するところから、動きの追加や公開までを説明します。

初めての方は、[XRiftとXRift Studioでできること](./course-introduction.md)から読んでください。二つの関係と、Node Graphやコードで何を作れるかを紹介しています。

## 制作から公開まで学ぶ

[制作から公開までのコース](./learning-course.md)では、XRiftと作り方の紹介、準備、保存、素材、仕掛け、テスト、公開、更新、招待を順番に進められます。動画と文章を使い、各レッスンでできたかを確かめながら学びます。

## 動画を見ながら試す

[動画で学ぶ XRift Studio](./video-tutorials.md)では、1本約1分の教材を4つの章にまとめています。配置、質感、仕掛け、仕上げを、動画と短い操作の要点で確認できます。

## はじめて使う

まだアプリを入れていない方は、[インストール](./installation.md)から始めてください。起動できたら、[最初のワールドを作る](./first-world.md)へ進んでください。

インストールせずに使う場合は、[ブラウザのビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開いてください。iPadでの操作は、[iPadで作り、パソコンへ引き継ぐ](./ipad.md)で説明します。ブラウザ版βからのワールド公開と、`.xriftstudio`ファイルをMacやWindowsへ渡して公開する方法は、[公開の手順](./publishing.md)を参照してください。

デスクトップ版では、初回セットアップを済ませると制作を始められます。XRiftへのログインとAI接続はあとから設定できます。まずは素材を置き、色を変え、自動保存を確認してからPlayで見て回ってください。

## 操作を調べる

各パネルの使い方は[画面の見方](./editor-basics.md)、英語の項目名の意味は[用語集](./glossary.md)で確認できます。検索には、画面の項目名や「床をすり抜ける」のような症状を入力してください。

## このガイドの対象

基本の制作手順はデスクトップ版を対象にしています。iPadでのタッチ操作や保存方法は、[iPadの案内](./ipad.md)を参照してください。スマートフォンでも、パネルを切り替えながら配置や質感を編集できます。ブラウザに保存した作品をファイルとして手元に残すには書き出し、XRiftで遊べるようにするには公開の操作が必要です。

アプリの開発に必要なビルド、デプロイ、APIの説明は、GitHubの開発文書にあります。

## 作ったものを別のプロジェクトでも使う

家具やギミックなど、Hierarchyで選んだ部分を`.xriftstudio`ファイルに書き出せます。別の作品へ取り込む手順は、[Entityを別のワールド・アイテムへ渡す](./hierarchy-transfer.md)を参照してください。
