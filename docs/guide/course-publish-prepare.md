# 公開前のバックアップと作品情報を整える

動画：未収録（文章で進められます）

## このレッスンでできること

制作データを手元に残し、ワールド名・説明・サムネイルと、公開に使う環境を決めます。このページではまだXRiftへ送信しません。

## 始める前に

- 編集できるワールドのプロジェクトを開いてください
- [Playでの確認](./play-mode.md)を済ませ、開始位置から歩けること、床をすり抜けないこと、仕掛けを操作できることを確かめてください
- 使用したモデル・画像・音声を、ワールドで公開してよいか確認してください。必要な作者名やライセンス表記も準備します

## 手順

### 1. 保存できたことを確かめる

1. Playを実行している場合は、Stopで編集へ戻ります。
2. デスクトップ版では「保存済み」、ブラウザ版では「ブラウザに保存済み」の表示を確認します。
3. 保存エラーが出ている場合は、編集画面を閉じずに原因を確認します。先に[保存と復旧](./save-and-open.md)を進めてください。

ブラウザへの保存は、そのブラウザの保存領域に作品がある状態です。ダウンロードしたファイルとは別なので、次の手順でバックアップを残します。

### 2. プロジェクトを書き出す

#### デスクトップ版

1. 「プロジェクト一覧」へ戻り、作品のカードを確認します。
2. カードの「.xriftstudioファイルに書き出す」を使い、保存先を選びます。
3. 保存先でファイル名と更新日時を確認します。制作日が分かる名前で残すと、後から探しやすくなります。

#### ブラウザ版

1. パソコンのブラウザでは上部の「プロジェクトを書き出す」、iPadなどのタッチ向け画面では「ファイル → プロジェクトを書き出す」を開きます。
2. 準備が終わったら、ファイル名と容量を見て「ダウンロード」を押します。
3. ブラウザのダウンロード一覧で、保存できたことと保存先を確認します。

書き出したファイルには、シーンや取り込んだ素材が含まれます。複製やファイルからの取り込みで作ったプロジェクトは、別の未公開プロジェクトになります。公開済みワールドの更新には、元のプロジェクトを使ってください。

### 3. ワールド名と説明を入力する

1. 編集画面の「シーン設定」を開き、「公開情報」を探します。
2. 「ワールド名」に、作品の名前を入力します。タイトルの上限は120文字です。
3. 「説明」に、何ができる場所なのか、どこから始めるのかを書きます。説明の上限は1,000文字です。
4. テンプレートの名前や説明が残っていないか読み直します。

例として、ワールド名を「はじめての展示室」、説明を「入口から順に、3つの展示を見て回れます。青いボタンを押すと、展示台の色が変わります。」とすると、訪れた人が最初の行動を選べます。作品にない機能や、未確認の対応端末は書かないでください。

デスクトップ版では、公開の確認画面にある「タイトル」「説明」からも編集できます。どちらの環境でも、公開時には両方の入力が必要です。

### 4. サムネイルを用意する

1. 作品の特徴が見える位置へ視点を動かします。
2. 「XRiftへ公開」で確認画面を開きます。この段階では送信されません。
3. デスクトップ版は「現在のワールドから作成」、ブラウザ版は「シーンから撮影」を使います。手元の画像を使う場合は、デスクトップ版の「画像を選択」、ブラウザ版の「画像を選ぶ」または「画像を変更」を使ってください。
4. プレビューで、作品が写っているか、暗すぎないか、個人情報が含まれていないかを確認します。

デスクトップ版ではサムネイルが公開条件です。ブラウザ版βは未設定でも送信できますが、作品を見分けられる画像を用意しておきましょう。

### 5. 公開に使う環境を決める

- デスクトップ版：ワールドやアイテムを公開できます。未準備の場合は、アプリが案内する公開用セットアップを進めます
- ブラウザ版β：スクリプトを含まないワールドを直接送信できます。`write:worlds`権限を持つAPIキーが必要です
- アイテム、スクリプトを含むワールド、必要なAPIキーを使えない場合：`.xriftstudio`ファイルをパソコンへ渡し、デスクトップ版から公開します

端末を移す場合は、初回の公開前に移しておくと、以後の更新元を一つにできます。具体的な受け渡しは[iPadで作り、パソコンへ引き継ぐ](./ipad.md)を参照してください。

## できたか確認する

- バックアップファイルを保存した場所が分かる
- ワールド名・説明・サムネイルが自分の作品に合っている
- 公開する素材の利用条件を確認した
- ブラウザ版かデスクトップ版か、公開に使う環境が決まった

## うまくいかないとき

- 書き出しが失敗する：編集画面を閉じずにエラーを読みます。ブラウザ版で扱える容量を超える場合は、[iPadの案内](./ipad.md#プロジェクトを保存してパソコンへ渡す)を確認してください
- 画像が古い：現在のシーンから撮影し直し、公開画面のプレビューを確認します
- 容量が大きい：[容量と描画負荷](./performance.md)に沿って素材を調整し、見た目をPlayで確かめます。公開時の自動縮小には頼らないでください
