# 公開前のバックアップと作品情報を整える

動画：未収録（文章で進められます）

## このレッスンでできること

公開前に制作データのバックアップを手元へ残し、ワールド名・説明・サムネイルと、公開に使う環境を決めます。このレッスンではまだXRiftへ送信しません。

## 始める前に

- 公開したいワールドのプロジェクトを開いておきます。
- [Playでの確認](./play-mode.md)を済ませ、開始位置から歩けること、床をすり抜けないこと、仕掛けが動くことを確かめておきます。
- 作品に使ったモデル・画像・音声を公開してよいか利用条件を確認し、必要な作者名やクレジット表記も準備しておきます。

## 手順

### 1. 保存が完了しているか確かめる

1. Play中であれば、Stopを押して編集画面へ戻ります。
2. 画面上部の表示が、デスクトップ版では「保存済み」、ブラウザ版では「ブラウザに保存済み」になっていることを確認します。
3. 「保存エラー」が出ている場合は、画面を閉じずに原因を確認し、先に[保存して制作を再開する](./save-and-open.md)の手順で解消してください。

ブラウザへの保存は使用中のブラウザ内にデータが置かれている状態なので、手元にファイルを残すため、次の手順でバックアップを書き出しておきます。

### 2. プロジェクトを書き出してバックアップする

#### デスクトップ版

1. 「プロジェクト一覧」へ戻り、対象の作品カードを確認します。
2. カードの「.xriftstudioファイルに書き出す」を選び、保存先を指定します。
3. 保存したフォルダーを開き、ファイル名と更新日時を確認します。日付を入れた名前にしておくと、あとから見つけやすくなります。

#### ブラウザ版

1. パソコンでは上部の「プロジェクトを書き出す」、iPadなどのタッチ画面では「ファイル → プロジェクトを書き出す」を開きます。
2. 準備が終わったら、ファイル名と容量を確認して「ダウンロード」を押します。
3. ブラウザのダウンロード一覧で、保存完了と保存先を確認します。

書き出したファイルには、シーンや取り込んだ素材がまとめて入っています。なお、複製やファイルからの取り込みで作ったプロジェクトは別の未公開プロジェクトとして扱われるため、公開済みワールドを更新したいときは必ず元のプロジェクトを使ってください。

### 3. ワールド名と説明を入力する

1. 編集画面の「シーン設定」を開き、「公開情報」を確認します。
2. 「ワールド名」に作品の名前を入力します（上限120文字）。
3. 「説明」に、何ができる場所なのかや最初に見るポイントを書きます（上限1,000文字）。
4. テンプレートの仮の名前や説明がそのまま残っていないか読み直します。

たとえば、ワールド名を「はじめての展示室」、説明を「入口から順に3つの展示を見て回れます。青いボタンを押すと、展示台の色が変わります。」のように書いておくと、訪れた人が最初の行動をイメージしやすくなります。実際に動く機能や、動作確認できた端末に合わせて記載しておくと親切です。

デスクトップ版では、公開の確認画面にある「タイトル」「説明」からも編集できます。どちらの環境でも、公開するには両方の入力が必要です。

### 4. サムネイルを用意する

1. 作品の雰囲気が伝わりやすい位置へ視点を動かします。
2. 「XRiftへ公開」を押して確認画面を開きます（この時点ではまだ送信されません）。
3. デスクトップ版は「現在のワールドから作成」、ブラウザ版は「シーンから撮影」を押します。手元の画像を使いたい場合は、デスクトップ版の「画像を選択」、ブラウザ版の「画像を選ぶ」または「画像を変更」を使ってください。
4. プレビューを見て、作品がはっきり写っているか、暗すぎないか、個人情報などが映り込んでいないかを確認します。

デスクトップ版ではサムネイルの設定が必須です。ブラウザ版βでは未設定のまま送信できますが、一覧で見分けやすいよう画像を用意しておくのがおすすめです。

### 5. 公開に使う環境を決める

- **デスクトップ版**：ワールドもアイテムも公開できます。公開用の準備がまだの場合は、アプリの案内に沿ってセットアップを進めます。
- **ブラウザ版β**：スクリプトを含まないワールドをそのまま送信できます（`write:worlds`権限のあるAPIキーが必要です）。
- **スクリプトを含む作品や、必要なAPIキーを用意できない場合**：`.xriftstudio`ファイルをパソコンへ移し、デスクトップ版から公開します。

別の端末へ移す予定があるなら、初回公開の前に移しておくと、今後の更新も一つのプロジェクトで管理できて便利です。受け渡しの手順は[iPadで作り、パソコンへ引き継ぐ](./ipad.md)をご覧ください。

## できたか確認する

- バックアップファイル（`.xriftstudio`）の保存先を把握できました。
- ワールド名・説明・サムネイルが自分の作品に合っていることを確認しました。
- 使用している素材の利用条件を確認できました。
- ブラウザ版とデスクトップ版のどちらから公開するか決まりました。

## うまくいかないとき

- **書き出しに失敗する**：編集画面を閉じずにエラー内容を確認してください。ブラウザ版で扱える容量を超える場合は、[iPadの案内](./ipad.md#プロジェクトを保存してパソコンへ渡す)も確認します。
- **サムネイルが古いまま**：現在のシーンから撮影し直し、公開画面のプレビューに反映されたか確認してください。
- **容量が大きすぎる**：[容量と描画負荷を減らす](./performance.md)を参考に素材を調整し、見た目をPlayで確かめてください。公開時に画像が自動で縮小されることはないため、あらかじめ手元で調整しておきます。
