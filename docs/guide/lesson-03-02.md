# Delayで待ってから動かす

[動画を再生する：Delayで待ってから動かす](./media/tutorials/lesson-03-02.mp4)

Delayを使い、動き始めるまでの待ち時間を加えます。

## 操作の要点

1. 処理の途中にSet Delayを入れます。
2. 待機後に行いたい処理をDoneへつなぎます。
3. Playで、開始直後と待機後の動きを見比べます。

## 試すときのポイント

Outは待機を始めた直後に進みます。時間が経ってから動かす処理はDoneにつないでください。
