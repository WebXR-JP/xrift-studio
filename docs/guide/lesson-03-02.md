# Delayで待ってから動かす

[動画を再生する：Delayで待ってから動かす](./media/tutorials/lesson-03-02.mp4)

## このレッスンでできること

`Set Delay`を使って、きっかけが起きてから2秒待ったあとに`Box`が動き始める仕掛けを作ります。

## 始める前に

- `On Start`または`On Interact`から`Box`を動かすNode Graphを用意しておきます。
- まだの場合は、先に[ノードをつないで箱を動かす](./lesson-03-00.md)で基本のつなぎ方を確認しておくとスムーズです。

## 操作の要点

1. グラフ編集画面で`Set Delay`ノードを追加します。
2. きっかけ（`On Start`や`On Interact`）から`Set Property`へ直接つながっていた線を外し、きっかけの`Out`を`Set Delay`の`In`につなぎます。
3. `Set Delay`を選び、待機時間を`2`秒に設定します。
4. `Set Delay`の`Done`から`Set Property`の`In`へつなぎます（`Out`は待機を始めた直後に進むため、待ってから動かしたいときは必ず`Done`を使います）。
5. 保存してPlayを押し、きっかけの直後は動かず、2秒待ってから動き始めることを確認します。
6. `Set Delay`の待機時間と、`Set Property`の`Duration (s)`（動き始めてから終わるまでの時間）をそれぞれ変えて、違いを体感してみてください。

## できたか確認する

- 動き始めるまでの待機時間（2秒）と、移動にかかる時間（`Duration (s)`）の違いが分かりました。
- 待機後に動かしたい処理が、`Set Delay`の`Done`からつながっています。

## うまくいかないとき

- **待たずにすぐ動いてしまう**：`Set Delay`の`Out`につないでいないか、元の直結した線が残っていないか確認してください。
- **2秒待っても動かない**：`Done`から`Set Property`の`In`への接続、Node Graphの取り付け先、`Set Property`のTargetを見直してみてください。
