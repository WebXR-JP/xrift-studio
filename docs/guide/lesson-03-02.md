# Delayで待ってから動かす

[動画を再生する：Delayで待ってから動かす](./media/tutorials/lesson-03-02.mp4)

## このレッスンでできること

きっかけのあと2秒待ち、それからBoxを動かします。

## 始める前に

- On StartまたはOn Interactから動くグラフを用意します。
- [Node Graphの基本](./lesson-03-00.md)で、対象と処理の接続が動くことを先に確認します。

## 操作の要点

1. グラフにSet Delayを追加します。
2. 元のきっかけからSet Propertyへの接続を外し、きっかけのOutをSet DelayのInへつなぎます。
3. Set Delayを選び、待機時間を2秒にします。
4. Set DelayのDoneを、Set PropertyのInへつなぎます。Outは待機を始めた直後に進むため、今回は使いません。
5. 保存してPlayし、きっかけの直後には動かず、待ってから動き始めるか確認します。
6. 待機時間と、Set PropertyのDuration (s)による移動時間を別々に変えて比べます。

## できたか確認する

- 待機の2秒と、動き始めてからの移動時間を区別できる。
- 待機後の処理がDoneからつながっている。

## うまくいかないとき

- すぐ動く：Set DelayのOutや、元の直結した線が残っていないか確認します。
- 待っても動かない：DoneからInへの線、グラフの取り付け、Set Propertyの対象を確認します。
