# 地形と草を作る

地形を使うと、山や島のような起伏を作れます。室内や平らな床だけでよい場合は、追加する必要はありません。

始める前に保存状態を確認し、Play中ならStopで編集へ戻ってください。

## 地形を追加する

平らな地面から作るには、上部の「素材を追加 → Entityを作成 → World → Terrain → 平らなTerrain」を選んでください。形の見本を使うには、「Assets → 外部から追加 → 地形」でプリセットを選び、シーンに追加します。

草が含まれるプリセットもあります。先に地面の広さと形を決め、あとから草の量を調整してください。

## 地面の形を変える

Hierarchyで地形を選び、Inspectorでブラシを選んでください。小さい半径と弱い強さから、少しずつ塗ります。「盛り上げる」で丘を作り、「掘る」で低くできます。急な段差は、「滑らかにする」で整えてください。

平らにするには、高さを設定するブラシを使います。「穴を開ける」では、地面に実際の穴ができるため、歩く場所に注意してください。大きく変える前に保存し、意図しない変更は元に戻します。

## 草を生やす・消す

地形の草の設定で層や草のセットを選び、草用のブラシで範囲を塗ってください。道や入口の草を減らすと、歩く場所を見分けやすくなります。

草用のブラシでは、地面の高さは変わりません。高さを変えるブラシと切り替えて使ってください。草の揺れは、シーン設定の風で調整できます。

## 歩いて確認する

Playで丘、入口、穴の周りを歩き、すり抜けや転落がないか確認してください。開始位置は地面の上に置きます。[Colliderと開始位置](./collision.md)も参照してください。

草を増やす前後で、動作の重さを比べてください。密度や地形の細かさに加え、見える範囲に絞る方法もあります。公開前に[容量と描画負荷](./performance.md)を確認してください。
