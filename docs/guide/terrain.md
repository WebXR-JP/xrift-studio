# 地形と草を作る

山や島など、地面に起伏が必要なときに使います。室内や平らな床だけのワールドでは、地形を追加する必要はありません。

**始める前に：** 保存し、Play中なら**Stop**で編集に戻ります。

## 地形を追加する

平らな状態から作る場合は、**追加 → 地形**を選びます。形が入ったものから始める場合は、**Assets → 外部から追加 → 地形**でプリセットを選び、シーンへ追加します。

プリセットには草が入っているものがあります。最初は地面の広さと形を決め、草の量は後で調整してください。

## 地面の形を変える

1. Hierarchyで地形を選びます。
2. Inspectorで地形のブラシを選びます。
3. 小さめの半径と弱い強さから始め、少しずつ塗ります。
4. **盛り上げる**で丘を作り、**掘る**で低くします。段差が強すぎる部分は**滑らかにする**で整えます。

平らにしたい範囲には高さを設定するブラシを使います。**穴を開ける**操作は見た目だけでなく地面に穴を作るため、歩く場所には注意してください。大きく変える前に保存し、意図しない変更は元に戻します。

## 草を生やす・消す

地形の草の設定で層や草のセットを選び、草用のブラシで生やす範囲を塗ります。道や入口では草を減らすと、歩く場所が分かりやすくなります。

草用のブラシは地面の高さを変えません。高さを編集するブラシと切り替えて使います。シーン設定の**風**で揺れを調整できます。

## 歩いて確認する

**Play**で丘や入口、穴の周辺を歩き、通り抜けや転落が起きないか確認します。開始位置は地面より上に置いてください。[衝突判定と開始位置](./collision.md)も確認します。

草を増やす前と増やした後の動作を比べます。草の密度や地形の細かさを上げるだけでなく、見える範囲に絞ることも有効です。公開前は[容量と描画負荷](./performance.md)を確認してください。
