# 地形と草を作る

地形機能を使うと、山や島のように起伏のある地面を作れます。室内や平らな床だけのワールドであれば、地形を追加する必要はありません。

編集を始める前に保存状態を確認し、Play中であればStopを押して編集画面に戻っておきます。

## 地形を追加する

- **平らな地面から作る**：上部の「素材を追加 → Entityを作成 → World → Terrain → 平らなTerrain」を選びます。
- **形の見本から作る**：「Assets → アセットストア → 地形」でプリセットを選び、シーンに追加します。

あらかじめ草が配置されているプリセットもあります。まずは地面全体の広さと形を仕上げてから、あとで草の量を調整すると整えやすくなります。

## 地面の形を変える

Hierarchyで地形を選び、Inspectorからブラシを選択します。最初は小さい半径と弱い強さに設定し、少しずつ様子を見ながら塗るのがコツです。

- **盛り上げる**：地面を高くして丘や山を作ります。
- **掘る**：地面を低くしてくぼみや谷を作ります。
- **滑らかにする**：急な段差や角張った斜面をなだらかに整えます。
- **高さを設定するブラシ**：指定した高さに平らにならします。
- **穴を開ける**：地面に実際の穴を開けます。プレイヤーが歩く動線と重ならないよう注意してください。

大きく形を変える前に保存しておき、意図せず崩れてしまったときは「元に戻す」でやり直します。

## 草を生やす・消す

地形の草の設定で層や草のセットを選び、草用のブラシで生やしたい範囲を塗ります。道や入口の周辺は草を減らしておくと、歩ける場所が見分けやすくなります。

草用のブラシを使っている間は地面の高さは変わりません。地面の起伏を直したいときは高さを変えるブラシへ切り替えて使います。草の揺れ方は、シーン設定の風で調整できます。

## 歩いて確認する

形と草が整ったらPlayを押し、丘の上、入口、穴の周りなどを実際に歩いて、すり抜けや意図しない転落がないか確かめます。プレイヤーの開始位置は必ず地面の上に置いてください。詳しくは[Colliderと開始位置](./collision.md)も参照してください。

草を増やす前後で動作の重さを見比べることも大切です。草の密度や地形の細かさを調整するほか、見える範囲に絞って配置すると負荷を抑えられます。公開前には[容量と描画負荷](./performance.md)も確認しておきましょう。
