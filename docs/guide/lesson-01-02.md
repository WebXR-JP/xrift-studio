# オブジェクトを移動・拡大縮小する

[動画を再生する：オブジェクトを移動・拡大縮小する](./media/tutorials/lesson-01-02.mp4)

位置と大きさの数値を変えて、オブジェクトの配置を調整します。

## 操作の要点

1. Hierarchyで動かすEntityを選びます。
2. InspectorのTransformで位置と大きさを、一つずつ変えます。
3. 視点を動かし、床との位置関係を確かめます。

## 試すときのポイント

視点の移動とEntityの移動を区別し、意図した場所に配置できるか試してください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./objects.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
