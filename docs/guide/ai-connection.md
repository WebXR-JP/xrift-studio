# AIに編集を手伝ってもらう

AIを接続すると、配置や設定の変更を頼めます。まず[最初のワールド](./first-world.md)で、自動保存とPlayの操作を試してください。基本操作が分かると、AIが変更した内容も確認しやすくなります。

## 接続前に自動保存を確認する

AIに編集を頼む前に、画面が「保存済み」になっていることを確認してください。大きく変更する場合は、プロジェクトを複製しておくと元の状態を残せます。

## AI接続を開く

画面下部のステータスバーで「AI接続」を開いてください。対応するAIクライアントと接続状態が表示されます。使うクライアントを選んで登録します。

AIクライアントとの接続には、MCPという仕組みを使います。登録後に再読み込みなどを求められたら、画面の案内に従ってください。登録の操作が終わったら、接続状態の表示も確認します。

AIサービスの契約、利用料金、モデルの選択は、XRift Studioのアプリ配布とは別に扱われます。

## ChatGPTで新しいワールドを作る

デスクトップ版では、同じ「AI接続」パネルの「ChatGPTでワールドを作る」から生成できます。Node.jsのインストールやコマンド操作は不要です。

1. 「ChatGPTに接続」を押し、開いたブラウザでログインとChatGPTプランの利用許可を完了します。
2. 使用するモデルを選び、作りたい場所を2000文字以内で入力します。例：「秋の公園。木とベンチのある静かな広場」。
3. 使いたい外部素材の種類を選び、「新しいワールドを作る」を押します。
4. 現在の作品を保存した後、新しいワールドが別のプロジェクトとして保存され、Editorで開きます。Scene ViewとPlayで内容を確認してください。

生成には選択したChatGPTアカウントの利用枠を使用します。XRiftへのログインとは別です。接続はStudio終了時に解除されます。「接続を解除」してから別アカウントにログインできます。

「生成に使う外部素材」で3Dモデル・マテリアル・音声を個別に選べます。モデルとマテリアルはPoly Haven、音声は音蔵のカタログから選びます。マテリアルだけを選ぶ場合は、3Dモデルと音声のチェックを外してください。基本形状にテクスチャ付きのglTF PBR Materialを適用します。すべて外すと基本形状だけで生成します。

基本形状と外部モデル、Audio Sourceを合わせて最大32個配置します。外部素材は合計6種類まで、カタログのダウンロードサイズが1種類あたり32MB以内の選択肢を使います。候補は各種類64件までです。同じ素材は一度だけ取り込み、テクスチャ・材質・ライセンス情報と一緒に新しいプロジェクトへ保存します。候補に合う素材がない場合は基本形状を使います。音声は環境音としてループ再生し、音量などはInspectorのAudio Sourceで調整できます。

Assetsで取り込んだ素材を確認し、通常のモデル・Material・Audioと同じように編集できます。取り込みに失敗した場合は現在の作品を開いたままにします。作成途中の新しいプロジェクトが一覧に残る場合があります。公開や外部アセット購入は行いません。生成中に別の作品へ移動した場合は、元の作品に結果を適用せず停止します。現在の作品の保存に失敗した場合も切り替えません。

生成に失敗した場合は、パネルのエラーと通知を確認し、再接続やモデル変更、依頼を短くしての再試行を行ってください。生成の完了は、見た目や動作の品質を保証するものではありません。

## 最初は小さな変更を頼む

「選んだ球の位置は変えず、色だけを青にしてください」のように、対象と変更内容を具体的に伝えてください。

変更後はHierarchyとInspectorで対象を確認し、Playで見た目や動作を確かめます。意図した結果にならなければ、取り消せる操作は元に戻すか、バックアップを開いてください。

## 依頼に含めること

作りたい見た目、変更してよい範囲、残したいものを伝えてください。公開や削除など、戻しにくい操作を頼む場合は、依頼に明記します。

AIが完了を報告しても、保存や公開の状態は画面で確認してください。説明と実際の結果が一致しているかを確かめます。

## 接続できないとき

「AI接続」の状態表示を確認し、必要に応じてクライアントの再起動や登録をやり直してください。原因が分からない場合は、[復旧と問い合わせ](./recovery.md)を参照してください。認証情報や秘密のキーは、問い合わせに含めないでください。
