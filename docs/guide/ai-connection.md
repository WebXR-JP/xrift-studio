# AIに編集を手伝ってもらう

AIを接続すると、配置や設定の変更を頼めます。まず[最初のワールド](./first-world.md)で、自動保存とPlayの操作を試してください。基本操作が分かると、AIが変更した内容も確認しやすくなります。

## 接続前に自動保存を確認する

AIに編集を頼む前に、画面が「保存済み」になっていることを確認してください。大きく変更する場合は、プロジェクトを複製しておくと元の状態を残せます。

## MCP接続を開く

歯車の「設定」を開き、「MCP接続」を選んでください。対応するAIクライアントと接続状態を確認し、使うクライアントを選んで登録します。

MCP接続は制作チャットとは別の設定画面です。ChatGPTのタブを開いたまま確認できます。設定画面を閉じても、制作チャットの入力内容と接続状態は残ります。

AIクライアントとの接続には、MCPという仕組みを使います。登録後に再読み込みなどを求められたら、画面の案内に従ってください。登録の操作が終わったら、接続状態の表示も確認します。

AIサービスの契約、利用料金、モデルの選択は、XRift Studioのアプリ配布とは別に扱われます。

## ChatGPTで現在のワールドを編集する

デスクトップ版では、ワールドを開いて画面下部のロボット型の「ChatGPTを開く」を押すと、制作チャットのタブが開きます。Node.jsのインストールやコマンド操作は不要です。チャットはScene Viewの横に開き、別のタブへ移ったりタブを閉じたりしても入力内容と接続処理は残ります。同じアイコンから再び開けます。

1. 会話中央の接続カードで「ChatGPTに接続」を押し、開いたブラウザでログインとChatGPTプランの利用許可を完了します。接続中・復元中の案内や、失敗時のエラーと再接続も同じ場所に表示します。Studioへ戻り、右上のアカウントアイコンから接続中のアカウントを確認します。ブラウザの応答受信メッセージだけでは、接続は完了していません。
2. 入力欄の下で使用するモデルと「思考量」を選び、変更したい内容を2000文字以内で入力します。初期値は「低（速さ優先）」です。低に対応しないモデルでは利用できる控えめな思考量を選びます。「モデルの既定」はモデル側の標準設定を使います。「低（速さ優先）」「中（標準）」「高（じっくり）」など、使える選択肢はモデルごとに変わります。思考量の情報がないモデルでは「モデルの既定」を使います。例：「選択したBoxを右へ1m移動してください」。選択中のEntityと現在のSceneの情報を参考にします。結果を見てから次の依頼を送ると、少しずつ編集を進められます。
3. 矢印の「依頼を送信」を押します。確認したPlanに従い、現在のSceneを少しずつ変更し、その都度保存します。名前・位置・回転・大きさの調整に加え、モデルの追加・差し替え、Material、Skybox、Audio Source、Colliderの設定を頼めます。「このEntityの位置と回転を保ってモデルを差し替えて」「BGMの音量を少し下げて」のように伝えてください。
4. 変更する前に相談したい場合は「Plan」を選んでから送信します。Planを作るだけではSceneやプロジェクトのファイルを変更しません。音量や背景の明るさ、使用する素材名などを確認して「Planを反映」を押すか、「Planを破棄」を押してください。
5. チャットのPlanと進行状況を読みながら、Scene View、Hierarchy、Inspectorで結果を確認します。結果のEntityを押すとInspectorで選択できます。反映が完了したらPlayで内容を確認してください。

相談と生成には選択したChatGPTアカウントの利用枠を使用します。XRiftへのログインとは別です。接続情報はOSの安全な保存先に保管し、Studioの起動時に復元します。復元中は完了を待ってください。期限切れなどで復元できない場合は再接続します。「接続を解除」すると保存した接続情報も消え、別アカウントにログインできます。接続情報をプロジェクトやMCPの応答へ含めません。

制作中のプロジェクトにある素材と、素材ストアの内蔵カタログを使えます。Poly Haven、ambientCG、AI LOWPOLY PROPS、音蔵は、必要な種類だけ検索します。外部素材が不要な位置・音量などの調整では、全ストアの検索を待ちません。ストアごとに対応する種類から候補を選びます。

大きい依頼は、一度に反映する範囲を小さく分けます。Planで今回の変更と残りの作業を確認し、反映後に「続ける」を押すと、保存した結果と会話を踏まえて次の作業へ進みます。件数を数えたり、EntityのJSONを作ったりする必要はありません。同じ素材は依頼内で一度だけ取り込み、テクスチャ・材質・ライセンス情報と一緒に保存します。

チャット上部の「新しいチャット」で相談を分け、「制作チャットの履歴」から切り替えられます。履歴は端末に最大20チャット、各30件保存します。「チャットの操作」から名前の変更、作業履歴の全体コピー、履歴の削除ができます。履歴を削除してもSceneは変わりません。再起動すると未反映のPlanは終了しますが、相談と結果は残り、続きの依頼を送れます。

「変更を戻す」は、その依頼で反映したSceneとAssetsの状態を戻して保存します。その後に別の編集が入っている場合は、上書きを防ぐため戻せません。戻すための控えはStudioを開いている間だけ保持します。ダウンロードした素材ファイルとチャット履歴は残ります。

Assetsで取り込んだ素材を確認し、通常のモデル・Material・Audioと同じように編集できます。Planの検証や保存に失敗した場合は、反映を停止してエラーを残します。素材の取り込みや配置の途中で失敗した場合も、保存済みの結果は残ります。制作中の停止ボタンは以降の処理を止めるため、反映済みの内容は元に戻しません。生成中に別の作品やSceneへ移動した場合は、その移動先に結果を適用せず停止します。Planの対象Entityを手で変更した場合は、依頼を送り直してPlanを見直してください。公開や外部アセット購入は行いません。

生成に失敗した場合は、パネルのエラーと通知を確認し、再接続やモデル変更、依頼を短くしての再試行を行ってください。生成の完了は、見た目や動作の品質を保証するものではありません。

MCPからも接続状態の確認、接続・解除、モデル一覧の取得、生成を行えます。ブラウザでの許可は本人が行います。接続開始は`connect_chatgpt`、状態確認は`get_chatgpt_connection`です。`list_chatgpt_models`でモデルと対応する思考量を確認し、`generate_chatgpt_world`の`reasoningEffort`へ対応する値だけを渡します。省略時はモデル側の既定設定を使います。通常は現在のSceneへ反映し、`mode: "plan"`ならPlanだけを作って、`apply_chatgpt_plan`で後から反映できます。反映時に再推論は行いません。別のワールドを作る場合は`target: "new"`を指定します。返されたIDを`get_chatgpt_generation`へ渡して、工程、保存済みの件数、Planの確認待ち、完了・停止・失敗を確認してください。`cancel_chatgpt_generation`はPlanの破棄や制作の停止に使います。反映後は`get_editor_context`で状態を取得し、`capture_scene_view`で実物を確認します。

会話の一覧は`list_chatgpt_sessions`、全文は`get_chatgpt_session`、作成・切り替え・名前変更・削除は`manage_chatgpt_session`を使います。続きの依頼では`generate_chatgpt_world`に`sessionId`を渡します。戻せる依頼は`revert_chatgpt_generation`で戻せます。モデルだけを設定する場合は`set_entity_model`を使うと、既存Entityの名前・位置・回転・大きさを保てます。

## 最初は小さな変更を頼む

「選んだ球を右へ1m移動してください」のように、対象と変更内容を具体的に伝えてください。まず小さく調整し、結果を見てから次の依頼を送ると、意図に合わせて編集を進められます。

変更後はHierarchyとInspectorで対象を確認し、Playで見た目や動作を確かめます。意図した結果にならなければ、取り消せる操作は元に戻すか、バックアップを開いてください。

## 依頼に含めること

作りたい見た目、変更してよい範囲、残したいものを伝えてください。公開や削除など、戻しにくい操作を頼む場合は、依頼に明記します。

AIが完了を報告しても、保存や公開の状態は画面で確認してください。説明と実際の結果が一致しているかを確かめます。

## 接続できないとき

「MCP接続」の状態表示を確認し、必要に応じてクライアントの再起動や登録をやり直してください。原因が分からない場合は、[復旧と問い合わせ](./recovery.md)を参照してください。認証情報や秘密のキーは、問い合わせに含めないでください。
