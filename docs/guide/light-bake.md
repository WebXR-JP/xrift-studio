# ライトベイクで陰影を焼く

ライトベイクは、動かないMeshに当たる光と影をあらかじめ計算し、1枚の画像（ライトマップ）に焼く機能です。やわらかい影、床や壁で跳ね返った光、物陰の暗さが加わります。影を描画のたびに計算しなくて済むので、ライトの多いワールドも軽くできます。

焼いた陰影は、編集画面、Play、公開したワールドで同じ画像を使います。公開のときに作り直すことはありません。

## 対象を選んでベイクする

1. エディター左下の電球のボタンから「ライトベイク」を開きます。
2. 「対象のMesh」で、焼く対象を選びます。「動かないMeshを選ぶ」を押すと、物理・Script・アニメーションの付いていないMeshをまとめて選べます。
3. 「ベイク」を押します。計算中も編集を続けられます。途中でやめるときは「中止」を押してください。

終わると状態が「ベイク済み」になり、Scene Viewに陰影が出ます。結果は「ライトマップ」としてAssetsに保存されます。

対象は一覧のチェックでも、Scene Viewでも選べます。「Scene Viewでクリックして選ぶ」を押すと、対象のMeshに色が付き、クリックするたびに対象と対象外が切り替わります。

対象にするのは、床、壁、建物、固定の家具など、動かない物だけにしてください。焼いた陰影は、物を動かしても元の場所に残ります。一覧で「動く」と表示されたMeshには、物理、Script、風、アニメーションのどれかが付いています。

Unlit、MToon、カスタムシェーダーのMaterialを使うMeshは、対象にすると影を落として光を跳ね返しますが、焼いた陰影は表示しません。

## ライトの扱いを選ぶ

「ライト」では、ライトごとに二つの扱いを選べます。

| 扱い | 焼く内容 | 描画時 |
|---|---|---|
| リアルタイム | 跳ね返った光だけ | これまでどおり照らす |
| ベイク | 光と影のすべて | ライトを消す |

初期値は「リアルタイム」です。見た目はほぼそのままで、跳ね返った光と物陰の暗さが加わります。

「ベイク」にすると、そのライトの影まで焼き、描画ではライトを消します。影の計算が要らなくなり、縁のやわらかい影になります。ただし、対象でないMeshやアバターには、そのライトが届かなくなります。アバターを照らす光を残すには、ライトを一つ「リアルタイム」のままにするか、「シーン設定」のAmbient Lightを有効にしてください。

Ambient LightとSkyboxのIBLは、物陰で遮られるぶんだけ焼かれます。光そのものは描画時にも届くので、対象でないMeshの明るさは変わりません。

## 設定を選ぶ

| 設定 | 内容 |
|---|---|
| ライトマップの大きさ | 画像の一辺の上限です。細かさはここから自動で決まります。影がギザギザに見えるときは大きくしてください。 |
| 品質 | 「下書き」は配置を確かめる速さ優先で、ざらつきが残ります。「標準」がふだんの仕上げ、「高品質」は公開前の仕上げです。 |
| 影のやわらかさ | 「ベイク」にしたライトの、影の縁のぼかし具合です。 |

ライトマップは明るさを正確に持つため、半精度のEXRで保存します。大きさを2倍にすると、ファイルの容量と表示に使うGPUメモリは約4倍になります。4096pxはGPUメモリを約128MB使うので、スマートフォンやスタンドアロンのVR機器向けには2048px以下を選んでください。

## 焼き直す・外す

ベイクの後に対象、ライト、配置を変えると、状態が「Sceneが変わりました」になります。「焼き直す」を押すと、今のSceneに合った陰影になります。焼き直しても、Assetsのライトマップは増えません。

「外す」を押すと、焼いた陰影をSceneから外し、「ベイク」にしたライトも描画に戻ります。ライトマップのAssetは残ります。ベイクと「外す」は、どちらも「元に戻す」で取り消せます。

対象から外したMeshは、焼き直す前でもすぐに陰影が外れます。ライトを「リアルタイム」へ戻した場合も、すぐに点きます。

## 公開する

デスクトップ版の「XRiftへ公開」は、Assetsのライトマップをそのままコピーします。ライトマップの容量は、ライトベイクの状態欄で確認できます。

ブラウザ版からの公開は、焼いた陰影にまだ対応していません。ライトマップを使っているSceneは公開の前に止まります。デスクトップ版から公開するか、「外す」でライトマップを外してから公開してください。

## 陰影が出ない・おかしいとき

| 症状 | 確認すること |
|---|---|
| ベイクしても陰影が出ない | Scene Viewの表示モードを「シーン」にしてください。「Unlit」「Wireframe」では、ライトと同じく陰影も表示しません。 |
| 「対象のMeshがありません」と出る | 対象を選び、表示モードを「シーン」にして、Modelの読み込みが終わってから実行してください。 |
| 影の縁がギザギザ | ライトマップを大きくするか、対象を減らしてください。細かさは状態欄の「1mあたり○px」で分かります。 |
| ざらつきが残る | 品質を「標準」か「高品質」にしてください。 |
| 物を動かしたら影が残った | 「焼き直す」を押してください。動かす予定の物は対象から外します。 |
| 対象でない物やアバターが暗い | そのライトが「ベイク」になっています。「リアルタイム」へ戻すか、Ambient Lightを有効にしてください。 |
| 壁の根元から光が漏れる | 壁が床を突き抜けている、または厚みのない板で部屋を仕切っている場合に起こります。壁を床の上で止めるか、壁に厚みを持たせてください。 |
