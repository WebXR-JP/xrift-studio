# ライトベイクで陰影を焼く

ライトベイクは、動かないMeshに当たる光と影をあらかじめ計算し、1枚の画像（ライトマップ）に焼き込んでおく機能です。やわらかな影、床や壁で跳ね返った間接光、物陰の自然な暗さが加わります。描画のたびに影を計算しなくて済むため、ライトの数が多いワールドも軽くできます。

焼き込んだライトマップは、編集画面、Play、公開後のワールドのすべてで同じ画像が使われます。公開時に自動で作り直されることはありません。

## 対象を選んでベイクする

1. エディター左下の電球ボタンから「ライトベイク」を開きます。
2. 「対象のMesh」で焼き込む対象を選びます。「動かないMeshを選ぶ」を押すと、物理・Script・アニメーションが付いていないMeshをまとめて選択できます。
3. 「ベイク」を押します。計算中もそのまま編集を続けられます。途中で止めたいときは「中止」を押してください。

計算が終わると状態が「ベイク済み」に変わり、Scene Viewに陰影が表示されます。生成されたライトマップはAssetsに保存されます。

対象は一覧のチェックボックスだけでなく、Scene View上でも切り替えられます。「Scene Viewでクリックして選ぶ」を押すと対象のMeshに色が付き、クリックするたびに対象と対象外を切り替えられます。

ベイクの対象には、床、壁、建物、固定された家具など動かないものだけを選んでください。焼き込んだ陰影は、あとからオブジェクトを動かしても元の位置に残ってしまいます。一覧で「動く」と表示されているMeshには、物理、Script、風、アニメーションのいずれかが設定されています。

なお、Unlit、MToon、カスタムシェーダーのマテリアルを使うMeshを対象に含めると、ほかの物へ影を落としたり光を跳ね返したりはしますが、そのMesh自身には焼き込んだ陰影が表示されません。

## ライトの扱いを選ぶ

「ライト」の欄では、シーン内のライトごとに次の2つの扱いを選べます。

| 扱い | 焼き込む内容 | 描画時の動作 |
| --- | --- | --- |
| リアルタイム | 跳ね返った光（間接光）だけ | これまでどおりリアルタイムで照らす |
| ベイク | 光と影のすべて | リアルタイムのライトを消す |

初期設定は「リアルタイム」です。元の見た目をほぼそのまま活かしながら、跳ね返った光と物陰の暗さを足せます。

「ベイク」を選ぶと、そのライトの影までライトマップへ焼き込み、描画時にはライトを消します。影のリアルタイム計算が不要になり、縁のやわらかい影になります。ただし、ベイク対象外のMeshやアバターには、そのライトの光が当たらなくなります。アバターを照らす光を残したい場合は、ライトを1つ「リアルタイム」のままにしておくか、「シーン設定」のAmbient Lightを有効にしてください。

Ambient LightとSkyboxのIBLについては、物陰で遮られるぶんだけがライトマップに焼き込まれます。光そのものは描画時にも当たるため、対象外のMeshの明るさは変わりません。

## 設定を選ぶ

| 設定 | 内容 |
| --- | --- |
| ライトマップの大きさ | 生成する画像の1辺の上限です。細かさはここから自動で決まります。影がギザギザに見えるときは大きくします。 |
| 品質 | 「下書き」は配置確認向けの速さ優先で、ざらつきが残ります。普段の制作では「標準」、公開前の仕上げには「高品質」を選びます。 |
| 影のやわらかさ | 「ベイク」にしたライトの影の縁をどれくらいぼかすか調整します。 |

ライトマップは明るさの幅を正確に記録するため、半精度のEXR形式で保存されます。画像の大きさを2倍にすると、ファイル容量と表示に使うGPUメモリは約4倍に増えます。4096pxではGPUメモリを約128MB消費するため、スマートフォンやスタンドアロンVR機器での快適さを重視する場合は2048px以下を選んでください。

## 焼き直す・外す

ベイクしたあとに、対象Mesh、ライト、オブジェクトの配置などを変更すると、状態が「Sceneが変わりました」に変わります。「焼き直す」を押すと最新のSceneに合わせて再計算され、Assets内のライトマップが増えることなく上書き更新されます。

「外す」を押すと焼き込んだ陰影がSceneから外れ、「ベイク」にしていたライトもリアルタイム描画に戻ります。このときライトマップのAsset自体は削除されずに残ります。ベイクの実行も「外す」も、「元に戻す」で取り消せます。

対象からチェックを外したMeshは、焼き直す前でも即座に陰影が外れます。ライトを「リアルタイム」に戻した場合も、すぐに点灯します。

## 公開する

デスクトップ版の「XRiftへ公開」を使うと、Assets内のライトマップがそのまま公開データにコピーされます。ライトマップの容量は、ライトベイク画面の状態欄で確認できます。

ブラウザ版からの公開は、まだライトマップに対応していません。ライトマップを使用中のSceneは公開前に停止するため、デスクトップ版から公開するか、「外す」でライトマップを解除してから公開してください。

## 陰影が出ない・おかしいとき

| 症状 | 確認すること |
| --- | --- |
| ベイクしても陰影が出ない | Scene Viewの表示モードを「シーン」にしてください。「Unlit」「Wireframe」では、ライトと同様に焼き込んだ陰影も表示されません。 |
| 「対象のMeshがありません」と出る | 対象のMeshを選び、表示モードを「シーン」にしたうえで、Modelの読み込みが完了してから実行してください。 |
| 影の縁がギザギザに見える | ライトマップを大きくするか、焼き込む対象を減らしてください。細かさの目安は状態欄の「1mあたり○px」で確認できます。 |
| 陰影にざらつきが残る | 品質を「標準」または「高品質」に上げて焼き直してください。 |
| 物を動かしたら元の場所に影が残った | 「焼き直す」を押してください。動作中に動かす予定の物は、ベイクの対象から外しておきます。 |
| 対象外の物やアバターが暗い | ライトの扱いが「ベイク」になっています。ライトを1つ「リアルタイム」へ戻すか、Ambient Lightを有効にしてください。 |
| 壁の根元から光が漏れる | 壁が床を突き抜けていたり、厚みのない板だけで部屋を仕切っていたりすると起こりやすくなります。壁を床の上で止めるか、壁に厚みを持たせてください。 |
