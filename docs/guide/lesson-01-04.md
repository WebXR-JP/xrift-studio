# 複製とUndo・Redoを使う

[動画を再生する：複製とUndo・Redoを使う](./media/tutorials/lesson-01-04.mp4)

## このレッスンでできること

`Box`を複製して並べ、移動した操作をUndo・Redoで戻したりやり直したりしながら、気軽に試せる編集手順を身につけます。

## 始める前に

- 練習に使う`Box`を一つ選んでおきます。
- 大事な作品を編集するときは、あらかじめ[保存とバックアップ](./course-save-backup.md)を残しておくと安心です。

## 操作の要点

1. Hierarchyで`Box`を右クリックし、「複製」を選びます。
2. 複製されたEntityを選び、位置Xを少しずらして、元の`Box`と重ならないようにします。
3. `Ctrl + Z`（Macは`⌘ + Z`）を押し、直前の移動を1回分戻します。
4. 画面のやり直し（Redo）操作で、移動後の位置へ戻します。複製と移動は別々の操作として記録されるため、どこまで戻ったかを画面で確認しながら進めます。
5. 複製した片方だけ色を変えたい場合は、Entityを複製したあとで[マテリアルを分ける手順](./materials.md#一つだけ色を変える)もあわせて行います。

## できたか確認する

- Hierarchyに元と複製のEntityが並び、それぞれ別の位置に置けました。
- 1回のUndoでどの操作が元に戻ったのか、画面上で確認できました。

## うまくいかないとき

- **複製したのに増えたように見えない**：元のEntityとまったく同じ位置に重なっているためです。Hierarchyで複製先を選び、位置を少しずらしてみてください。
- **片方の色を変えたら両方の色が変わった**：2つのEntityが同じマテリアルを共有しています。片方専用のマテリアルを新しく作って割り当ててください。
