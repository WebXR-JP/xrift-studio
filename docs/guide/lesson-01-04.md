# 複製とUndo・Redoを使う

[動画を再生する：複製とUndo・Redoを使う](./media/tutorials/lesson-01-04.mp4)

## このレッスンでできること

Boxを複製し、移動した変更をUndo・Redoで確かめます。

## 始める前に

- 練習用のBoxを一つ選びます。
- [バックアップ](./course-save-backup.md)を残し、既存作品の大きな編集と分けて試します。

## 操作の要点

1. HierarchyのBoxを右クリックして「複製」を選びます。
2. 複製したEntityを選び、位置Xを少し変えます。元と重なっていた二つのBoxが見分けられるようにします。
3. Ctrl + Z、Macでは⌘ + Zで、直前の移動を一回戻します。
4. 画面のやり直し操作で、移動後の状態へ戻します。複製と移動は別の操作なので、どこまで戻したか確認してください。
5. 片方だけ色を変える場合は、Entityの複製に続いて[マテリアルを分ける](./materials.md#一つだけ色を変える)手順も行います。

## できたか確認する

- Hierarchyに元と複製のEntityがあり、別々の位置へ置ける。
- 一回のUndoが何を戻したか、画面で確認できる。

## うまくいかないとき

- 増えたように見えない：元のEntityと重なっている可能性があります。Hierarchyと位置を確認します。
- 両方の色が変わる：同じマテリアルを共有しています。一つ専用のマテリアルを作って割り当てます。
