# 審査と一覧への公開を確認する

動画：未収録（文章で進められます）

## このレッスンでできること

アップロードしたバージョンの審査結果と、現在使われているバージョンを確認します。そのうえで、ワールド一覧に掲載するかを自分で選びます。

## 始める前に

[ワールドの送信](./course-publish-upload.md)を終え、送信した作品のワールドIDとバージョンを確認できるようにしてください。公開したアカウントでXRiftにログインします。

## 手順

### 1. 自分のワールドを開く

1. [XRiftのワールド画面](https://app.xrift.net/worlds)を開きます。
2. 「マイワールド」を選び、送信した作品を探します。
3. 作品を開き、名前・サムネイル・作成者を確認します。
4. 所有者向けの「バージョン履歴」を開き、送信結果に表示されたバージョンと照合します。

一覧にない場合は、ログイン中のアカウントと送信結果を確かめます。すぐに同じ作品を作り直して送らないでください。

### 2. 審査の状態を読む

「バージョン履歴」では、次の表示を区別します。

- 「審査中」／`PENDING`：判定待ちです。結果が出るまで待ちます
- 「審査通過」／`ACTIVE`：そのバージョンは審査を通過しています
- 「審査却下」／`REJECTED`：そのバージョンは利用できません。原因を確認して修正します
- 「現在使用中」：ワールドが現在使っているバージョンです。審査通過の表示と合わせて確認します

アップロード後にはXRift側の審査があります。手元の公開チェックを通過しただけで、サーバー側の審査が済んだことにはなりません。審査時間は状況によるため、待ち時間だけで成否を判断しないでください。

更新版が審査中や却下でも、以前の通過版が公開されたままの場合があります。「作品が開けた」だけで更新成功とせず、送信した版と「現在使用中」が合っているか確かめます。審査の流れは[公式CLI資料](https://docs.xrift.net/cli/commands#xrift-upload-world)にも記載されています。

### 3. 一覧に掲載するかを選ぶ

1. 自分のワールド詳細で「設定」を開きます。
2. 「ワールド一覧に公開する」のチェック状態を確認します。
3. 一覧や検索から見つけてもらう場合はチェックを入れます。一覧に載せず、URLを渡して案内する場合は外した状態にします。
4. 変更が反映されたか、画面を開き直して確認します。エラーが表示されたら、反映されたと決めつけないでください。

新規ワールドの一覧掲載は、初期状態では無効です。送信や審査通過とは別に確認してください。

**「限定公開」は、一覧・検索に載せず、URLを知っている人がアクセスできる設定です。秘密の保管場所にはなりません。** 見せられない資料、個人情報、認証情報を入れないでください。

ワールドの一覧掲載と、集まる部屋であるインスタンスの参加条件も別の設定です。友達を呼ぶ前に、[インスタンスと招待](./course-publish-invite.md)を確認します。

### 4. 公開後の確認へ進める状態を確かめる

1. 「バージョン履歴」で、確認したい版が「審査通過」「現在使用中」になっていることを確かめます。
2. 「インスタンス」を開きます。初回のワールドが審査中・却下の場合は、インスタンスを作成できません。
3. 名前・説明・サムネイルが意図した内容になっているか読み直します。
4. 一覧掲載の設定を確認し、[ワールドに入り、友達を招く](./course-publish-invite.md)へ進みます。

## できたか確認する

- 送信したバージョンの審査結果を確認した
- 審査通過と「現在使用中」の違いが分かる
- 一覧に掲載するかを選び、反映を確認した
- 限定公開を秘密保持の仕組みとして使っていない

## うまくいかないとき

- 「設定」「バージョン履歴」がない：公開したアカウントでログインしているか、対象作品の作成者を確認します
- 審査中が続く：しばらく待って同じ版の状態を確認します。新しい送信を重ねても、審査完了の確認にはなりません
- 審査却下になった：表示された理由や公開時の検査結果を確認します。原因が分からなければ、キーを除いたエラーと発生段階をまとめ、[復旧と問い合わせ](./recovery.md)を参照してください
- 一覧に出ない：審査の状態と「ワールド一覧に公開する」を別々に確認します。限定公開の作品を検索だけで探そうとしないでください
