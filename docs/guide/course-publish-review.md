# 審査と一覧への公開を確認する

動画：未収録（文章で進められます）

## このレッスンでできること

アップロードしたバージョンの審査結果と、現在ワールドで使われているバージョンを確認します。そのうえで、ワールド一覧に掲載するかどうかを自分で選びます。

## 始める前に

[ワールドを一度だけ送信する](./course-publish-upload.md)を済ませ、控えておいたワールドIDとバージョンを手元に用意します。公開したのと同じアカウントでXRiftにログインしておいてください。

## 手順

### 1. 自分のワールドを開く

1. [XRiftのワールド画面](https://app.xrift.net/worlds)を開きます。
2. 「マイワールド」を選び、送信した作品を探します。
3. 作品を開いて、ワールド名・サムネイル・作成者が合っているか確認します。
4. 所有者向けの「バージョン履歴」を開き、送信完了画面に表示されたバージョン番号と照合します。

一覧に見当たらない場合は、ログインしているアカウントや送信時の控えを確認してください。確認しないまま同じ作品を作り直して再送すると、別ワールドが重複してしまいます。

### 2. 審査の状態を確認する

「バージョン履歴」では、次の表示を見分けます。

- **「審査中」／`PENDING`**：判定を待っている状態です。結果が出るまでしばらく待ちます。
- **「審査通過」／`ACTIVE`**：そのバージョンは審査を通過しています。
- **「審査却下」／`REJECTED`**：そのバージョンは公開できません。理由を確認して修正します。
- **「現在使用中」**：いま実際にワールドで使われているバージョンです。「審査通過」とあわせて確認します。

アップロードしたあとにはXRift側での審査があります。Studioの公開チェックを通っただけでは、審査まで終わったことにはなりません。審査にかかる時間はタイミングによって変わるため、少し時間を置いてから状態を確認してください。

なお、更新版が審査中や却下になっていても、以前通過したバージョンがそのまま公開され続けている場合があります。「ワールドが開けた」だけで更新完了と判断せず、今回送信したバージョンが「現在使用中」になっているか確認してください。審査の流れは[公式CLI資料](https://docs.xrift.net/cli/commands#xrift-upload-world)にも記載されています。

### 3. ワールド一覧に掲載するか選ぶ

1. 自分のワールド詳細ページで「設定」を開きます。
2. 「ワールド一覧に公開する」のチェックを確認します。
3. 一覧や検索から見つけてもらいたい場合はチェックを入れます。一覧には載せず、URLを知っている人だけに案内したい場合はチェックを外したままにします。
4. 設定を変えたら、画面を開き直して反映されたか確認します。エラーが表示された場合は、反映されていない可能性があるためもう一度確かめてください。

新しく公開したワールドは、初期状態では一覧掲載がオフになっています。審査通過とは別に確認しておきましょう。

**「限定公開」は、一覧や検索に載らずURLを知っている人が開ける設定です。秘密の保管場所ではないため、非公開の資料・個人情報・認証情報などは作品に入れないでください。**

また、ワールドの一覧掲載と、人が集まる部屋（インスタンス）の参加条件は別の設定です。友達を呼ぶ前に、[ワールドに入り、友達を招く](./course-publish-invite.md)で参加条件も確認します。

### 4. 実際に入れる状態か確かめる

1. 「バージョン履歴」で、確認したいバージョンが「審査通過」かつ「現在使用中」になっているか確かめます。
2. 「インスタンス」タブを開きます（初回公開のワールドが審査中・却下の間はインスタンスを作れません）。
3. ワールド名・説明・サムネイルに誤りがないか読み直します。
4. 一覧掲載の設定を確認したら、[ワールドに入り、友達を招く](./course-publish-invite.md)へ進みます。

## できたか確認する

- 送信したバージョンの審査状態を確認できました。
- 「審査通過」と「現在使用中」の違いが分かりました。
- ワールド一覧に掲載するかどうかを選び、設定が反映されたことを確認しました。
- 限定公開でもURLを知っていれば開けることを理解し、秘密情報を入れていないと確認できました。

## うまくいかないとき

- **「設定」や「バージョン履歴」が表示されない**：公開に使ったアカウントでログインしているか、作品の作成者が自分になっているか確認してください。
- **「審査中」が続く**：少し時間を置いてから同じバージョンの状態を確認します。新しく送信し直しても、審査が早まるわけではありません。
- **「審査却下」になった**：表示された理由や公開時のチェック内容を確認します。原因が分からない場合は、APIキーなどの秘密情報を除いたエラー内容と発生段階をまとめて[復旧と問い合わせ](./recovery.md)を参照してください。
- **一覧や検索に出てこない**：審査状態と「ワールド一覧に公開する」のチェックをそれぞれ確認します。限定公開のワールドは検索に出ないため、「マイワールド」か控えておいたURLから開いてください。
