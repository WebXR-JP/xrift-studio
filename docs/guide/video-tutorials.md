# 動画で学ぶ XRift Studio

見て、止めて、同じ操作を試せる1本約1分の動画教材を、4つの章にまとめました。初めての方は「新しいプロジェクトを作る」から、特定の操作を調べたいときは気になる動画からご覧ください。

公開まで順番に進めたい方は、[制作から公開までのコース](./learning-course.md)がおすすめです。動画レッスンの詳しい解説に加えて、保存・テスト・公開・更新・招待の手順もまとめています。

動画は全19本（合計約18分）です。どのレッスンにも操作の要点と詳しいガイドへのリンクがあり、すべての動画にナレーションと日本語字幕が入っています。文字が小さく見えるときは、全画面表示にすると見やすくなります。

動画はブラウザ版βの画面で収録しています。[ブラウザのビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開くか、デスクトップ版の[インストールとセットアップ](./installation.md)を済ませて、画面を見ながら一緒に試してみてください。[iPadでの操作](./ipad.md)は専用ガイドで確認できます。

## 教材について

収録当時の画面と現在のバージョンでは、ボタンの配置や名前が少し異なる場合があります。見当たらない項目があるときは、各レッスンから関連ガイドもあわせてご確認ください。見たい動画のページを開いて再生ボタンを押すと再生が始まります。

動画のナレーションには合成音声を使用しています。利用条件やクレジットについては、[動画教材の利用条件](./video-credits.md)をご覧ください。
