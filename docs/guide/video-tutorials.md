# 動画で学ぶ XRift Studio

見て、止めて、同じ操作を試す。1本約1分の教材を、4つの章にまとめました。初めてなら「新しいプロジェクトを作る」から、操作を調べたいときは気になる動画から始めてください。

全19本・約18分。各動画に短い操作の要点と、詳しい使い方へのリンクがあります。各動画にナレーションが入り、字幕も動画内に表示されます。画面が小さい場合は全画面にすると読みやすくなります。

動画はブラウザ版βの画面で制作しています。[ブラウザのビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開くか、デスクトップ版の[インストールとセットアップ](./installation.md)を済ませて、一緒に試してください。[iPadの操作](./ipad.md)は別の案内で確認できます。

## 教材について

録画時の画面と現在のアプリでは、配置や操作名が異なる場合があります。各レッスンから詳しい使い方も確認してください。動画は必要なものだけ開いて再生でき、自動再生はしません。

音声付きの教材には合成音声を含みます。利用条件と制作上のクレジットは、[教材の利用条件](./video-credits.md)を確認してください。
