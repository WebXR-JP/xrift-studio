# Hierarchyで選ぶ・視点を動かす

[動画を再生する：Hierarchyで選ぶ・視点を動かす](./media/tutorials/lesson-01-03.mp4)

Hierarchyで対象を選び、作業しやすい視点へ動かします。

## 操作の要点

1. HierarchyでEntityの名前を選びます。
2. Fを押して、選択したEntityに視点を合わせます。
3. ホイールで近づいたり離れたりして、作業しやすい見え方にします。

## 試すときのポイント

視点を動かしても、EntityのTransformの値は変わりません。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./editor-basics.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
