# Entityを別のワールド・アイテムへ渡す

Hierarchyで選んだEntityを、子Entityと必要な素材を含む `.xriftstudio` ファイルに書き出せます。別のワールドやアイテムでは、今のプロジェクトを開いたまま、必要な部分だけ追加します。

## 選んだ部分を書き出す

1. Hierarchyで渡したいEntityを選びます。親を選ぶと子Entityも含まれます。複数選択も使えます。
2. SceneまたはHierarchyのEntityを右クリックし、「選択範囲を書き出す」を選びます。
3. 選択範囲・配置・書き出す種類（ワールド／アイテム）を確認して「書き出しを準備」を押します。
4. Entity・素材・ファイルの数と注意事項を確認し、「.xriftstudioを保存」を押します。

ブラウザではブラウザの保存先へ、デスクトップ版では選んだ保存先へ書き出します。選択を外した部分や使っていない素材、シーンの空・照明などの設定、元の公開先の情報は含めません。Entityとして作ったライトは選択に含まれていれば受け渡します。

書き出すときに元のプロジェクトは変更しません。Scriptを編集中なら、その内容を保存してからコピーします。

## 今のHierarchyへ追加する

1. 追加先のワールドまたはアイテムを開きます。ワールドの一部をアイテムにする場合は、新しいアイテムを作って開きます。
2. 上部の「素材を追加」から「.xriftstudioから追加」を選びます。
3. `.xriftstudio` または従来の `.zip` を選びます。ビジュアルプロジェクト全体のファイルも使えます。
4. 複数シーンがある場合はシーンを選び、追加したいEntityにチェックを付けます。
5. 追加先と配置を選び、「追加する内容を確認」を押します。
6. 注意事項を確認して「Hierarchyへ追加」を押します。

追加先はScene直下、操作を始めたときに選んでいたEntityの子、またはそのEntityと同じ階層から選べます。特定のEntityの子にしたいときは、ダイアログを開く前にそのEntityを選んでください。

今のプロジェクトの種類、シーン設定、公開先は変わりません。「プロジェクトを開く」と違い、今あるEntityも置き換えません。追加後は新しいEntityが選択されます。Undoで、追加したEntityと素材の登録をまとめて取り消せます。Redoも使えます。

## 配置を選ぶ

| 配置 | 動き |
| --- | --- |
| 元のワールド座標を保つ | 元のシーン内の位置を保ちます。追加先の親に位置・回転・大きさがあっても補正します。 |
| 先頭のEntityを原点へ移す | 最初に選んだEntityの位置を基準に、Sceneまたは追加先の親の原点へ移します。複数Entityの相対的な配置を保ちます。 |
| 元のローカル座標を使う | 保存されている位置・回転・大きさをそのまま使います。追加先の親の影響を受けます。 |

アイテムへのファイル読み込みでは「原点へ移す」が初期値です。既に部分書き出しされたファイルでは、書き出した時点の座標が基準です。切り離す前の親の情報には戻せません。

親の回転と不均等な大きさによって、通常の位置・回転・大きさだけでは形を保てない場合があります。その場合はエラーを表示します。親ごと選ぶか、ローカル座標を選んで調整してください。

## コピーして別のプロジェクトへ貼り付ける

Hierarchyで選んで **Ctrl+C**（Macは **Cmd+C**）を押し、「コピーしました」と表示されたら別のワールド・アイテムへ移動します。移動先で **Ctrl+V**（Macは **Cmd+V**）を押すと、追加内容の確認画面を開きます。タッチ操作では選択したHierarchy行の「…」を使います。

素材のファイルもコピー時点で保持します。同じアプリのウィンドウ、または同じブラウザのタブでプロジェクトを切り替える操作に対応します。OSのクリップボードではありません。別ウィンドウ、別タブ、別端末、再起動後に渡す場合は `.xriftstudio` を使ってください。

## 注意事項が出たとき

選択外のEntityを参照するComponentは参照を外して無効にします。関連するEntityも一緒に選ぶか、追加後に参照先を設定してください。Graphも不足する参照を外して注意事項を表示します。追加先で使えないワールド専用のComponentは、設定を残して無効にします。

Prefabは現在の内容を展開して渡します。元Prefabとの同期は引き継ぎません。無効なPrefabは、有効にするか展開してから書き出してください。Model内部のEntityだけを選んだ場合は、Model本体を選び直してください。

Scriptのコード自体は変更しません。Editでも実行するScriptは、受け渡すコピーだけをPlay時の実行へ変更します。Scriptは隔離された実行環境ではありません。受け取ったコードや外部URLを確認してからPlayしてください。コードに直接書いたEntity ID・Asset IDは自動変換しません。

一度に受け渡す上限はEntity 20,000件、素材ファイル512件、1ファイル128 MB、素材合計256 MBです。ファイル全体と展開後のデータにも256 MBの上限があります。容量不足や参照ファイルがない場合は追加を中止します。選択を分けるか、素材を取り込み直してください。

プロジェクト全体を保存・開く方法は[保存して、また開く](./save-and-open.md)、素材の追加は[Assetsを使う](./assets.md)を参照してください。

## そのままアイテムとして開く

書き出し画面の「書き出すプロジェクトの種類」で「アイテム」を選びます。保存した `.xriftstudio` を独立したアイテムプロジェクトとして開けます。元のワールドと公開情報は変わりません。ワールド専用のComponentは無効で保持されるため、書き出し準備後の注意事項を確認してください。別の既存プロジェクトへ追加する場合は、追加先の種類が優先されます。

同じプロジェクトへの通常の貼り付け・反転して貼り付けは、従来の即時操作を維持します。別プロジェクトへの貼り付けは、素材を含めた確認画面を開きます。コピー完了の通知が出てからプロジェクトを切り替えてください。
