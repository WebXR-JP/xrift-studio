# Entityを別のワールド・アイテムへ渡す

Hierarchyで選んだEntityを、子Entityと必要な素材も含めて`.xriftstudio`ファイルに書き出せます。受け取る側ではワールドやアイテムを開いたまま、必要なEntityだけを追加できます。

## 選んだ部分を書き出す

1. Hierarchyで渡したいEntityを選びます。親を選ぶと子も含まれます。複数選択もできます。
2. SceneかHierarchyのEntityを右クリックし、「選択範囲を書き出す」を選びます。
3. 選択範囲、配置、書き出す種類を確認して「書き出しを準備」を押します。種類はワールドかアイテムを選べます。
4. Entity、素材、ファイルの数と注意事項を確認し、「.xriftstudioを保存」を押します。

ブラウザ版ではブラウザの保存先、デスクトップ版では選んだ保存先に書き出されます。選択していないEntityや使っていない素材、シーンの空や照明の設定、元の公開先の情報は含まれません。Entityとして置いたライトは、選択していれば含まれます。

書き出しても、元のプロジェクトは変わりません。Scriptを編集中の場合は、編集内容を保存してからコピーされます。

## MToon・VRMモデルを渡す

MToonを使うEntityを書き出すと、マテリアルの色、陰影、輪郭線の設定と、参照しているテクスチャが含まれます。VRM 0.xやVRM 1.0を書き出す場合は、Model本体を選んでください。元のモデルファイル、取り込んだマテリアルや画像、モデルポーズをまとめて渡せます。

取り込み先でモデルのMaterialsを開くと、[MToonの色や輪郭線](./materials.md#mtoonマンガのような陰影と輪郭線を付ける)を引き続き編集できます。照明や環境光には追加先の設定が使われるため、Playで見た目を確認してください。

## 今のHierarchyへ追加する

1. 追加先のワールドかアイテムを開きます。ワールドの一部をアイテムにする場合は、新しいアイテムを作って開きます。
2. 上部の「素材を追加 → .xriftstudioから追加」を選びます。
3. `.xriftstudio`か従来の`.zip`ファイルを選びます。ビジュアルプロジェクト全体のファイルも使えます。
4. 複数のシーンがあれば一つを選び、追加したいEntityにチェックを付けます。
5. 追加先と配置を選び、「追加する内容を確認」を押します。
6. 注意事項を読んで「Hierarchyへ追加」を押します。

追加先は、Scene直下、操作開始時に選んでいたEntityの子、そのEntityと同じ階層から選べます。特定のEntityの子にするには、ダイアログを開く前にそのEntityを選んでください。

現在のEntityを残したまま、新しいEntityが追加されて選択されます。プロジェクトの種類、シーン設定、公開先は変わりません。Undoで追加したEntityと素材の登録をまとめて取り消せ、Redoでやり直せます。

## 配置を選ぶ

| 配置 | 動き |
| --- | --- |
| 元のワールド座標を保つ | 元のシーンでの位置を保ちます。追加先の親の位置、回転、大きさを補正して配置します。 |
| 先頭のEntityを原点へ移す | 最初に選んだEntityを、Sceneか追加先の親の原点へ移します。複数のEntityの相対的な位置は保たれます。 |
| 元のローカル座標を使う | 保存されている位置、回転、大きさをそのまま使います。追加先の親のTransformによって見た目が変わります。 |

アイテムへ読み込むときは、最初に「原点へ移す」が選ばれています。部分書き出ししたファイルでは、書き出し時点の座標が基準です。元の親から切り離す前の座標には戻せません。

親の回転と不均等な大きさの組み合わせによっては、位置、回転、大きさだけでは元の形を保てません。その場合はエラーが表示されます。親ごと選ぶか、ローカル座標で追加してから調整してください。

## コピーして別のプロジェクトへ貼り付ける

HierarchyでEntityを選び、Ctrl+C、MacではCmd+Cを押してください。「コピーしました」の表示を確認してから別のワールドやアイテムへ移動します。移動先でCtrl+V、MacではCmd+Vを押すと、追加内容の確認画面が開きます。タッチ操作では、選択したHierarchy行の「…」からコピーできます。

素材ファイルも、コピー時点の内容が保持されます。同じアプリのウィンドウか、同じブラウザのタブでプロジェクトを切り替えた場合に貼り付けられます。OSのクリップボードには保存されません。別ウィンドウ、別タブ、別端末、再起動後に渡す場合は、`.xriftstudio`ファイルを使ってください。

## 注意事項が出たとき

選択外のEntityを参照するComponentは、参照が外れて無効になります。関連するEntityも一緒に選ぶか、追加後に参照先を設定してください。Graphでも、不足する参照は外れ、注意事項が表示されます。追加先で使えないワールド専用のComponentは、設定を残したまま無効になります。

Prefabは現在の内容に展開され、元のPrefabとの同期は引き継がれません。無効なPrefabは、有効にするか展開してから書き出してください。Model内部のEntityだけを選んだ場合は、Model本体を選び直します。

Scriptのコードは変更されません。Editでも動くScriptは、渡すコピーだけがPlay時の実行に変更されます。Scriptは隔離された環境で動くわけではないため、受け取ったコードや外部URLを確認してからPlayしてください。コードに直接書かれたEntity IDとAsset IDは、自動では変換されません。

一度に渡せる上限は、Entityが20,000件、素材ファイルが512件です。素材の容量は1ファイル128 MB、合計256 MBまでです。ファイル全体と展開後のデータにも、それぞれ256 MBの上限があります。容量不足や参照ファイルの欠落がある場合は、追加が中止されます。選択を分けるか、素材を取り込み直してください。

プロジェクト全体の保存と取り込みは[保存して、また開く](./save-and-open.md)、素材の取り込みは[Assetsを使う](./assets.md)を参照してください。

## そのままアイテムとして開く

書き出し画面の「書き出すプロジェクトの種類」で「アイテム」を選ぶと、保存した`.xriftstudio`ファイルを独立したアイテムとして開けます。元のワールドや公開情報は変わりません。ワールド専用のComponentは設定を残して無効になるため、準備後の注意事項を確認してください。既存のプロジェクトへ追加する場合は、追加先の種類に合わせて取り込まれます。

同じプロジェクトでの「貼り付け」と「反転して貼り付け」は、すぐに反映されます。別のプロジェクトへ貼り付ける場合は、素材を含む確認画面が開きます。「コピーしました」の通知を確認してから、プロジェクトを切り替えてください。
