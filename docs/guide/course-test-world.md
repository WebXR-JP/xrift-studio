# 公開前のワールドを同じ順番でテストする

動画：未収録（文章で進められます）

関連動画：[床Collider・SpawnPoint・Playを確認する](./lesson-01-05.md)

## このレッスンでできること

開始位置から床・仕掛け・音の順番でワールドをテストし、Stopで編集に戻る流れを身につけます。修正したあとも毎回同じ順番で確認できる、シンプルなチェックリストを作ります。

## 始める前に

- 床とSpawnPointがあるワールドを開き、[保存とバックアップ](./course-save-backup.md)を済ませておきます。
- 仕掛けや音をまだ作っていない場合は、その項目を「今回はなし」として読み飛ばして構いません。
- 外部から受け取ったScriptが含まれている場合は、Playする前にコードの内容や接続先のURLを確認してください。Scriptは隔離された環境で実行されるわけではないため、信頼できるものだけ動かします。

## 手順

### 1. 開始位置と歩くルートを決める

Stopで編集画面に戻り、HierarchyでSpawnPointを選びます。開始位置が歩ける床の上にあり、壁や床に埋まっていないか確認してください。

次に、毎回確認するルートを一つ決めておきます。たとえば「開始位置 → 床の端 → 入口のボタン → 音源 → 開始位置」のように決めておくと、修正の前後を比べやすくなります。

### 2. Playで床を歩いて確かめる

1. Playを押し、モデルの読み込みが終わるまで待ちます。
2. パソコンでは中央のPlay Windowをクリックし、WASDまたは矢印キーで歩きます。マウスで視点を動かし、SpaceまたはEでジャンプできます。
3. iPadでは、画面上に表示される移動・ジャンプ・操作ボタンを使って歩きます。
4. 床の中心、端、通路、段差の付近を歩き、すり抜けて落ちたり見えない壁に引っかかったりしないか確かめます。

床が見えていても、当たり判定がなければ立って歩けません。落ちてしまう場合は先に進まず、Stopで編集に戻って[歩ける床と開始位置を作る](./collision.md)を参考に直しましょう。

### 3. 仕掛けを一つずつ試す

押せるボタンなどの仕掛けがあれば、近づいてクリックし、狙ったとおりに動くか確認します。待ち時間がある仕掛けは、動作が終わるまで待って確かめてください。

反応しないときはStopで戻り、[Node Graphの取り付けとInteractableの設定](./interactivity.md)を見直します。衝突用のColliderを付けただけでは、押して反応する仕掛けにはなりません。

仕掛けが複数あるときは、最初からまとめて動かさず、一つずつ「操作する → 結果を見る」を繰り返すと不具合の原因を見つけやすくなります。

### 4. 音を近くと遠くで聞く

音源を置いている場合は、近づいたときと離れたときの両方で聞こえ方を確かめます。BGMはワールド内を歩き回り、ちょうどよい音量になっているか確認します。ボタンで鳴る効果音は、実際に押して鳴るか試してください。

音が鳴らない場合は、[Audio Sourceへの割り当て・音量・再生条件](./audio.md)を確認します。音声ファイルをAssetsに取り込んだだけでは再生されません。

### 5. Stopで戻り、直したあともう一度試す

パソコンではEscキーでマウス固定を解除してからStopを押します。編集時の選択状態と視点に戻ったことを確認してください。マテリアルや素材、シーン設定の修正は、必ずStopで編集画面に戻ってから行います。

位置・回転・大きさなど、一部のInspector項目はPlay中に変更してもそのまま編集データに反映され、自動保存されます。元に戻したい操作はPlay中に試さないよう気をつけてください。

気になる点を一つ直したら、保存完了を確認してもう一度Playし、手順1で決めたルートを歩きます。直した場所だけでなく、その前後の動きもあわせて確かめておくと安心です。

## できたか確認する

次のチェックリストを手元にメモして使ってみてください。該当しない項目は「今回はなし」にしておきます。

- [ ] SpawnPointから始まり、床や壁に埋まらずに立てました。
- [ ] 床の中心・端・通路・段差を思いどおりに歩けました。
- [ ] 仕掛けを操作したとき、対象が想定どおりに動きました。
- [ ] 音が必要なタイミングで鳴り、近くでも遠くでもちょうどよい音量でした。
- [ ] Stopで編集に戻り、修正後にも同じルートでもう一度確認できました。
- [ ] 最後の修正が「保存済み」または「ブラウザに保存済み」になりました。

なお、Playで確認できるのは一人での動作です。複数人での同期、画面共有、スマートフォンやVR端末ごとの権限・動作については、XRiftへ公開したあとに実際の環境で確認します。

## うまくいかないとき

- **歩けない・視点が動かない**：読み込み完了後にPlay Windowをクリックしてください。マウス固定に対応していない環境では、画面をドラッグして視点を動かします。
- **落下して開始位置に戻り続ける**：Stopで編集に戻り、床のColliderが有効か、動かない床のRigid Bodyが`fixed`になっているか、SpawnPointが床の上にあるかを確認します。
- **ボタンを押しても反応しない**：手が届く距離まで近づいて試してください。それでも動かない場合は、Interactableの有無、Node Graphの取り付け先、グラフ内のエラー一覧を確認します。
- **音が聞こえない**：音源の設定や聞こえる範囲に加えて、端末やブラウザがミュートになっていないかも確認してください。
- **Stopボタンを押しにくい**：パソコンではEscキーでマウス固定を解除してから押します。もう一度マウスを固定したいときは、少し間を置いてからPlay Windowをクリックしてください。
