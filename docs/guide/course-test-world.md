# 公開前のワールドを同じ順番でテストする

動画：未収録（文章で進められます）

関連動画：[床Collider・SpawnPoint・Playを確認する](./lesson-01-05.md)

## このレッスンでできること

入口から床、仕掛け、音の順にワールドを確認し、Stopで編集に戻ります。直したあとも同じ順番で試せる、短いチェックリストを作ります。

## 始める前に

- 床とSpawnPointのあるワールドを開き、[保存とバックアップ](./course-save-backup.md)を済ませます。
- 仕掛けや音をまだ作っていない場合は、その項目を「今回はなし」として進められます。
- 外部から受け取ったScriptがある場合は、内容と外部URLを確認してからPlayしてください。Scriptは隔離された環境で動くわけではありません。

## 手順

### 1. 入口と歩く道を決める

Stopで編集に戻り、HierarchyでSpawnPointを選びます。開始位置が歩ける床の上にあり、壁や床に埋まっていないか確かめます。

確認する道順を一つ決めてください。例えば「開始位置 → 床の端 → 入口のボタン → 音源 → 開始位置」です。同じ道順で比べると、直した場所を確認しやすくなります。

### 2. Playを始め、床を歩く

1. Playを押し、モデルの読み込みを待ちます。
2. パソコンでは中央のPlay Windowをクリックし、WASDまたは矢印キーで歩きます。マウスで周りを見て、SpaceまたはEでジャンプできます。
3. iPadでは、画面の移動、ジャンプ、操作ボタンを使います。
4. 床の中心、端、通路、段差の近くを確認します。意図せず落ちたり、見えない壁に止められたりしないか見ます。

床が見えることと、床に立てることは別です。落ちる場合は先へ進まず、Stopで戻って[Colliderと開始位置](./collision.md)を直してください。

### 3. 仕掛けを一つずつ試す

押せるボタンがあれば近づいてクリックし、意図したものが動くか確認します。待ち時間のある仕掛けは、処理が終わるまで待ってください。

動かないときはStopで戻り、[Node Graphの取り付けとInteractable](./interactivity.md)を確認します。衝突用のColliderだけでは、押せる仕掛けにはなりません。

複数の仕掛けがある場合は、一つずつ「押す → 結果を見る」と試します。最初から全部を同時に動かさない方が、問題の場所を探しやすくなります。

### 4. 音を近くと遠くで聞く

音源がある場合は、近づいたときと離れたときの両方で聞きます。BGMはワールド内を歩き、意図した音量で聞こえるか確かめます。ボタンで鳴らす音は、操作してから確認してください。

鳴らない場合は、[Audio Sourceへの割り当て、音量、再生の開始条件](./audio.md)を確認します。音声ファイルをAssetsに置いただけでは再生されません。

### 5. Stopで戻り、修正後にもう一度試す

パソコンではEscでマウス固定を解除し、Stopを押します。編集時の選択と視点に戻ったことを確認してください。マテリアルや素材、シーン設定の修正は、Stopで戻ってから行います。

位置、回転、大きさなど、一部のInspector操作はPlay中でも編集データを変更し、自動保存されます。Play中なら何を変えても元に戻る、という使い方はしないでください。

問題を一つ直したら、保存状態を確認し、もう一度Playして手順1で決めた道順を歩きます。修正した場所と、その前後を確認してください。

## できたか確認する

次の項目をメモして使ってください。該当するものがなければ「今回はなし」と書きます。

- [ ] SpawnPointから始まり、床や壁に埋まらない
- [ ] 床の中心、端、通路、段差を意図したとおり歩ける
- [ ] 仕掛けを操作すると、対象が想定どおり動く
- [ ] 音が必要なときに鳴り、近く・遠くの音量が意図どおりになる
- [ ] Stopで編集に戻れ、修正後に同じ道順を試せた
- [ ] 最後の修正が「保存済み」または「ブラウザに保存済み」になった

この確認は一人のPlayで行うものです。複数人の同期、画面共有、端末ごとの権限や動作は、公開先でも実際の条件で確認します。

## うまくいかないとき

- **歩けない・視点が動かない**：読み込み後にPlay Windowをクリックします。マウス固定が使えない環境では画面をドラッグしてください
- **落下して開始位置に戻り続ける**：Stopで戻り、床のColliderが有効か、動かない床のRigid Bodyがfixedか、SpawnPointが床の上かを確認します
- **ボタンを押しても反応しない**：手が届く位置まで近づきます。それでも動かない場合はInteractable、グラフの取り付け、問題の一覧を確認します
- **音が聞こえない**：音源の設定に加え、聞こえる範囲と端末・ブラウザのミュートを確認します
- **Stopを押しにくい**：パソコンではEscでマウス固定を解除します。固定し直す場合は少し待ち、Play Windowを再度クリックしてください
