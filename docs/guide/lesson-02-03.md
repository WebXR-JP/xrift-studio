# PBRの色と光沢を調整する

[動画を再生する：PBRの色と光沢を調整する](./media/tutorials/lesson-02-03.mp4)

PBRマテリアルの色と光沢を調整します。

## 操作の要点

1. Assetsでマテリアルを選び、Base Colorを変えます。
2. Metallicで金属度、Roughnessで反射のぼけ方を調整します。
3. 対象のMesh Rendererに割り当て、同じ照明で見比べます。

## 試すときのポイント

同じマテリアルを使うEntityには、変更がまとめて反映されます。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./materials.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
