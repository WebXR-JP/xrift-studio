# PBRの色と光沢を調整する

[動画を再生する：PBRの色と光沢を調整する](./media/tutorials/lesson-02-03.mp4)

## このレッスンでできること

Boxへ自分のPBRマテリアルを割り当て、色と反射を調整します。

## 始める前に

- BoxなどのEntityを置き、Stopで編集へ戻ります。
- 一つだけ変える練習では、共有中の素材を直接上書きせず、新しいマテリアルを作ります。

## 操作の要点

1. Assetsの追加メニューか右クリックから「新規マテリアル」を選びます。
2. マテリアルを選び、InspectorでBase Colorを変えます。
3. まずMetallicを0、Roughnessを0.5にして違いを見やすくします。
4. HierarchyでBoxを選び、「Mesh Renderer → マテリアル」に作成した素材を指定します。
5. Assetsで同じマテリアルを選び直し、Roughnessを0.15と0.8で比べます。同じ照明・視点で確認してください。
6. 金属を試すときはMetallicを1にし、IBLなど反射する環境も用意します。

## できたか確認する

- 選んだBoxに自作の色が付き、Mesh Rendererの割り当ても一致する。
- Roughnessを上げると反射がぼけることを、同じシーンで比べられる。

## うまくいかないとき

- 色が変わらない：選択中のマテリアルとMesh Rendererの割り当てを確認します。
- ほかのEntityも変わる：同じ素材を共有しています。[一つだけ色を変える](./materials.md#一つだけ色を変える)手順へ戻ります。
