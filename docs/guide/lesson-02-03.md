# PBRの色と光沢を調整する

[動画を再生する：PBRの色と光沢を調整する](./media/tutorials/lesson-02-03.mp4)

## このレッスンでできること

`Box`に自分だけのPBRマテリアルを割り当て、色やツヤの見え方を調整します。

## 始める前に

- `Box`などのEntityを配置し、Play中ならStopで編集画面へ戻ります。
- ほかのオブジェクトの色まで一緒に変わらないよう、共有中のマテリアルは直接変えず、新しくマテリアルを作って練習します。

## 操作の要点

1. Assetsの追加メニュー、または右クリックから「新規マテリアル」を選びます。
2. 作成したマテリアルを選び、Inspectorで`Base Color`を好みの色に変えます。
3. まずは`Metallic`を`0`、`Roughness`を`0.5`にして、基準となる質感を見やすくしておきます。
4. Hierarchyで`Box`を選び、「Mesh Renderer → マテリアル」に作成したマテリアルを割り当てます。
5. Assetsでそのマテリアルを選び直し、`Roughness`を`0.15`と`0.8`で変えて、同じ照明・同じ視点のままツヤの違いを見比べます。
6. 金属らしい質感を試したいときは、`Metallic`を`1`にし、IBLなどの反射環境も用意しておくと自然な光沢が出ます。

## できたか確認する

- 選んだ`Box`に作成したマテリアルの色が反映され、`Mesh Renderer`の割り当ても一致しました。
- `Roughness`を上げるほど反射がやわらかくぼやけることを、同じシーン上で見比べられました。

## うまくいかないとき

- **色を変えても見た目が変わらない**：編集しているマテリアルと、`Box`の`Mesh Renderer`に割り当てられているマテリアルが同じか確認してください。
- **ほかのEntityの色まで一緒に変わった**：同じマテリアルを複数のEntityで共有しています。[一つだけ色を変える手順](./materials.md#一つだけ色を変える)を参考に、専用のマテリアルを割り当ててください。
