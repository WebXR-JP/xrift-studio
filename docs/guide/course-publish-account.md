# 公開用のアカウントを確認する

動画：未収録（文章で進められます）

## このレッスンでできること

自分のXRiftアカウントで公開する準備を整えます。デスクトップ版のログイン手順と、ブラウザ版βでAPIキーを使う手順をそれぞれ確認します。

## 始める前に

[公開前のバックアップと作品情報を整える](./course-publish-prepare.md)を済ませておきます。アカウントへのログインやAPIキーの発行・入力は、必ずアカウントの持ち主ご自身で行ってください。パスワードやAPIキーは、メモの共有・AIチャット・問い合わせ・画面録画などに含めないよう気をつけてください。

## 手順

### 1. 公開に使うXRiftアカウントを確認する

1. [XRift](https://app.xrift.net/)を開きます。
2. ログインしていない場合は、お使いの方法でログインします。初めて利用する場合は、公式画面の登録案内と利用規約を確認してアカウントを作成してください。
3. 表示名を見て、今回の作品を公開したいアカウントになっているか確認します。

ブラウザでXRiftにログインしただけでは、デスクトップ版の認証やブラウザ版βへのAPIキー入力は完了していません。お使いの環境に合わせて、次の手順へ進んでください。

### 2-A. デスクトップ版から公開する場合

1. XRift Studioで、公開したいプロジェクトを開きます。
2. 「XRiftへ公開」を押し、「XRiftアカウント」の欄を確認します。
3. 未ログインになっていたら「ログイン」を押します（公開用のセットアップが案内された場合は、先にそちらを完了してください）。
4. 開いたブラウザで、ご自身のXRiftアカウントで認証を完了します。別のアカウントでログインしていた場合はそのまま進めず、公開したいアカウントに切り替えてください。
5. Studioに戻り、「ログインしました」という通知や公開画面のアカウント表示を確認します。

認証はアプリが公式ツール経由で行うため、認証用の設定ファイルを自分で編集する必要はありません。

### 2-B. ブラウザ版βから公開する場合

ブラウザ版βの送信で使うAPIキーは、ワールドやアイテムを書き込める大切な秘密情報です。ご自身が管理している端末で扱ってください。

1. [XRiftの設定](https://app.xrift.net/settings)を開きます。
2. 「APIキー」の「新規作成」を押し、用途が分かりやすい「キー名」を入力します（例：「Studioのワールド公開用」）。
3. 「スコープ」では、ワールドなら`write:worlds`、アイテムなら`write:items`を選びます。必要な権限だけを選び、関係のない権限は付けないようにしてください。必要であれば「有効期限（任意）」も設定します。
4. 権限と期限を確かめて「作成」を押します。表示されたキーは周囲に見えない場所で扱ってください。
5. Studioの公開画面へ戻り、「XRift APIキー」欄にキーを入力します。ここではまだアップロードボタンを押しません。

なお、公式の[Public API v1資料](https://docs.xrift.net/public-api/v1)では確認時点で読み取り用スコープのみが掲載されていますが、Studioの公開機能ではワールドに`write:worlds`、アイテムに`write:items`が必要です。実際の設定画面でこれらの権限を選べない場合は、別の権限を試さず、プロジェクトを書き出してデスクトップ版のログイン方式で公開してください。

#### APIキーをブラウザに保存するかどうか選ぶ

StudioはAPIキーをプロジェクトデータやWeb Storageには保存しないため、公開画面を閉じると入力したキーは消えます。

対応しているブラウザでは、送信後に「APIキーをブラウザに保存」を選べます。保存確認とキーの選択を終え、保存完了の表示を確認してください。次回からは自動入力や「保存済みキーを選ぶ」を使えます。ただし、ブラウザの同期設定によっては別端末にも共有されることがあるため、共有パソコンなどでは保存しないでください。

## できたか確認する

- 作品を公開するXRiftアカウントを確認できました。
- デスクトップ版では、Studio側もログイン済みになりました。
- ブラウザ版βでは、必要なスコープを確認したAPIキーを公開画面へ入力できました。
- パスワードやAPIキーが、作品データ・チャット・録画などに残っていないことを確認しました。

## うまくいかないとき

- **ブラウザで認証したのにStudioが未ログインのまま**：Studioから開いた認証画面で最後まで完了したか確認してください。「ログインを完了してください」と表示されている場合は、開いた公式画面の案内を確認します。
- **`401`エラーが出る**：APIキーの期限切れ・無効化・入力ミスがないか確認してください。問い合わせるときも、キー自体は本文に貼り付けないでください。
- **`403`エラーが出る**：APIキーのスコープと、更新先ワールドの所有アカウントが合っているか確認します。必要な範囲を超えて権限を増やさないよう注意してください。
- **APIキーを他人に見られたかもしれない**：そのキーはそのまま使わず、XRiftの設定画面から無効化・管理してください。ブラウザに保存していた場合は、ブラウザ側の保存情報も見直します。
