# 保存して制作を再開する

編集内容は自動保存され、次回はプロジェクト一覧から開けます。XRiftで公開するには、保存後に公開の操作が必要です。

iPadではブラウザに保存されます。手元にファイルを残すには、「プロジェクトを書き出す」で`.xriftstudio`ファイルを保存してください。パソコンへ渡す方法は、[iPadの案内](./ipad.md)を参照してください。以下はデスクトップ版の操作です。

## 自動保存を確認する

ビジュアルエディターのシーン、Script、GLSLと、コードエディターのテキストは、編集すると自動保存されます。通常は保存ボタンやショートカットを押す必要はありません。

プロジェクト名の近くに「保存待ち」「保存中」「保存済み」と表示されます。アプリを終了する前に、「保存済み」を確認してください。「保存エラー」が出た場合は、編集画面を閉じずにエラーの内容を確かめます。

Ctrl + S、Macでは⌘ + Sを押すと、その時点の変更をすぐに保存できます。

## 次回開く

エディターの「プロジェクト一覧」を押すと、残っている変更が保存されてから一覧に戻ります。作品のカードを選ぶと、続きを編集できます。

名前やサムネイルを設定すると、作品が増えても見分けやすくなります。公開用の日本語タイトルと、フォルダー名に使うプロジェクト名は、それぞれ設定できます。

## 新しいワールドを直接開く

ブラウザ版の `/new` を開くと、新しいワールドをブラウザに保存し、そのままビジュアルエディターが開きます。開くたびに別の作品を作ります。作成後のURLには作品のプロジェクトIDが付くので、続きを編集するときはそのURLを使ってください。

ChatGPT版も、新規起動から共通のエディターへ進みます。作品が開かれていない状態でも、会話で新規制作を頼めます。ChatGPTは `create_world` で作品を作成し、保存とScene Viewへの反映を確認します。既存作品の再開には作品リンクか、エディターの「プロジェクト一覧」を使ってください。

会話での作成・追編集は、Editorを開く前にも続けられます。途中の編集では画面を開かず、確認するときに最新の結果を共通Editorへ取り込みます。データの編集、ブラウザへの保存、画面への反映、Scene View画像の受信は、それぞれ確認します。画像が届かない場合も編集データは使えますが、見た目は未確認です。

Sitesには作品や素材の保存領域を設けていません。会話内の編集結果を次の編集へ引き継ぎ、Editorへ取り込んだ作品はブラウザに保存します。会話の履歴だけを確実なバックアップとは扱わず、制作後は`.xriftstudio`ファイルも書き出してください。

## ブラウザ版で作品へのリンクを使う

ブラウザ版で作品を開くと、URLに保存済みのプロジェクトIDが付きます。そのURLをブックマークすると、次回は作品一覧を挟まず、同じ作品を共通のエディターで開けます。

リンクは、このブラウザの同じサイトに保存した作品を指定します。別の端末やサイトへ作品データを送る共有リンクではありません。作品が見つからない場合はエラーが表示されるので、作品一覧から選ぶか、書き出したファイルを取り込んでください。同じIDの作品ファイルを追加で取り込むと、コピーに新しいIDを付け、元の作品へのリンクを保ちます。

ChatGPT版も同じプロジェクトID・保存処理・エディターを使います。ChatGPT版への作品リンクはプラグインのエディターを直接開きます。通常のブラウザ版とChatGPTの表示領域では保存先が分かれるため、作品の受け渡しにはファイルの書き出しと取り込みを使ってください。自動同期はありません。

## バックアップする

大きく作り替える前は、作品のカードから「複製」するか、「.xriftstudioファイルに書き出す」でバックアップしてください。

別のパソコンでは、「ファイルから取り込む」で`.xriftstudio`ファイルを開けます。従来の`.zip`ファイルも取り込めます。複製や取り込みで作られたプロジェクトは、元の作品とは別の未公開プロジェクトになります。

VRM 0.xやVRM 1.0のファイルと、Inspectorで編集したMToonの色、輪郭線、テクスチャも保存されます。取り込み先でモデルのMaterialsを開き、設定と見た目を確認してください。操作は[VRMの案内](./assets.md#vrmアバターを取り込む)を参照してください。

Ctrl + Zで取り消せる範囲は限られます。変更前の状態を確実に残すには、ファイルに書き出しておいてください。

## コードエディターへ書き出す

デスクトップ版の上部にある「コードエディターへ書き出す」から、シーンと素材を既存のコードプロジェクトに追加できます。MToonの設定とVRMモデルも書き出されます。

1. 「コードプロジェクトを選ぶ」で書き出し先を選びます。ワールドはワールド、アイテムはアイテムのコードプロジェクトを指定してください。
2. 「Componentとして追加」を選ぶと、既存の起動ファイルが保たれます。書き出し後に「組み込み用コードをコピー」を使い、既存の`World.tsx`か`Item.tsx`に追加してください。
3. 書き出したシーンから起動する場合は、「起動するシーンを切り替える」を選びます。起動ファイルのバックアップと置き換えを確認してください。
4. 「必要なパッケージ」の案内を読んで、「コードエディターへ書き出す」を押します。
5. 完了画面の「フォルダーを開く」か「VS Codeで開く」から、生成内容を確認できます。パッケージのインストールが必要な場合は、表示された手順を実行してからシーンを開いてください。

元のビジュアルプロジェクトも引き続き編集できます。ただし、書き出したコードの変更はビジュアルエディターに自動では戻りません。バックアップや別端末でのビジュアル編集には、[.xriftstudioファイル](#バックアップする)を使ってください。

### VS Codeやターミナルが開かない

「VS Codeで開く」を使うには、VS Codeのインストールと`code`コマンドの設定が必要です。macOSでは、VS Codeのコマンドパレットで`Shell Command: Install 'code' command in PATH`を実行し、XRift Studioを再起動してください。各OSでの設定は、[VS Codeの公式案内](https://code.visualstudio.com/docs/configure/command-line)を参照してください。

「ターミナルを開く」では、プロジェクトのフォルダーを作業場所として起動します。WindowsではWindows Terminalを探し、見つからなければコマンドプロンプトを開きます。macOSではTerminalを使います。Linuxでは、GNOME Terminal、Konsole、Xfce Terminal、システムのターミナル、xtermの順に探します。対応するターミナルがない場合は、画面の案内に従ってインストールしてください。

## 保存したのに見つからない

プロジェクト一覧の検索と絞り込みを解除してください。似た名前の複製や、別の保存先を開いていないかも確認します。

保存エラーが出ていた場合は、保存が完了していない可能性があります。編集画面を閉じずに、エラーの内容と保存先を確認してください。

## データを消さずに復旧する

パネルの位置や大きさの問題は、「パネル配置を初期化」で戻せます。プロジェクトのデータは削除されません。

「完全リセット」では、保存済みプロジェクトやログイン情報も削除され、元に戻せません。不具合が出たら、先に[復旧と問い合わせ](./recovery.md)の手順を確認してください。

## 一部だけ別のワールド・アイテムへ渡す

Hierarchyで選んだEntityを、子Entityと必要な素材も含めて`.xriftstudio`ファイルに書き出せます。追加先では「.xriftstudioからHierarchyへ追加」を使ってください。プロジェクト全体を開き直さず、必要な部分を取り込めます。詳しくは[Entityを別のワールド・アイテムへ渡す](./hierarchy-transfer.md)を参照してください。
