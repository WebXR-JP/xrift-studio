# 保存して制作を再開する

編集内容は自動保存され、次回もプロジェクト一覧から制作を再開できます。**保存**と**XRiftへの公開**は別の操作です。

iPadではブラウザに保存し、**プロジェクトを書き出す**から`.xriftstudio`ファイルを手元に残します。パソコンへの受け渡しは[iPadの案内](./ipad.md)を参照してください。以下はデスクトップ版の保存手順です。

## 自動保存を確認する

ビジュアルエディターのシーン・Script・GLSLと、コードエディターのテキスト編集は**自動保存**されます。通常は、保存ボタンやショートカットを押す必要はありません。

画面上部のプロジェクト名の近くに、**保存待ち**・**保存中**・**保存済み**が表示されます。**保存済み**になれば、変更は保存されています。アプリを終了するときは、この表示を確認します。

**保存エラー**が出た場合は、編集画面を閉じずにエラーの内容を確認してください。

必要なときは **Ctrl + S**（Macは **⌘ + S**）で、その時点の変更をすぐに保存することもできます。

## 次回開く

エディターの**プロジェクト一覧**を押すと、残っている変更を保存してから一覧に戻ります。プロジェクト一覧にある、作成したプロジェクトのカードを選ぶと制作を再開できます。

名前やサムネイルを付けておくと、作品が増えても見分けられます。公開する日本語のタイトルと、フォルダー名として使うプロジェクト名は別です。

## バックアップする

大きく作り替える前は、プロジェクトのカードから**複製**して別のプロジェクトを作るか、**.xriftstudioファイルに書き出す**で手元に残します。

別のパソコンへ渡す場合は、保存した`.xriftstudio`ファイルを**ファイルから取り込む**で開きます。従来の`.zip`ファイルも取り込めます。複製・取り込み後のプロジェクトは未公開となり、元とは別の作品として扱われます。

**Ctrl + Zだけをバックアップの代わりにしないでください。** 取り消しで戻れる範囲と、ファイルとして残したバックアップは異なります。

## 保存したのに見つからない

プロジェクト一覧の検索文字と絞り込みを解除してください。似た名前の複製や、別の保存先を開いていないかも確認します。

保存エラーがあった場合は、まだ保存が完了していない可能性があります。編集画面を閉じずに、エラー文と保存先を確認してください。

## データを消さずに復旧する

レイアウトの問題なら、まず**パネル配置を初期化**を使います。プロジェクトを消す操作ではありません。

**完全リセットは元に戻せません。** 保存済みプロジェクトやログイン情報なども消えるため、不具合対応の最初の手段にはしません。[復旧と問い合わせ](./recovery.md)で安全な順番を確認してください。
