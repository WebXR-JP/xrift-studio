# 保存して制作を再開する

作ったものを確実に残し、次回も同じプロジェクトを開ける状態にします。**保存**と**XRiftへの公開**は別の操作です。

iPadではブラウザに保存し、**プロジェクトを書き出す**からZIPを手元に残します。パソコンへの受け渡しは[iPadの案内](./ipad.md)を参照してください。以下はデスクトップ版の保存手順です。

## 保存する

**Ctrl + S**（Macは**⌘ + S**）で保存します。初回に名前や保存先を求められたら入力し、画面の保存状態を確認します。

自動保存にも対応していますが、保存エラーが出ている状態で終了しないでください。特に新しいプロジェクトでは、一度保存できたことを確かめます。

## 次回開く

エディターからライブラリへ戻る前に保存します。プロジェクト一覧にある、作成したプロジェクトのカードを選ぶと制作を再開できます。

名前やサムネイルを付けておくと、作品が増えても見分けられます。公開する日本語のタイトルと、フォルダー名として使うプロジェクト名は別です。

## バックアップする

大きく作り替える前は、プロジェクトのカードから**複製**して別のプロジェクトを作るか、**ZIPに書き出す**で手元に残します。

別のパソコンへ渡す場合は、保存したZIPを**ZIPから取り込む**で開きます。複製・取り込み後のプロジェクトは未公開となり、元とは別の作品として扱われます。

**Ctrl + Zだけをバックアップの代わりにしないでください。** 取り消しで戻れる範囲と、ファイルとして残したバックアップは異なります。

## 保存したのに見つからない

プロジェクト一覧の検索文字と絞り込みを解除してください。似た名前の複製や、別の保存先を開いていないかも確認します。

保存エラーがあった場合は、まだ保存が完了していない可能性があります。編集画面を閉じずに、エラー文と保存先を確認してください。

## データを消さずに復旧する

レイアウトの問題なら、まず**パネル配置を初期化**を使います。プロジェクトを消す操作ではありません。

**完全リセットは元に戻せません。** 保存済みプロジェクトやログイン情報なども消えるため、不具合対応の最初の手段にはしません。[復旧と問い合わせ](./recovery.md)で安全な順番を確認してください。
