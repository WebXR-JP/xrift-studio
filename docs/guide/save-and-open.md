# 保存して制作を再開する

編集した内容は自動で保存されるため、次回はプロジェクト一覧からそのまま続きを開けます。なお、XRift上で他の人が遊べるようにするには、保存したあとで別途公開の操作が必要です。

iPadなどのブラウザ版では、作品データはブラウザ内に保存されます。手元にファイルとして残したい場合は、「プロジェクトを書き出す」で`.xriftstudio`ファイルを保存してください。パソコンへ渡す手順は[iPadの案内](./ipad.md)にまとめています。以下ではデスクトップ版の操作を説明します。

## 自動保存を確認する

ビジュアルエディターのシーン・Script・GLSLや、コードエディターのテキストは、編集すると自動で保存されます。通常は操作のたびに保存ボタンを押す必要はありません。

画面上部のプロジェクト名の近くに、「保存待ち」「保存中」「保存済み」のいずれかが表示されます。アプリを終了する前に「保存済み」になっているか確認しておきましょう。「保存エラー」が出たときは、編集画面を閉じずにエラーの内容を確かめてください。

その時点の変更をすぐ保存したいときは、`Ctrl + S`（Macでは `⌘ + S`）を押します。

## 次回開く

エディターの「プロジェクト一覧」を押すと、未保存の変更を保存したうえで一覧画面に戻ります。作品カードを選べば、前回の続きから編集を再開できます。

作品が増えても探しやすいように、名前やサムネイルを設定しておくと便利です。公開時に表示される日本語タイトルと、フォルダー名に使うプロジェクト名は別々に設定できます。

コードエディターの`xrift.json`設定は、「保存」ボタンか保存ショートカットで保存します。別のファイルやJSON表示へ切り替えるとき、プロジェクト一覧へ戻るとき、Play・チェック・公開を始めるときにも変更が先に保存されます。保存に失敗した場合は、入力中の内容を残したまま現在の画面にとどまります。

## バックアップする

大きく作り替える前は、作品カードのメニューから「複製」するか、「.xriftstudioファイルに書き出す」でバックアップを取っておきましょう。

別のパソコンへ移すときは、プロジェクト一覧の「ファイルから取り込む」から`.xriftstudio`ファイルを開けます（従来の`.zip`ファイルにも対応しています）。複製や取り込みで作ったプロジェクトは、元の作品とは別の未公開プロジェクトとして扱われます。

VRM 0.xやVRM 1.0のファイル、およびInspectorで調整したMToonの色・輪郭線・テクスチャも一緒に保存されます。取り込み先ではモデルのMaterialsを開き、設定と見た目にずれがないか確認してください。詳しい操作は[VRMの案内](./assets.md#vrmアバターを取り込む)をご覧ください。

`Ctrl + Z` で取り消せる履歴には限りがあります。確実に元の状態へ戻せるようにするには、節目のタイミングでファイルに書き出しておくのが安心です。

## コードエディターへ書き出す

デスクトップ版の上部にある「コードエディターへ書き出す」を使うと、ビジュアルエディターのシーンと素材を既存のコードプロジェクトへ追加できます。MToonの設定やVRMモデルも一緒に書き出されます。

1. 「コードプロジェクトを選ぶ」で書き出し先を指定します。ワールドはワールド用、アイテムはアイテム用のコードプロジェクトを選んでください。
2. 「Componentとして追加」を選ぶと、既存の起動ファイルはそのまま残ります。書き出し後に「組み込み用コードをコピー」を使い、既存の`World.tsx`または`Item.tsx`へ組み込みます。
3. 書き出したシーンから直接起動したい場合は、「起動するシーンを切り替える」を選び、起動ファイルのバックアップと置き換えを確認します。
4. 「必要なパッケージ」の案内を確認して、「コードエディターへ書き出す」を押します。
5. 完了画面の「フォルダーを開く」または「VS Codeで開く」から生成結果を確認できます。パッケージの導入が必要な場合は、画面に表示された手順を済ませてからシーンを開いてください。

元のビジュアルプロジェクトも引き続き編集できますが、書き出したあとのコード側への変更はビジュアルエディターへ自動では反映されません。バックアップや別の端末でビジュアル編集を続けたいときは、[.xriftstudioファイル](#バックアップする)を使ってください。

### VS Codeやターミナルが開かない

「VS Codeで開く」を利用するには、VS Codeのインストールに加えて`code`コマンドの設定が必要です。macOSでは、VS Codeのコマンドパレットから `Shell Command: Install 'code' command in PATH` を実行したあと、XRift Studioを再起動してください。各OSでの詳しい設定方法は、[VS Codeの公式案内](https://code.visualstudio.com/docs/configure/command-line)をご覧ください。

「ターミナルを開く」は、プロジェクトフォルダーを作業場所としてターミナルを起動します。OSごとに次の順でアプリを探します。

- **Windows**：Windows Terminal（見つからない場合はコマンドプロンプト）
- **macOS**：Terminal
- **Linux**：GNOME Terminal → Konsole → Xfce Terminal → システムのターミナル → xterm

対応するターミナルが入っていない場合は、画面の案内に従ってインストールしてください。

## 保存したのに見つからない

まずはプロジェクト一覧の検索欄や絞り込み条件を解除してみてください。似た名前の複製プロジェクトや、別の保存先フォルダーを開いていないかも確認します。

直前に保存エラーが出ていた場合は、変更が保存しきれていない可能性があります。編集画面を閉じずに、エラーの内容と保存先を確かめてください。

## データを消さずに復旧する

パネルの位置や大きさが崩れただけであれば、「パネル配置を初期化」で元に戻せます。プロジェクトのデータは消えません。

一方で「完全リセット」を実行すると、保存済みプロジェクトやログイン情報も削除され、元に戻せなくなります。不具合が起きたときは、リセットする前に必ず[復旧と問い合わせ](./recovery.md)の手順を確認してください。

## 一部だけ別のワールド・アイテムへ渡す

Hierarchyで選んだEntityだけを、子Entityや必要な素材とまとめて`.xriftstudio`ファイルに書き出すこともできます。受け取る側のプロジェクトで「.xriftstudioからHierarchyへ追加」を使えば、プロジェクト全体を開き直さずに必要なパーツだけを取り込めます。詳しくは[Entityを別のワールド・アイテムへ渡す](./hierarchy-transfer.md)をご覧ください。
