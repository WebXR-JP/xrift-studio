# 煙・雪・光の粒を置く

パーティクルは、小さな粒を大量に飛ばして煙、雪、火花、光の粒などを表現する素材です。

## 見本を追加する

まずは見本から試すと仕組みがつかみやすくなります。「Assets → アセットストア → Particle」から好みのプリセットを選んで追加し、シーン上の配置場所と粒が飛ぶ方向を確認します。

自分で一から作りたい場合は、Assetsの追加メニューで新しいパーティクルを作成し、シーンへドラッグ＆ドロップすると粒を放出するEntityとして配置できます。

## 見た目を調整する

Assetsでパーティクル素材を選ぶと、Inspectorで次の項目を調整できます。

- 放出数
- 粒が消えるまでの時間（寿命）
- 移動する速さ
- 色と大きさ

最初から多くの項目を同時にいじるより、まずは放出数と大きさから1つずつ動かして変化を見比べると調整しやすくなります。

粒が長く残る設定では、時間がたつにつれて画面上の粒が増え、処理が重くなることがあります。配置した直後だけでなく、Playをしばらく続けた状態で動作を確認してください。

## 押したときだけ出す

「3Dセット → 紙吹雪のボタン」を使うと、ボタンを押したタイミングで粒を放出する見本を試せます。設定済みの[Node Graph](./interactivity.md)を開けば、ワールド開始時に放出を止めておき、操作されたときだけ放出する構成をそのまま確認できます。

## 重い・画面を隠してしまう

動作が重くなったり、粒で画面が見づらくなったりしたときは、放出数、粒が残る時間、粒の大きさを下げて見比べてみてください。大きな半透明の粒がカメラの近くで幾重にも重なると、視界を遮るだけでなく描画負荷も大きく増えます。あわせて[軽くする方法](./performance.md)も参照してください。
