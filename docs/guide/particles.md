# 煙・雪・光の粒を置く

パーティクルは、小さな粒で煙、雪、火花などを表現する素材です。

## 見本を追加する

「Assets → 外部から追加 → Particle」で、見本を選んで追加してください。配置された位置と、粒が出る方向を確認します。

自分で作る場合は、Assetsでパーティクルを作ってください。シーンへドラッグすると、粒を放出するEntityを配置できます。

## 見た目を調整する

パーティクル素材を選ぶと、放出数、粒が消えるまでの時間、速さ、色、大きさを変えられます。最初は放出数と大きさから、一つずつ調整してください。

粒が長く残る設定では、時間がたつほど処理が重くなる場合があります。編集直後の確認に加え、Playをしばらく続けてください。

## 押したときだけ出す

「3Dセット → 紙吹雪のボタン」は、押すと粒が出る見本です。設定済みの[Node Graph](./interactivity.md)を開くと、開始時に放出を止め、操作時に放出する処理を確認できます。

## 重い・画面を隠してしまう

放出数、粒が残る時間、大きさを下げて比べてください。大きな半透明の粒が近くに重なると、視界を遮ったり描画の負荷が増えたりします。[軽くする方法](./performance.md)も参照してください。
