# 煙・雪・光の粒を置く

**パーティクル**は、小さな粒を使って煙、雪、火花などを表現する素材です。

## 見本を追加する

**Assets → 外部から追加 → Particle**で、使いたい見本を選んで追加します。シーンに配置された位置と、粒が出る方向を確認してください。

自分で作る場合は、Assetsでパーティクルを作り、シーンへドラッグして放出用のEntityを配置します。

## 見た目を調整する

パーティクル素材を選び、放出数、粒が消えるまでの時間、速さ、色、大きさを調整します。一度にすべて変えず、まず放出数と大きさから試します。

表示された粒が長く残る設定では、時間がたつほど重くなる場合があります。編集直後だけでなく、しばらくPlayを続けて確認してください。

## 押したときだけ出す

**3Dセット → 紙吹雪のボタン**は、ボタンを押すと粒を出す見本です。設定済みの[ノードグラフ](./interactivity.md)を見て、開始時に止める処理と操作時に出す処理を確認できます。

## 重い・画面を隠してしまう

放出数、残る時間、粒の大きさを下げて比較します。近くに大きな半透明の粒が重なると、視界や描画負荷に影響します。[軽くする方法](./performance.md)も確認してください。
