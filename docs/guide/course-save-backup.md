# 保存して開き直し、バックアップを残す

動画：未収録（文章で進められます）

## このレッスンでできること

練習したワールドを保存して開き直し、プロジェクト全体の`.xriftstudio`ファイルを一つ残します。自動保存、ファイルへの書き出し、XRiftへの公開の違いも確認します。

## 始める前に

- [新しいプロジェクト](./lesson-01-01.md)を作り、位置や色を一つ変更しておきます。
- 開き直したときに比べられるよう、変えたEntityの名前、位置、色を覚えておきます。
- Play中ならStopで編集に戻り、素材の取り込みや変換が終わるまで待ちます。

## 手順

### 1. 自動保存の完了を確認する

画面上部の保存状態を見ます。変更後は「保存待ち」「保存中」を経て、デスクトップ版では「保存済み」、ブラウザ版では「ブラウザに保存済み」になります。通常は毎回保存ボタンを押す必要はありません。

「保存エラー」が出たら、編集画面を閉じずに内容を確認してください。「再試行」で保存をやり直せます。保存の完了を確認する前に、アプリやタブを閉じて試さないでください。

### 2. 一覧から同じ作品を開き直す

**デスクトップ版**：エディターの「プロジェクト一覧」を押し、先ほどの作品のカードを選びます。一覧へ戻るときにも、残っている変更の保存が行われます。

**ブラウザ版**：上部の「プロジェクトを開く」を押し、「このブラウザから開く」で同じ作品を選びます。iPadでは「ファイル → プロジェクトを開く」から進みます。

Hierarchyで変更したEntityを選び、Inspectorの値とシーンの見た目を確認します。覚えておいた位置や色が残っていれば、制作を再開できています。

### 3. プロジェクト全体を書き出す

**デスクトップ版**

1. 保存状態を確認し、「プロジェクト一覧」へ戻ります。
2. 対象の作品のカードにある「.xriftstudioファイルに書き出す」を選びます。
3. 保存先とファイル名を確認して書き出し、ファイルができたことを確かめます。

**ブラウザ版・iPad**

1. 上部の「プロジェクトを書き出す」を押します。iPadでは「ファイル → プロジェクトを書き出す」です。
2. 準備が終わったら、表示されたファイル名と容量を確認します。
3. 「ダウンロード」を押し、ブラウザのダウンロード一覧で完了と保存先を確かめます。Safariでは、iPadの「ファイル」でも保存先を確認できます。

見つけやすい場所に、日付や「色変更前」など区切りが分かる名前で保管してください。「ダウンロードを開始しました」の表示だけで終わらず、保存されたファイルを確認します。

### 4. バックアップを開いて確認する

1. プロジェクト一覧の「ファイルから取り込む」から、書き出した`.xriftstudio`を選びます。ブラウザの編集画面では「プロジェクトを開く → ファイルから開く → ファイルを選ぶ」からも取り込めます。
2. 取り込んだ作品で、変更したEntity、色、必要な素材が残っているか確認します。
3. 元の作品と見分け、今後どちらを編集するか決めます。取り込んだ作品は別の未公開プロジェクトです。元の公開先の更新にはなりません。

これはバックアップから開けるかを試す手順です。元の作品を削除する必要はありません。

### 5. 全体のバックアップと部分書き出しを区別する

プロジェクト全体の書き出しには、シーン、Assets、Prefab、取り込んだ素材が含まれます。

Hierarchyの「選択範囲を書き出す」も同じ`.xriftstudio`形式ですが、選んだEntityと子Entity、必要な素材だけを渡す操作です。選択していないEntityやシーン全体の空・照明の設定などは含まれません。全体のバックアップには、手順3を使ってください。

部分だけ別の作品に追加する操作は[Entityの受け渡し](./hierarchy-transfer.md)で説明しています。「コードエディターへ書き出す」も用途が異なるため、この練習では使いません。

## できたか確認する

- 開き直しても、変更した位置や色が残っている
- プロジェクト全体の`.xriftstudio`を、見つけられる場所に保存した
- ファイルから取り込んだ別プロジェクトでも、必要な内容を確認できた
- 自動保存やファイルの書き出しだけでは、XRiftで公開されないと分かる

## うまくいかないとき

- **一覧に作品がない**：検索や絞り込みを解除します。ブラウザ版では、同じ端末・ブラウザを使っているか確認してください
- **書き出しのボタンが使えない**：Stopで戻り、取り込みや変換の完了を待ちます。書き出しに失敗した場合は、エラーを読んでから再試行してください
- **取り込んだら一部のEntityしかない**：Hierarchyの部分書き出しを使っていないか確認します。元の作品からプロジェクト全体を書き出し直してください
- **ブラウザで大きなファイルを開けない**：ファイル本体と展開後のデータはそれぞれ256 MB以内、ファイル数は20,000以内です。超える場合はデスクトップ版で扱います
- **保存できない**：エラーと空き容量を確認します。サイトデータの削除や「完全リセット」は保存済み作品を失うため、先に[復旧の案内](./recovery.md)を確認してください
