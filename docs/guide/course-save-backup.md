# 保存して開き直し、バックアップを残す

動画：未収録（文章で進められます）

## このレッスンでできること

練習で作ったワールドをきちんと保存して開き直し、プロジェクト全体のバックアップ（`.xriftstudio`ファイル）を一つ残します。あわせて、自動保存・ファイルへの書き出し・XRiftへの公開の違いを確認します。

## 始める前に

- [新しいプロジェクトを作る](./lesson-01-01.md)でワールドを作り、オブジェクトの位置や色を何か一つ変えておきます。
- 開き直したあとで比べやすいよう、変えたEntityの名前・位置・色をメモしておきます。
- Play中ならStopで編集に戻り、素材の取り込みや変換が終わるまで待ちます。

## 手順

### 1. 自動保存が完了したか確認する

画面上部にある保存状態の表示を見ます。編集すると「保存待ち」「保存中」と変わり、デスクトップ版では「保存済み」、ブラウザ版では「ブラウザに保存済み」になります。通常は自動で保存されるため、毎回手動で保存ボタンを押す必要はありません。

もし「保存エラー」と表示されたら、編集画面を閉じずにエラーの内容を確認してください。「再試行」を押すと保存をやり直せます。保存が終わる前にアプリやタブを閉じると直前の変更が失われることがあるため、必ず完了表示を確認してから閉じてください。

### 2. 一覧から同じ作品を開き直す

- **デスクトップ版**：エディターの「プロジェクト一覧」を押し、先ほどの作品のカードを選びます。一覧へ戻るときにも、残っている変更が保存されます。
- **ブラウザ版**：上部の「プロジェクトを開く」から「このブラウザから開く」を選び、同じ作品を開きます。iPadでは「ファイル → プロジェクトを開く」を使います。

開いたらHierarchyで変更したEntityを選び、Inspectorの数値やシーンの見た目を確認します。メモしておいた位置や色がそのまま残っていれば、問題なく保存できています。

### 3. プロジェクト全体を書き出す

#### デスクトップ版

1. 保存完了を確認してから「プロジェクト一覧」へ戻ります。
2. 対象の作品のカードにある「.xriftstudioファイルに書き出す」を選びます。
3. 保存先とファイル名を決めて書き出し、指定した場所にファイルができていることを確認します。

#### ブラウザ版・iPad

1. 上部の「プロジェクトを書き出す」を押します（iPadでは「ファイル → プロジェクトを書き出す」です）。
2. 準備が終わったら、表示されたファイル名と容量を確認します。
3. 「ダウンロード」を押し、ブラウザのダウンロード一覧で完了と保存先を確認します。Safariの場合は、iPadの「ファイル」アプリでも保存先を確かめられます。

日付や「色変更前」など区切りが分かる名前にして、見つけやすい場所へ保管しておきましょう。「ダウンロードを開始しました」と表示されたら、保存先にファイルが入っていることも確認しておくと安心です。

### 4. バックアップから開けるか試す

1. プロジェクト一覧の「ファイルから取り込む」から、書き出した`.xriftstudio`ファイルを選びます。ブラウザ版の編集画面では「プロジェクトを開く → ファイルから開く → ファイルを選ぶ」からも取り込めます。
2. 取り込んだプロジェクトを開き、変更したEntityや色、必要な素材がそろっているか確認します。
3. 元の作品と見分けられるようにし、これからどちらを編集するか決めておきます。ファイルから取り込んだプロジェクトは別の未公開プロジェクトとして扱われるため、公開済みワールドの更新先にはなりません。

これはバックアップから復元できるかを確かめる練習なので、元のプロジェクトはそのまま残しておいて大丈夫です。

### 5. 全体のバックアップと部分書き出しの違いを知る

プロジェクト全体の書き出しには、シーン・Assets・Prefab・取り込んだ素材がすべて含まれます。

Hierarchyの「選択範囲を書き出す」も同じ`.xriftstudio`形式ですが、こちらは選んだEntityとその子Entity、必要な素材だけを別の作品へ渡すための機能です。選んでいないEntityや空・照明などのシーン設定は含まれないため、全体のバックアップには必ず手順3を使ってください。

一部のEntityだけを別の作品へ移す方法は[Entityを別のワールド・アイテムへ渡す](./hierarchy-transfer.md)で詳しく説明しています。また、「コードエディターへ書き出す」はコード編集へ移るための機能なので、バックアップには使いません。

## できたか確認する

- プロジェクトを開き直しても、変更した位置や色が残っていることを確認できました。
- プロジェクト全体の`.xriftstudio`ファイルを、見つけやすい場所に保存できました。
- バックアップから取り込んだプロジェクトでも、変更内容が再現されていることを確認できました。
- 自動保存やファイルの書き出しだけでは、XRift上には公開されないことが分かりました。

## うまくいかないとき

- **一覧に作品が見当たらない**：検索や絞り込みがかかっていないか確認します。ブラウザ版では、前回と同じ端末・同じブラウザで開いているかも確かめてください。
- **書き出しボタンが押せない**：Play中ならStopで編集に戻り、素材の取り込みや変換が終わるまで待ちます。書き出しに失敗した場合は、エラーの内容を確認してからやり直してください。
- **取り込んだら一部のEntityしか入っていない**：Hierarchyの「選択範囲を書き出す」を使ってしまった可能性があります。元の作品からプロジェクト全体を書き出し直してください。
- **ブラウザ版で大きなファイルを開けない**：ブラウザ版で扱える目安は、ファイル本体と展開後のデータがそれぞれ256 MB以内、ファイル数20,000以内です。これを超える場合はデスクトップ版で開いてください。
- **保存エラーが解消しない**：エラー内容と端末の空き容量を確認します。サイトデータの削除や「完全リセット」を行うと保存済みの作品が消えてしまうため、先に[復旧の案内](./recovery.md)を確認してください。
