# ノードをつないで箱を動かす

[動画を再生する：ノードをつないで箱を動かす](./media/tutorials/lesson-03-00.mp4)

ノードをつなぎ、箱を動かす仕組みを作ります。

## 操作の要点

1. AssetsでNode Graphを作り、対象のEntityに取り付けます。
2. On Startなどのきっかけから、対象を動かす処理へ線をつなぎます。
3. Playで動きを確認し、Stopで編集へ戻ります。

## 試すときのポイント

この教材は字幕で説明します。グラフを作っただけでは実行されないため、Entityへの取り付けも確認してください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./interactivity.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
