# ノードをつないで箱を動かす

[動画を再生する：ノードをつないで箱を動かす](./media/tutorials/lesson-03-00.mp4)

## このレッスンでできること

`On Start`と`Set Property`を線でつなぎ、Playが始まったタイミングで`Box`が自動で動く仕掛けを作ります。

## 始める前に

- `Box`が置かれたワールドを開き、Play中ならStopで編集画面へ戻ります。
- 練習を始める前に、今の状態を保存しておきます。

## 操作の要点

1. Assetsの追加メニューから、新しいNode Graphを作成します。
2. Hierarchyで`Box`を選び、グラフ編集画面の上部にある案内から、`Box`にそのNode Graphを取り付けます。
3. グラフに最初から置かれている`On Start`を確認し、`Set Property`ノードを追加します。
4. `Set Property`を選び、Node InspectorのTargetでEntityに`Box`、Componentに「位置・回転・大きさ」、Propertyに「位置」を指定します（Entityだけを選んだ状態では位置の項目が出ないため、順番に選んでください）。
5. 移動先の位置は、元のYとZはそのままでXだけ`1.5`増やします（元のXが`0`なら`1.5`）。`Duration (s)`を`1`にすると、1秒かけて滑らかに移動します。
6. `On Start`の`Out`から`Set Property`の`In`へ、紫色の処理の線をつなぎます。
7. エラー一覧に問題がないことと保存完了を確認したら、Playで`Box`が動く様子を確かめます。確認が終わったらStopで編集へ戻ります。

## できたか確認する

- Node Graphが`Box`に取り付いており、Play開始をきっかけに`Box`が動きました。
- 編集時の初期位置と、Play中に仕掛けで動いた位置の違いを確認できました。

## うまくいかないとき

- **グラフを作ったのにまったく動かない**：作成したNode Graphが`Box`（Entity）に取り付いているか確認してください。
- **対象が見つからないエラーが出る**：シーン上から対象のグラフを開き直し、`Set Property`のTargetでEntityを選び直します。動作に対応していないノードが使われていないかもあわせて確認してください。
