# ノードをつないで箱を動かす

[動画を再生する：ノードをつないで箱を動かす](./media/tutorials/lesson-03-00.mp4)

## このレッスンでできること

On StartからSet Propertyへつなぎ、Play開始時にBoxを動かします。

## 始める前に

- BoxのあるワールドでStopを押し、編集へ戻ります。
- 練習前に保存します。この教材は字幕で説明する動画です。

## 操作の要点

1. Assetsの追加メニューで新しいNode Graphを作ります。
2. HierarchyでBoxを選び、グラフ編集画面上部の案内からBoxへグラフを取り付けます。
3. グラフにあるOn Startを確認し、Set Propertyを追加します。
4. Set Propertyを選び、Node InspectorのTargetで、EntityをBox、Componentを「位置・回転・大きさ」、Propertyを「位置」にします。Entityだけを選んだ状態では、位置の項目は選べません。
5. 移動先の値は、元のYとZを保ち、Xだけ1.5増やします。元のXが0なら1.5です。Duration (s)を1にすると、1秒かけてその位置へ動きます。
6. On StartのOutからSet PropertyのInへ、紫の処理の線をつなぎます。
7. 問題の一覧と保存状態を確認し、PlayでBoxの動きを見ます。確認後はStopへ戻ります。

## できたか確認する

- グラフがBoxに付いており、Play開始をきっかけに動く。
- Boxの初期位置と、Play中に仕掛けが変えた位置を区別できる。

## うまくいかないとき

- グラフを作ったのに動かない：Entityへの取り付けを確認します。
- 対象が見つからない：シーンから対象のグラフを開き、TargetのEntityを選び直します。実行未対応のNodeは使わないでください。
