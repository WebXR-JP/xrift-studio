# テクスチャで模様を付ける

**テクスチャ**は、色や細かな凹凸などに使う画像です。まず[マテリアルを作って割り当てる](./materials.md#作って割り当てる)ところまで済ませてください。

## 色の画像を貼る

1. PNG、JPGなどの画像を**Assets**へ追加します。
2. Assetsで、編集したいマテリアルを選びます。
3. **Base Color Map**の欄で画像を選びます。
4. **Base Color**を白にして、画像の色を確かめます。

画像が暗くなったり色が変わったりする場合は、Base Colorが掛け合わされていないか確認します。ライトの影響も受けます。

## 貼る大きさや向きを変える

マテリアルのテクスチャ設定で、繰り返し、位置、回転を調整します。画像を選ぶと、繰り返し方やフィルターも確認できます。

モデルのどこに画像が貼られるかは、モデルの**UV**にも依存します。UVがない場合や配置が意図と違う場合は、画像の差し替えだけでは直りません。モデルを作ったツールで確認してください。

## Normal Mapで細かな凹凸を表す

Normal Map（ノーマルマップ）は、陰影で細かな凹凸を表します。**メッシュを変形しないため、輪郭や衝突判定は変わりません。**

**Tangent Space（接線空間）**の画像をNormal Mapへ割り当てます。色補正なしの**Linear**として扱います。Normal Scaleは0で効果なし、1が標準です。まず1で見て、必要に応じて強さを変えてください。

色の写真をNormal Mapの欄へ入れても、適切な凹凸にはなりません。素材の配布元で画像の用途を確かめてください。

## Occlusion Mapとの違い

**Occlusion Map**は、画像を使って隙間やくぼみに陰影を付けます。Normal Mapとは役割が違います。

**SSAO**も陰影を加えますが、こちらはシーン設定で使い、画面に映った形状をもとに処理します。画像をモデルへ貼る設定ではありません。

## PBR用の画像を使う

**Metallic Roughness Map**は、GチャンネルをRoughness、BチャンネルをMetallicに使います。別々に配布された画像を、名前だけ見てそのまま両方の代わりにしないでください。

色のマップと数値のマップは色空間の扱いが異なります。各欄の入力条件を優先してください。最初は[外部カタログ](./external-resources.md)のマテリアルを取り込み、設定済みの組み合わせを確認する方法もあります。

## 遠くで模様がちらつく

画像の**Mipmaps**を確認します。縮小表示用の画像を用意し、遠くの細かな模様のちらつきを抑えるための設定です。

画像が大きいほど常に良いわけではありません。[容量と描画負荷](./performance.md)も確認し、実際に見える大きさに合わせてください。
