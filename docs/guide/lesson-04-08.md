# Bloomで光をにじませる

[動画を再生する：Bloomで光をにじませる](./media/tutorials/lesson-04-08.mp4)

## このレッスンでできること

Emissiveの明るい部分にBloomを加え、にじみを調整します。

## 始める前に

- [自分のマテリアル](./lesson-02-03.md)を割り当てたBoxなどを用意します。
- Stopで編集へ戻り、表示モードを「シーン」、描画品質を「高品質」にします。

## 操作の要点

1. Assetsでマテリアルを選び、EmissiveとEmissive Strengthを調整します。
2. シーン設定のPost ProcessingでBloomを確認します。
3. Thresholdを変え、どの明るさから光がにじむか見ます。
4. Strengthで強さ、Radiusで広がりを一つずつ調整します。
5. 効果が強すぎて形が分からなくなっていないか、同じ視点で見比べます。Playでも確認します。

## できたか確認する

- 表面の明るさと、画面上の光のにじみを分けて調整できる。
- にじませたい部分が分かり、必要な形や文字が読める。

## うまくいかないとき

- 効果が見えない：軽量表示ではBloomが省略されます。表示品質とThresholdを確認します。
- 周囲が明るくならない：EmissiveとBloomだけでは周囲を照らしません。必要な場所へライトを置きます。
