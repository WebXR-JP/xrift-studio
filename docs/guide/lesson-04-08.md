# Bloomで光をにじませる

[動画を再生する：Bloomで光をにじませる](./media/tutorials/lesson-04-08.mp4)

Bloomを使い、光のにじみを調整します。

## 操作の要点

1. マテリアルのEmissiveとEmissive Strengthを調整します。
2. シーン設定のPost ProcessingでBloomを確認します。
3. Threshold、Strength、Radiusを少しずつ変えて見比べます。

## 試すときのポイント

EmissiveとBloomだけでは周囲の物を照らしません。周囲も明るくするにはライトを置いてください。
