# Bloomで光をにじませる

[動画を再生する：Bloomで光をにじませる](./media/tutorials/lesson-04-08.mp4)

## このレッスンでできること

`Emissive`で明るくした部分に`Bloom`（画面効果）を加え、光のにじみ具合をバランスよく調整します。

## 始める前に

- [PBRの色と光沢を調整する](./lesson-02-03.md)で作った自分のマテリアルを割り当てた`Box`などを用意します。
- Play中ならStopで編集画面に戻り、表示モードを「シーン」、描画品質を「高品質」に切り替えておきます。

## 操作の要点

1. Assetsでマテリアルを選び、`Emissive`の色と`Emissive Strength`（発光の強さ）を調整します。
2. 「シーン設定」を開き、`Post Processing`の中にある`Bloom`を確認して有効にします。
3. まず`Threshold`を動かし、どの明るさ以上の部分がにじむのかを確かめます。
4. 次に`Strength`で光のにじみの強さを、`Radius`でにじみの広がり方を一つずつ調整します。
5. にじみが強すぎて形や文字が見づらくなっていないか、同じ視点で見比べます。最後にPlayでも見え方を確かめておきましょう。

## できたか確認する

- マテリアル側の発光（`Emissive`）と、画面全体の光のにじみ（`Bloom`）を分けて調整できました。
- 光らせたい部分がきれいに強調され、周囲の形や文字も読み取れるバランスになりました。

## うまくいかないとき

- **Bloomの効果が見えない**：軽量表示ではBloomが省略されます。描画品質を「高品質」にしたうえで、`Threshold`が高すぎないか確認してください。
- **光っているのに周囲の物が明るくならない**：`Emissive`と`Bloom`は表面の光やにじみを表現する設定で、周囲を照らすライトの代わりにはなりません。周りを明るくしたい場所にはライトを配置してください。
