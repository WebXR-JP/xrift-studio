# ワールドを動画に録画する

ワールドを動画に残すときは、シーンの表示メニューにある**録画**を開きます。録画用カメラは編集中の視点と分けて設定できます。

## 録画する範囲を決める

1. **録画ビューを表示**を押します。
2. **録画用カメラ**か**編集中の視点**を選びます。
3. 録画用カメラなら、**全体**でEntityが収まる位置へ移動し、録画ビューでドラッグして構図を調整します。
4. **グリッドやギズモを映す**を確認します。作品だけを撮る場合はオフにします。

**エディターのパネルを表示**は編集用パネルの表示を切り替えます。**REC 表示**の印は動画には入りません。

## サイズを設定して開始する

1. **録画サイズ**でアスペクト比、**短辺の解像度**、**フレームレート**を選びます。
2. 動きも撮る場合は[Play](./play-mode.md)で動作を確認します。
3. **録画を開始**を押します。
4. 撮り終わったら**録画を停止**を押し、保存が終わるまで待ちます。

録画中にサイズを変えても、変更は次の録画から反映されます。シーンが表示されていない間は最後のフレームが続くため、録画中はシーンが表示されていることを確認してください。

## 保存した動画を見つける

デスクトップ版では、**保存先**に表示されているフォルダーへ保存します。プロジェクトの保存先がある場合はプロジェクトフォルダーを使います。それ以外では**フォルダーを選ぶ**で保存先を選び、**既定に戻す**で戻せます。録画中は保存先を変更できません。

保存後の**フォルダーを開く**で、保存した動画の場所をFinderやエクスプローラーに表示します。動画を再生するボタンではありません。

フォルダーが開かない場合は、パネルに表示された保存パスをコピーしてFinderやエクスプローラーで確認してください。失敗のメッセージと保存パスは[不具合報告](./recovery.md)の確認材料になります。

## ブラウザ版との違い

ブラウザ版は**60秒まで**のサンプル録画をダウンロードします。保存先はブラウザのダウンロード設定で決まり、デスクトップ版のフォルダー選択とは別です。長時間の録画にはデスクトップ版を使ってください。
