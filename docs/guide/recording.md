# ワールドを動画に録画する

シーンの表示メニューから「録画」を開くと、ワールドを動画に保存できます。録画用カメラは、編集中の視点と別に設定できます。

## 録画する範囲を決める

「録画ビューを表示」を押し、「録画用カメラ」か「編集中の視点」を選んでください。録画用カメラでは、「全体」でEntityが収まる位置に合わせ、録画ビューをドラッグして構図を調整できます。

作品だけを撮るには、「グリッドやギズモを映す」をオフにしてください。「エディターのパネルを表示」では、編集用パネルの表示を切り替えられます。RECの印は動画に入りません。

## サイズを設定して開始する

「録画サイズ」でアスペクト比、短辺の解像度、フレームレートを選んでください。動作を撮る場合は、先に[Play](./play-mode.md)で確認します。「録画を開始」で撮影し、終わったら「録画を停止」を押してください。保存が終わるまで待ちます。

録画中にサイズを変えた場合は、次の録画から適用されます。シーンが表示されていない間は、最後のフレームが続きます。撮影中は、シーンを表示しておいてください。

## 保存した動画を見つける

デスクトップ版では、「保存先」に表示されたフォルダーに保存されます。プロジェクトに保存先がある場合は、そのフォルダーが使われます。それ以外は「フォルダーを選ぶ」で指定し、「既定に戻す」で戻せます。録画中は保存先を変えられません。

保存後に「フォルダーを開く」を押すと、動画の保存場所がFinderやエクスプローラーで開きます。このボタンでは動画は再生されません。

フォルダーが開かない場合は、表示された保存パスをコピーし、Finderやエクスプローラーで開いてください。失敗のメッセージと保存パスは、[不具合報告](./recovery.md)で確認に使えます。

## ブラウザ版との違い

ブラウザ版では、60秒までのサンプル録画をダウンロードできます。保存先はブラウザのダウンロード設定で決まります。長時間の録画には、デスクトップ版を使ってください。
