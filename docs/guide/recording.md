# ワールドを動画に録画する

シーンの表示メニューから「録画」を開くと、ワールドの様子を動画として保存できます。録画用カメラは、編集中の視点とは別に設定できます。

## 録画する範囲を決める

「録画ビューを表示」を押し、撮影に使う視点を「録画用カメラ」か「編集中の視点」から選びます。「録画用カメラ」では、「全体」でEntity全体が収まる位置に合わせ、録画ビューをドラッグして構図を調整できます。

作品だけを映したいときは、「グリッドやギズモを映す」をオフにしてください。「エディターのパネルを表示」で、編集用パネルを画面に含めるかどうかも切り替えられます。録画中のRECマークは動画には入りません。

## サイズを設定して開始する

「録画サイズ」でアスペクト比、短辺の解像度、フレームレートを選びます。仕掛けなどの動きを撮影したい場合は、先に[Play](./play-mode.md)で動作を確認しておいてください。「録画を開始」で撮影を始め、終わったら「録画を停止」を押して保存が完了するまで待ちます。

録画中にサイズを変えた場合は、次回の録画から反映されます。シーンが画面に表示されていない間は直前のフレームがそのまま映り続けるため、撮影中はシーンを表示したままにしてください。

## 保存した動画を見つける

デスクトップ版では、「保存先」に表示されたフォルダーに動画が保存されます。プロジェクトに保存先がある場合はそのフォルダーが使われます。別の場所へ保存したいときは「フォルダーを選ぶ」で指定でき、「既定に戻す」で元に戻せます。録画中は保存先を変更できません。

保存後に「フォルダーを開く」を押すと、動画の保存場所がFinderやエクスプローラーで開きます。このボタンでは動画自体は再生されません。

フォルダーが開かない場合は、表示された保存パスをコピーしてFinderやエクスプローラーで直接開いてください。エラーメッセージと保存パスは、[不具合報告](./recovery.md)の際の確認材料として使えます。

## ブラウザ版との違い

ブラウザ版では、最大60秒までのサンプル録画をダウンロードできます。保存先はブラウザのダウンロード設定に従います。長時間の録画にはデスクトップ版を使ってください。
