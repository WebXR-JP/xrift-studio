# Prefabを作って再利用する

[動画を再生する：Prefabを作って再利用する](./media/tutorials/lesson-02-08.mp4)

## このレッスンでできること

複数のEntityをひとまとまりのPrefabとして保存し、同じ組み合わせをシーンへもう一つ配置できるようにします。

## 始める前に

- 一つにまとめたいEntityを2つ以上用意しておきます。
- 親子関係を大きく組み替える前に、[保存とバックアップ](./course-save-backup.md)を残しておくと安心です。

## 操作の要点

1. Hierarchyで、まとめたいEntityを一つの親Entityの下へドラッグして入れます。
2. 親Entityを少し動かし、子Entityも一緒に付いてくることを確認してから元の位置へ戻します。
3. 親EntityをHierarchyからAssetsパネルへドラッグし、Prefabとして保存します。
4. 保存したPrefabをAssetsからシーンへ配置し、元のオブジェクトと離れた位置へ動かします。
5. 子Entityを含めて同じ構成で置けているか見比べます。なお、シーンに置いた1体だけの調整と、「プレハブに反映」による元Prefabの更新は別の操作として使い分けます。

## できたか確認する

- AssetsにPrefabが保存され、シーンへ配置すると組み合わせ全体がそのまま現れました。
- 親Entityを動かしたとき、子Entityも一緒に動きます。

## うまくいかないとき

- **配置したら一部のパーツしか出てこない**：Prefabとして保存する前に、必要なEntityがすべて親Entityの中に入っているかHierarchyで確認してください。
- **片方の色を変えたら別のPrefabの色も変わった**：Prefabとは別に、同じマテリアルを共有している可能性があります。個別に変えたいときは専用のマテリアルを割り当ててください。
