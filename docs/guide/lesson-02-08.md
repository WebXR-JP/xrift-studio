# Prefabを作って再利用する

[動画を再生する：Prefabを作って再利用する](./media/tutorials/lesson-02-08.mp4)

## このレッスンでできること

複数のEntityを一組のPrefabとして保存し、もう一つ配置します。

## 始める前に

- 組み合わせたいEntityを二つ以上用意します。
- 大きな親子関係の変更前に[バックアップ](./course-save-backup.md)を残します。

## 操作の要点

1. Hierarchyで、まとめたいEntityを一つの親の下へドラッグします。
2. 親を少し動かし、子も一緒に動くことを確認して元へ戻します。
3. 親EntityをHierarchyからAssetsへドラッグし、Prefabとして保存します。
4. 保存したPrefabをシーンへ置き、元と離れた位置へ移動します。
5. 子Entityを含む構成を比べます。配置したものの変更と「プレハブに反映」による元素材の更新は分けて扱います。

## できたか確認する

- AssetsにPrefabがあり、もう一度配置すると組み合わせ全体が現れる。
- 親を動かすと、必要な子Entityが一緒に動く。

## うまくいかないとき

- 一部だけ複製される：保存する前に、必要なEntityが親の下に入っているか確認します。
- 別の配置の色も変わった：Prefabとは別に、マテリアルを共有していないか確認します。
