# Prefabを作って再利用する

[動画を再生する：Prefabを作って再利用する](./media/tutorials/lesson-02-08.mp4)

Prefabを作り、同じ構成を再利用します。

## 操作の要点

1. まとめたいEntityを一つの親の下に整理します。
2. 親EntityをHierarchyからAssetsへドラッグして保存します。
3. 保存したプレハブを配置し、同じ構成を再利用できるか確認します。

## 試すときのポイント

「プレハブに反映」を使う前に、ほかの配置への影響を確認してください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./prefabs.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
