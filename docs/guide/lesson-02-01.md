# 外部GLBを読み込んで配置する

[動画を再生する：外部GLBを読み込んで配置する](./media/tutorials/lesson-02-01.mp4)

外部のGLBモデルを読み込み、空間に配置します。

## 操作の要点

1. GLBファイルをAssetsへ取り込みます。
2. 取り込んだモデルをAssetsからシーンへドラッグして配置します。
3. Hierarchyで選び、位置と大きさを調整します。

## 試すときのポイント

Assetsへの取り込みだけでは、シーンには配置されません。モデルが見つからないときはFで視点を合わせてください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./assets.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
