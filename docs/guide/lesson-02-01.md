# 外部GLBを読み込んで配置する

[動画を再生する：外部GLBを読み込んで配置する](./media/tutorials/lesson-02-01.mp4)

## このレッスンでできること

GLBを取り込んでシーンに置き、大きさを整えます。

## 始める前に

- 利用・公開の条件を確認したGLBを一つ用意します。
- [保存とバックアップ](./course-save-backup.md)を済ませます。

## 操作の要点

1. 「Assets → ファイルから素材を追加」でGLBを選ぶか、Assetsへファイルをドラッグします。
2. 読み込み設定が出たら内容を確認し、完了を待ちます。失敗時は通知の詳細を確認してください。
3. Assetsに追加されたモデルを、中央のシーンへドラッグします。
4. Hierarchyで配置したEntityを選び、Fで視点を合わせます。
5. InspectorのTransformで位置と大きさを整えます。床との位置関係や材質も確認します。

## できたか確認する

- Assetsの素材と、Hierarchyに置いたEntityを区別できる。
- モデルが意図した大きさ・位置に表示され、必要な画像が欠けていない。

## うまくいかないとき

- Assetsにはあるがシーンにない：取り込み後、シーンへの配置が必要です。
- 大きすぎる・小さすぎる：Fで見つけてからTransformで直します。視点を近づけるだけではモデルのサイズは変わりません。
