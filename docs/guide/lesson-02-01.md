# 外部GLBを読み込んで配置する

[動画を再生する：外部GLBを読み込んで配置する](./media/tutorials/lesson-02-01.mp4)

## このレッスンでできること

外部のGLBモデルをプロジェクトに取り込み、シーンへ配置して位置と大きさを整えます。

## 始める前に

- 利用条件や公開条件を確認したGLBファイルを一つ用意します。
- 取り込みを試す前に、[保存とバックアップ](./course-save-backup.md)を済ませておくと安心です。

## 操作の要点

1. 「Assets → ファイルから素材を追加」からGLBファイルを選ぶか、Assetsパネルへ直接ドラッグ＆ドロップします。
2. 読み込み設定が表示されたら内容を確認し、取り込みが終わるまで待ちます（エラーが出た場合は通知の詳細を確認してください）。
3. Assetsに追加された3Dモデルを、中央のシーン画面へドラッグして配置します。
4. Hierarchyで配置したEntityを選び、`F`キーで視点を合わせます。
5. Inspectorの`Transform`で位置と大きさを調整し、床との接し方や質感もあわせて確認します。

## できたか確認する

- Assetsに入っている元データと、Hierarchyに配置したEntityの違いが分かりました。
- モデルが狙った位置・大きさで表示され、テクスチャなどの欠けもありません。

## うまくいかないとき

- **Assetsには入ったのにシーンに表示されない**：取り込んだあとに、Assetsからシーンへドラッグして配置する操作が必要です。
- **モデルが大きすぎる・小さすぎる**：`F`キーで全体を見つけてから、Inspectorの`Transform`で大きさを調整してください。カメラを近づけてもモデル自体のサイズは変わりません。
