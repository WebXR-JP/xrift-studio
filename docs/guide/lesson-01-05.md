# 床Collider・SpawnPoint・Playを確認する

[動画を再生する：床Collider・SpawnPoint・Playを確認する](./media/tutorials/lesson-01-05.mp4)

床の当たり判定と開始位置を確認し、Playで動作を確かめます。

## 操作の要点

1. 床を選び、Colliderが追加され、有効になっているか確認します。
2. SpawnPointを歩ける床の上に置きます。
3. Playで床の中心や端を歩き、Stopで編集に戻ります。

## 試すときのポイント

床が見えていても、Colliderがないと立てません。落下を繰り返す場合は開始位置も見直してください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./collision.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
