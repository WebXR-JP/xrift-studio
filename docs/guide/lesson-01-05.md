# 床Collider・SpawnPoint・Playを確認する

[動画を再生する：床Collider・SpawnPoint・Playを確認する](./media/tutorials/lesson-01-05.mp4)

## このレッスンでできること

床に立ち、開始位置から歩ける状態を作ります。

## 始める前に

- PlaneとSpawnPointのあるワールドを開きます。
- Play中ならStopで戻ります。床や開始位置を削除せず確認から始めます。

## 操作の要点

1. Hierarchyで床を選び、InspectorでColliderが有効か確認します。
2. 床など動かさないEntityにRigid Bodyがある場合は、fixedになっているか確認します。
3. Colliderの形と大きさが、歩く範囲に合っているか見ます。Planeの広さはScale XとY、厚みはScale Zで変わります。
4. SpawnPointを選び、歩ける床の上へ移動します。床や壁の内部を避けてください。
5. Playで読み込みを待ち、中央の画面をクリックします。床の中央、端、段差の順に歩きます。
6. Escでマウス固定を解除し、Stopで編集へ戻ります。

## できたか確認する

- 開始直後に落下を繰り返さず、床の上に立てる。
- 歩かせたい範囲で床をすり抜けず、Stopで編集へ戻れる。

## うまくいかないとき

- 床が見えるのに落ちる：見た目とは別に、Colliderの有効状態と厚みを確認します。
- 出現すると押し出される：SpawnPointが床・壁の内部にないか見直します。形や親子関係を変えたあとも再テストしてください。
