# 押すと動くボタンを作る

[動画を再生する：押すと動くボタンを作る](./media/tutorials/lesson-03-01.mp4)

## このレッスンでできること

Boxを押したときだけ動く仕掛けを作ります。

## 始める前に

- [ノードをつないで箱を動かす](./lesson-03-00.md)を済ませます。
- 床と開始位置を用意し、Boxに近づける配置にします。

## 操作の要点

1. 操作を受けるBoxを選び、InspectorのAdd ComponentからInteractableを追加します。
2. BoxのNode Graphを開き、On Interactを用意します。
3. On InteractのOutを、対象を動かすSet PropertyのInへつなぎます。押したときだけ試す場合、On Startから同じ処理へつながる線は外します。
4. Set PropertyのTarget、目標位置、Duration (s)を確認します。
5. 保存状態を確認してPlayへ進み、Boxに近づいてクリックします。
6. EscとStopで編集へ戻ります。繰り返し試す前に、開始時の位置と目標位置を確かめます。

## できたか確認する

- 開始直後には動かず、Boxを押すと目標位置へ動く。
- 操作を受けるEntityに、Interactableとグラフが取り付いている。

## うまくいかないとき

- ぶつかれるのに押せない：ColliderとInteractableは別の役割です。同じ操作対象のInteractableを確認します。
- 二回目に動かない：すでに同じ目標位置へ移動している可能性があります。往復させる別の処理があるとは限りません。
