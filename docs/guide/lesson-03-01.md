# 押すと動くボタンを作る

[動画を再生する：押すと動くボタンを作る](./media/tutorials/lesson-03-01.mp4)

ボタンを押したときに動く仕組みを作ります。

## 操作の要点

1. 操作を受けるEntityにInteractableを追加します。
2. Node Graphを取り付け、On Interactから実行したい処理へつなぎます。
3. Playで近づいて押し、対象が動くか確認します。

## 試すときのポイント

ColliderとInteractableは役割が異なります。押せないときは、グラフの取り付けとInteractableを確認してください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./interactivity.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
