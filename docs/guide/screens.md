# 鏡・動画・画面共有を置く

鏡、動画プレイヤー、画面共有は、それぞれComponentとしてワールドに配置できます。見た目だけのスクリーンモデルを置いただけでは、動画再生や画面共有の機能は働きません。

## 機能を選んで配置する

「Assets → アセットストア → Component」を開き、鏡・動画プレイヤー・画面共有など使いたい機能を選びます。詳細画面で説明と設定項目を確認してからシーンに追加しましょう。

配置したEntityを選んだら、Inspectorで位置・大きさ・各機能の設定を調整します。画面の前に立つスペースや、複数人で見るときの距離感も意識して配置すると使いやすくなります。

## Playで配置と操作を確かめる

Playに入り、画面の向きや大きさ、操作パネルに手が届くかどうかを実際に確認します。壁や床など別の面に埋まっていないかもあわせて見ておきましょう。

動画のURLを指定する必要がある場合は、入力条件を確認してください。動画ファイルそのものではなく通常のWebページのURLを入れると、再生できない場合があります。

## 公開先でも確認する

画面共有は、利用するブラウザや端末の対応状況、画面選択の権限によって挙動が変わります。Playで一通り確認したら、公開後のワールドでも試しておくのが確実です。

公開先のワールドに入ったら、共有する側と見る側の両方から見え方をチェックしましょう。同期の仕組みや利用条件の詳細は、公式Componentの説明と画面上の案内をご覧ください。

## 表示されないとき

うまく映らない場合は、次の点を順に確認してみてください。

- Componentが有効になっており、必要な設定項目が正しく入力されているか
- スクリーンの裏側を見ていたり、壁の中に埋まっていたりしないか
- 画面共有の権限エラーや、動画URLのエラーが出ていないか（出ている場合は先に解消します）
