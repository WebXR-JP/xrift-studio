# 鏡・動画・画面共有を置く

鏡、動画プレイヤー、画面共有は、Componentとしてワールドに追加できます。スクリーンのモデルだけを置いても、動画や画面共有は使えません。

## 機能を選んで配置する

「Assets → 外部から追加 → Component」を開き、鏡、動画プレイヤー、画面共有などを選んでください。詳細の説明と入力項目を確認してから追加します。配置したEntityを選び、位置、大きさ、機能の設定を調整してください。

画面の前に立つ場所や、複数人で見る距離を考えて配置します。

## Playで配置と操作を確かめる

Playで、画面の向きや大きさ、操作する場所に手が届くかを確認してください。壁や別の面に埋まっていないかも確かめます。

動画のURLなどが必要な場合は、入力条件を確認してください。WebページのURLでは、動画を再生できない場合があります。

## 公開先でも確認する

画面共有は、ブラウザや端末の対応、画面選択の権限によって動作が変わります。Playで確認したあと、公開先でも試してください。

公開したワールドに入り、共有する人と見る人の両方から確認します。同期や利用条件は、公式Componentの説明と画面の案内を参照してください。

## 表示されないとき

Componentが有効か、必要な設定が入っているかを確認してください。画面の裏側を見ていたり、壁の中に配置されていたりしないかも確かめます。権限やURLのエラーがあれば、先に解消してください。
