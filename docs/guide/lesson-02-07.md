# MToonでアニメ調の陰影を作る

[動画を再生する：MToonでアニメ調の陰影を作る](./media/tutorials/lesson-02-07.mp4)

## このレッスンでできること

マテリアルを`MToon`に切り替え、明るい面の色・影になる面の色・輪郭線を調整してアニメ調の見た目に仕上げます。

## 始める前に

- 対象のEntityにマテリアルを割り当て、Play中ならStopで編集画面へ戻ります。
- そのマテリアルをほかのEntityと共有していないか確認し、必要であれば専用のマテリアルを新しく作っておきます。

## 操作の要点

1. Assetsでマテリアルを選び、「Inspector → Shading → マテリアルの種類」を開きます。
2. `MToon 0.x`または`MToon 1.0`を選びます（対応させたいVRMのバージョンが決まっている場合は、そちらに合わせてください）。
3. `Base Color`で光が当たる面の色を、「MToon → Shade Color」で影になる面の色を調整します。
4. `Outline Color`と`Outline Width`を一つずつ調整します。初期の幅（`0.003 m`）はモデルの大きさによって太すぎたり細すぎたりするため、実際の見た目に合わせて見直してください。
5. シーンのライトの下で明暗の境界を確認します。輪郭線が不要な場合は、`Outline Width Mode`を`None`にします。

## できたか確認する

- 明るい面と影になる面の色を、それぞれ思いどおりに調整できました。
- 輪郭線の有無や太さが、モデルの大きさに自然に収まっています。

## うまくいかないとき

- **`Metallic`や`Roughness`が見当たらない**：`MToon`ではPBR専用の項目は表示されません。PBRの設定を使いたいときは、マテリアルの種類を`Standard (PBR)`へ戻してください。
- **素材のプレビューとシーンでの見え方が違う**：プレビューと実際のシーンではライトの当たり方が異なります。シーン上で確認しながら調整してください。
