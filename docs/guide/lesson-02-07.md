# MToonでアニメ調の陰影を作る

[動画を再生する：MToonでアニメ調の陰影を作る](./media/tutorials/lesson-02-07.mp4)

MToonを使った、アニメ調の陰影を確認します。

## 操作の要点

1. Assetsでマテリアルを選びます。
2. InspectorのShadingからMToon 0.xまたはMToon 1.0を選びます。
3. Base ColorとShade Colorを調整し、必要ならOutlineも確認します。

## 試すときのポイント

MToonとPBRでは調整する項目が異なります。切り替えたあと、シーンの照明で陰影を確かめてください。

動画内の画面と現在の操作名が異なる場合は、[詳しい使い方](./materials.md)も確認してください。本文は現在のガイド・ソースを基にした要点で、音声の逐語録ではありません。
