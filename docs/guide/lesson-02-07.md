# MToonでアニメ調の陰影を作る

[動画を再生する：MToonでアニメ調の陰影を作る](./media/tutorials/lesson-02-07.mp4)

## このレッスンでできること

MToonの明るい面・暗い面・輪郭線を調整します。

## 始める前に

- 対象へマテリアルを割り当て、Stopで編集に戻ります。
- 材質を共有している範囲を確認し、必要なら専用のマテリアルを作ります。

## 操作の要点

1. Assetsでマテリアルを選び、「Inspector → Shading → マテリアルの種類」を開きます。
2. MToon 0.xかMToon 1.0を選びます。対応させたいVRMの版がある場合は確認してください。
3. Base Colorで明るい面、「MToon → Shade Color」で暗い面の色を変えます。
4. Outline ColorとOutline Widthを一つずつ調整します。初期の幅0.003 mは、モデルの大きさに合わせて見直します。
5. シーンのライトの下で、明るい面と暗い面の境界を確認します。輪郭線が不要ならOutline Width ModeをNoneにします。

## できたか確認する

- 明るい面と暗い面の色を別々に調整できる。
- 輪郭線の有無と太さが、実際のモデルの大きさに合っている。

## うまくいかないとき

- MetallicやRoughnessが見つからない：MToonではPBR専用の項目が表示されません。PBRの編集はStandard (PBR)へ戻します。
- プレビューと印象が違う：素材の見本とシーンでは照明が異なります。シーンで確認して調整してください。
