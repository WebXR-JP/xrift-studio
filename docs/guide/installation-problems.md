# インストール・起動で困ったとき

まずは、ダウンロードしたファイルがアプリのインストーラーになっているか確認しましょう。配布ページにある「Source code」は開発用のソースコードなので、アプリ本体としては起動できません。

## ファイルが見つからない

[ダウンロード案内](https://webxr-jp.github.io/xrift-studio/#download)から、お使いのOSに合ったファイルを選びます。ページを開けない場合や一覧から直接探したい場合は、[配布一覧](https://github.com/WebXR-JP/xrift-studio/releases/latest)も確認できます。

## macOSで開けない

配布元とダウンロードしたファイルに問題がないことを確かめたうえで、macOSの「システム設定 → プライバシーとセキュリティ」を開きます。XRift Studioを開くための許可ボタンが表示されていれば、警告の内容を確認し、このアプリに限って許可してください。

一方で、危険なソフトウェアやファイルの改ざんを示す警告が出た場合は許可せず、公式の配布先からダウンロードし直すか、配布元へ確認してください。Gatekeeperを一括で無効にしたり、内容が分からないままターミナルのコマンドを実行したりするのは危険なので避けてください。

## Windowsで起動できない

次の点を確認してみてください。

- ダウンロードが途中で途切れず完了しているか
- Windows用のファイル（`.msi`または`.exe`）を使っているか
- 保護機能の警告が出た場合、入手先と警告の内容に不審な点がないか

原因を自分で判断できないときは、警告の文面をメモして[問い合わせ](./recovery.md)からご連絡ください。セキュリティ機能を一括で停止するような操作は避けてください。

## Linuxで起動できない

お使いのディストリビューションに合う形式（`.deb`、`.rpm`、`.AppImage`）を選んでいるか確認します。AppImageを使う場合は、ファイルのプロパティなどから実行許可を付ける必要がある場合があります。エラーメッセージが表示されるときは、その内容を手がかりに環境側の設定を見直してください。

## セットアップで止まる

インターネットに接続できているかを確認し、画面に出たエラーメッセージを控えたうえで「セットアップを再試行」を試します。同じエラーが繰り返し出る場合は、「ヘルプと報告」から状況をお知らせください。

セットアップが完了するとプロジェクト一覧が開きます。そこから[最初のワールド](./first-world.md)へ進めます。
