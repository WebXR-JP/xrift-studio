# インストール・起動で困ったとき

まず、ダウンロードしたファイルがアプリのインストーラーか確認してください。配布ページの「Source code」は、開発用のソースコードです。

## ファイルが見つからない

[ダウンロード案内](https://webxr-jp.github.io/xrift-studio/#download)から、お使いのOSに合うファイルを選んでください。案内を開けない場合は、[配布一覧](https://github.com/WebXR-JP/xrift-studio/releases/latest)で確認できます。

## macOSで開けない

配布元とダウンロードしたファイルを確認し、macOSの「システム設定 → プライバシーとセキュリティ」を開いてください。アプリを開くための許可が表示されていれば、警告の内容を読んで、そのアプリに限って許可します。

危険なソフトウェアや改ざんに関する警告が出た場合は、許可せず、公式の配布先から再ダウンロードするか、配布側へ確認してください。Gatekeeperを一括で無効にしたり、意味が分からないままターミナルのコマンドを実行したりすることは避けてください。

## Windowsで起動できない

ダウンロードが完了しているか、Windows用のファイルを使っているか確認してください。保護機能の警告が出た場合は、ファイルの入手先と警告の内容を確かめます。

原因を判断できない場合は、警告の文面を控えて[問い合わせ](./recovery.md)をしてください。セキュリティ機能を一括で停止することは避けてください。

## Linuxで起動できない

お使いの環境に合う配布形式か確認してください。AppImageでは、ファイルに実行許可を設定する必要がある場合があります。表示されたエラーを確認し、原因に関係する設定から調べてください。

## セットアップで止まる

インターネットの接続状態を確認し、表示されたエラーを控えてください。「セットアップを再試行」でやり直せます。同じエラーが続く場合は、「ヘルプと報告」を開いてください。

セットアップが完了すると、プロジェクト一覧が開きます。そこから[最初のワールド](./first-world.md)の手順へ進めます。
