# インストール・起動で困ったとき

まず、ダウンロードしたものがアプリのインストーラーか確認します。配布ページの**Source code**は、通常の利用者が開くアプリではありません。

## ファイルが見つからない

[ダウンロード案内](https://webxr-jp.github.io/xrift-studio/#download)からOSに合う配布ファイルを選びます。案内が取得できない場合は[配布一覧](https://github.com/WebXR-JP/xrift-studio/releases/latest)を確認します。

## macOSで開けない

配布元とダウンロードしたファイルを確認したうえで、macOSの**システム設定 → プライバシーとセキュリティ**に、アプリを開く許可が表示されているか確認します。警告に従って、そのアプリに限って許可してください。

危険なソフトウェアや改ざんを示す警告の場合は、そのまま許可せず、公式の配布先からの再ダウンロードと配布側への確認を行います。Gatekeeperを全体で無効にしたり、意味を確認せず端末コマンドを実行したりしないでください。

## Windowsで起動できない

ダウンロードが完了していることと、Windows用の配布ファイルを使っていることを確認します。保護の警告がある場合は、ファイルの入手先と表示内容を確認してください。

原因が判断できない場合は警告の文面を控え、[問い合わせ](./recovery.md)へ進みます。セキュリティ機能を一律に停止する手順は使いません。

## Linuxで起動できない

お使いの環境に合う配布形式か確認します。AppImageでは実行を許可するファイル設定が必要な場合があります。表示されたエラーを確認し、無関係なシステム設定を次々に変えないでください。

## セットアップで止まる

接続状態を確認し、アプリに表示された失敗内容を残します。**セットアップを再試行**でやり直してください。同じエラーが続く場合は、**ヘルプと報告**を開きます。

セットアップが完了するとプロジェクト一覧が開きます。そこから[最初のワールド](./first-world.md)を作ります。
