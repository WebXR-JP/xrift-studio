# HDRIを背景と環境光に使う

[動画を再生する：HDRIを背景と環境光に使う](./media/tutorials/lesson-01-08.mp4)

## このレッスンでできること

環境画像を背景に表示し、IBLで反射の違いを比べます。

## 始める前に

- 利用条件を確認したHDRIなどの環境画像を用意します。横:縦が2:1の全天球画像を使います。
- 反射を見比べるBoxや球と、編集できるマテリアルを用意します。

## 操作の要点

1. 環境画像をAssetsへ取り込みます。
2. 「シーン設定 → Skybox」のSkybox Textureに画像を割り当てます。
3. 「背景に表示」を有効にします。Skybox Shaderが優先されている場合は、Shaderを「なし」にして画像を確認します。
4. Rotationで向きを、Intensityの1を基準に明るさを調整します。
5. IBLを有効にして、同じマテリアルの反射や照明を見比べます。背景だけ使う場合と区別してください。

## できたか確認する

- 全天球画像が意図した向きで背景に表示される。
- 背景の表示とIBLの役割を分けて確認できる。

## うまくいかないとき

- 別の空が表示される：Skybox Shaderは画像より優先されます。割り当てを確認します。
- 画像が正しくつながらない：6面を並べたキューブマップではなく、1枚の全天球画像か確認します。
