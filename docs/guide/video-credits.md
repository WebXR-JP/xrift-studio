# 動画教材の利用条件

この動画シリーズは、XRift Studioの基本操作を学ぶための教材です。

## 音声と字幕

全19本の動画に、日本語のナレーションと字幕が入っています。ナレーションには、制作者が使用を許可した声をもとにOmniVoice（k2-fsa）で生成した合成音声を使っています。なお、元の録音データや参照音声、音声モデルは配布していません。

## 利用・再配布するときの確認事項

音声生成に使ったモデルには非商用の利用条件があるため、この動画シリーズは非商用の学習教材として公開しています。商用利用や再配布を検討される場合は、音声や画面内に映る各素材の利用条件をそれぞれ確認してください。XRift Studioのソースコードに適用されているMITライセンスは、動画内のすべての素材にそのまま適用されるわけではありません。

参考として、[OmniVoiceの公式モデルカード](https://huggingface.co/k2-fsa/OmniVoice#license)ではコードがApache-2.0、学習済みモデルがCC-BY-NCと案内されています。あわせて[音声生成コードのライセンス](https://github.com/k2-fsa/OmniVoice/blob/master/LICENSE)も確認してください。これらは音声生成に利用したコードとモデルの条件であり、動画全体の権利をひとまとめに示すものではありません。

## 画面と解説の違いについて

動画は制作当時のブラウザ版βの画面で収録しています。現在のアプリと操作名やパネルの配置が異なる場合は、各レッスンの関連ガイドから最新の手順を確認してください。

また、各レッスンに載せている「操作の要点」は現在のバージョンに合わせて手順を整理したもので、動画のナレーションの書き起こしではありません。
