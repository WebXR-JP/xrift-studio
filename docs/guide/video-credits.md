# 動画教材の利用条件

このシリーズは、XRift Studioの操作を学ぶための短い教材です。完成したMP4動画を掲載しています。

## 音声と字幕

一部の動画は、OmniVoice / k2-fsaで生成した合成音声を使用しています。「ノードをつないで箱を動かす」は字幕で説明する教材です。元の録音ファイルや音声モデルは配布していません。

## 利用・再配布の確認

音声生成に使ったモデルには非商用条件があります。この教材は非商用の学習用として案内しています。商用利用や再配布を行う場合は、音声・画面内の素材それぞれの利用条件を確認してください。XRift StudioのソースコードのMITライセンスが、そのまま動画内のすべての素材に適用されるわけではありません。

[OmniVoiceの公式モデルカード](https://huggingface.co/k2-fsa/OmniVoice#license)では、コードはApache-2.0、学習済みモデルはCC-BY-NCと案内されています。[音声生成コードのライセンス](https://github.com/k2-fsa/OmniVoice/blob/master/LICENSE)も確認してください。これらは生成に使ったコード・モデルの条件であり、完成動画全体の権利を一括して示すものではありません。

## 画面と説明の違い

動画は制作時のブラウザ版βの画面を記録しています。現在のアプリと操作名やパネルの配置が異なる場合は、各教材の「詳しい使い方」から最新の本文を確認してください。

本文の「操作の要点」は現在のガイド・ソースを基にした補足で、音声の逐語録ではありません。
