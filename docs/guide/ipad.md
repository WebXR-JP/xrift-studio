# iPadで作り、パソコンへ引き継ぐ

iPadのSafariでビジュアルエディターを開き、配置や質感の調整を進められます。仕上げたプロジェクトを`.xriftstudio`ファイルに保存し、MacまたはWindowsのXRift Studioで開いて公開します。

## ブラウザ版を開く

[XRift Studioの紹介ページ](https://webxr-jp.github.io/xrift-studio/)で**iPadで制作を始める**を押します。同じSafariに前回のプロジェクトが残っている場合は、制作を再開します。**保存した作品を開く**から、別の作品や手元のファイルを直接開くこともできます。

上部の**作品**メニューに、**素材を追加**・**作品を開く**・**.xriftstudioで保存**をまとめています。保存状態は作品名の下で確認できます。**作品を開く**では、このブラウザに保存したプロジェクトを選ぶほか、**新規ワールド**・**新規アイテム**を作れます。新規作成では名前を入力して**作成して開く**を押します。一覧には更新日時と編集中の作品が表示されます。**.xriftstudioを開く**から、以前書き出した`.xriftstudio`ファイルも開けます。従来の`.zip`ファイルも取り込めます。

## 画面とタッチ操作

パソコン版と同じHierarchy・Assets・Inspectorを使います。iPadでは、必要なパネルをボタンで切り替えます。同じボタンをもう一度押すと、パネルを閉じてシーンを広く表示できます。横向きではシーンの横に、狭い画面ではシーンの下にパネルが開きます。

| やりたいこと | 操作 |
| --- | --- |
| Entityを選ぶ | シーン内のEntity、またはHierarchyの行をタップ |
| 視点を回す | シーンを1本指でドラッグ |
| 視点をずらす | 2本指でドラッグ |
| 近づく・離れる | 2本指でピンチ |
| 選んだEntityを見る | **選択へ寄る** |
| 複数のEntityを選ぶ | **複数選択**を有効にして順番にタップ |
| ギズモや地形を触らずに視点を変える | **視点だけ操作**を有効にする |
| 複製・削除・配置などを行う | HierarchyやAssetsで対象を選び、**操作**を開く |

位置・回転・大きさは、ギズモに加えてInspectorのTransformへ数値を入力して調整できます。Assetsの素材は**操作**からシーンへ配置できるため、ドラッグだけに頼る必要はありません。

数値欄はタップすると現在の値を選択します。そのまま新しい値を入力し、キーボードの完了操作で閉じられます。Assetsではフォルダーを選んだまま種類で絞り込めます。

Playでは画面の移動・ジャンプ・操作ボタンを使い、Stopで編集へ戻ります。パソコンやXRift内での最終確認も行ってください。

## 手元の素材を取り込む

読み込みメニューから、iPadの「ファイル」にあるモデルや画像などを選びます。素材もブラウザのプロジェクトへ保存され、書き出す`.xriftstudio`ファイルに含まれます。GLTFと外部テクスチャのように複数ファイルへ分かれているモデルは、必要なファイルをまとめて選びます。単一ファイルのGLBは受け渡しが簡単です。

取り込みや変換が終わってから、プロジェクトを書き出してください。重いときは素材数やテクスチャ解像度を抑え、Assetsパネルを閉じます。編集画面の描画品質を下げても、保存する作品の設定は変わりません。[容量と描画負荷](./performance.md)も参照してください。

## プロジェクトを保存してパソコンへ渡す

1. **作品 → .xriftstudioで保存**を押します。
2. 準備が終わったら、ファイル名と容量を確認し、**ファイルに保存**を押します。
3. Safariのダウンロード一覧で保存先を確認します。**共有する**が表示される端末では、共有メニューも使えます。
4. iCloud Driveなどで`.xriftstudio`ファイルをMacまたはWindowsへ渡します。
5. パソコン版のプロジェクト一覧で**ファイルから取り込む**を選びます。
6. 取り込んだプロジェクトを開き、[公開の準備](./publishing.md)を進めます。

受け渡し形式は**`.xriftstudio`**です。シーン・Assets・Prefabと、取り込んだ素材を一つにまとめた、デスクトップ版と共通のプロジェクトです。ファイルを展開せず、そのまま取り込めます。取り込み先では新しい未公開の作品として扱われます。

書き出しに失敗した場合は、編集内容を残してエラーと**もう一度試す**を表示します。ブラウザ版では、ファイル本体・展開後のデータともに256 MBまで、20,000ファイルまでが対象です。大きなプロジェクトはパソコン版で扱ってください。

## ブラウザへの保存と書き出しの違い

**ブラウザに保存済み**は、そのSafariの保存領域へ保存できた状態です。iCloud Driveなどへファイルを保存したことは意味しません。ブラウザのサイトデータを削除すると、保存したプロジェクトも失われます。制作の区切りでは`.xriftstudio`ファイルを手元に残してください。

ブラウザが突然終了した場合、最後の変更まで保存できていないことがあります。Safariへ戻ったら内容を確かめます。保存エラーが出ているときは、空き容量などを確認してから再試行してください。

同じ作品は一つのタブで編集します。別のタブで編集中と表示されたら、そのタブで紹介ページへ戻るかタブを閉じてから開き直してください。別の作品は同時に開けます。

## パソコンで行う作業

XRiftへの公開、MCPでのAI接続、コードエディターへの書き出し、外部プロバイダーからの素材取得など、デスクトップ専用の操作はパソコンへ引き継いで行います。iPadのブラウザ版では、公開用トークンを入力する必要はありません。

iPhoneでもエディターを直接開けます。初回は操作案内をエディター上に表示し、**編集を始める**で閉じます。最初はシーンを広く表示し、必要なパネルを切り替えて配置・色・数値を編集できます。iPhoneでは、選んだパネルを作業領域いっぱいに表示します。**シーン**で3D表示へ戻れます。**シーン操作**で移動・回転・拡縮やタッチ操作のボタンを表示します。作品の保存と`.xriftstudio`の受け渡しも同じ入口を使います。下部の常設アイコン列は表示せず、**シーン設定**と**タッチ操作の使い方**は**作品**メニューから開きます。
