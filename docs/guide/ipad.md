# iPadで作り、パソコンへ引き継ぐ

iPadのSafariでも、ビジュアルエディターで配置や質感を編集できます。ブラウザ版βでは、ワールドを直接送信して公開する機能も試せます。`.xriftstudio`ファイルに書き出すと、MacやWindowsのXRift Studioで続きを編集できます。

## ブラウザ版を開く

[ビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開いてください。起動時とリロード時にはプロジェクト一覧が表示されます。保存済みの作品を選ぶか、「ワールド」か「アイテム」を選んで「新規作成」を押します。「ファイルから開く」では、`.xriftstudio`ファイルを取り込めます。

エディターのURLをブックマークすると、紹介ページを経由せずに開けます。このURLを共有しても、編集中のプロジェクトは渡りません。作品を渡すには、`.xriftstudio`ファイルを書き出してください。

上部の「ファイル」メニューに、「素材を追加」「プロジェクトを開く」「プロジェクトを書き出す」があります。保存状態は、プロジェクト名の下で確認できます。

「プロジェクトを開く」では、ブラウザに保存した作品を選んだり、新しいワールドやアイテムを作ったりできます。種類を選ぶと「新規作成」が押せるようになります。名前を入力して「作成して開く」を押してください。一覧には更新日時が表示され、現在編集中の作品も確認できます。「ファイルから開く」では、書き出した`.xriftstudio`ファイルや従来の`.zip`ファイルを取り込めます。

## 画面とタッチ操作

パソコン版と同じHierarchy、Assets、Inspectorを使います。iPadでは、ボタンでパネルを切り替えてください。同じボタンをもう一度押すと閉じられ、シーンを広く表示できます。横向きではシーンの横、狭い画面ではシーンの下にパネルが開きます。

| やりたいこと | 操作 |
| --- | --- |
| Entityを選ぶ | シーンのEntityかHierarchyの行をタップ |
| 視点を回す | シーンを1本指でドラッグ |
| 視点をずらす | 2本指でドラッグ |
| 近づく・離れる | 2本指でピンチ |
| 選んだEntityを見る | 「選択へ寄る」を押す |
| 複数のEntityを選ぶ | 「複数選択」を有効にして順にタップ |
| ギズモや地形を触らずに視点を変える | 「視点だけ操作」を有効にする |
| Entityをコピー・複製する | HierarchyでEntityを選び、その行の「…」を開く |
| 素材を配置する | Assetsで素材を選び、「操作」を開く |

位置、回転、大きさは、ギズモの操作かInspectorのTransformへの数値入力で調整できます。ドラッグでの配置が難しい場合は、Assetsで素材を選び、「操作」からシーンへ配置してください。

数値欄をタップすると、現在の値が選択されます。新しい値を入力し、キーボードの完了操作で閉じてください。Assetsでは、フォルダーを選んだまま素材の種類で絞り込めます。

Playでは、画面の移動、ジャンプ、操作ボタンを使います。Stopで編集へ戻れます。公開前には、パソコンやXRiftでも見た目と動作を確認してください。

## 手元の素材を取り込む

上部の「ファイル → 素材を追加 → 3Dモデル / 3Dアセット」で、iPadの「ファイル」にあるモデルや画像を選んでください。取り込んだ素材はブラウザのプロジェクトに保存され、書き出す`.xriftstudio`ファイルにも含まれます。GLTFと外部テクスチャのように複数のファイルを使うモデルは、必要なファイルをまとめて選びます。GLBは一つのファイルで取り込めます。

取り込みや変換が終わってから、プロジェクトを書き出してください。動作が重い場合は、素材の数やテクスチャの解像度を抑え、Assetsパネルを閉じてください。編集画面の描画品質を下げても、保存されるプロジェクトの設定は変わりません。詳しくは[容量と描画負荷](./performance.md)を参照してください。

## カタログから素材を追加する

上部の「ファイル → 素材を追加 → 外部から追加」を開いてください。狭い画面では、上部でカテゴリを選び、素材をタップして詳細を開きます。プレビューや設定を確認してから追加してください。「一覧へ戻る」で選び直せます。Assetsの「外部から追加」からも同じ画面を開けます。

広い画面では、カテゴリ、一覧、詳細が横に並びます。詳細は縦にスクロールでき、長い追加ボタンも画面内に表示されます。ブラウザ版では、音蔵の音源を直接追加できます。それ以外の外部プロバイダーは、パソコン版で使ってください。

## プロジェクトを保存してパソコンへ渡す

1. 「ファイル → プロジェクトを書き出す」を押します。
2. 準備が終わったら、ファイル名と容量を確認して「ダウンロード」を押します。
3. Safariのダウンロード一覧で保存先を確認します。「共有する」が表示される端末では、共有メニューも使えます。
4. iCloud Driveなどを使い、`.xriftstudio`ファイルをMacかWindowsへ渡します。
5. パソコン版のプロジェクト一覧で「ファイルから取り込む」を選びます。
6. 取り込んだ作品を開いて続きを編集するか、[公開の準備](./publishing.md)を進めます。

`.xriftstudio`には、シーン、Assets、Prefab、取り込んだ素材がまとめて保存されます。デスクトップ版と共通の形式なので、展開せずに取り込めます。取り込み先では、新しい未公開プロジェクトになります。

書き出しに失敗した場合も編集内容は残り、エラーと「もう一度試す」が表示されます。ブラウザ版で扱えるのは、ファイル本体と展開後のデータがそれぞれ256 MB以内、ファイル数が20,000以内のプロジェクトです。これを超える場合は、パソコン版で扱ってください。

## ブラウザへの保存と書き出しの違い

「ブラウザに保存済み」は、そのSafariの保存領域に保存された状態です。iCloud Driveなどにファイルが保存されたわけではありません。サイトデータを削除すると、プロジェクトも失われます。制作の区切りでは、`.xriftstudio`ファイルを書き出して手元に残してください。

ブラウザが突然終了すると、直前の変更が保存されていない場合があります。Safariを開き直したら、編集内容を確認してください。保存エラーが出ている場合は、空き容量などを確かめてから再試行します。

同じプロジェクトは、一つのタブで編集してください。別のタブで編集中と表示されたら、そちらのタブで紹介ページへ戻るか、タブを閉じてから開き直します。異なるプロジェクトは同時に開けます。

## XRiftへ公開する

ブラウザ版βからワールドを公開するには、XRiftの設定で`write:worlds`権限付きのAPIキーを発行してください。「XRiftへ公開」を押し、公開画面でキーを入力します。送信後は、対応ブラウザのパスワード管理機能への保存を選べます。保存しない場合は、次回も入力してください。詳しくは[ブラウザ版βでワールドを公開する](./publishing.md#ブラウザ版βでワールドを公開する)を参照してください。

アイテムとスクリプトを含むワールドは、パソコンへ引き継いで公開してください。MCPでのAI接続、コードエディターへの書き出し、音蔵以外の外部プロバイダーからの素材取得にも、デスクトップ版を使います。

iPhoneでもエディターを直接開けます。初回は操作案内が表示され、「編集を始める」で閉じられます。必要なパネルを切り替えながら、配置、色、数値を編集してください。選んだパネルは作業領域いっぱいに表示され、「シーン」で3D画面に戻れます。

「シーン操作」では、移動、回転、拡縮やタッチ操作のボタンを表示できます。保存と`.xriftstudio`の受け渡しは、iPadと同じメニューを使います。iPhoneには下部の常設アイコン列がないため、「シーン設定」と「タッチ操作の使い方」は「ファイル」メニューから開いてください。
