# iPadで作り、パソコンへ引き継ぐ

iPadのSafariでも、ビジュアルエディターを使って配置や質感を編集できます。ブラウザ版βでは、作ったワールドやアイテムをそのままXRiftへ送信して公開する機能も試せます。また、`.xriftstudio`ファイルとして書き出せば、MacやWindowsのXRift Studioで続きを制作できます。

## ブラウザ版を開く

Safariで[ビジュアルエディター](https://webxr-jp.github.io/xrift-studio/editor.html)を開きます。起動時やページを再読み込みしたときはプロジェクト一覧が表示されるので、次のいずれかで作業を始めます。

- 保存済みの作品を選んで続きを開く
- 「ワールド」または「アイテム」を選んで「新規作成」を押し、名前を入力して「作成して開く」を選ぶ
- 「ファイルから開く」で、書き出しておいた`.xriftstudio`ファイル（従来の`.zip`ファイルにも対応）を取り込む

エディターのURLをブックマークしておくと、紹介ページを通らずにすぐ開けます。ただし、このURLを他の人に共有しても編集中のプロジェクトは渡りません。作品データを渡したいときは、`.xriftstudio`ファイルを書き出してください。

画面上部の「ファイル」メニューには「素材を追加」「プロジェクトを開く」「プロジェクトを書き出す」がまとまっています。保存状態はプロジェクト名の下で確認できます。「プロジェクトを開く」の一覧では、更新日時や現在編集中の作品も確認できます。

## 画面とタッチ操作

パソコン版と同じHierarchy・Assets・Inspectorを使いますが、iPadでは各ボタンでパネルを開閉しながら作業します。開いているパネルのボタンをもう一度押すと閉じられ、シーンを広く表示できます。横向きではシーンの横、狭い画面ではシーンの下にパネルが開きます。

| やりたいこと | 操作 |
| --- | --- |
| Entityを選ぶ | シーンのEntityかHierarchyの行をタップ |
| 視点を回す | シーンを1本指でドラッグ |
| 視点をずらす | 2本指でドラッグ |
| 近づく・離れる | 2本指でピンチ |
| 選んだEntityを見る | 「選択へ寄る」を押す |
| 複数のEntityを選ぶ | 「複数選択」を有効にして順にタップ |
| ギズモや地形を触らずに視点を変える | 「視点だけ操作」を有効にする |
| Entityをコピー・複製する | HierarchyでEntityを選び、その行の「…」を開く |
| 素材を配置する | Assetsで素材を選び、「操作」を開く |

位置・回転・大きさは、シーン上のギズモ操作でもInspectorのTransformへの数値入力でも調整できます。ドラッグでの配置がやりにくいときは、Assetsで素材を選んで「操作」からシーンへ配置してください。

数値欄をタップすると現在の値がすべて選択されるため、そのまま新しい値を入力してキーボードの完了操作で確定できます。Assetsでは、フォルダーを選んだまま素材の種類で絞り込むこともできます。

Play中は、画面に表示される移動・ジャンプ・操作ボタンを使って確認します。編集へ戻るときはStopを押します。公開する前には、パソコンや実際のXRift上でも見た目と動作を確認しておきましょう。

## 手元の素材を取り込む

上部の「ファイル → 素材を追加 → 3Dモデル / 3Dアセット」から、iPadの「ファイル」アプリにあるモデルや画像を選べます。取り込んだ素材はブラウザ内のプロジェクトに保存され、書き出す`.xriftstudio`ファイルにも含まれます。GLTFと外部テクスチャのように複数ファイルで構成されるモデルは、必要なファイルをまとめて選択してください（GLBであれば1ファイルだけで取り込めます）。

プロジェクトを書き出すのは、素材の取り込みや変換が終わってからにしてください。動作が重く感じるときは、素材の数やテクスチャの解像度を抑え、使っていない間はAssetsパネルを閉じておくと快適になります。編集画面の描画品質を下げても、保存されるプロジェクトの設定自体は変わりません。詳しくは[容量と描画負荷](./performance.md)をご覧ください。

## カタログから素材を追加する

上部の「ファイル → 素材を追加 → アセットストア」またはAssetsの「アセットストア」からカタログを開けます。

- **狭い画面**：上部でカテゴリを選び、素材をタップして詳細を開きます。プレビューや設定を確認してから追加し、選び直すときは「一覧へ戻る」を使います。
- **広い画面**：カテゴリ・一覧・詳細が横に並びます。詳細は縦にスクロールでき、追加ボタンも画面内に収まるように表示されます。

ブラウザ版では音蔵の音源を直接追加できます。それ以外の外部プロバイダーを利用する場合は、デスクトップ版をお使いください。

## プロジェクトを保存してパソコンへ渡す

1. 「ファイル → プロジェクトを書き出す」を押します。
2. 準備が終わったら、ファイル名と容量を確認して「ダウンロード」を押します。
3. Safariのダウンロード一覧で保存先を確認します。「共有する」が表示される端末では、共有メニューも使えます。
4. iCloud Driveなどを使い、`.xriftstudio`ファイルをMacやWindowsへ渡します。
5. パソコン版のプロジェクト一覧で「ファイルから取り込む」を選びます。
6. 取り込んだ作品を開いて続きを編集するか、[公開の準備](./publishing.md)を進めます。

`.xriftstudio`ファイルには、シーン・Assets・Prefab・取り込んだ素材がまとめて入っています。デスクトップ版と共通の形式なので、解凍せずにそのまま取り込めます。取り込み先では新しい未公開プロジェクトとして追加されます。

書き出しに失敗しても編集中の内容は消えず、エラーメッセージと「もう一度試す」が表示されます。ブラウザ版で扱えるのは、ファイル本体と展開後のデータがそれぞれ256 MB以内、ファイル数が20,000以内のプロジェクトです。これを超える規模の作品は、パソコン版で扱ってください。

## ブラウザへの保存と書き出しの違い

「ブラウザに保存済み」は、お使いのSafariの保存領域にデータが置かれている状態です。iCloud Driveなどにファイルとして保存されたわけではないため、Safariのサイトデータを削除するとプロジェクトも消えてしまいます。制作の節目では、`.xriftstudio`ファイルを書き出して手元に残しておきましょう。

また、ブラウザが予期せず終了した場合、直前の変更が保存しきれていないことがあります。Safariを開き直したら編集内容を確認し、保存エラーが出ている場合は端末の空き容量などを確かめたうえで再試行してください。

同じプロジェクトを複数のタブで同時に開くのは避けてください。「別のタブで編集中」と表示されたら、もう一方のタブで紹介ページへ戻るかタブを閉じてから開き直します（別のプロジェクトであれば同時に開けます）。

## XRiftへ公開する

ブラウザ版βから直接公開するには、あらかじめXRiftの設定画面でAPIキーを発行しておきます（ワールド用は `write:worlds`、アイテム用は `write:items` の権限が必要です）。エディターの「XRiftへ公開」を押し、公開画面でそのキーを入力して送信します。

送信後は、対応ブラウザのパスワード管理機能にキーを保存するか選べます。保存しない場合は、次回公開するときにも入力が必要です。詳しい手順は[ブラウザ版βでワールド・アイテムを公開する](./publishing.md#ブラウザ版βでワールドアイテムを公開する)をご覧ください。

アイテムもブラウザ版から公開できます（`write:items` 権限のAPIキーが必要です）。ただし、次の用途にはデスクトップ版を使います。

- スクリプトを含む作品の公開（パソコンへ引き継いで公開します）
- MCP接続
- コードエディターへの書き出し
- 音蔵以外の外部プロバイダーからの素材取得

### iPhoneで使う場合

iPhoneのブラウザでもエディターを直接開けます。初回は操作案内が表示され、「編集を始める」を押すと閉じられます。

必要なパネルを切り替えながら配置・色・数値を編集する仕組みで、選んだパネルが作業領域いっぱいに開き、「シーン」を押すと3D画面に戻ります。「シーン操作」からは移動・回転・拡縮やタッチ操作のボタンを表示でき、下部の歯車から「シーン設定」も開けます。保存や`.xriftstudio`の受け渡しはiPadと同じメニューを使い、「タッチ操作の使い方」は「ファイル」メニューからいつでも確認できます。
