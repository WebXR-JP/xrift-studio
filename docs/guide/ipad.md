# iPadで作り、パソコンへ引き継ぐ

iPadのSafariでビジュアルエディターを開き、配置や質感の調整を進められます。仕上げたプロジェクトをZIPで保存し、MacまたはWindowsのXRift Studioで開いて公開します。

## ブラウザ版を開く

[XRift Studioの紹介ページ](https://webxr-jp.github.io/xrift-studio/)からビジュアルエディターを開きます。同じSafariに前回のプロジェクトが残っている場合は、制作を再開します。

上部の**開く**では、このブラウザに保存したプロジェクトを選ぶほか、**新規ワールド**・**新規アイテム**を作れます。**ZIPを選ぶ**から、以前書き出したプロジェクトも開けます。

## 画面とタッチ操作

パソコン版と同じHierarchy・Assets・Inspectorを使います。iPadでは、必要なパネルをボタンで切り替えます。同じボタンをもう一度押すと、パネルを閉じてシーンを広く表示できます。横向きではシーンの横に、狭い画面ではシーンの下にパネルが開きます。

| やりたいこと | 操作 |
| --- | --- |
| Entityを選ぶ | シーン内のEntity、またはHierarchyの行をタップ |
| 視点を回す | シーンを1本指でドラッグ |
| 視点をずらす | 2本指でドラッグ |
| 近づく・離れる | 2本指でピンチ |
| 選んだEntityを見る | **選択へ寄る** |
| 複数のEntityを選ぶ | **複数選択**を有効にして順番にタップ |
| ギズモや地形を触らずに視点を変える | **視点だけ操作**を有効にする |
| 複製・削除・配置などを行う | HierarchyやAssetsで対象を選び、**操作**を開く |

位置・回転・大きさは、ギズモに加えてInspectorのTransformへ数値を入力して調整できます。Assetsの素材は**操作**からシーンへ配置できるため、ドラッグだけに頼る必要はありません。

Playでは画面の移動・ジャンプ・操作ボタンを使い、Stopで編集へ戻ります。パソコンやXRift内での最終確認も行ってください。

## 手元の素材を取り込む

読み込みメニューから、iPadの「ファイル」にあるモデルや画像などを選びます。素材もブラウザのプロジェクトへ保存され、書き出すZIPに含まれます。GLTFと外部テクスチャのように複数ファイルへ分かれているモデルは、必要なファイルをまとめて選びます。単一ファイルのGLBは受け渡しが簡単です。

取り込みや変換が終わってから、プロジェクトを書き出してください。重いときは素材数やテクスチャ解像度を抑え、Assetsパネルを閉じます。編集画面の描画品質を下げても、保存する作品の設定は変わりません。[容量と描画負荷](./performance.md)も参照してください。

## ZIPを保存してパソコンへ渡す

1. 上部の**プロジェクトを書き出す**を押します。
2. 準備が終わったら、ファイル名と容量を確認し、**ファイルに保存**を押します。
3. Safariのダウンロード一覧で保存先を確認します。**共有する**が表示される端末では、共有メニューも使えます。
4. iCloud DriveなどでZIPをMacまたはWindowsへ渡します。
5. パソコン版のプロジェクト一覧で**ZIPから取り込む**を選びます。
6. 取り込んだプロジェクトを開き、[公開の準備](./publishing.md)を進めます。

現在の受け渡し形式は**`.zip`**です。拡張子を変えたり、あらかじめZIPを展開したりする必要はありません。シーン・Assets・Prefabと、取り込んだ素材をまとめた、デスクトップ版と共通のプロジェクトです。取り込み先では新しい未公開の作品として扱われます。

書き出しに失敗した場合は、編集内容を残してエラーと**もう一度試す**を表示します。ブラウザ版のZIPは、圧縮ファイル・展開後のデータともに256 MBまで、20,000ファイルまでが対象です。大きなプロジェクトはパソコン版で扱ってください。

## ブラウザへの保存とZIPの違い

**ブラウザに保存済み**は、そのSafariの保存領域へ保存できた状態です。iCloud DriveなどへZIPを保存したことは意味しません。ブラウザのサイトデータを削除すると、保存したプロジェクトも失われます。制作の区切りではZIPを手元に残してください。

ブラウザが突然終了した場合、最後の変更まで保存できていないことがあります。Safariへ戻ったら内容を確かめます。保存エラーが出ているときは、空き容量などを確認してから再試行してください。

## パソコンで行う作業

XRiftへの公開、MCPでのAI接続、コードエディターへの書き出し、外部プロバイダーからの素材取得など、デスクトップ専用の操作はパソコンへ引き継いで行います。iPadのブラウザ版では、公開用トークンを入力する必要はありません。

スマートフォンは今回の制作画面の対象に含めていません。狭い画面では案内が表示されます。
