# XRiftへ公開する

エディターの「XRiftへ公開」から作品を送信すると、XRiftで公開できます。エディター内に保存しただけでは、ほかの人からは見られません。

公開前に[Play](./play-mode.md)で見た目と動作を確かめ、保存状態が「保存済み」になっていることを確認してください。手順1〜5はデスクトップ版の操作です。ブラウザ版を使う場合は、[ブラウザ版βのワールド公開](#ブラウザ版βでワールドを公開する)を参照してください。

## 1. 公開の確認画面を開く

「XRiftへ公開」を押し、タイトル、説明、サムネイル、公開先、保存状態を確認してください。

公開用のセットアップが必要な場合は、画面の案内に従って準備します。ソースを手動でビルドする必要はありません。未ログインの場合も、この画面からログインへ進めます。

## 2. 作品の情報を整える

タイトル、説明、サムネイルを作品に合わせて設定してください。テンプレートの情報が残っていれば、編集します。

現在のシーンからサムネイルを撮影する場合は、作品の特徴が見える向きに視点を動かしてください。撮影後は、保存された画像を確認します。

## 3. 容量と問題を確認する

初回読み込みの容量と、容量が大きい素材の内訳を確認してください。必要に応じて、[軽くする方法](./performance.md)に沿って調整します。

テクスチャは、編集画面で使っている画像のまま公開されます。解像度や圧縮を変えるには、Inspectorで画像を書き出して適用してください。Playで変更後の見た目を確かめてから公開します。

問題が表示された場合は、対象を修正してから公開画面に戻ってください。REJECTなど、送信できない結果が出ている間は公開に進めません。

## 4. 送信と審査を待つ

保存、変換、検査、アップロードの進捗が表示されます。処理中はボタンを繰り返し押さず、画面の案内を待ってください。

アップロードが終わっても、審査中であれば公開が完了していない場合があります。ほかの人が入れる状態になったか、公開状況を確認してください。

## 5. 公開した作品を開く

公開URLが表示されたら、そのページで作品を確認してください。画面共有や複数人での同期など、Playだけで確認できない機能も、実際の利用条件で試します。

URLが表示されない場合は、完了表示と審査の状態を確認してください。URLを推測して開くことは避けてください。

## ブラウザ版βでワールドを公開する

パソコン、iPad、スマートフォンのブラウザ版βでは、ワールドをXRiftに直接送信する機能を試せます。アイテムとスクリプトを含むワールドは、[プロジェクトを書き出して](./ipad.md)デスクトップ版から公開してください。

1. [XRiftの設定](https://app.xrift.net/settings)で、`write:worlds`権限付きのAPIキーを発行します。キーは他人に渡さず、公開画面でだけ入力してください。発行や認証の方法は[XRiftのPublic API v1資料](https://docs.xrift.net/public-api/v1)を参照できます。資料のスコープ表には、現在は読み取り権限だけが掲載されています。
2. ブラウザ版でワールドを開き、タイトル、説明、サムネイルを整えます。「XRiftへ公開」を押し、公開先と内容を確認します。
3. APIキーを入力して送信します。XRift Studioは、キーをプロジェクトやWeb Storageに保存しません。
4. 結果に表示されるワールドIDとバージョンを確認します。XRiftの「マイワールド」で審査の状態を確かめ、閲覧できるか試してください。`PENDING`は判定待ちです。`REJECTED`の場合は、公開物や権限設定の修正が必要です。

対応ブラウザでは、送信完了画面の「APIキーをブラウザに保存」から、パスワード管理機能に保存できます。ブラウザの保存確認で「保存」を選び、保存が終わったら公開画面の「保存済みキーを確認」を押してください。キーの選択画面で今回保存したキーを選ぶと、保存を確認できます。保存確認が表示されない場合は、ブラウザのパスワード保存設定を確認し、「保存をもう一度依頼」を押してください。次回は自動入力か「保存済みキーを選ぶ」で使えます。ブラウザの同期設定によっては、別の端末にも同期されます。保存しない場合は、公開画面を閉じるとキーが消えます。

通信が切れて送信結果が分からなくなった場合は、XRiftの公開状況を先に確認してください。同じ内容をすぐに再送しないでください。

## 公開した作品を更新する

同じプロジェクトから再公開すると、保存されている公開先の作品が更新されます。送信前に、更新先が意図した作品か確認してください。

複製したプロジェクトやZIPから取り込んだプロジェクトは、新しい未公開プロジェクトになります。元の公開先は引き継がれません。

## 送信結果が分からない

再送する前に、XRiftで公開状況を確認してください。すでに公開されていれば、編集に戻れます。公開されていないことを確認できた場合に限り、「未公開を確認して送信保留を解除」からやり直してください。

エラーが出ている場合は、内容を控えて[復旧と問い合わせ](./recovery.md)を参照してください。
