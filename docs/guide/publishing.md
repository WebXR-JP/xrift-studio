# XRiftへ公開する

作品をXRiftへ送る操作は、エディターの**XRiftへ公開**から始めます。保存しただけでは、ほかの人に公開されません。

**始める前に：** [Play](./play-mode.md)で見た目と動作を確認し、作品を保存してください。制作手順はデスクトップ版を対象にしています。

## 1. 公開の確認画面を開く

**XRiftへ公開**を押します。タイトル、説明、サムネイル、公開先、保存状態などを確認します。

公開用のセットアップがまだの場合は、アプリの案内に沿って準備します。手動でソースをビルドする必要はありません。未ログインの場合は、同じ公開の流れからログインへ進みます。

## 2. 作品の情報を整える

**タイトル・説明・サムネイル**を自分の作品に合わせます。テンプレートのままの項目がある場合は、先に編集してください。

現在のシーンからサムネイルを保存する場合は、作品の特徴が見える向きで撮影し、保存された画像を確認します。

## 3. 容量と問題を確認する

初回ロードの容量や、重い素材の内訳を確認します。必要なら[軽くする方法](./performance.md)に沿って調整します。

問題が表示されたら、対象の項目を修正してから公開へ戻ります。**REJECT**など送信に進めない結果を、無視して続けることはできません。

## 4. 送信と審査を待つ

保存、変換、検査、アップロードなどの進み具合が表示されます。処理中は同じ操作を繰り返さず、画面の案内を待ちます。

**審査中は、まだ公開が完了していない場合があります。** アップロードが終わったことと、ほかの人が入れる状態になったことを区別してください。

## 5. 公開した作品を開く

公開URLが表示されたら、そのページを開いて作品を確認します。画面共有や複数人での同期など、Playだけで確認できなかった機能も実際の利用条件で確かめます。

URLが出ていない場合は、完了表示や審査の状態を確認し、URLを推測して作らないでください。

## 公開した作品を更新する

同じプロジェクトから再公開すると、保存されている公開先を更新します。送信前に、意図した作品が更新先になっているか確認してください。

複製やZIPから取り込んだプロジェクトは、元の公開先とは別の未公開プロジェクトとして扱われます。

## 送信結果が分からない

**もう一度すぐに送信しないでください。** XRiftで公開状況を確認します。公開済みなら編集に戻ります。**公開されていないことを確認できた場合に限り**、**未公開を確認して送信保留を解除**からやり直します。

画面にエラーがある場合は内容を残し、[復旧と問い合わせ](./recovery.md)へ進みます。
