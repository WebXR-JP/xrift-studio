# XRiftへ公開する

エディターの「XRiftへ公開」から作品を送信すると、XRift上で公開できます。エディター内に保存しただけでは、ほかの人からは見られません。

公開する前に[Play](./play-mode.md)で見た目と動作を確かめ、保存状態が「保存済み」になっていることを確認してください。手順1〜5はデスクトップ版の操作です。ブラウザ版を使う場合は、[ブラウザ版βのワールド・アイテム公開](#ブラウザ版βでワールドアイテムを公開する)を参照してください。

## 1. 公開の確認画面を開く

「XRiftへ公開」を押し、タイトル、説明、サムネイル、公開先、保存状態を確認します。

公開用のセットアップが済んでいない場合は、画面の案内に従って準備してください。ソースコードを手動でビルドする必要はありません。XRiftに未ログインの場合も、この画面からログインへ進めます。

## 2. 作品の情報を整える

タイトル、説明、サムネイルを作品に合わせて設定します。テンプレートのまま残っている情報があれば書き換えてください。

現在のシーンからサムネイルを撮影する場合は、作品の特徴が分かりやすく映る向きに視点を合わせてから撮影し、保存された画像を確認します。

## 3. 容量と問題を確認する

初回読み込みの容量と、容量が大きい素材の内訳を確認します。必要に応じて、[軽くする方法](./performance.md)に沿って調整してください。

テクスチャは、編集画面で使っている画像のまま公開されます。解像度や圧縮形式を変えるには、Inspectorで画像を書き出して適用し、Playで変更後の見た目を確かめてから公開します。

問題が表示された場合は、対象を修正してから公開画面に戻ってください。`REJECT`など送信できない結果が出ている間は公開へ進めません。

## 4. 送信と審査を待つ

送信を始めると、保存・変換・検査・アップロードの進捗が表示されます。処理中はボタンを繰り返し押さず、画面の案内を待ってください。

アップロードが終わっても、審査中の間は公開が完了していません。ほかの人が入れる状態になったか、XRift側で公開状況を確認してください。

## 5. 公開した作品を開く

公開URLが表示されたら、実際に開いて作品を確認します。画面共有や複数人での同期など、Playだけでは確かめられない機能も公開先で試してください。

URLが表示されない場合は、完了表示と審査の状態を確認してください。URLを推測して開くことは避けてください。

## ブラウザ版βでワールド・アイテムを公開する

パソコン、iPad、スマートフォンのブラウザ版βからも、ワールドとアイテムをXRiftへ送信できます。スクリプトを含む作品は、[プロジェクトを書き出して](./ipad.md)デスクトップ版から公開してください。

1. [XRiftの設定](https://app.xrift.net/settings)で、ワールドには`write:worlds`、アイテムには`write:items`の権限を持つAPIキーを用意します。キーは他人に渡さず、公開画面だけで入力してください。[Public API v1資料](https://docs.xrift.net/public-api/v1)のスコープ表には、現在は読み取り権限だけが掲載されています。必要な権限を設定画面で選べない場合は、デスクトップ版から公開してください。
2. ブラウザ版で作品を開き、タイトル、説明、サムネイルを整えます。「XRiftへ公開」を押し、公開先と内容を確認します。
3. APIキーを入力し、「ワールドをアップロード」または「アイテムをアップロード」を押します。更新の場合は「このワールドを更新」または「このアイテムを更新」の表示と、更新先のIDを確認してください。XRift StudioはAPIキーをプロジェクトやWeb Storageに保存しません。
4. 結果画面に表示されるワールドIDまたはアイテムIDとバージョンを確認します。XRiftの「マイワールド」または「マイアイテム」で審査の状態を確かめ、問題なく使えるか試してください。`PENDING`は審査待ち、`REJECTED`は公開物や権限設定の修正が必要な状態です。

対応ブラウザでは、送信完了画面の「APIキーをブラウザに保存」からパスワード管理機能に保存できます。

1. ブラウザの保存確認ダイアログで「保存」を選びます。
2. 保存が終わったら、公開画面の「保存済みキーを確認」を押して今回保存したキーを選び、正しく保存されたか確認します。
3. 保存確認が表示されない場合は、ブラウザのパスワード保存設定を見直してから「保存をもう一度依頼」を押してください。

次回からは自動入力、または「保存済みキーを選ぶ」で入力できます。ブラウザの同期設定によっては別の端末にも同期されます。保存しない場合は、公開画面を閉じるとキーは消えます。

通信が切れて送信結果が分からなくなった場合は、同じ内容をすぐ再送せず、先にXRiftで公開状況を確認してください。ブラウザ版では画面を閉じたり再読み込みしたりしても送信保留が残ります。公開されていないことを確認できた場合に限り、「未公開を確認して送信保留を解除」を使ってやり直してください。

## 公開した作品を更新する

同じプロジェクトから再公開すると、紐づいている公開先の作品が更新されます。送信前に、更新先が意図した作品かどうかを確認してください。

複製したプロジェクトやZIPから取り込んだプロジェクトは、新しい未公開プロジェクトとして扱われます。元の公開先は引き継がれません。

## 送信結果が分からない

再送する前に、必ずXRift側で公開状況を確認してください。すでに公開されていれば、そのまま編集に戻れます。公開されていないことを確認できた場合に限り、「未公開を確認して送信保留を解除」からやり直してください。

エラーが出ている場合は、内容を控えたうえで[復旧と問い合わせ](./recovery.md)を参照してください。
