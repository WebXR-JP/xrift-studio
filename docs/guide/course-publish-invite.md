# ワールドに入り、友達を招く

動画：未収録（文章で進められます）

## このレッスンでできること

公開したワールドに集まる部屋を作り、友達と同じ場所で試します。ここでいう招待は、実際に開いたインスタンスのURLを相手へ渡す方法です。

## 始める前に

- [審査と現在使用中のバージョン](./course-publish-review.md)を確認してください
- XRiftへログインし、試すワールドの詳細を開いてください
- 一緒に確認する相手に、試したい内容を伝えておきます

「ワールド」は作品の空間、「インスタンス」はその空間に人が集まる部屋です。同じワールドでも別のインスタンスに入ると、同じ場所で会えません。

## 手順

### 1. インスタンスの参加条件を選ぶ

1. 自分のワールド詳細で「インスタンス」を開きます。
2. インスタンス一覧の「新規作成」を押します。
3. 「インスタンス名」に、試遊用だと分かる名前を入力します。例は「展示室の動作確認」です。
4. 「最大人数」を、参加する人数に合わせて設定します。作成者も参加人数に含めて考えてください。
5. 「パブリック（誰でも参加可能）」と「ゲストの参加を許可」を、別々に確認します。

参加条件は次のように選びます。

- ログインした友達と試す：パブリックを外し、ゲスト参加も外します。相手がインスタンス作成者のフレンドであることを確認してください
- アカウントのない人にもURLで案内する：ゲスト参加を許可します。URLを受け取ったゲストが参加できる範囲になることを理解して選んでください
- 広く参加してもらう：パブリックのまま作成します。ゲストも含めるかは、もう一つの設定で選びます

**プライベートでも、ゲスト参加を許可すると、URLから来たゲストは参加できます。** プライベートのインスタンスにログインして参加する場合は、作成者かそのフレンドである必要があります。参加条件は、ワールドの「ワールド一覧に公開する」と別です。どの設定でも、秘密情報を作品へ入れないでください。

### 2. 作成して自分で入る

1. ワールド・名前・人数・参加条件を読み直し、「作成」を一度押します。
2. 作成したインスタンスのカードが一覧に出たら、そのカードを選びます。
3. 入室前の画面で、ワールド名・インスタンス名・オーナー・参加者数を確認します。
4. 音声設定を確認します。マイクやデバイスの許可は、使う目的を読んで本人が選んでください。
5. 「入室する」を押し、読み込みが終わるまで待ちます。

実行権限の確認が表示された場合は、外部接続先などの内容を読んでから判断します。今後の作品も信頼する設定を、今回の入室だけの確認と同じつもりで選ばないでください。

### 3. 同じインスタンスのURLを渡す

1. 自分が入ったインスタンスのURLを、ブラウザのアドレス欄からコピーします。
2. 試してもらう相手へ、そのURLとインスタンス名を伝えます。Studioの編集画面のURLや、別のインスタンスのURLを送らないようにしてください。
3. ログインが必要な設定か、ゲスト参加を許可しているかも伝えます。ゲストは表示名など、実際に出た案内に従って進めてもらいます。
4. 相手にも同じインスタンス名を確認してもらい、入室後に互いの姿が見えるか確かめます。

ワールド詳細のURLは、作品を紹介するために使えます。一緒に集まるときは、入る部屋まで一致するインスタンスのURLを渡してください。URLやIDは実画面から取得し、推測して作りません。

### 4. 公開後の動作を二人で確認する

1. 開始位置から移動し、床・壁・通路で困らないか確かめます。
2. 案内文、画像、音声が相手にも見える・聞こえるか確認します。
3. 仕掛けを一人ずつ操作し、作りたい動作になっているか確かめます。二人で共有する変化か、それぞれの画面だけの変化かも見ます。
4. スマートフォンやVRでの利用を案内する予定なら、その端末でも読み込み・文字・操作・負荷を確認します。パソコンで動いただけで、全端末の確認済みにはしません。
5. 問題があれば、端末、操作、起きたことをメモし、[同じワールドを更新する](./course-publish-update.md)手順で直します。

画面共有を試す場合は、通知や個人情報が映らない対象を選びます。必要のない画面・マイクまで共有する必要はありません。

## できたか確認する

- 自分が選んだ参加条件でインスタンスを作れた
- 相手と同じインスタンス名を確認し、同じ空間で会えた
- 入口からの移動、表示、音声、仕掛けを実際に試した
- 確認した端末と、まだ試していない端末を分けて記録した

## うまくいかないとき

- インスタンスを作れない：ログインとワールドの審査状態を確認します。初回の審査中や却下では作成できません
- インスタンス一覧が見えない：一覧を見るにはログインが必要です。ゲストへは、許可したインスタンスのURLを直接渡します
- 相手が入れない：満員、ゲスト参加の許可、作成者とのフレンド関係を確認します。参加条件を広げる前に、誰を入れたいのか決めてください
- 入れたのに会えない：ワールド名だけでなく、インスタンス名とURLを見比べます
- ローカルのPlayと動作が違う：[Playで確認できる範囲](./play-mode.md)を確認し、公開先での問題として記録します
