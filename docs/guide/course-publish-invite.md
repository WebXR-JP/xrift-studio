# ワールドに入り、友達を招く

動画：未収録（文章で進められます）

## このレッスンでできること

公開したワールドに人が集まる部屋（インスタンス）を作り、友達と同じ空間に入って動作確認します。ここでは、実際に開いたインスタンスのURLを相手へ渡して招待する手順を進めます。

## 始める前に

- [審査と一覧への公開を確認する](./course-publish-review.md)を済ませ、確認したいバージョンが「現在使用中」になっていることを確かめます。
- XRiftへログインし、試したいワールドの詳細ページを開いておきます。
- 一緒に試す相手がいる場合は、「何を試したいか」をあらかじめ伝えておくとスムーズです。

なお、「ワールド」は作品の空間そのもの、「インスタンス」はその空間に人が集まる部屋のことです。同じワールドでも別のインスタンスに入ると、同じ場所で会うことはできません。

## 手順

### 1. インスタンスの参加条件を選ぶ

1. 自分のワールド詳細ページで「インスタンス」を開きます。
2. インスタンス一覧の「新規作成」を押します。
3. 「インスタンス名」に、試遊用だと分かりやすい名前を入力します（例：「展示室の動作確認」）。
4. 「最大人数」を参加する人数に合わせて設定します。自分自身も人数に含めて考えてください。
5. 「パブリック（誰でも参加可能）」と「ゲストの参加を許可」をそれぞれ確認します。

目的に合わせて、次のように選びます。

- **ログインしている友達だけで試す**：「パブリック」も「ゲストの参加を許可」もオフにします。相手がインスタンス作成者のフレンドになっていることを確認してください。
- **アカウントを持っていない人にもURLで来てもらう**：「ゲストの参加を許可」をオンにします。URLを受け取ったゲストが参加できる設定になることを把握したうえで選んでください。
- **広く誰でも入れるようにする**：「パブリック」をオンのまま作成します。ゲストも含めるかどうかは「ゲストの参加を許可」で選びます。

**プライベート設定でも、「ゲストの参加を許可」をオンにするとURLを知っているゲストは参加できます。** 一方、プライベートのインスタンスにログインして入る場合は、作成者本人かそのフレンドである必要があります。また、この参加条件はワールドの「ワールド一覧に公開する」とは別の設定です。どの設定であっても、秘密情報は作品の中に入れないでください。

### 2. インスタンスを作成して自分で入る

1. ワールド・インスタンス名・最大人数・参加条件を読み直し、「作成」を一度押します。
2. 一覧に作成したインスタンスのカードが表示されたら、そのカードを選びます。
3. 入室前の画面で、ワールド名・インスタンス名・オーナー・参加者数を確認します。
4. 音声設定を確かめます。マイクやデバイスの利用許可は、表示された目的を確認してご自身で選んでください。
5. 「入室する」を押し、読み込みが終わるまで待ちます。

実行権限の確認が表示された場合は、外部接続先などの内容を読んで判断してください。「今後の作品も信頼する」を選ぶと別の作品にも適用されるため、今回の入室だけ確認したいときは選ばないようにします。

### 3. 同じインスタンスのURLを相手へ渡す

1. 自分が入っているインスタンスのURLを、ブラウザのアドレス欄からコピーします。
2. 一緒に試す相手へ、そのURLとインスタンス名を伝えます（Studioの編集画面のURLや別のインスタンスのURLを送らないよう注意してください）。
3. ログインが必要な設定か、ゲスト参加を許可しているかもあわせて伝えておきます。ゲストの場合は、画面に表示される案内に沿って表示名などを入力してもらいます。
4. 相手にも同じインスタンス名であることを確認してもらい、入室後に互いの姿が見えるか確かめます。

ワールド詳細ページのURLは作品紹介に使えますが、一緒に集まって遊ぶときは、実際に開いたインスタンスのアドレス欄からURLをコピーして渡してください。

### 4. 公開後の動きを二人で確かめる

1. 開始位置から歩き回り、床・壁・通路で引っかからないか確かめます。
2. 案内文・画像・音声が、相手の画面でも正しく見えたり聞こえたりするか確認します。
3. 仕掛けを一人ずつ操作して、狙った動きになるか試します。二人の画面で同期する変化か、操作した人の画面だけの変化かも確認しておきます。
4. スマートフォンやVR端末での利用も想定している場合は、パソコンだけでなく実機でも読み込み時間・文字の読みやすさ・操作感・動作の重さを確認しておくと安心です。
5. 直したい点が見つかったら、使った端末・行った操作・起きたことをメモし、[同じワールドを更新する](./course-publish-update.md)の手順で修正します。

画面共有を試すときは、通知や個人情報が映り込まないウィンドウを選び、不要な画面やマイクは共有しないよう気をつけてください。

## できたか確認する

- 自分の目的に合った参加条件でインスタンスを作成できました。
- 相手と同じインスタンス名を確認し、同じ空間で会えました。
- 移動・表示・音声・仕掛けを実際の公開先で確かめられました。
- 動作確認した端末と、まだ試していない端末を分けて記録できました。

## うまくいかないとき

- **インスタンスを作成できない**：ログイン状態とワールドの審査状態を確認します。初回公開が審査中や却下の間は作成できません。
- **インスタンス一覧が表示されない**：一覧の閲覧にはログインが必要です。ゲストには、参加を許可したインスタンスのURLを直接渡してください。
- **相手が入室できない**：満員になっていないか、ゲスト参加の許可設定や作成者とのフレンド関係が合っているか確認します。設定を広げる前に、誰を招きたいか整理しておくと安心です。
- **入室できたのに相手と会えない**：ワールド名だけでなく、インスタンス名とURLが一致しているか見比べてください。
- **StudioのPlayと動作が違う**：[Playで動作を確かめる](./play-mode.md)で確認できる範囲を確かめ、公開先で起きた現象としてメモしておきます。

## 次のレッスン

これで、作ったワールドを公開して状態を確かめ、友達と一緒に体験するまでの流れが一通り完了です。これから少しずつ改良していくときは、元のプロジェクトを残したまま更新してみてください。
