# 3Dモデルの読み込み

ビジュアルエディターでは、3D モデルを **3Dモデルの素材** として取り込み、シーンに配置できます。

## 対応している形式

| 形式 | 説明 |
| --- | --- |
| **GLB** | 自己完結型の glTF バイナリ。推奨。 |
| **glTF** | テキストベースの glTF。 |
| **OBJ** | 汎用の 3D モデル形式。 |
| **VRM 0.x / 1.x** | アバター向けの形式。ボーンとシェイプキーを抽出できます。 |

## 取り込む手順

1. Assetsで、モデルファイルをドラッグ＆ドロップするか、読み込みメニューから選択します。
2. 読み込んだモデルがAssetsに追加されます。
3. モデルをシーンへドラッグして配置します。

## 配置する

モデルをシーンへドラッグすると、Entityとして配置されます。Inspectorで次の項目を調整できます。

- **位置・回転・大きさ**: 位置、回転、スケール
- **Mesh Renderer**: マテリアル、影の設定
- **衝突判定**: 衝突判定（インポート 3Dモデルにはメッシュの衝突判定が初期設定されます）

配置時の自動再生を有効にすると、**全クリップをループ再生するノードグラフ**が作られ、Entityに付きます。再生するクリップや繰り返しはグラフで調整します。不要なクリップはノードを削除してください。詳しくは [ノードで動きを作る](./interactivity.md) を参照してください。

## アバターのポーズを保存する

VRM などのスキンメッシュモデルでは、ボーンの XYZ 回転とシェイプキーの値をEntityごとに保存できます。シーンと XRift 向け生成コードへ反映されます。

## 再インポート

3Dモデルの素材のソースを変更した場合は、**再インポート** で派生メタデータを更新できます。3Dモデルの素材の ID と参照は保持されます。

## 制約

- OBJ の外部 MTL／テクスチャはディスク上から自動探索しません。同じ同時に読み込むファイルへ含めた分だけ解決します。
- 付属ファイルを参照する glTF／OBJ は、依存ファイルを同じ同時に読み込むファイルへ含めた時だけ自己完結 GLB へ正規化します。単体で選んだ場合は不足依存として止まります。
- VRM の静的ポーズは保存できますが、キーフレーム、クリップ、補間、タイムライン編集はまだありません。
