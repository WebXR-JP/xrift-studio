# 空と水をつくる

空と水のシェーダーは、空模様や波を描くマテリアルです。[外部から追加](./external-resources.md)のカタログで選び、色や動きを調整できます。

## Skybox Shader

### 追加する

1. Assetsの **外部から追加** を押します。
2. 左の一覧から **Skybox Shader** を選びます。
3. プリセットを選び、**Skyboxに設定** を押します。

**追加後にSkyboxへ設定** を有効にしたまま追加すると、シーン設定のSkyboxに割り当てられます。Skybox ShaderはSkybox Textureより優先して背景を描きます。チェックを外すとマテリアルだけが追加されます。

### プリセット

33種類・11カテゴリから選べます。昼・夕暮れ・朝焼け・夜空・オーロラ・宇宙に加え、天候・幻想・スタイル・抽象・水中の表現を収録しています。積雲、巻雲、雲海、天の川、環のある惑星など、全種類は[Skybox Shaderの一覧](../SKY_SHADERS.md)を参照してください。

一覧は実描画の静止画、詳細だけはライブ表示です。詳細をドラッグするか矢印キーで見回し、一時停止・再生・視点リセットで比較できます。

### 調整する

追加前は「軽量・標準・高精細」から描画品質を選べます。品質はマテリアルに保存されます。追加後に品質を変える場合は、同じプリセットを選び直して追加してください。既存の設定を残す場合は、先にプロジェクトをバックアップします。

マテリアルを選ぶと、Inspectorの **調整できる値** で数値と色を変更できます。プリセットによって項目は変わりますが、たとえば 立体的な雲の夕空 では次のようなものを調整できます。

- **雲**: 量、濃さ、細かさ、雲底と雲頂の高さ、流れる速さ
- **太陽**: 高さ（度）、方角（度）、大きさ、まわりの光の広がり
- **遠景**: 尾根の高さ、起伏、かすみ、手前と奥の尾根の色
- **色**: 天頂の色、地平線の色、日なた／日かげの雲の色

**既定値へ戻す** でプリセットの値に戻せます。同じプリセットをカタログからもう一度追加した場合も、マテリアルがプリセットの値で上書きされます。

### 背景と照明を分けて設定する

**Skybox**は背景、**IBL**は画像を照明や反射に使う設定です。Skybox Shaderを追加しただけでは、周囲の照明や反射は変わりません。必要に応じて**シーン設定 → Skybox**で**Skybox Texture**にHDRIなどを選び、**IBL**を有効にしてください。

**Intensity**は背景とIBLの明るさ、**Rotation**は背景とIBLの水平方向を調整します。Skybox Shaderでは、これらの設定に対応する項目がある場合に反映されます。Shader自体の色や動きは、マテリアルのInspectorで調整します。背景全体ではなく画像だけ上下逆に見えるときは、**Flip Y**を確認してください。

Skybox Shaderは編集中も表示されます。背景が見えないときは、シーン上部の表示モードを**シーン**に戻してください。**Unlit**や**Wireframe**ではSkyboxを表示しません。

## Water Shader

### 追加する

1. **外部から追加** から **Water Shader** を選びます。
2. プリセットを選び、**「〇〇をマテリアルへ追加」** を押します。

追加されるのはマテリアルです。水面にしたいメッシュ（平面など）を作り、そのマテリアルスロットへ割り当てて使います。

### プリセット

海・水面を21種類から選べます。名前だけでなく、日本語の説明や特徴でも検索できます。

| カテゴリ | プリセット |
| --- | --- |
| 外洋・うねり | 波のある海、外洋の大きなうねり、風が渡る海 |
| 海岸・磯 | 海岸の打ち寄せる波、磯に寄せる波 |
| 南国・浅瀬 | 南国の浅い入り江、サンゴ礁の浅瀬 |
| 荒天・雨 | 嵐の海、雨の港 |
| 夕景・夜の海 | 夕日に染まる海、月明かりの海、夜光虫の入り江 |
| アニメ・絵画 | トゥーン調の海、アニメ調の夏の海、水彩画の海、墨絵の波 |
| 幻想・SF | オーロラ色の海、ホログラムの海、虹色の海、氷河の海 |
| 湖・内海 | 穏やかな湖 |

### 調整する

追加する前は、詳細プレビューの下にある「波・さざ波」「反射・透明感」「泡」「演出」「色」で調整します。追加した後もInspectorの **調整できる値** で変更できます。

選択中の詳細で動きを確認できます。「試し風」はプレビュー専用です。シーン設定や追加するマテリアルの風設定は変更しません。

分割していない平面では「頂点変位」を0にします。波の輪郭も上下させる場合は、十分に分割した水平メッシュを使って頂点変位を上げます。

> **表現の範囲**: 岸の泡は「岸の位置・方角・幅」による直線の演出です。地形や岩との接触を自動検出しません。反射は設定した空色の近似、集光模様は水面上の演出です。物体の鏡映、実際の水深、背景の屈折、水底への集光は扱いません。

同じプリセットを追加し直すと、同じマテリアルが現在の設定で更新されます。既存の調整を残す場合は、更新する前にプロジェクトを保存・バックアップしてください。詳細は [水面シェーダー v2の仕様と検証範囲](../WATER_SHADER_V2.md) にまとめています。

### 風の向きと強さを変える

水面の波の向きと速さは、マテリアル側ではなく **シーン設定の風** から受け取ります。草と同じ風で動くため、水だけ別方向に流れることがありません。プリセットの **波の速さ** は、その風に対する倍率です。0 にすると水面が止まります。
