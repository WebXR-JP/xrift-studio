# ノードで動きを作る

ノードは「待つ」「色を変える」などの処理を表す部品です。線でつなぐと、コードを書かずに動きや仕掛けを作れます。

まず動く見本を試す場合は、**外部から追加 → 3Dセット**の仕掛けを配置してください。自分で組み立てる場合は、次の手順でグラフを作ります。

## 作成してEntityに付ける

1. **Assets**の追加メニューから、新しい**ノードグラフ**を作ります。ノードエディターが開きます。
2. グラフを動かすEntityを**Hierarchy**で選びます。
3. エディター上部の案内から、選んだEntityにグラフを付けます。Inspectorでは**グラフの実行**Componentとして表示されます。

**素材として作っただけでは動きません。**「開始時に実行」から始まるグラフも、Entityに付ける必要があります。

プレイヤーが押すと動く仕掛けには、同じEntityに**操作を受け付ける（Interactable）**も必要です。不足している場合は、上部の案内から追加できます。

## きっかけを選ぶ

| ノード | 実行するタイミング |
| --- | --- |
| 開始時に実行 | ワールドの開始時に一度だけ |
| 毎フレーム実行 | 画面が更新されるたび。重い処理はつながないでください。 |
| 操作されたとき | プレイヤーがEntityを操作したとき |
| イベントを受信 | 対応するイベントが送られたとき |

空いている場所を右クリックするか、**追加**を押してノードを選びます。現在のノード名、説明文、`flow/setDelay`などの操作IDで検索できます。Enterで先頭の候補を追加します。

## 線をつなぐ

処理の接続は紫、値の接続は水色です。処理と値を直接つなぐことはできません。

| 接続先 | 次の処理が始まるタイミング |
| --- | --- |
| 出力 | 処理を開始した直後。待機や時間をかける変化の完了は待ちません。 |
| 完了後 | 待機・再生・値の変化が終わった後 |
| 失敗時 | 処理を実行できなかったとき |

たとえば「3秒待ってから扉を動かす」場合は、**開始時に実行 → 指定時間待つ → Entityの設定を変更**とつなぎます。待機ノードの秒数を3にし、**完了後**から次の入力へ線をつないでください。

**順に実行**は、接続先を順番に開始するノードです。アニメーションや待機が終わるまで待つ機能ではありません。終わってから次へ進める場合は、それぞれの**完了後**を使います。

**番号を変えて繰り返す**は、終了番号を含みません。開始0・終了3なら、番号0・1・2の3回です。**番号で分岐**は0が1番目、1が2番目の接続先になります。

## 位置・色・音量などを変える

**Entityの設定を変更**を追加し、**Node Inspector**で対象、変更する項目、値を選びます。

| 対象 | 主な設定 |
| --- | --- |
| Entity | 表示・非表示 |
| 位置・回転・大きさ | 座標、角度、倍率 |
| アニメーション | 再生・停止、クリップ番号、速度、再生位置 |
| マテリアル | 基本色、発光、不透明度 |
| パーティクル | 放出、放出数、色、大きさ |
| 音源 | 再生・停止、音量、繰り返し |
| ライト | 点灯・消灯、明るさ、色 |
| テキスト・画像 | 表示内容や見た目 |
| シーン | 露出、霧、空、画面のフェードなど |
| プレイヤー | 移動先など |

初期状態では、そのグラフが付いたEntityが対象です。別のものを動かす場合だけ、対象を選び直します。グラフによるマテリアルの変更は、対象のEntityにだけ反映されます。

数値や色には、**かける時間（秒）**と**変わり方**を指定できます。時間が0ならすぐに変わります。位置には移動量ではなく、移動先の座標を入力します。

「オン・オフを切り替え」は、実行するたびに表示や点灯などの状態を反転します。

## ほかの人にも見せる

シーンの見た目やプレイヤーの移動は、操作した人の端末だけに反映されます。ほかの人の画面や位置は変わりません。

扉・色などの変更を共有する場合は、対象の設定で**みんなに見せる**を有効にします。同じ部屋の参加者と、後から入った人にも状態が反映されます。同時に変更された場合は、最後に受け付けた値が残ります。1人での動作確認だけでは共有を確認できないため、公開先でも複数人で確認してください。

## モデルのアニメーションを再生する

アニメーションのあるモデルは、読み込み設定に応じて、配置時に再生用のグラフが作られます。後から作る場合は、モデルの設定からアニメーション用グラフを作成し、そのモデルのEntityに付けます。

グラフには各アニメーションの再生ノードが並びます。不要なものはノードを削除してください。終了位置を指定しない再生は繰り返すため、1回だけ再生する場合は終了位置を指定します。

以前のAnimationComponentは、プロジェクトを開いたときにグラフへ移行されます。自動再生が無効なものや、存在しないクリップを参照するものは同じ形では移行できません。表示された件数と内容を確認してから保存してください。

## 保存と動作確認

グラフは自動保存されます。エラーがある間は保存を止めるため、下部の保存状態と**問題の一覧**を確認してください。

**タイムライン**では、開始時からの処理順や時間を確認できます。未到達のノードは、条件や接続を確認する手掛かりです。実際の見た目や操作は**Play**で確かめてください。

**実行未対応**のノードは保存できても動きません。**対象の設定が必要**と表示された場合は、対象にモデルや音源などがあるか確認します。利用できるかどうかはノードの表示と問題の一覧で判断してください。

1つの素材に複数のグラフを作れます。通常のグラフ実行では、素材内のグラフはすべて実行対象です。「既定のグラフ」は、モデルへの埋め込みなど、1つだけを選ぶ場面に使います。

## 編集の操作

| 操作 | 方法 |
| --- | --- |
| 表示範囲を動かす | 空いている場所をドラッグ、またはホイール |
| 拡大・縮小 | Ctrl + ホイール |
| 元に戻す・やり直す | Ctrl + Z / Ctrl + Shift + Z |
| 複製・コピー・貼り付け | Ctrl + D / Ctrl + C / Ctrl + V |
| ノードや線を削除 | Delete、Backspace |
| 左から右へ並べ直す | 整列 |

保存形式は`KHR_interactivity`を基にしたJSONです。XRift固有の操作には拡張が含まれるため、他のツールで同じ動作になるとは限りません。詳しい形式や対応状況は[開発仕様](../KHR_INTERACTIVITY_EDITOR.md)を参照してください。

作例は[12秒の演出を作る](./interactivity-timeline.md)、コードでの制作は[スクリプト](./scripting.md)、AIからの編集は[AI連携](./ai-connection.md)にまとめています。
