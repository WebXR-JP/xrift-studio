# ノードで動きをつける（Interactivity）

Interactivity は、ノードをつないで動きを組む仕組みです。保存されるのは独自形式ではなく、glTF の標準拡張 **KHR_interactivity** に準拠した JSON です。

TypeScript を書く [Scripting](./scripting.md) とは別の道具で、コードを書かずに「開始から 3 秒待ってドアを開ける」「音量を 2 秒かけて上げる」といった、時間に沿って進む動きを組めます。

実際に 1 本作ってみる手順は [タイムラインを 1 本つくる](./interactivity-timeline.md) にあります。

## 何をきっかけに動くか

| ノード | いつ動くか |
| --- | --- |
| 開始時（`event/onStart`） | ワールドに入った直後に 1 回 |
| 毎フレーム（`event/onTick`） | 毎フレーム |
| イベント受信（`event/receive`） | 「イベント送信」が送った名前を受け取ったとき |
| インタラクト時（`xrift/onInteract`） | Entity に付けた Interaction Trigger が押されたとき |

「インタラクト時」を使うグラフは、Entity へ **Interaction Trigger** コンポーネントで結びつけ、その Entity に公式の **Interactable** も付けます。片方だけだと、押せるのに何も起きない、または動くのに押せない状態になります。

## グラフを作る

1. Assets パネルの **＋** から **新規 Interactivity Graph** を選びます。
2. 作られた Asset はそのままノードエディターで開きます。あとから開くときはダブルクリックです。
3. **追加** を押すと、ノードを 1 つ置くほかに、つながった状態のレシピを選べます。

1 つの Asset は複数のグラフを持てます。左上のプルダウンで切り替え、その右のメニューから追加・複製・名前変更・削除ができます。**Asset の中のグラフはすべて同時に動きます**。演出のまとまりごとにグラフを分けると、あとから読みやすくなります。

「既定のグラフにする」で選んだ 1 つは、Model へ埋め込む場合や、1 つだけを走らせる書き出しで使われます。

## 画面の見かた

- 線の色が種類を表します。**紫が flow（処理の流れ）**、**水色が value（値）** です。この 2 つはつながりません。
- ノードを選ぶと、そのノードにつながる線が太くなり、右の **Node Inspector** で値と設定を編集できます。
- 下部に **ノード数・接続数・KHR graph validation** が出ます。検証が通らないグラフは、保存する前に気づけます。
- **整列** で、流れの順に左から右へ並べ直します。
- **JSON** で、実際に保存される内容をそのまま確認・貼り付けできます。

ドラッグまたはホイールで移動、Ctrl + ホイールで拡大縮小します。ノードは 24px のグリッドに吸着します。

### 覚えておくと早い操作

| 操作 | キー |
| --- | --- |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z |
| 選んだノードを複製する（接続は引き継がない） | Ctrl+D |
| 選んだノードをコピー / 貼り付け | Ctrl+C / Ctrl+V |
| ノードや線を削除する | Delete または Backspace |
| 閉じる、パネルを閉じる | Esc |

線は端をつかんで別の socket へ付け替えられます。つながらない組み合わせは、ドラッグ中に拒否されます。

## つなげるノード

**きっかけ** — 開始時、毎フレーム、イベント送信、イベント受信、インタラクト時

**流れを組む** — 分岐、値で分岐、順番に実行、待機、待機を取り消す、N 回だけ通す、回数で繰り返す、条件の間くり返す、順番に切り替え、すべて揃うまで待つ、連続実行を防ぐ

**動かす** — プロパティを変える、ON/OFF を反転する、アニメーション再生、アニメーション停止、時間を指定して停止

**値** — 四則演算、比較、論理、三角関数、クランプ、補間、乱数、変数の取得・設定・ゆっくり変える

パレットの各行には、Play と公開先で実際に動くかどうかのバッジが付きます。**「Play未対応」と出るものは、置いて保存はできますが動きません。** いまのところ `pointer/*`（glTF のプロパティを JSON ポインタで直接指すもの）がこれに当たります。同じことは「プロパティを変える」でできます。

## 何を変えられるか

「プロパティを変える」で書き込める対象は 8 種類です。対象は Node Inspector のピッカーから選びます。Scene 全体もこの一覧の先頭にあります。

| 対象 | 変えられるもの |
| --- | --- |
| Entity | 表示 / 非表示 |
| Transform | 位置、回転（度）、大きさ |
| Animation | 再生中か、クリップ、速度、再生位置 |
| Material | ベースカラー、発光、発光の強さ、不透明度 |
| Particle | 放出、リスタート、放出量、大きさ、不透明度、色 |
| Audio Source | 再生 / 一時停止 / 停止、音量、ループ |
| Light | ON/OFF、明るさ、色 |
| Scene | 露出、フェード、フェードの色 |

Material への書き込みは、その Entity が使っている分だけに効きます。同じ Material を使う別の Entity には影響しません。Play を止めると、書き換えた値は元に戻ります。

## 時間をかけて変える

数値・色・XYZ のプロパティには **「かける時間（秒）」** と **「変わり方」** が出ます。0 のままならその場で変わり、秒数を入れるとその時間をかけて滑らかに変化します。

変わり方は 7 種類です。選ぶと、隣に曲線の形が出ます。

| 変わり方 | どんな動き |
| --- | --- |
| 一定の速さ | 最初から最後まで同じ速さ |
| ゆっくり始まる / 強くゆっくり始まる | 動き出しが遅い。落下や加速に |
| ゆっくり止まる / 強くゆっくり止まる | 止まり際が遅い。ほとんどの移動はこれで自然になる |
| 両端がゆっくり | 動き出しと止まり際の両方が遅い。カメラの寄りに |
| 少し行き過ぎて戻る | 目標を少し越えてから戻る。蓋や看板が止まるときに |

ON/OFF と選択肢のプロパティには時間の欄が出ません。途中の値を持たないため、時間を指定しても最後に飛ぶだけになるからです。

「プロパティを変える」には出力が 2 つあります。**「出力」は変化を始めた時点で次へ進み、「完了後」は変化し終わってから次へ進みます。** 同時にいくつも動かしたいときは「出力」、順番に動かしたいときは「完了後」につなぎます。時間が 0 のときは、どちらもその場で通ります。

## 動きを確かめる

**タイムライン** を開くと、Play を始めなくても「いつ何が起きるか」が見られます。

- 対象ごとに行が並び、時刻が点で置かれます。停止まで決まっている再生と、時間をかける変化は、長さのある帯になります。
- 表示範囲は 30 / 60 / 120 / 300 秒から選べます。
- 時刻のつまみを動かすと、その先の項目が控えめになります。
- 項目を押すと、それを起こしたノードが選ばれます。

タイムラインを開いている間は、**一度も動かなかったノードが薄く表示され「未到達」と出ます**。つないだつもりで線が外れている、条件が一度も true にならない、といった見落としはここで見つかります。

Diagnostics の各行を押すと、対象のノードへ移動します。別のグラフのノードなら、そのグラフに切り替わります。

## Scripting との使い分け

| | Interactivity | [Scripting](./scripting.md) |
| --- | --- | --- |
| 書くもの | ノードの接続 | TypeScript |
| 保存形式 | glTF 標準の JSON | プロジェクト内の Script Asset |
| 向いていること | 時間に沿って進む演出、待つ・繰り返す・順番に動かす | 条件が複雑な処理、外部データ、独自の描画 |
| 他のツールで開く | KHR_interactivity として読める | XRift Studio 固有 |

## AI から同じことをする

ノードエディターでできる操作は、Undo / Redo と表示だけの操作を除いて MCP からも実行できます。グラフの作成、ノードの追加と接続、対象の指定、かける時間と変わり方、整列、そして実行結果の取得までが tool になっています。詳しくは [AI と一緒に Scene を編集する](./ai-connection.md) を参照してください。
