# ノードで動きをつける（Interactivity）

Interactivity は、ノードをつないで動きを組む仕組みです。保存されるのは独自形式ではなく、glTF の標準拡張 **KHR_interactivity** に準拠した JSON です。

TypeScript を書く [Scripting](./scripting.md) とは別の道具で、コードを書かずに「開始時に色を変える」「毎フレーム少しずつ動かす」といった処理を組めます。

## 何をきっかけに動くか

きっかけになるノードは 3 種類です。

| ノード | いつ動くか |
| --- | --- |
| `event/onStart` （開始時） | ワールドに入った直後に 1 回 |
| `event/onTick` （毎フレーム） | 毎フレーム |
| `event/receive` （イベント受信） | `event/send` で送られたイベントを受け取ったとき |

> **クリックや視線に反応するトリガーはありません。** 触ったら開く扉のような、利用者の操作に応じた動きは Interactivity では作れません。時間とイベントで進む動きのための仕組みです。

## 作る

1. Assets パネルで **Interactivity** を選び、新しい Asset を作成します。
2. 作成した Asset をダブルクリックすると、ノードエディターが開きます。
3. **追加** から、よくある動きのレシピを選ぶと、つながった状態のノードがそのまま置かれます。

`Animation on start` のレシピは、`event/onStart` から `animation/start` へ線がつながった状態で始まります。

## ノードエディターの見かた

- 線の色で種類がわかります。**紫が flow（処理の流れ）**、**水色が value（値）** です。
- ノードを選ぶと、右の **Node Inspector** で色や時間などの値を直接編集できます。
- 下部に **ノード数・接続数・KHR graph validation** の状態が出ます。検証が通らないグラフは保存前に気づけます。
- **全体表示** でグラフ全体を画面に収め、**JSON** で実際に保存される内容を確認できます。

ドラッグまたはホイールで移動、Ctrl + ホイールで拡大縮小します。

## 使えるノード

KHR_interactivity の標準的な操作が使えます。

| 種類 | 例 |
| --- | --- |
| **フロー制御** | 分岐、順次実行、繰り返し、待機、間引き |
| **数値** | 四則演算、三角関数、ベクトル演算、比較、クランプ |
| **アニメーション** | 再生、停止、指定時刻で停止 |
| **変数** | 取得、設定、補間 |
| **ポインタ** | Material のプロパティを取得・設定・補間 |

「ポインタ」はマウスポインタではなく、glTF のプロパティを指す **JSON ポインタ** です。これを使って Base Color、発光、Metallic、Roughness、テクスチャのタイリングやオフセットなどを動かせます。

## Scripting との使い分け

| | Interactivity | [Scripting](./scripting.md) |
| --- | --- | --- |
| 書くもの | ノードの接続 | TypeScript |
| 保存形式 | glTF 標準の JSON | プロジェクト内の Script Asset |
| きっかけ | 開始時・毎フレーム・イベント | ライフサイクルと `update(delta)` |
| 利用者の操作への反応 | できない | XRift の Component と組み合わせて可能 |
