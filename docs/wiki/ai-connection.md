# AIと一緒に編集する

**AI連携**パネルからAIクライアントを接続すると、開いているシーンを読み取り、Entityや素材を編集できます。接続にはMCPを使います。

## 接続する

1. ビジュアルエディターで**AI連携**を開きます。
2. インストール済みのAIクライアントを検出します。
3. 使うクライアントを選んで登録します。
4. クライアントを再起動するか、MCPの接続を読み込み直します。

設定項目はCodex、Claude Code、Claude Desktop / Cowork、OpenCode、Cursor向けに用意しています。クライアントによって利用できる接続方法が異なるため、パネル内の案内も確認してください。

Ollamaを使う場合は、モデルがツールの呼び出しに対応しているか設定時に確認します。モデルのダウンロードやクライアントの起動は自動では行いません。

## 作ってほしいものを伝える

場所の名前だけでなく、**そこで何をするか、どんな雰囲気にするか、何を置かないか**を伝えると、意図を共有しやすくなります。

> 夜、友人4人で焚き火を囲んで話す広場を作ってください。草原の地形は使わず、床は石畳にします。完成したら開始位置から見た画像を確認してください。

AIが最初に示す設計案を確認し、方向性が違う場合は制作に入る前に伝えます。Blenderでモデルも作る場合は、Blender側のMCP接続も用意してください。

## 編集が重なったとき

複数のクライアントからの編集は順番に処理されます。処理が混雑すると`EDITOR_BUSY`が返るため、最新のシーンを読み直してから再試行します。

ローカルのMCPサーバーに接続する設定は、同じ端末で動くクライアント向けです。リモート環境からそのまま接続できる設定ではありません。

詳しい操作と制約は[AI連携の仕様](../MCP_EDITOR_TOOLS.md)を参照してください。
