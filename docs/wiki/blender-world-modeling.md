# Blender で部屋をつくって取り込む

家具や小物なら[外部リソース](./external-resources.md)から追加できますが、「この寸法の部屋」を
まるごと用意したいときは、Blender で組んで GLB として取り込むのが早道です。

このページは、部屋や内装のような**建築まわりのモデル**を Blender で作って XRift Studio へ
持ち込むときに、つまずきやすいところをまとめたものです。

## 作る順番

一度に完成させようとせず、大きい形から決めていくと手戻りが減ります。

1. 部屋（床・天井・壁）
2. テーブルなど大きな家具
3. 椅子
4. 窓とドアの開口部
5. 壁の仕上げ（腰壁、見切り）
6. 吸音パネルやルーバー
7. 小物と機材
8. 照明器具の位置

各段階でレンダリングして全体を確認してから次へ進みます。

## 面をぴったり重ねない

**いちばん多い失敗がこれです。** 壁に貼るパネルの裏面を、壁の内面とちょうど同じ座標に
置いてしまうと、XRift でその面がチラチラと明滅します（Z-fighting）。

```
壁の内面   x = -1.80
パネル裏面 x = -1.80   ← 同じ。これが原因
```

同じ平面に 2 枚の面があると、どちらが手前かを数値の丸め誤差が決めるため、カメラが動くたびに
勝敗が入れ替わります。**パネルは壁へ 3〜5mm 食い込ませてください。**

```
壁の内面   x = -1.80
パネル裏面 x = -1.804  ← 壁の中へ沈める
```

Blender のビューポートでは出ないのに XRift で出ることがよくあります。Blender は近くを
映していることが多く、深度の精度に余裕があるためです。**Blender で見えない ＝ 大丈夫、
ではありません。**

同じことが次の組み合わせでも起こります。

| 置くもの | 相手 |
| --- | --- |
| 吸音パネル、化粧パネル | 壁の内面 |
| 腰壁、幅木、見切り、笠木 | 壁の内面 |
| 天井埋め込みのダウンライト | 天井の下面 |
| テーブルや椅子の脚の底面 | 床の天面 |
| 卓上の機材の底面 | 天板の上面 |
| 窓枠・ドア枠 | 開口部の縁 |

**1 つのオブジェクトの中でも同じです。** 照明器具の「筒」と「レンズ」を結合して 1 つに
まとめても、両方の底面が同じ高さにあれば明滅します。部品どうしも数 mm 重ねてください。

## マテリアルを片面にする

Blender のマテリアルは初期状態で両面描画です。そのまま書き出すと glTF に
`doubleSided: true` として記録され、**背中合わせに重なった面が両方描画されて**
明滅の原因になります。

マテリアルプロパティの **Settings → Backface Culling** を有効にしてください。
ガラスのように裏側からも見せたいものだけ、両面のまま残します。

箱で組んだ部屋は、部屋に面した側の法線がもともと部屋を向いているので、片面にしても
見た目は変わりません。描画の負荷はむしろ下がります。

## 書き出す前に確認すること

| 項目 | なぜ |
| --- | --- |
| スケールがすべて 1 | 1 以外だと法線と衝突判定が崩れます |
| UV がすべてのメッシュにある | テクスチャが貼れません |
| モディファイアが残っていない | 意図しない形で書き出されます |
| 空のマテリアルスロットがない | 取り込み後に色が付きません |

書き出しは **glTF 2.0 (.glb)** を選び、次を設定します。

- **Include → Cameras / Punctual Lights**: オフ（照明は XRift 側で置きます）
- **Data → Mesh → Apply Modifiers**: オン
- **Data → Material → Images**: 元が JPEG なら「Automatic」のままで容量を抑えられます

## 取り込んだあとにすること

GLB の取り込み手順そのものは[3D 素材の取り込み](./importing-assets.md)を参照してください。
部屋をまるごと取り込んだ場合は、追加で次を確認します。

**初期状態の床を消す。** 新規ワールドには 8×8m の床が入っています。自作の床と同じ高さに
あるので、そのままだと重なって明滅します。Hierarchy で「床」を選び、Inspector の
チェックを外して無効にしてください。

**Spawn Point を部屋の中へ動かす。** 初期位置は原点から離れた場所にあり、たいていの部屋は
そこまで届きません。部屋の中の何もない場所へ移し、見せたい方向へ向けます。

**軸の向きが変わります。** Blender の `+Y` 側にあった壁は、XRift では `-Z` 側になります。
Blender の座標 `(x, y, z)` は XRift の `(x, z, -y)` に対応します。

**当たり判定を減らす。** 取り込み時に全パーツへ Mesh Collider が付きます。文字や
サイン、照明器具のように触らないものは、Collider を無効にすると軽くなります。

## AI に任せる

この一連の作業は、[AI と一緒に Scene を編集する](./ai-connection.md)で接続したコーディング
エージェントに任せられます。リポジトリには `xrift-blender-world` というスキルが同梱されて
いて、ここに書いた注意点と、面の重なりを機械的に検出するスクリプトが入っています。

「Blender で 3.6 × 2.8m の収録スタジオを作って、XRift に取り込んで」のように頼むと、
このページの手順に沿って進めます。

## できあがったものを試す

「収録スタジオ」は、このページの手順で作った部屋です。外部アセットの「セット」から
Scene へ置くと、机・椅子・マイク・ON AIR サインまで入った一室が一度に入ります。
Mesh Collider 付きなので、置いたらそのまま中を歩けます。
中身の作りを見たいときの参考にしてください。
