# データの保存場所とリセット

XRift Studio のランタイム、キャッシュ、ログイン情報、プロジェクトは、OS ごとに次の場所に保存されます。

| OS | 保存場所 |
| --- | --- |
| Windows | `%APPDATA%\net.xrift.studio\` |
| macOS | `~/Library/Application Support/net.xrift.studio/` |
| Linux | `~/.local/share/net.xrift.studio/` |

プロジェクトはこの下の `projects` に置かれます。実際のパスは、プロジェクトライブラリの件数の下にも表示されています。

## リセット（危険領域）

右上の歯車から **設定とバージョン情報** を開くと、下部に **危険領域 (Danger Zone)** があります。ここから 2 種類のリセットを実行できます。どちらも実行後にアプリが再起動します。

| リセット | 削除されるもの | 残るもの |
| --- | --- | --- |
| **ランタイムのみ** | Node.js、`@xrift/cli`、ログイン状態 | プロジェクト |
| **完全リセット** | 上記に加えて、アプリが管理するすべてのプロジェクト | なし |

どちらを押しても、削除される内容を示す確認画面が出ます。そこで実行を選ぶまで何も削除されません。

> **重要**: 完全リセットは元に戻せません。残したいワールドやアイテムは、先に別の場所へバックアップしてください。

`@xrift/cli` のバージョンを確認している間は、どちらのボタンも押せません。確認が終わるまで待ってください。

## リセットの使いどころ

- **セットアップに失敗する**: ネットワーク接続を確認し、アプリを再起動して再試行します。直らない場合に「ランタイムのみ」を実行します。
- **Node.js や CLI を入れ直したい**: 「ランタイムのみ」で再セットアップできます。プロジェクトは残ります。
- **環境ごと初期状態に戻したい**: 「完全リセット」を実行します。

## バージョンを確認する

同じ画面の上部で、アプリ本体、同梱の Node.js、`@xrift/cli` のバージョンを確認できます。アプリ本体は **更新を確認** から手動でも確認できます。
