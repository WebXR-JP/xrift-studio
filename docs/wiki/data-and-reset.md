# データの保存場所とリセット

XRift Studio のランタイム、キャッシュ、ログイン情報、プロジェクトは、OS ごとに次の場所に保存されます。

| OS | 保存場所 |
| --- | --- |
| Windows | `%APPDATA%\net.xrift.studio\` |
| macOS | `~/Library/Application Support/net.xrift.studio/` |
| Linux | `~/.local/share/net.xrift.studio/` |

## リセット（Danger Zone）

About の **Danger Zone** から、次のリセットを実行できます。

| リセット | 削除されるもの | 残るもの |
| --- | --- | --- |
| **ランタイムのみ** | Node.js、CLI、キャッシュ、ログイン状態 | プロジェクト |
| **プロジェクトのみ** | アプリが管理するプロジェクト | ランタイム、ログイン状態 |
| **完全リセット** | 上記のランタイムとプロジェクトすべて | なし |

> **重要**: リセット前に、残したいワールドやアイテムを別の場所へバックアップしてください。

## リセットの使いどころ

- **セットアップに失敗する**: ネットワーク接続を確認し、再起動して再試行。直らない場合は「ランタイムのみリセット」を実行します。
- **環境を初期状態に戻したい**: 「ランタイムのみリセット」で Node.js と CLI を再セットアップできます。
- **プロジェクトをすべて消したい**: 「プロジェクトのみリセット」または「完全リセット」を実行します。
