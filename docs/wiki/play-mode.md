# Play / Stopで動作を確認する

ビジュアルエディターでは、編集状態を保ったまま **Play** へ切り替えて、シーンの動作を確認できます。別のブラウザや開発サーバーを開く必要はありません。

## Playで動作を確認する

エディターの **Play** ボタン（`F6` または `Ctrl/⌘ + Enter`）を押します。中央が **Play Window** に切り替わり、太い境界と専用のヘッダーで編集用のシーンと区別されます。

- **ワールド**: 公開したワールドと同じ一人称プレイヤーが起動します。重力、衝突判定、ジャンプ、掴み、操作、スクリプト、ノードグラフの動作をそのまま確認できます。

シーンの 3D モデルを読み込み終えてからプレイヤーが出ます。読み込み中は案内面に「3Dモデルを読み込み中」と出て、重力もまだかかりません。モデルと一緒に衝突判定が届くので、先にプレイヤーを出すと床のない世界へ落ち、あとから地面がかぶさって埋まった状態で始まってしまうためです。読み込みが 15 秒で終わらないときは、待たずにプレイヤーを出します。
- **アイテム**: ワールドの移動やプレイヤーを前提にせず、単体の見え方を確認します。

### ワールドの操作

Play Windowをクリックするとマウスが固定され、プレイヤーを操作できます。

| 操作 | 内容 |
| --- | --- |
| クリック | マウス固定を開始 / クロスヘアの先の操作を受け付けるを押す |
| ドラッグ | マウス未固定のあいだの視点操作 |
| WASD、矢印キー | 移動 |
| Space、E | ジャンプ |
| G | 掴む / 置く（つかんで移動） |
| マウスホイール | 掴んでいる間の距離調整 |
| Esc | マウス固定を解除 |

クロスヘアは、届く範囲（3.5m）に操作を受け付けるがあるときだけ明るくなります。公開ワールドと同じ距離なので、ここで届かないボタンはアップロード後も届きません。

床に衝突判定がないと落下し、Y が -10 を下回った時点で開始位置へ戻ります。これも公開ワールドと同じ挙動なので、落ちる場合は衝突判定を確認してください。

マウス固定中はキー入力をワールドが受け取ります。HierarchyとInspectorを操作するときは Esc でマウス固定を解除してください。

Esc の直後はブラウザが約 1 秒のあいだマウス固定を受け付けません。すぐクリックし直すと固定できない旨が案内面に出るので、少し待ってからクリックしてください。

マウスが固定できていないあいだは、画面をドラッグして視点を動かせます。感度は固定中と同じなので、見える範囲は変わりません。macOS の WebView のようにマウス固定自体を受け付けない環境では、続けて 2 回断られた時点で案内面が「この環境ではマウスを固定できません」に変わります。その場合もドラッグで視点、WASD で移動、クリックで操作ができるので、動作確認は続けられます。

操作を受け付けるを押すのに衝突判定や RigidBody は必要ありません。クロスヘアは描画されているメッシュを見ています（衝突判定は歩いてぶつかるかどうかだけを決めます）。

鏡、タグ選択、動画プレイヤー、画面共有などの公式Componentは、動作確認でも編集中と同じ実描画で動きます。開始位置のマーカーだけは動作確認で消えます。公開したワールドでも表示されないためです。

Play Windowに映るのは編集データのコピーです。HierarchyとInspectorは編集データを表示し続けます。

## 動作確認中にできること

動作確認を止めずに次を変更できます。変更は通常どおり履歴と自動保存に入り、変更したEntityだけが作り直されます。

- 位置・回転・大きさ、衝突判定の設定
- Entityの追加・削除・複製・親子付け替え、Componentの追加
- スクリプトの宣言済みプロパティ（次のフレームから反映）

動作確認中は次を変更できません。

- 素材、マテリアル、シーン設定
- ギズモ操作と素材のドロップ

スクリプトの `ctx.materials`、`ctx.lights`、`ctx.audioSources` などによる変更は、そのスクリプトが動いている間だけの一時的なものです。停止すると保存済みの値へ戻ります。

## Stopで編集に戻る

**Stop**（`Ctrl/⌘ + Enter`）を押すと編集モードに戻ります。マウス固定は自動で解除されます。実行中のアバター、カメラ、入力状態、物理は破棄され、動作確認中に加えた編集を含む最新のシーンと、動作確認前の選択・カメラへ戻ります。実行中の位置や速度が保存データへ書き戻されることはありません。

## 公式サンプルのテンプレート

新規プロジェクトの **XRift公式サンプル** は、押すと動くところまで用意されています。

- **青いボタン 2 つ** — 押すと色が変わる / 押すと光る
- **紫のポータル** — 押すと隠し部屋へテレポート。隠し部屋のポータルを押すと入口へ戻る

元の公式コードサンプルはボタンにもポータルにも処理が無く、「0回クリック」も増えない固定文字列でした。Studio へ変換したあとにノードグラフを付けて、押したら動く状態にしています。中身は普通の Graph なので、開いて書き換えられます。
