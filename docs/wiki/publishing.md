# XRift への公開（アップロード）

制作したワールドやアイテムを XRift に公開します。

## 公開の流れ

1. **ログイン** します。
2. **アップロード** を押します。
3. タイトル、説明、サムネイルを確認します。
4. ビジュアル制作データは、保存・検査・XRift 向け TSX 変換を行ってから種別に応じてアップロードします。
5. アップロード完了後に公開 URL を表示し、そのまま XRift のページを開きます。

## 公開前の確認

アップロードの直前に、`xrift.json` のタイトル・説明とサムネイルが**テンプレートのままではない**ことを確認します。未編集のままなら公開を開始せず、編集画面へ案内します。すべて整ったときだけアップロードを続けます。

## アイテムの検査

アイテムでは、ビルドを含むセキュリティチェックを実行し、結果と修正に必要なログを確認できます。

## 公開情報を整える

タイトル、説明、ビルド設定、サムネイルを編集できます。ワールドでは物理・カメラ、アイテムでは権限も設定できます。
