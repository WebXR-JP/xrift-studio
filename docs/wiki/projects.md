# プロジェクトの作成とライブラリ

XRift Studio では、制作する作品を「プロジェクト」として管理します。プロジェクトライブラリは、サムネイル、名前、説明、件数、作成入口を一望できる制作のホームです。

## プロジェクトライブラリ

セットアップが完了すると、プロジェクトライブラリが表示されます。ここでは次のことができます。

- 保存済みのプロジェクトをカードで一覧表示
- 種別、サムネイル、名前、説明でプロジェクトを見分ける
- 新しいプロジェクトを作成する
- 既存のプロジェクトを開いて制作を再開する

一覧の先頭には、常に**新規プロジェクト**の入口が置かれています。空の状態でも次の操作を失いません。

## 新しいプロジェクトを作る

1. プロジェクトライブラリで **新規プロジェクト** を選びます。
2. 次の 4 通りから選びます。

| 種別 | 説明 |
| --- | --- |
| ワールド（クラシック） | コードでワールドを制作する |
| ワールド（ビジュアル） | ビジュアルエディターでワールドを制作する |
| アイテム（クラシック） | コードでアイテムを制作する |
| アイテム（ビジュアル） | ビジュアルエディターでアイテムを制作する |

3. 作成が完了すると、作成したプロジェクトがそのまま開きます。

### ワールドとアイテムの違い

- **ワールド**: 複数人が入れる 3D 空間。地形、建物、インタラクティブなオブジェクトなどを配置します。
- **アイテム**: ワールド横断で使える持ち運び可能なインタラクティブオブジェクト。

### クラシックとビジュアルの違い

- **クラシック**: コード（World.tsx など）と設定ファイルを直接編集します。XRift の通常の開発フローに近い形です。
- **ビジュアル**: コードを書かずに、Hierarchy、Scene View、Inspector、Assets を使って視覚的に Scene を組み立てます。制作データは型付きデータとして保存されます。

## プロジェクトを開く

プロジェクトライブラリで、開きたいプロジェクトのカードを選びます。選んだプロジェクトがエディターで開きます。

## プロジェクトの保存場所

プロジェクトはアプリが管理する領域に保存されます。詳しくは [データの保存場所とリセット](./data-and-reset.md) を参照してください。
