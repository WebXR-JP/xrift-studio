# プロジェクトを作る・開く

作品ごとにプロジェクトを作ります。セットアップが終わると、保存済みのプロジェクトが一覧に表示されます。

## 新しく作る

**新規プロジェクト**を押し、作品の種類と編集方法を選びます。

| 選ぶ項目 | 内容 |
| --- | --- |
| ワールド | 人が入って過ごせる3D空間を作ります。 |
| アイテム | ワールドで使うアイテムを作ります。 |
| ビジュアル編集 | 素材を画面上に配置し、Inspectorやノードで見た目と動きを調整します。 |
| コード編集 | `World.tsx`などのコードと設定ファイルを直接編集します。 |

プロジェクト名はフォルダー名にも使います。半角の英小文字・数字・ハイフンが使え、先頭は英小文字か数字にします。画面で使うタイトルは、作成後に公開情報で設定できます。

作成が終わると、そのプロジェクトが開きます。[編集画面の使い方](./visual-editor.md)か[コード編集](./classic-editor.md)へ進んでください。

## 制作を再開する

一覧でプロジェクトのカードを選ぶと、編集画面が開きます。名前やサムネイルを設定しておくと、作品が増えても見分けやすくなります。

保存場所は[データの保存とリセット](./data-and-reset.md)を参照してください。

## 複製・受け渡し

カードの**複製**で、別名のプロジェクトを作れます。**ZIPに書き出す**でまとめたファイルは、別のXRift Studioの**ZIPから取り込む**で開けます。**Gitから取り込む**は、リポジトリの内容を新しいプロジェクトとしてコピーします。GitHub上にforkを作る操作ではありません。

複製・取り込み後のプロジェクトは未公開になります。元の作品とは別に公開でき、元の公開先には影響しません。
