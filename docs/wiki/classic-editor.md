# コード編集

コード編集プロジェクトでは、コードと設定ファイルを直接編集してワールドやアイテムを制作します。XRiftの通常の開発手順に沿って作業できます。

## 画面の構成

コード編集は、次のような画面で構成されています。

- **ファイル一覧**: プロジェクト内のファイルを一覧表示します。
- **コードエディター**: 選択したファイルを編集します。
- **ログ**: 実行ログを確認します。
- **動作確認 / XRiftへ公開**: ローカルプレビューや公開を行います。

## コードと設定を編集する

ファイル一覧から編集するファイルを選びます。ファイルを追加するには、ファイル一覧にドロップしてください。ファイルの追加だけではXRiftへ送信されません。

- `Ctrl/⌘ + S` で保存します。
- 主要なファイルは次のとおりです。

| ファイル | 役割 |
| --- | --- |
| `World.tsx` | ワールドのメインコード（React Three Fiber） |
| `xrift.json` | プロジェクトの設定（タイトル、説明、ビルド設定など） |

### `xrift.json` の編集

`xrift.json` は、**フォーム**と **JSON** の両方で編集できます。

- **フォーム**: タイトル、説明、サムネイルなどを入力欄から編集します。
- **JSON**: 直接 JSON を編集します。

## ローカルで動作を確認する

1. プロジェクトを保存します。
2. **動作確認** を押します。開発サーバーが起動します。
3. プレビュー URL をブラウザで開きます。
4. 実行ログは同じ画面で確認できます。

## 外部ツールで作業を続ける

プロジェクトを **VS Code** または **ターミナル** で開くことができます。外部ツールで作業を続けたい場合に便利です。
