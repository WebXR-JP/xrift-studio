# クラシックエディター（コード編集）

クラシックプロジェクトでは、コードと設定ファイルを直接編集してワールドやアイテムを制作します。XRift の通常の開発フローに近い形です。

## 画面の構成

クラシックエディターは、次のような画面で構成されています。

- **ファイルツリー**: プロジェクト内のファイルを一覧表示します。
- **コードエディター**: 選択したファイルを編集します。
- **ログペイン**: 実行ログを確認します。
- **実行 / アップロード**: ローカルプレビューや公開を行います。

## コードと設定を編集する

内蔵エディタでテキストファイルを編集・保存します。

- `Ctrl/⌘ + S` で保存します。
- 主要なファイルは次のとおりです。

| ファイル | 役割 |
| --- | --- |
| `World.tsx` | ワールドのメインコード（React Three Fiber） |
| `xrift.json` | プロジェクトの設定（タイトル、説明、ビルド設定など） |

### `xrift.json` の編集

`xrift.json` は、**フォーム**と **raw JSON** の両方で編集できます。

- **フォーム**: タイトル、説明、サムネイルなどを入力欄から編集します。
- **raw JSON**: 直接 JSON を編集します。

## ローカルで動作を確認する

1. プロジェクトを保存します。
2. **実行** を押します。開発サーバーが起動します。
3. プレビュー URL をブラウザで開きます。
4. 実行ログは同じ画面で確認できます。

## 外部ツールで作業を続ける

プロジェクトを **VS Code** または **ターミナル** で開くことができます。外部ツールで作業を続けたい場合に便利です。
