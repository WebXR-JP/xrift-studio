# コードエディター用に書き出す

ビジュアルエディターで作ったシーンと素材を、コードエディターで扱えるXRiftのコードプロジェクトへ書き出せます。配置したシーンを引き継ぎ、コードを書いて制作を続けられます。

書き出されるのは、公開時に XRift へ送っているものと同じ TypeScript / React Three Fiber のソースです。公式テンプレートの依存関係に加え、Textなどで必要なパッケージを記録します。依存パッケージのインストール後、`npm run dev` で開いて確認できます。

書き出しは**一方向**です。書き出した先を編集しても、元のビジュアルエディターのプロジェクトへは戻りません。

## エディターから書き出す

ビジュアルエディターのヘッダーにある **コードエディターへ書き出す** を押します。

1. 書き出し先のコードプロジェクトをフォルダー選択で指定します。同じ種別（ワールド／アイテム）である必要があります。
2. 追加される内容と、必要な依存パッケージの一覧を確認します。
3. 実行すると、ビジュアルエディターのプロジェクト ID ごとの領域へシーンのソース、接続コード、由来情報が追加され、素材はワールド直下へ置かれます。
4. 完了後は、フォルダー、VS Code、ターミナル、接続用スニペットへそのまま進めます。

既存の `xrift.json`、サムネイル、開始ファイルファイルは既定では変更しません。開始ファイルを切り替える場合はバックアップと明示的な確認を求めます。手書きのコードを黙って上書きすることはありません。

同じビジュアルエディターのプロジェクトを再度書き出すと、前回書き出したファイルのうち今回生成しなかったものは取り除かれます。手書きのファイルと開始ファイルのバックアップには触れません。

開始ファイルのバックアップは内容ごとに保存します。繰り返し書き出しても、最初のコードと、途中で手直ししたコードを保持します。依存パッケージの取得に失敗した場合は、再度書き出すと取得済みのバージョンを確認して再試行します。自動インストールを使わない場合は、完了画面に表示されるコマンドを実行してください。

## CLI で書き出す

新しい空のフォルダーへコードプロジェクトごと書き出す場合は CLI を使います。

```bash
xrift-studio convert ./my-visual-project --to classic --out ./my-xrift-world
```

| オプション | 説明 |
| --- | --- |
| `--to classic` | 書き出し先の形式を指定します。 |
| `--out <path>` | 書き出し先のフォルダーを指定します。空のフォルダーが必要です。 |
| `--dry-run` | 書き込まずに、診断と生成予定の内容だけを表示します。 |
| `--update` | 同じビジュアルエディターのプロジェクトから生成した、未改変の書き出しだけを更新します。 |

`--update` は、書き出し後にコードエディター側でファイルを追加・削除・変更していない場合だけ実行できます。編集済みの書き出し先を上書きすることはありません。

CLI は npm 公開前のため、リポジトリからビルドして実行します。

```bash
pnpm cli:build
node dist/cli/xrift-studio.mjs convert ./my-visual-project --to classic --out ./my-xrift-world
cd ./my-xrift-world
npm install
npm run dev
```

## 書き出されるもの

- `src/World.tsx` または `src/Item.tsx`: シーン全体を React Three Fiber の JSX として書いたソース。エディターから既存 project へ追加する場合は `src/xrift-studio/<project-id>/` の下に置き、`Scene.tsx` から `XriftStudioScene` として読み込めます
- `src/xrift-studio/*.ts(x)`: 生成コードが使うライト、音声、パーティクル、テキスト、スクリプト、ノードグラフのランタイム。Studio の動作確認と同じ実装です
- `src/scripts/*.ts(x)`: スクリプトを静的 import できる module にしたもの
- 素材一式: 3Dモデル、テクスチャ、音声などの実ファイル。ワールド直下（`public/`）へ `xrift-studio-` を先頭に付けた名前で置きます
- デコーダーとフォント: KTX2 変換ファイル、Draco デコーダー、テキストの書体。公開したワールドが CDN を必要としないよう同梱します
- `package.json` の依存関係: `@xrift/world-components` の版と、テキスト（troika-three-text）やOpen Brush（three-icosa）が必要とするパッケージ
- `.xrift-studio/export-manifest.json`: 由来とハッシュ。`--update` の判定に使います

## 書き出さないもの

- 書き出し先で加えた変更を、ビジュアルエディターのプロジェクトへ戻す同期
- `xrift-studio-runtime` npm package への依存。同 package は未公開のため、書き出し先が npm から取得するものには含めません
