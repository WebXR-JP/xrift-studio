# 12秒の演出を作る

ワールドの開始から、画面のフェード、音、扉、ライトが順に変わる演出を作ります。[ノードの基本操作](./interactivity.md)を確認してから進めてください。

## 用意するもの

動かす扉、ライト、音源をシーンに配置します。音源は**自動で再生する**をオフにし、音量を0にします。ライトの初期の明るさも0にしてください。

新しいノードグラフを作り、シーン内のEntityに**グラフの実行**として付けます。名前は「オープニング」などにします。

## 初期状態を設定する

「開始時に実行」の後に「Entityの設定を変更」を2つ置きます。対象はどちらも**シーン**です。

最初のノードで**フェードの色を白**にし、次のノードで**画面のフェードを1**にします。かける時間はいずれも0です。フェードは1で画面を覆い、0でシーンが見えます。色を指定し忘れると、白い画面から始まりません。

## 時間に沿ってつなぐ

以降は「Entityの設定を変更」を追加します。時間をかける処理の後は、**出力ではなく完了後**から次の入力へつないでください。

| 開始時刻 | 対象と設定 | 目標値 | かける時間 |
| --- | --- | --- | --- |
| 0秒 | シーンの画面のフェード | 0 | 2秒 |
| 2秒 | 音源の再生 | 再生 | 時間指定なし |
| 2秒 | 音源の音量 | 1 | 2秒 |
| 4秒 | 扉の位置 | 開いた位置のXYZ座標 | 3秒 |
| 7秒 | ライトの明るさ | 2 | 1秒 |
| 8秒 | 音源の音量 | 0 | 4秒 |
| 8秒 | シーンの画面のフェード | 1 | 4秒 |

再生ノードの**出力**から音量のノードへつなぐと、再生開始と音量の変化が同時に始まります。最後の2つも、音量のノードの**出力**からフェードのノードへつなぎ、同時に始めます。これで12秒後に終わります。8秒の位置に待機は入れません。

扉の位置は「動かす量」ではなく「移動先」です。シーンで扉を開いた位置へ動かし、座標を控えてから元に戻すと入力しやすくなります。

変わり方は、一定の速さか、ゆっくり止まる設定から試してください。時間が同じでも動き方が変わります。

## 確認する

**タイムライン**を開き、2秒・4秒・7秒・8秒の順に処理が始まり、最後が12秒になっているか確認します。

| 見つかった問題 | 確認すること |
| --- | --- |
| 最初から大きな音が鳴る | 音源の初期音量が0か、自動再生をオフにしたか |
| 複数の処理が早く始まる | 「完了後」ではなく「出力」につないでいないか |
| 終了時刻がずれる | 余計な待機がないか、秒数が表と一致しているか |
| 未到達のノードがある | 開始ノードから線がつながっているか |
| 動作確認で何も起きない | グラフをEntityに付けたか、保存エラーがないか |

保存状態を確認してから**動作確認**で見た目と音を確かめます。**停止**すると、グラフが動作中に変えた値は保存済みの設定へ戻ります。

押して始める場合は「開始時に実行」を「操作されたとき」に替え、グラフを付けたEntityに**操作を受け付ける（Interactable）**を追加します。
