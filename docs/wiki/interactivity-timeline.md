# タイムラインを 1 本つくる

[ノードで動きをつける](./interactivity.md) の作例です。ワールドに入ってから 12 秒間、順番に進む演出を 1 本作ります。コードは書きません。

作るもの:

| 時刻 | 起きること |
| --- | --- |
| 0 秒 | 画面が白いところから始まる |
| 0 → 2 秒 | 白がゆっくり晴れる |
| 2 秒 | 環境音が鳴り始め、2 秒かけて音量が上がる |
| 4 秒 | 扉が 3 秒かけて開く。止まり際はゆっくり |
| 7 秒 | 扉の上のライトが 1 秒かけて明るくなる |
| 8 → 12 秒 | 音量が 4 秒かけて下がり、白へ戻る |

## 用意するもの

Scene に次の 3 つがあれば足ります。名前は何でもかまいません。

- **扉** — 動かす Entity。Primitive の Box で十分です
- **ライト** — Light コンポーネントを付けた Entity
- **環境音** — Audio Source を付けた Entity。**Autoplay はオフ**にしておきます

Autoplay をオフにするのが要点です。オンのままだと、グラフが鳴らす前から鳴っています。

## 1. グラフを作る

Assets パネルの **＋** から **新規 Interactivity Graph**。作られた Asset がそのままノードエディターで開きます。

グラフの名前を「オープニング」にしておくと、あとで増えたときに見分けられます。左上のプルダウンの右にあるメニューから変えられます。

## 2. 白から始めて、晴らす

**追加** から「開始時」と「プロパティを変える」を置き、開始時の **出力** を「プロパティを変える」の **入力** へつなぎます。

置いた「プロパティを変える」を選び、Node Inspector で:

| 欄 | 値 |
| --- | --- |
| 対象 | **Scene** |
| プロパティ | **フェード** |
| 値 | 0 |
| かける時間（秒） | 2 |
| 変わり方 | ゆっくり止まる |

フェードは 1 が「覆われている」、0 が「見えている」です。ワールドに入った時点では覆われていないので、**その手前にもう 1 つ**「プロパティを変える」を置き、フェードを **1**、かける時間 **0** にして、開始時 → こちら → さっきの順につなぎます。時間 0 の変化はその場で終わるので、**出力** でも **完了後** でも次へ進みます。

ここまでで「白く覆う → 2 秒かけて晴らす」ができました。

## 3. 晴れ終わってから音を鳴らす

2 秒かけるフェードの **完了後** を、次のノードへつなぎます。ここが「出力」ではなく **完了後** であることが、この作例のいちばん大事なところです。

- **出力** … 変化を始めた時点で次へ進む（同時に動かしたいとき）
- **完了後** … 変化し終わってから次へ進む（順番に動かしたいとき）

完了後の先に「プロパティを変える」を 2 つ並べます。

1 つめ（音を鳴らし始める）:

| 欄 | 値 |
| --- | --- |
| 対象 | 環境音の **Audio Source** |
| プロパティ | 再生 |
| 値 | 再生 |

選択肢のプロパティなので、時間の欄は出ません。

2 つめ（音量を上げる）。1 つめの **出力** につなぎます:

| 欄 | 値 |
| --- | --- |
| 対象 | 環境音の **Audio Source** |
| プロパティ | 音量 |
| 値 | 1 |
| かける時間（秒） | 2 |
| 変わり方 | ゆっくり止まる |

音量の初期値が 1 のままだと、鳴り始めた瞬間に最大音量になります。Audio Source の Volume を 0 にしておくか、鳴らす前に「音量 0、時間 0」を挟みます。

## 4. 扉を開ける

音量を上げるノードの **完了後** から「プロパティを変える」へ:

| 欄 | 値 |
| --- | --- |
| 対象 | 扉の **Transform** |
| プロパティ | 位置 |
| 値 | 開いた先の XYZ |
| かける時間（秒） | 3 |
| 変わり方 | ゆっくり止まる |

値は「そこまで動かす」ではなく「その座標にする」です。開いた状態の座標を入れます。Scene View で扉をいったん開いた位置へ動かして数値を控え、元に戻してから入力すると早いです。

**変わり方を「少し行き過ぎて戻る」にすると、扉が勢いよく開いて跳ね返ります。** 蓋や看板には合いますが、重い扉には合いません。曲線は選ぶと隣に形が出るので、見比べて決めてください。

## 5. ライトを明るくする

扉の **完了後** から:

| 欄 | 値 |
| --- | --- |
| 対象 | ライトの **Light** |
| プロパティ | 明るさ |
| 値 | 2 |
| かける時間（秒） | 1 |
| 変わり方 | ゆっくり止まる |

## 6. 終わりへ向かう

ライトの **完了後** から「待機」を置き、秒数を 1 にします。待機は **完了後** が待った先です。「出力」は待たずにその場で次へ進むので、間違えるとここだけ先に進んでしまいます。

待機の **完了後** から、最後の 2 つを **同時に** 動かします。片方の「プロパティを変える」の **出力** をもう片方の **入力** につなぐと、2 つが同時に始まります。

- 音量 → 0、かける時間 4、ゆっくり止まる
- Scene のフェード → 1、かける時間 4、ゆっくり止まる

## 7. 確かめる

**タイムライン** を開きます。対象ごとに行が並び、時間をかける変化は長さのある帯になります。狙った時刻と並びになっているかを、Play を始める前にここで見られます。

うまくいっていないときの見かた:

- **薄いノードがある** — 一度も動いていません。線が外れているか、手前のノードで止まっています。押すとそのノードが選ばれます
- **帯が重なっている** — 同時に動いています。順番にしたいなら、つなぎ先を「出力」から「完了後」へ変えます
- **最後の項目が想定より早い / 遅い** — どこかの「かける時間」か「待機」の秒数です。帯の長さがそのまま秒数です
- **何も出ない** — 「開始時」が置かれていないか、そこから線が出ていません

数値を直したら **整列** を押すと、流れの順に並び直って読みやすくなります。

確認できたら閉じて保存し、**Play** で実際の見え方を見ます。Play を止めると、グラフが書き換えた値はすべて元に戻ります。

## この先

- **押したら始まるようにする** — 「開始時」を「インタラクト時」に差し替え、この Asset を Entity の **Interaction Trigger** に設定し、その Entity に **Interactable** を付けます
- **繰り返す** — 最後のノードの **完了後** を先頭へ戻すと、そのまま繰り返します。回数を決めたいときは間に「N 回だけ通す」を挟みます
- **分けて管理する** — 演出が長くなったら、グラフを分けて「イベント送信」と「イベント受信」でつなぎます。同じ Asset の中のグラフはすべて同時に動きます
