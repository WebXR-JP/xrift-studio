# 地形と衝突判定

ビジュアルエディターでは、地形（Terrain）を作成してブラシで編集したり、Entity に衝突判定（Collider）を設定したりできます。

## 地形（Terrain）

地形は、高さサンプル（heightmap）で表現されるメッシュです。ブラシで形を整えられます。

### 作成する

作り方は 2 通りあります。

**平らな地形から始める**

1. **Create メニュー** を開きます。
2. **地形** を選びます。平らな高さサンプル Terrain が Scene に追加されます。

**形と草が入ったプリセットから始める**

1. Assets パネルの **外部から追加** を押します。
2. 左の一覧から **Terrain** を選びます。
3. プリセットを選び、**「〇〇を Scene へ追加」** を押します。

プリセットには起伏と草が最初から入っています。追加後は普通の Terrain なので、そのままブラシで彫り足せます。

| プリセット | 大きさ |
| --- | --- |
| **草原** | 80 × 80 m |
| **なだらかな丘** | 120 × 120 m |
| **谷** | 120 × 120 m |
| **乾いた台地** | 100 × 100 m |
| **島** | 100 × 100 m |
| **尾根** | 140 × 100 m |

カタログのカードは、実際の高さフィールドと草の配置を WebGL で描画しています。

### 編集する

地形を選択すると、Inspector でブラシを使って編集できます。

| ブラシ | 説明 |
| --- | --- |
| **盛り上げる（Raise）** | 指定した強さで高さを上げます。 |
| **掘る（Lower）** | 指定した強さで高さを下げます。 |
| **高さを設定（Flatten / Set Height）** | 指定した高さに平らにします。 |
| **滑らかにする（Smooth）** | 高さを滑らかにブレンドします。 |
| **穴を開ける（Hole）** | 実際のランタイムメッシュに穴を開けます。 |

ブラシの半径、強さ、フォールオフを調整できます。

### 地形の設定

Inspector で次の設定を編集できます。

- **サイズ**: 幅と奥行き
- **解像度**: サンプル数
- **マテリアル**: 地形に使うマテリアル

地形は、Scene View、static Trimesh Collider、生成コードで同じ三角形を使います。

## 草を生やす

草は Terrain の一部として持ちます。地形を選ぶと Inspector から編集できます。

### 草の層

草は層（レイヤー）で重なります。プリセットの「草原」は 3 層構成です。

| 層 | 本数の目安 |
| --- | --- |
| 短い芝 | 50,000（上限） |
| 背の高い草 | 19,200 |
| 花付きの草 | 3,840 |

短い芝を一面に敷き、その上へ背の高い草と花を重ねる、という積み方です。**草のセット** を選ぶと、この組み合わせをまとめて切り替えられます。

### 塗って生やす、塗って消す

草はブラシで部分的に塗れます。生やしたい斜面だけ濃くしたり、道になる部分を消したりできます。ブラシは中心から縁に向かって弱くなるので、一度のストロークで消えるのではなく、重ねるほど薄くなります。

> 草のブラシは高さフィールドを書き換えません。草を塗るつもりが地面を彫ってしまうことはありません。

### 風で揺れる

草の揺れは、Scene 設定の **Wind**（風の向き、速さ、強さ、突風）から来ます。[Water Shader](./sky-and-water.md) の水面も同じ風を使うため、草と水が別々の方向へ動くことはありません。

草は公開したワールドにも出力されます。出力されるのは配置のルールで、本数分の座標ではありません。実際の草はエディターと同じアルゴリズムで実行時に生成されます。

## 衝突判定（Collider）

Collider は、Entity の物理的な衝突判定を定義します。

### 初期設定

- **Primitive** には **Box Collider** が初期設定されます。
- インポートした **Model** には **Mesh Collider** が初期設定されます。

### 設定する

Collider を選択して Inspector で次の設定を編集します。

- **形状**: Box、Sphere、Capsule、Mesh など
- **Center / Half Extents**: 中心とサイズ
- **自動フィット**: メッシュに合わせて自動調整

### Rigid Body（剛体）

物理挙動を追加するには、Entity に **Rigid Body** を追加します。重力、質量、速度などを設定できます。
