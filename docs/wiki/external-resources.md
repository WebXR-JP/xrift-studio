# 外部の素材を追加する

Assetsの **外部から追加** を押すと、素材のカタログが開きます。ダウンロードから取り込みまでアプリの中で完結するので、ブラウザでファイルを探して保存し直す必要はありません。

## カタログの種類

左の一覧は「素材サイト」「空と自然」「光と演出」「ワールド機能」の 4 つの区分に分かれています。追加したいものから選んでください。

| カタログ | 区分 | 提供 | 内容 |
| --- | --- | --- | --- |
| **Poly Haven** | 素材サイト | CC0 | 空の HDRI、質感、小物モデルを検索して追加 |
| **ambientCG** | 素材サイト | CC0 | 床や壁の質感と HDRI を追加、モデルは検索のみ |
| **Skybox Shader** | 空と自然 | 公式 | 空の色や動きを描くマテリアル |
| **Water Shader** | 空と自然 | 公式 | 湖・海・セルルックの水面マテリアル |
| **Terrain** | 空と自然 | 公式 | 起伏と草の入った地形 |
| **発光Entity** | 光と演出 | 公式 | Bloomでネオンのように光がにじむ形 |
| **Particle** | 光と演出 | 公式 | 炎・雪・桜などのエフェクト |
| **3Dセット** | 光と演出 | 公式 | 焚き火・家具に加え、しかけ付きのチュートリアルセット |
| **Open Brush** | 光と演出 | 公式 | 手描き風ブラシのマテリアル |
| **Component** | ワールド機能 | 公式 | 移動先への入口、鏡、開始位置など |

一覧の見本と、選択した素材の詳細で見た目を確認できます。空と水の一覧には描画済みの静止画を使い、選択中の詳細だけが動きます。

## HDRI とマテリアルを追加する（Poly Haven / ambientCG）

1. **外部から追加** を押し、左の一覧から **Poly Haven** または **ambientCG** を選びます。
2. 名前、カテゴリ、タグで検索します。
3. 右側で **解像度** と **ファイル形式** を選びます。ダウンロード容量の目安が表示されます。
4. HDRI の場合、**インストール後にSkyboxへ設定** を有効にしておくと、追加と同時にSkyboxに設定されます。

HDRI は環境テクスチャとして保存されます。あとからシーンへドラッグして差し替えることもできます。

## 公式カタログから追加する

Skybox Shader、Water Shader、Terrain、発光Entity、Particle、3Dセットは、カタログから選んで追加ボタンを押すだけです。追加されたものは通常の素材やEntityになるので、Inspectorで編集できます。

- Skybox ShaderとWater Shaderは **マテリアル** として残ります。詳しくは [空と水をつくる](./sky-and-water.md) を参照してください。
- Terrainでは **地形Entity** が 1 つ増えます。詳しくは [地形と衝突判定](./terrain-and-colliders.md) を参照してください。

## しかけ付きのセットで仕組みを覚える（3Dセット）

「しかけ・チュートリアル」には、**音**と**ノードグラフ**を設定済みのセットがあります。ボタンを押すと音が鳴る、灯りが点くなど、動く見本を置いて仕組みを確認できます。

ボタンはどれも同じ作りで、押すと沈んで光り、元へ戻ります。仕組みを覚えたあとは、ボタンだけを複製して自分の仕掛けの入口として使えます。

| セット | 何が入っているか | 覚えられること |
| --- | --- | --- |
| **音の出るボタン** | 操作を受け付ける、音源、グラフの実行 | 押したら何かが起きる、をひと通り作る |
| **灯りのスイッチ** | ボタン、ランプ、ライト（消灯で配置） | 押したEntityとは別のEntityを動かす |
| **紙吹雪のボタン** | ボタン、パーティクル、開始時に止めるグラフ | 押したときだけ出るエフェクトを作る |
| **自動で閉まる扉** | 扉、音、時間をかけて動くグラフ | 「動かす」「待つ」「戻す」を 1 本につなぐ |
| **隠し扉のスイッチ** | ボタン、非表示で置かれる宝箱 | 隠しておいたものを押したときに出す |
| **テレポート台** | 台、画面フェード、プレイヤーの移動 | 操作した人だけを動かす／暗転させる |
| **色を変えるライトパネル** | 3 つのボタン、ランプ | 同じ対象を複数のボタンから変える |
| **昼と夜のパネル** | 2 つのボタン、シーンの露出と環境光 | ワールド全体の見え方を押した人の画面だけで変える |
| **文字が変わる看板** | 2 つのボタン、テキスト | 看板の文言をその場で差し替える |
| **環境音のスピーカー** | ループする音源 | 空間に置く音の、聞こえる範囲を決める |
| **画質のスイッチ** | ボタン、シーンのPost Processing切り替え | 見る人が自分の端末に合わせて軽くできるようにする |

詳細パネルには、**動き**（押すと何が起きるか）と、**このセットで分かること**（目的と手順）が配置する前から書かれています。追加したあとも手順が読めるように、これらのセットだけはカタログを開いたままにします。手順を確認してカタログを閉じ、**Play**を押してください。

同梱の音は音声素材として追加されるため、自分の音へ差し替えられます。配置したセットも通常のEntityなので、[ノードで動きを作る](./interactivity.md)と同じノードエディター でグラフを編集できます。

## ライセンス表記

素材ごとの配布元、作者、ライセンスは、カタログの詳細で確認できます。取り込んだ素材にも権利表記を保存し、公開時に一緒に出力します。別の場所へ書き出す場合も、必要な表記を取り除かないでください。
