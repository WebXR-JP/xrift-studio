# 外部リソースから追加する

Assets パネルの **外部から追加** を押すと、素材のカタログが開きます。ダウンロードから取り込みまでアプリの中で完結するので、ブラウザでファイルを探して保存し直す必要はありません。

## カタログの種類

左の一覧は「素材サイト」「空と自然」「光と演出」「ワールド機能」の 4 つの区分に分かれています。追加したいものから選んでください。

| カタログ | 区分 | 提供 | 内容 |
| --- | --- | --- | --- |
| **Poly Haven** | 素材サイト | CC0 | 空の HDRI、質感、小物モデルを検索して追加 |
| **ambientCG** | 素材サイト | CC0 | 床や壁の質感と HDRI を追加、モデルは検索のみ |
| **Skybox Shader** | 空と自然 | 公式 | 画像ではなく GLSL で空を描く Material |
| **Water Shader** | 空と自然 | 公式 | 湖・海・セルルックの水面 Material |
| **Terrain** | 空と自然 | 公式 | 起伏と草の入った地形 |
| **発光オブジェクト** | 光と演出 | 公式 | ネオンのように Bloom で光る形 |
| **Particle** | 光と演出 | 公式 | 炎・雪・桜などのエフェクト |
| **3Dセット** | 光と演出 | 公式 | 焚き火・家具に加え、しかけ付きのチュートリアルセット |
| **Open Brush** | 光と演出 | 公式 | 手描き風ブラシの Material |
| **Component** | ワールド機能 | 公式 | Portal、Mirror、Spawn Point など |

公式カタログのカードは、静止画のサムネイルではなく **実際の GLSL や高さフィールドを WebGL で描画** しています。カードで見えているものが、そのままシーンに入ります。

## HDRI とマテリアルを追加する（Poly Haven / ambientCG）

1. **外部から追加** を押し、左の一覧から **Poly Haven** または **ambientCG** を選びます。
2. 名前、カテゴリ、タグで検索します。
3. 右側で **解像度** と **ファイル形式** を選びます。ダウンロード容量の目安が表示されます。
4. HDRI の場合、**インストール後に Skybox へ設定** を有効にしておくと、追加と同時にシーンの空になります。

HDRI は環境 Texture Asset として保存されます。あとから Scene View へドラッグして差し替えることもできます。

## 公式カタログから追加する

Skybox Shader、Water Shader、Terrain、発光オブジェクト、Particle、3Dセットは、カタログから選んで追加ボタンを押すだけです。追加されたものは通常の Asset や Entity になるので、そのあとは Inspector で自由に編集できます。

- Skybox Shader と Water Shader は **Material Asset** として残ります。詳しくは [空と水をつくる](./sky-and-water.md) を参照してください。
- Terrain は **Terrain Entity** が 1 つ増えます。詳しくは [地形と衝突判定](./terrain-and-colliders.md) を参照してください。

## しかけ付きのセットで仕組みを覚える（3Dセット）

3Dセットのカタログには「しかけ・チュートリアル」という区分があります。形だけでなく、**音**と**Interactivity Graph**まで組み立てた状態で入るセットです。押したら音が鳴る、押したら灯りが点く、といった仕掛けは、Studio の中でいちばん「見ただけでは分からない」部分なので、動くものを 1 つ置いて中を開けるのがいちばん早い道になります。

| セット | 何が入っているか | 覚えられること |
| --- | --- | --- |
| **音の出るボタン** | Interactable、Audio Source、Interaction Trigger | 押したら何かが起きる、をひと通り作る |
| **灯りのスイッチ** | スイッチ、電球、Light、Interactivity Graph | 押した Entity とは別の Entity を動かす |
| **環境音のスピーカー** | ループする Audio Source | 空間に置く音の、聞こえる範囲を決める |
| **自動で閉まる扉** | 扉、音、時間をかけて動く Graph | 「動かす」「待つ」「戻す」を 1 本につなぐ |

詳細パネルには、**動き**（押すと何が起きるか）と、**このセットで分かること**（目的と手順）が配置する前から書かれています。追加したあとも手順が読めるように、これらのセットだけはカタログを開いたままにします。手順を見ながらカタログを閉じ、Play を開始してください。

音は Studio に同梱の WAV が Audio Asset としてプロジェクトへ入るので、そのまま自分の音へ差し替えられます。置いたあとはただの Entity と Component なので、[インタラクション](./interactivity.md) で説明しているのと同じ Node Editor でグラフを編集できます。

## ライセンス表記

Poly Haven と ambientCG の素材は CC0 です。Open Brush など MIT の素材は、作者とライセンスの情報が Asset 自体に保存され、公開したワールドにも一緒に出力されます。カタログの詳細パネルから配布ページとライセンスを開けます。
