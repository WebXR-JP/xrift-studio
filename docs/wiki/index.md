# XRift Studioの使い方

XRift Studioでは、3Dモデルや画像、音声を組み合わせて、XRiftのワールドとアイテムを作れます。XRift公式とは無関係の有志製ツールです。

初めて使う場合は、**インストール → プロジェクト作成 → 素材の配置 → 動作確認 → 公開**の順に進めてください。
