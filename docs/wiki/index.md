# XRift Studioの使い方

初めて使う方は、次の順に進めてください。

1. [インストールとセットアップ](./installation.md)を済ませます。
2. [プロジェクトを作成](./projects.md)し、[ビジュアルエディター](./visual-editor.md)で素材を配置します。コードを書く場合は[コードエディター](./classic-editor.md)を選びます。
3. [Playで動作を確認し、Stopで編集に戻ります](./play-mode.md)。
4. 完成したら[XRiftへ公開](./publishing.md)します。

詳しい操作は目次やページ検索から探せます。スマートフォンでは、左上のメニューから目次を開いてください。

うまく進めないときは[トラブルシューティング](./troubleshooting.md)を参照してください。
