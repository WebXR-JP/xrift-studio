# コードと検証環境の監査（2026-09-05）

今回の重点範囲は、Interactivity runtime のタイマー処理、fixture の登録と実行経路、Entity ツリーのソース、JSON・バージョン比較の共通関数、開発手順、公開中の PR・Issue。全ソースの精査や実画面の性能測定は含まない。

## 修正した点

- タイマー1件ごとの `filter → sort → filter` を、最小の予約を探す走査と `splice` に変更した。同時刻は予約 ID 順を保ち、コールバックが別の予約をキャンセル・追加する場合も、次の反復で最新の予約を読む。配列の全件走査は残る。
- `pnpm test:fixtures <ファイル...>` を追加した。必要な TypeScript モジュールだけを Vite で読み込み、本番ビルドや固定ポートなしで fixture を実行できる。CLI 専用の準備が必要な fixture は対象外。
- 既存のワールド制作状態テスト5件を `pnpm test:scripts` で実行できるようにした。
- `scene-entity-tree-store.ts` の直接埋め込まれた NUL を `\u0000` に変更した。実行時のキーは同じで、`rg` によるバイナリ扱いを解消した。
