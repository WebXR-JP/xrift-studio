# 設定デザインガイド

XRift Studio の Inspector では、Unity と同じく、選択した対象を少ない視線移動で編集できる配置を優先する。値・状態・操作をコンパクトにまとめ、補足説明は必要なときに確認できるようにする。

## 並び順

1. Entity の有効状態と名前
2. プレハブなど編集元への参照
3. `Transform`
4. 描画方式、ライト、衝突判定などの Component
5. 追加 Component

Component を有効にするチェック欄は見出しの先頭に置き、Entity 全体の有効・無効とは区別して表示する。

## 密度

- 見出しは 32px 前後、通常の入力欄は 28px 前後を基準にする。
- Component 内の間隔は 8px、関連するラベルと値の間隔は 4px を基準にする。
- 長い説明、重複する種別名、内部用語は常設せず、補足は `title` や読み上げ名へ移す。
- エラー、参照切れ、未設定のため次へ進めない状態だけは、短い文で常に表示する。

## 枠と階層

- Inspector 全体を第 1 の外枠、各 Component を第 2 の外枠とする。
- Component 内のマテリアル欄やプロパティ群にカード枠を重ねない。階層は区切り線、余白、薄い背景で示す。
- 通常の Component には影を使わない。影は選択、警告、モーダルなど前後関係を示す必要がある箇所だけに使う。
- 角丸は小さめに統一する。枠線と強い背景色を同じ階層に同時に重ねない。

## 参照フィールド

マテリアル、テクスチャ、3D モデルなどの視覚的な素材は、左から次の順で 1 行に並べる。

1. 色またはサムネイルのプレビュー
2. 素材の選択欄
3. 選択中の素材を開くアイコン

素材は名前とプレビューで見分けられるようにする。マテリアルのスウォッチには基本色と透明度を表示し、基本色のテクスチャがある場合はテクスチャアイコンを重ねる。アイコンだけの操作には、必ずツールチップと読み上げ名を付ける。

## 状態

- 有効・無効はチェック状態と表示の濃淡で示す。
- 選択中、ホバー、フォーカス、無効をそれぞれ異なる見た目にする。フォーカスリングは消さずに残す。
- 色だけで状態を伝えない。チェック、アイコン、読み上げ名のいずれかを併用する。
- Play 中に編集できない値は、配置を動かさず同じ位置のまま無効化する。

## レビュー項目

- [ ] 最初の一画面に主要な状態と値が収まっている。
- [ ] 同じ情報を見出し、ラベル、説明文で重複表示していない。
- [ ] Component 内にカード枠が入れ子になっていない。
- [ ] 視覚的な素材にプレビューがあり、その横で選択できる。
- [ ] Component ごとの有効・無効が見出しから操作できる。
- [ ] アイコン操作をホバーとキーボードフォーカスの両方で理解できる。
- [ ] エラー以外の説明文をツールチップへ移せるか確認した。
