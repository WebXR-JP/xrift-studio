# 設定デザインガイド

XRift Studio の設定は、Unity と同じく「選択した対象を、短い視線移動で編集できる」ことを優先する。説明画面にはしない。値・状態・操作だけを高密度に並べる。

## 並び順

1. オブジェクトの有効と名前
2. プレハブなど編集元への参照
3. Transform
4. 描画方式、ライト、衝突判定などのコンポーネント
5. 追加コンポーネント

コンポーネント自身の有効は見出しの先頭に置く。オブジェクト全体の有効とは区別して示す。

## 密度

- 見出しは 32px 前後、通常フィールドは 28px 前後を基準にする。
- コンポーネント内の間隔は 8px、関連するラベルと値は 4px を基準にする。
- 長い説明、重複する種別名、内部用語は常設しない。補足は `title` と読み上げ名へ移す。
- エラー、参照切れ、未設定のため次へ進めない状態だけは短い文で常設する。

## 枠と階層

- 設定パネルを第一の外枠、コンポーネントを第二の外枠とする。
- コンポーネント内のマテリアル枠やプロパティ群へカード枠を重ねない。区切り線、余白、薄い背景で階層を示す。
- 通常のコンポーネントに影を使わない。選択、警告、モーダルなど前後関係が必要な箇所だけに使う。
- 角丸は小さく統一する。枠線と強い背景色を同じ階層へ同時に重ねない。

## 参照フィールド

マテリアル、テクスチャ、3Dモデルなど視覚的な素材は、左から次の順に一行へ置く。

1. 色またはサムネイルのプレビュー
2. 素材の選択欄
3. 選択中素材を開くアイコン

識別を名前だけに頼らない。マテリアルのスウォッチは基本色と透明度を表示する。基本色のテクスチャがある場合はテクスチャアイコンを重ねる。アイコンだけの操作には必ず tooltip と読み上げ名を付ける。

## 状態

- 有効はチェック状態と無効時の濃淡で示す。
- 選択中、hover、focus、disabled を別の見た目にする。focus ring は残す。
- 色だけで状態を伝えない。チェック、アイコン、読み上げ名のいずれかを併用する。
- 動作確認中に編集できない値は同じ配置のまま無効化する。レイアウトを動かさない。

## レビュー項目

- [ ] 最初の一画面に主要な状態と値が収まる。
- [ ] 同じ情報を見出し、ラベル、説明文で三重に表示していない。
- [ ] コンポーネント内にカード枠が入れ子になっていない。
- [ ] 視覚的な素材にプレビューがある。その横で選択できる。
- [ ] コンポーネントごとの有効が見出しから操作できる。
- [ ] アイコン操作を hover とキーボード focus の両方で理解できる。
- [ ] エラー以外のガイド文を tooltip へ移せるか確認した。
