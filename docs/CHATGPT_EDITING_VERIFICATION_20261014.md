# ChatGPT による逐次編集の確認

確認日: 2026-10-14。ソースのバージョン: 1.0.4。

## 今回の範囲

- Inspector と素材ストアから、空の Entity へのモデル追加と既存モデルの差し替えを行う。名前・位置・回転・大きさは維持する。
- ChatGPT から現在の Scene に小さな変更を順に反映し、その都度保存する。Skybox、Audio Source、Collider、モデル、Material、同梱カタログを扱う。
- 思考量の初期値を低にし、素材が必要なときだけ対応ストアを検索する。大きな依頼は今回の Plan と残りの作業に分ける。
- 複数チャット、端末内の履歴、全文コピー、Continue、変更を戻す操作に対応する。Plan には設定値と素材名を表示する。
- 同じ操作を MCP からも使えるようにする。既存の手動編集、Scene の切り替え、Play、素材の非同期読み込みとの競合を検査する。

## 確認方法

既存作品とは分離したブラウザ検証用プロジェクトを使った。App、React、MCP のフロントエンド処理、素材の解析・生成・保存形式、Three.js の描画は実装そのものを使用している。ネイティブのファイル保存、認証、クラウド応答は検証用の境界に置き換えた。

通常のコード確認には `pnpm typecheck`、`pnpm e2e:typecheck`、`cargo check --manifest-path src-tauri/Cargo.toml` を実行した。本番ビルドや配布物の生成は行っていない。

## 確認済みの動作

| 対象 | 確認内容 |
| --- | --- |
| モデル | 実際の GLB を空 Entity に設定し、別モデルに差し替えた。Transform・名前・手動で追加した子 Entity と Component が維持され、自動 Collider が更新されることを保存と Play まで確認した |
| 素材ストア | ストアから選択 Entity にモデルを設定した。モデル解析中に発生したサムネイル更新が失われず、MCP の二重取り込みを拒否しつつ、同時に行った無関係な Scene 編集も維持されることを確認した |
| Scene 設定 | Skybox、Audio Source、Collider を 3 段階で保存した。名前と Transform が維持され、再表示後も設定が残ること、Plan 作成後に手動変更した Skybox への上書きを拒否することを確認した |
| BGM | 実際の PCM WAV を取り込み、Plan で音量 18%・ループ有効・空間音声無効を確認した。実際の Three.js Audio でのデコード、AudioContext の稼働、2 回の Play・Stop を確認し、Entity の移動・削除・Undo・プロジェクト再表示後も音声参照が残り disconnect 例外が出ないことを確かめた |
| 同梱素材 | Sky、Water、テクスチャ付きの焚き火を Plan から反映した。実際のメッシュとデコード済みテクスチャ、描画呼び出しを確認し、WebGL context loss やページ例外がないことを確かめた |
| 履歴 | 2 チャットの切り替え、未送信文の維持、名前変更、全文コピー、履歴削除、再読み込み後の復元を確認した。履歴を削除しても Scene は変わらない |
| Continue | 前の会話と現在の Scene を次の依頼に引き継いだ。完了済みの Entity を重複作成せず、残りの作業を続けられることを確認した |
| 変更を戻す | 依頼による変更を戻して保存できること、その後に手動編集がある場合は拒否されること、サムネイル生成だけでは手動編集と誤判定しないことを確認した |
| 接続画面 | デスクトップ幅とスマートフォン幅の両方で、接続前のボタンが会話中央に表示されることを確認した。接続・復元・失敗・モデルと思考量の選択も確認した |
| 既存の導線 | タブ切り替え、Plan の反映・破棄、停止、別ワールド作成後の進捗と保存失敗の表示を回帰確認した |

Rust のライブラリテストは 146 件すべて成功した。OS の資格情報保存先を操作する手動確認用テスト 1 件は未実行である。MCP の生成済みツール一覧は 162 件で一致した。

この範囲のブラウザテストは 29 件すべて成功した（接続・思考量 5 件、既存のタブ・生成導線 13 件、Scene 設定と BGM 3 件、履歴と同梱素材 5 件、モデルと MCP の競合 3 件）。修正したテストについては影響のあるケースを再実行した。

Node テストは 90 件成功した（利用ガイドと Vite ガイドの検査 17 件を含む）。モデル差し替え、素材の競合、Plan の検証と設定値の表示、対応するストアと種類、Scene 情報の収集、同梱素材の依存、履歴の保存上限と機密値除去、変更を戻す条件を確認した。

## 残る確認

実際のアカウントでの再ログイン、OS 再起動後の資格情報復元、実際のクラウド推論時間、各外部ストアへの本番ネットワーク通信は今回のブラウザ検証に含めていない。短い依頼で不要な検索を省く処理は確認したが、クラウド処理が 10 秒で完了することを保証するものではない。

編集と Play では同じ素材と描画処理を使った。今回の変更で公開処理は変更しておらず、公開先にアップロードしての比較は行っていない。

利用ガイドは本文・操作名・検索語を更新したが、掲載画像は更新していない。PR 段階ではガイドは未公開であり、`main` へのマージ後に既存のワークフローが公開する。
