# ChatGPTによる逐次編集の確認

確認日: 2026-10-14。ソースのバージョン: 1.0.4。

## 今回の範囲

- Inspectorと素材ストアから、空のEntityへのモデル追加と既存モデルの差し替え。名前・位置・回転・大きさを保持する。
- ChatGPTから現在のSceneへ小さな変更を順に反映し、その都度保存する。Skybox、Audio Source、Collider、モデル、Material、同梱カタログを扱う。
- 思考量の初期値を低にし、素材が必要な場合だけ対応ストアを検索する。大きな依頼は今回のPlanと残りの作業に分ける。
- 複数チャット、端末内の履歴、全文コピー、Continue、変更を戻す操作。Planには設定値と素材名を表示する。
- 同じ操作をMCPからも使う。既存の手動編集、Sceneの切り替え、Play、素材の非同期読み込みとの競合を検査する。

## 確認方法

既存作品と分かれたブラウザ検証用プロジェクトを使った。App、React、MCPのフロントエンド処理、素材の解析・生成・保存形式、Three.jsの描画は実装そのものを使用した。ネイティブのファイル保存、認証、クラウド応答は検証用の境界へ置き換えた。

通常のコード確認には `pnpm typecheck`、`pnpm e2e:typecheck`、`cargo check --manifest-path src-tauri/Cargo.toml` を使用した。本番ビルドや配布物の生成は行っていない。

## 確認済みの動作

| 対象 | 確認内容 |
|---|---|
| モデル | 実GLBを空Entityへ設定し、別モデルへ差し替え。Transform、名前、手動で追加した子EntityとComponentを保持。自動Colliderを更新し、保存・Playまで確認 |
| 素材ストア | ストアから選択Entityへモデルを設定。モデル解析中に生じたサムネイル更新を保持。MCPの二重取り込みを拒否し、同時に行った無関係なScene編集を失わない |
| Scene設定 | Skybox、Audio Source、Colliderを3段階で保存。名前とTransformを保ち、再表示後も設定が残る。Plan作成後に手動変更したSkyboxへの上書きを拒否 |
| BGM | 実PCM WAVを取り込み、Planで音量18%・ループ有効・空間音声無効を確認。実Three Audioのデコード、AudioContextの稼働、2回のPlay・Stopを確認。Entityの移動・削除・Undo・プロジェクトの再表示後も音声参照を保持し、disconnect例外なし |
| 同梱素材 | Sky、Water、テクスチャ付きの焚き火をPlanから反映。実Meshとデコード済みテクスチャ、描画呼び出しを確認。WebGL context lossとページ例外なし |
| 履歴 | 2チャットの切り替え、未送信文の保持、名前変更、全文コピー、履歴削除、再読み込み後の復元。履歴削除でSceneを変えない |
| Continue | 前の会話と現在のSceneを次の依頼へ渡す。完了済みのEntityを重複作成せず、残りの作業を続ける |
| 変更を戻す | 依頼の変更を戻して保存。その後に手動編集した場合は拒否。サムネイル生成だけでは手動編集と誤判定しない |
| 接続画面 | デスクトップ幅とスマートフォン幅で、接続前のボタンを会話中央に表示。接続・復元・失敗・モデルと思考量の選択を確認 |
| 既存の導線 | タブ切り替え、Planの反映・破棄、停止、別ワールド作成後の進捗と保存失敗の表示を回帰確認 |

Rustのライブラリテストは146件成功。OS資格情報保存先を操作する手動用テスト1件は未実行。MCPの生成済みツール一覧は162件で一致した。

この範囲のブラウザテスト29件が成功した。接続・思考量5件、既存のタブ・生成導線13件、Scene設定とBGM3件、履歴と同梱素材5件、モデルとMCPの競合3件。修正したテストは影響するケースを再実行した。

Nodeテスト90件が成功した（利用ガイドとViteガイドの検査17件を含む）。モデル差し替え、素材の競合、Planの検証と設定値の表示、対応するストアと種類、Scene情報の収集、同梱素材の依存、履歴の保存上限と機密値除去、変更を戻す条件を確認した。

## 残る確認

実アカウントでの再ログイン、OS再起動後の資格情報復元、実際のクラウド推論時間、各外部ストアへの本番ネットワーク通信は今回のブラウザ検証には含めていない。短い依頼で不要な検索を省く処理は確認したが、クラウド処理が10秒で完了するとは保証していない。

編集とPlayでは同じ素材と描画処理を使用した。今回の変更で公開処理は変更しておらず、公開先へアップロードしての比較は行っていない。

利用ガイドは本文・操作名・検索語を更新した。掲載画像は更新していない。PR段階ではガイドは未公開で、mainへのマージ後に既存のワークフローが公開する。
