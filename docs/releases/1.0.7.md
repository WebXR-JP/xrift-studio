# XRift Studio v1.0.7

- 制作チャットへEntityやMaterialを添付し、指定したEntityの配下やMaterialの設定を優先して編集できるようになりました。
- チャットの結果欄からMaterialの色・Roughness・Metallicと、Skybox・Fogの設定を直接調整できるようになりました。変更は通常の編集履歴と自動保存へ反映します。
- 次の依頼の候補を表示し、上下キーで選択、Tabで入力、Enterで送信できるようになりました。日本語の変換中や入力途中のキー操作はそのまま使えます。
- 制作チャットのPlan切り替えをなくし、送信すると編集が進む流れに揃えました。必要な確認は最大3ページの選択肢と自由入力で回答できます。
- 基本Componentと公式XRift Componentの追加・設定・取り外し、Entityの削除に対応しました。保存済みの変更は依頼単位で戻せます。
- 作業の記録を開いたまま表示し、具体的な変更項目と変更前後の値を確認できるようにしました。進行状況と同じ文が重複する表示も整理しました。
- Skyboxの素材・照明設定の不整合や、制作チャットとアプリ本体の設定情報の違いで編集が止まる問題を修正しました。
- チャットからMCP接続を開けるようにし、登録済みサーバーを開いたときに同梱版へ自動更新します。左下の歯車からはシーン設定を開けます。
- 編集履歴の「元に戻す」「やり直す」と自動保存が重なった場合に、保存状態と最後の変更が一致しない問題を修正しました。
