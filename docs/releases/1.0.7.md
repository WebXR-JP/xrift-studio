# XRift Studio v1.0.7

- 制作チャットに Entity や Material を添付し、指定した Entity の配下や Material の設定を優先して編集できるようになりました。
- チャットの結果欄から、Material の色・Roughness・Metallic や Skybox・Fog の設定を直接調整できるようになりました。変更内容は通常の編集履歴と自動保存に反映されます。
- 次の依頼候補を表示し、上下キーで選択、Tab で入力、Enter で送信できるようになりました。日本語の変換中や入力途中のキー操作には干渉しません。
- 制作チャットの Plan 切り替えをなくし、送信するとそのまま編集が進む流れに統一しました。確認が必要なときは最大 3 ページの選択肢と自由入力で回答できます。
- 基本 Component と公式 XRift Component の追加・設定・取り外し、Entity の削除に対応しました。保存済みの変更は依頼単位で元に戻せます。
- 作業の記録を開いたまま表示し、具体的な変更項目と変更前後の値を確認できるようにしました。進行状況と同じ文が重複して表示される問題も解消しています。
- Skybox の素材・照明設定の不整合や、制作チャットとアプリ本体の設定情報の違いによって編集が止まる問題を修正しました。
- チャットから MCP 接続を開けるようにし、登録済みサーバーを開いたときに同梱版へ自動更新するようにしました。左下の歯車からはシーン設定を開けます。
- 編集履歴の「元に戻す」「やり直す」と自動保存が重なったときに、保存状態と最後の変更が一致しなくなる問題を修正しました。
