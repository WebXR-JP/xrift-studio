# XRift Studio v0.10.0

- 上部の「素材を追加」から、基本形状・ライト・XRiftのギミックなどをカテゴリと検索で選べるようにしました。名前や用途で探せて、使えない候補は理由を表示します。
- Entityの新規作成と、既存EntityへのComponent追加を分けました。ComponentはInspectorから、選択中のEntityへの編集はSceneとHierarchyの同じ右クリックメニューから行います。
- Hierarchyで選んだEntityと必要な素材を `.xriftstudio` として書き出し、別のワールドやアイテムへ追加できるようにしました。書き出す種類で「アイテム」を選ぶと、独立したアイテムとして開けます。
- 同じウィンドウ・タブ内の別プロジェクトへ、素材ごとコピーして貼り付けられるようにしました。コピー完了の表示後にプロジェクトを切り替えてください。
- モデルの読み込み後に当たり判定を作り直すようにしました。「当たり判定に追加」で設定した形状が物理空間へ登録されるまでPlayを開始せず、解除した判定が次のPlayに残らないようにしています。
- 既存のMesh Colliderがある場合は作り直さずに再利用し、摩擦・反発・Triggerの設定が別のRigid Bodyで上書きされないようにしました。
