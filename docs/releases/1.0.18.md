# XRift Studio v1.0.18

- 既存の GLB から作成した Blender 編集元を再取り込みするときに、保存済みの MToon 設定が失われてしまう問題を修正しました。今回移行したモデルのように、MToon 設定がカスタムプロパティに保存されており、MToon のテクスチャ参照がないモデルが対象です。
- Blender でメッシュやボーンを編集して保存し、Assets の「Blenderから再取り込み」を使うと、同じ Model と配置に反映できます。最終的な MToon の表示は Studio で確認してください。
- 既存の GLB にモデルごとの編集用 `.blend` を追加する移行ツールを用意しました。元の GLB と Scene を残したまま、往復検証とバックアップを行ってから関連付けます。
