# XRift Studio v1.0.16

- アセットストアに「透過画像」を追加しました。うさぎ・猫・犬・小鳥、花や葉、雲や光、街の飾りなど、30 点の透過 PNG を同梱しています。追加のアカウントや API キーは不要です。
- 日本語名・英語名・カテゴリで画像を探し、明るい背景と暗い背景で輪郭を確認できます。追加すると元の PNG と透過設定済みの Material が Assets に保存されます。同じ素材をもう一度追加しても、編集済みの設定はそのまま残ります。
- ブラウザ版では画像だけの PNG 保存にも対応しました。AI からも既存のストア検索・取り込みツールを使って同じ素材を利用できます。
- Particle 向けに用途に合った透過画像を用意し、一日の空を選べるカタログを追加しました。
- 公開した Script から、ホストが提供するワールド共有ストレージや画面共有に接続する処理を修正しました。
