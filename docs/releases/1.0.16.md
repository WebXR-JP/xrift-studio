# XRift Studio v1.0.16

- アセットストアに「透過画像」を追加しました。うさぎ・猫・犬・小鳥、花や葉、雲や光、街の飾りなど、30点の透過PNGを同梱しています。追加のアカウントやAPIキーは不要です。
- 名前・英語名・カテゴリで画像を探し、明るい背景と暗い背景で輪郭を確認できます。追加すると元のPNGと透過設定済みMaterialをAssetsへ保存します。同じ素材を再び追加しても、編集した設定を保ちます。
- ブラウザ版では画像だけのPNG保存にも対応しました。AIからも既存のストア検索・取り込みツールで同じ素材を使えます。
- Particleに用途に合う透過画像を用意し、一日の空を選べるカタログを追加しました。
- 公開したScriptから、ホストが提供するワールド共有ストレージと画面共有へ接続する処理を修正しました。
