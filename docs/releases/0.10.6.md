# XRift Studio v0.10.6

- Entityの複製・貼り付けやPrefabの配置で、Interactableなどの識別子が重複し、公開できなくなる問題を修正しました。
- SceneやPrefabで使用中のScriptを、未使用の素材として削除できてしまう問題を修正しました。Scriptから参照している素材も削除前に使用箇所を確認できます。
- 公開用JavaScriptの配置と読み込み先を修正し、公開後に404でワールドを読み込めなくなる問題を解消しました。
- 公開準備が途中で失敗すると再試行できなくなる問題を修正しました。保存済みの公開先を確認できる場合、途中の出力を保全し、同じ公開先への準備をやり直します。
- Open Brushのモデルと通常のモデルを一緒に配置したワールドで、公開後にモデルの読み込みが停止する問題を修正しました。
- 公開時のテクスチャの自動縮小・圧縮をやめ、編集画面で使用中の画像をそのまま公開するようにしました。変更したい場合はInspectorで適用し、見た目を確認できます。コードエディターやCLIへの書き出しでも同じ画像を使います。
- KTX2画像のサイズと描画設定を修正し、明示的に圧縮した画像が正しく表示されない問題を解消しました。
