# XRift Studio v0.10.6

- Entity の複製・貼り付けや Prefab の配置で Interactable などの識別子が重複し、公開できなくなる問題を修正しました。
- Scene や Prefab で使用中の Script を、未使用の素材として削除できてしまう問題を修正しました。Script から参照している素材も、削除前に使用箇所を確認できます。
- 公開用 JavaScript の配置先と読み込みパスを修正し、公開後に 404 でワールドを読み込めなくなる問題を解消しました。
- 公開準備が途中で失敗すると再試行できなくなる問題を修正しました。保存済みの公開先を確認できる場合は途中の出力を残したまま、同じ公開先への準備をやり直せます。
- Open Brush のモデルと通常のモデルを一緒に配置したワールドで、公開後にモデルの読み込みが止まる問題を修正しました。
- 球体などに設定した Open Brush のシェーダーが公開時に失われる問題を修正しました。模様・色・シェーダーの編集内容が公開用コードにも引き継がれます。
- 球体・円柱・円錐の大きさや分割数が、編集画面と公開後で変わってしまう問題を修正しました。
- モデルの色と発光色が公開後に変わってしまう問題を修正しました。編集画面で使っている色の数値を、色空間の再変換や丸めをせずにそのまま渡します。
- KTX2 画像のローダーを編集と公開で統一し、同じ GPU でも変換形式の違いで色がわずかに変わる問題を解消しました。
- 軽量表示でも保存済みの露出とトーンマッピングを維持し、描画品質を切り替えたときの色味の差を抑えました。
- パーティクルの透明度を編集・Play・公開でそろえ、選択状態によって薄く表示される処理を取り除きました。
- 公開時のテクスチャ自動縮小・圧縮をやめ、編集画面で使用中の画像をそのまま公開するようにしました。圧縮やサイズ変更をしたい場合は Inspector から適用して見た目を確認できます。コードエディターや CLI への書き出しでも同じ画像を使います。
- KTX2 画像のサイズと描画設定を修正し、明示的に圧縮した画像が正しく表示されない問題を解消しました。
