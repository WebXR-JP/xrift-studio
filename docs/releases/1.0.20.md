# XRift Studio v1.0.20

- ライトベイク機能を追加しました。エディター左下の「ライトベイク」から動かない Mesh を選んでベイクすると、やわらかい影・跳ね返った光・物陰の暗さをライトマップに焼き込めます。ライトマップは Assets に保存され、編集・Play・デスクトップ版からの公開で同じ画像を使います。ブラウザ版からの公開は、ライトマップを使う Scene にまだ対応していません。
- VRM の髪や服の揺れもの（SpringBone）が、Play と公開したワールドで動くようになりました。揺れ方や当たり判定には VRM ファイルの設定を使います。編集中は揺れず、調整したポーズのまま表示されます。
- SpringBone の当たり判定を持つ VRM を取り込むとエディターが落ちてしまう問題を修正しました。
- 多くの Entity を配置した Scene で、Material の調整・Entity の選択・位置の数値ドラッグが軽くなりました。変更に関係する Entity とパネルだけを再描画します。
- 制作チャットで OpenAI のモデルを使うと依頼全体が拒否されてしまう問題を修正しました。
