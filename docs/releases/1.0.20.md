# XRift Studio v1.0.20

- ライトベイクを追加しました。エディター左下の「ライトベイク」で動かないMeshを選んでベイクすると、やわらかい影、跳ね返った光、物陰の暗さをライトマップに焼けます。ライトマップはAssetsに保存され、編集、Play、デスクトップ版からの公開で同じ画像を使います。ブラウザ版からの公開は、ライトマップを使うSceneにまだ対応していません。
- VRMの髪や服の揺れもの（SpringBone）が、Playと公開したワールドで動くようになりました。揺れ方と当たり判定にはVRMファイルの設定を使います。編集中は揺れず、調整したポーズのまま表示されます。
- SpringBoneの当たり判定を持つVRMを取り込むと、エディターが落ちる問題を修正しました。
- 多くのEntityを置いたSceneで、Materialの調整、Entityの選択、位置の数値ドラッグが軽くなりました。変更に関係するEntityとパネルだけを再描画します。
- 制作チャットでOpenAIのモデルを使うと、依頼全体が拒否される問題を修正しました。
