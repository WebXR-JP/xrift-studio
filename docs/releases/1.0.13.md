# XRift Studio v1.0.13

- UIKit製の案内パネルでビジュアルエディターが開けなくなる問題を修正しました。配布用ビルドでのクラス名の衝突と、描画ライブラリの重複を防ぎます。World Componentsは0.57.1、UIKitは1.0.77に揃えました。
- UIKit Panelテンプレートは、Playを押さずに編集画面で表示できるようになりました。既存のScriptもInspectorの「スクリプトを表示する場面」で「編集中の表示と動作確認」を選べます。ゲームの開始・更新処理はPlay中に動作します。
- Blenderでのモデル制作中に、実際の形状を撮影した途中画像を制作チャットへ表示します。最初のパーツ完成時、長い制作では約10秒経過後のパーツ完成時、最後のパーツ完成時に更新し、直近4枚を表示します。
- npmパッケージを登録する「追加機能の設定」を削除しました。
