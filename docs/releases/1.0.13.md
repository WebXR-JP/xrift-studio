# XRift Studio v1.0.13

- UIKit 製の案内パネルを使うとビジュアルエディターが開けなくなる問題を修正しました。配布用ビルドでのクラス名の衝突と、描画ライブラリの重複を防ぎます。World Components は 0.57.1、UIKit は 1.0.77 にそろえました。
- UIKit Panel テンプレートを、Play を押さずに編集画面上で表示できるようになりました。既存の Script も Inspector の「スクリプトを表示する場面」で「編集中の表示と動作確認」を選べます。ゲームの開始・更新処理は Play 中に動作します。
- Blender でのモデル制作中に、実際の形状を撮影した途中画像を制作チャットに表示するようにしました。最初のパーツ完成時、長い制作では約 10 秒経過後のパーツ完成時、最後のパーツ完成時に更新され、直近 4 枚が表示されます。
- npm パッケージを登録する「追加機能の設定」を削除しました。
