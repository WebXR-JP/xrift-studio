# XRift Studio v1.0.11

- Open Brush の DiamondHull で、モデルの配置位置やカメラ位置によって不自然に白飛びしてしまう問題を修正しました。見る角度によって縁が強く発光するブラシ本来の挙動は維持しています。
- Open Brush モデルの個別ノードに MToon や PBR のマテリアルを割り当てても反映されない問題を修正しました。同じブラシを使ったほかのノードには元の材質がそのまま残ります。
- ThickPaint などの切り抜きブラシの輪郭を滑らかにしました。Post Processing を使用した場合も、対応する端末ではアンチエイリアスが維持されます。編集画面と公開先で同じ描画処理を使います。
- 録画の撮影間隔のずれが積み重なってフレームを取りこぼす問題を修正しました。手動のフレーム取得に対応する環境では、描画直後の映像を録画に渡します。
