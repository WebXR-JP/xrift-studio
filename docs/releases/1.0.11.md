# XRift Studio v1.0.11

- Open BrushのDiamondHullで、モデルの配置位置やカメラ位置によって不自然に白飛びする問題を修正しました。見る角度によって縁が強く発光する、ブラシ本来の挙動は維持しています。
- Open Brushモデルの個別ノードにMToonやPBRのマテリアルを割り当てても反映されない問題を修正しました。同じブラシを使ったほかのノードは元の材質を保ちます。
- ThickPaintなどの切り抜きブラシの輪郭を滑らかにしました。Post Processingを使用した場合も、対応する端末ではアンチエイリアスを維持します。編集画面と公開先で同じ描画処理を使います。
- 録画の撮影間隔のずれが積み重なり、フレームを取りこぼす問題を修正しました。手動のフレーム取得に対応する環境では、描画直後の映像を録画へ渡します。
