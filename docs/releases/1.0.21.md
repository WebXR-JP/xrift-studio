# XRift Studio v1.0.21

- 葉が風にそよぐ木を標準アセットに追加しました。「アセットストア → 3Dセット → 自然」に、広葉樹・庭木・低木が標準と軽量版の2つずつ並びます。葉と枝はシーンの風で揺れ、明るさと陰はシーンのライトに合わせて変わります。
- 3Dモデルに割り当てたカスタムシェーダーも、シーンの風とライトを受け取るようになりました。編集画面・Play・デスクトップ版とブラウザ版からの公開で、同じ見え方になります。
- カスタムシェーダーで使えるuniformの種類（行列・配列・3Dテクスチャ・キューブマップ・EXRなど）と、加算合成やカリングの設定を増やしました。コンパイルできないときは、その理由をInspectorとGLSLエディターで確認できます。
- スクリプトから、動作中にカスタムシェーダーのuniformを書き換えられるようになりました（`ctx.materials.setUniform`）。
- Water Shaderに、風が止まっていても流れる川のプリセット（澄んだ小川・白く泡立つ早瀬・ゆるやかな川）を追加しました。
- GPUインスタンシングを使うGLBが公開したワールドで1個しか描かれない問題を修正し、インスタンスごとの独自属性もカスタムシェーダーへ届くようにしました。
- スクリプトの型の誤りで公開が止まったとき、どのスクリプトの何行目かを表示するようにしました。Playは型を確かめずにスクリプトを動かすため、Playで動いていても公開時の検査で止まることがあります。AIクライアントからは、アップロードせずに公開と同じ検査を実行できます。
- 公開用データのビルドに失敗したとき、原因の出力がどこにあるかの案内が表示されなかった問題を修正しました。
- AIクライアントが、グリッドや選択枠などの編集用の表示を除いたScene Viewの画像を撮れるようになりました。
- Inspectorの数値の欄で、入力中の文字が保存済みの値に戻ってしまうことがある問題を修正しました。
- アプリの画面とガイドの日本語を、より自然な表現に書き直しました。
