# XRift Studio v0.9.30

- iPad や iPhone などのブラウザ（Safari）から、固定 URL のブラウザエディターで直接ワールドやアイテムを制作できるようになりました。作品はブラウザ内に保存され、次回は保存済みの一覧から再開できます。ブラウザ版はベータ提供です。
- ブラウザで作った作品をデスクトップ版（macOS / Windows）に引き継げるようになりました。`.xriftstudio` 形式で書き出し、デスクトップ版の「ファイルから開く」で取り込みます。素材・Prefab・全シーンをそのまま移せるほか、従来の `.zip` も取り込めます。
- タッチ端末向けに、Hierarchy・Assets・Inspector の切り替え表示、ピンチによる視点操作、World Play の移動・ジャンプ、右クリックなしの操作メニュー、タッチ向け数値入力を追加しました。操作中に意図せず文字が選択される現象も防いでいます。
- 起動時のプロジェクト選択と新規作成を 1 つの画面にまとめ、ワールドかアイテムかを選んでから作成する流れにしました。
- 画面上の操作名を整理し、「作品を開く」「素材を追加」「.xriftstudio で保存」など、操作と結果が分かりやすい表記に統一しました。素材カタログと取り込み画面もスマートフォン幅に対応しています。
- 紹介ページ（LP）を刷新し、通常制作向けのデスクトップ版ダウンロードと、試用向けのブラウザ版（ベータ）への導線を整理しました。エディターの URL には共有用のメタ情報も追加しています。
