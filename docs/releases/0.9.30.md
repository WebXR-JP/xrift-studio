# XRift Studio v0.9.30

- iPad・iPhoneなどのブラウザ（Safari）から、固定URLのブラウザエディターで直接ワールドやアイテムを制作できるようにしました。作品はブラウザ内に保存され、次回は保存済みの一覧から再開できます。ブラウザ版はベータです。
- ブラウザで作った作品をデスクトップ版（Mac／Windows）へ引き継げます。`.xriftstudio` 形式で書き出し、デスクトップ版の「ファイルから開く」で取り込みます。素材・Prefab・全シーンを保ったまま移動でき、従来の `.zip` も取り込めます。
- タッチ端末ではHierarchy・Assets・Inspectorを切り替えて表示し、ピンチによる視点操作、World Playの移動・ジャンプ、右クリックなしの操作メニュー、タッチ向けの数値入力を追加しました。操作中の意図しない文字選択も防ぎます。
- 起動時のプロジェクト選択と新規作成を一つの画面にまとめ、ワールド／アイテムの種類を選んでから作成する流れにしました。
- 画面の操作名を整理し、「作品を開く」「素材を追加」「.xriftstudioで保存」など、操作と結果が分かる表示に統一しました。素材カタログと取り込み画面もスマホ幅に対応しました。
- 紹介ページ（LP）を刷新し、ブラウザで試す導線とデスクトップ版のダウンロードを整理しました。デスクトップ版を通常の制作に、ブラウザ版をベータの試用として案内します。エディターURLには共有用のメタ情報を追加しました。
