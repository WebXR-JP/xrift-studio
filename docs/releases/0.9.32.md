# XRift Studio v0.9.32

- 「外部から追加 → ギミック → カスタム車」から、オープンカーを配置できるようにしました。XRift公式コンポーネントのVehicleからも同じ車を追加できます。車体、座席、タイヤは通常のGLBとしてAssetsへ入り、設定済みのHierarchyをエディター上で確認・編集できます。
- 車の地面追従を標準で有効にしました。地面のコライダーに沿って坂道を走行し、移動中はタイヤが回転して後部から煙が出ます。各参加者の画面で同期済みの車の移動に合わせて表示します。
- XRiftへ公開したワールドで、座席のインタラクトが表示されない問題と、運転席に座ってもWASD操作が車に伝わらない問題を修正しました。修正を公開済みのワールドへ反映するには、Studioから再度公開してください。
- 車両の補助Scriptで発生していたビルド時の型エラーを修正しました。また、公開用テンプレートに含まれるサンプルの公開情報が原因で、XRiftへの送信前に処理が停止する問題を修正しました。
- ギミックなどの一覧を、十分な横幅がある場合は4列で表示するようにしました。狭い画面では3列・2列へ切り替わります。
- 地形の表面プリセットを10種類へ増やし、森林・湿地・火山などの分類から選べるようにしました。高さによる色の境界も調整しました。
- カスタム車の配置、モデルの再生成、MCPでの操作、運転・着席の確認手順をドキュメントに追加しました。
