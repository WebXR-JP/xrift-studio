# XRift Studio v0.9.32

- 「外部から追加 → ギミック → カスタム車」から、オープンカーを配置できるようになりました。XRift 公式コンポーネントの Vehicle からも同じ車を追加できます。車体・座席・タイヤは通常の GLB として Assets に入り、設定済みの Hierarchy をエディター上で確認・編集できます。
- 車の地面追従を標準で有効にしました。地面のコライダーに沿って坂道を走行でき、移動中はタイヤが回転して後部から煙が出ます。各参加者の画面でも、同期された車の動きに合わせて表示されます。
- XRift に公開したワールドで、座席のインタラクトが表示されない問題と、運転席に座っても WASD 操作が車に伝わらない問題を修正しました。公開済みワールドに反映するには、Studio から再公開してください。
- 車両用の補助 Script で発生していたビルド時の型エラーを修正しました。また、公開用テンプレートに含まれるサンプルの公開情報が原因で、XRift への送信前に処理が止まる問題も解消しています。
- ギミックなどの一覧を、画面幅に余裕があるときは 4 列で表示するようにしました。狭い画面では 3 列・2 列に切り替わります。
- 地形の表面プリセットを 10 種類に増やし、森林・湿地・火山などの分類から選べるようにしました。高さによる色の境界も調整しています。
- カスタム車の配置、モデルの再生成、MCP での操作、運転・着席の確認手順をドキュメントに追加しました。
