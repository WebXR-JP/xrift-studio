# XRift Studio v1.0.1

- 標準マテリアルにMToon 0.x／1.0を追加しました。陰影、輪郭の色・太さ、Rim、Matcap、UV AnimationなどをInspectorから設定できます。
- VRM 0.x／1.0の取り込みに対応しました。ボーン、Skin、Morphを保ったまま、取り込んだMToonマテリアルを編集できます。
- Standard (PBR)／MToonの種類を切り替えても、素材ごとの色、Map、UV設定を保持します。PBRへ切り替えた後も、MToonへ戻すと陰影や輪郭の設定を復元できます。
- Assetsで同じ種類のStandard (PBR)／MToonを複数選択すると、各設定を一括変更できます。変更していない色やMapは素材ごとに保持し、異なる値には「一部異なる」と表示します。
- MCPからもMToonの種類切り替え、設定変更、一括編集を行えます。RGBやUVの各成分だけを変更でき、一括操作は一回のUndoにまとまります。
- MToonのプレビューに向きのある照明を使い、Shade Colorによる陰影を確認しやすくしました。
- ボーンのあるモデルのNode編集をドラッグ中に表示へ反映するようにしました。VRM 0.xの軸の向きと、Bone回転設定を併用した場合のずれを修正し、ドラッグ一回を一回のUndoにまとめ、自動保存の更新を安定させました。
- `.xriftstudio`の書き出し・取り込み、Classicへの書き出し、ブラウザ版の書き出しで、MToonの設定、MapとUV、VRM素材を保持します。
- 同梱コードの内部名が原因で、MToon・VRMの公開がSDKのセキュリティ検査で止まる誤検知を修正しました。
- 音源の追加をAudio Sourceに統一し、グローバル音源と空間音響の説明を整理しました。カメラのNear Clip／Far Clipを含め、画面とガイドの用語をそろえました。
- READMEにHomebrewの導入手順とtapの説明を追加しました。
