# XRift Studio v1.0.1

- 標準マテリアルに MToon 0.x / 1.0 を追加しました。陰影、輪郭の色・太さ、Rim、Matcap、UV Animation などを Inspector から設定できます。
- VRM 0.x / 1.0 の取り込みに対応しました。ボーン・Skin・Morph を維持したまま、取り込んだ MToon マテリアルを編集できます。
- Standard (PBR) と MToon の種類を切り替えても、素材ごとの色・Map・UV の設定が引き継がれます。PBR に切り替えた後でも、MToon に戻せば陰影や輪郭の設定を復元できます。
- Assets で同じ種類の Standard (PBR) または MToon を複数選択すると、各設定を一括変更できるようになりました。変更していない色や Map は素材ごとにそのまま残り、値が異なる項目には「一部異なる」と表示されます。
- MCP からも MToon への切り替え、設定変更、一括編集を行えるようになりました。RGB や UV の各成分だけを変更でき、一括操作は 1 回の Undo にまとまります。
- MToon のプレビューに向きのある照明を使い、Shade Color による陰影を確認しやすくしました。
- ボーンのあるモデルの Node 編集を、ドラッグ中にリアルタイムで表示に反映するようにしました。VRM 0.x の軸の向きと Bone 回転設定を併用したときのずれを直し、1 回のドラッグを 1 回の Undo にまとめて自動保存の更新も安定させています。
- `.xriftstudio` の書き出し・取り込み、Classic への書き出し、ブラウザ版の書き出しでも、MToon の設定、Map や UV、VRM 素材がそのまま引き継がれます。
- 同梱コードの内部名が原因で、MToon や VRM の公開が SDK のセキュリティ検査に引っかかる誤検知を修正しました。
- 音源の追加を Audio Source に統一し、グローバル音源と空間音響の説明を整理しました。カメラの Near Clip / Far Clip を含め、画面とガイドの用語もそろえています。
- README に Homebrew の導入手順と tap の説明を追加しました。
