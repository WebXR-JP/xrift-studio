# XRift Studio v0.10.3

v0.10.2 では配布ファイルの添付に失敗したため、修正内容をこのバージョンに引き継いで配布します。

- Windows / macOS / Linux のインストーラーと自動更新ファイルをすべて添付してから公開するよう、リリース処理を修正しました。
- 公開時にモデルに対して行っていた自動加工と物理設定の自動置換をやめ、保存した設定のまま公開するようにしました。
- 公開したワールドで、Rigid Body を持つモデルが置換完了前に隠れて見えなくなる問題を直し、置換が確定してから切り替わるようにしました。
- 同じ Entity に有効な Rigid Body や Mesh Collider が複数設定されている場合、公開前確認で停止するようにしました。Rigid Body は 1 つにまとめ、Mesh Collider は子 Entity に分けて設定してください。
- 同じ Entity に Mesh Collider を重複して追加できないようにしました。
- Play 開始時に、子 Entity の暗黙的な当たり判定が親子で重ならないようにしました。
- 当たり判定用のモデルを描画のインスタンシング対象から外し、表示の不整合を解消しました。
