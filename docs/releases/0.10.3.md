# XRift Studio v0.10.3

v0.10.2 は配布ファイルの添付に失敗したため、この版に修正内容を引き継いで配布します。

- Windows / macOS / Linux のインストーラーと自動更新ファイルをすべて添付してから公開するよう、リリース処理を修正しました。
- 公開時にモデルへ加えていた自動加工と物理の自動置換を止め、保存した設定のまま公開するようにしました。
- 公開したワールドでRigid Bodyを持つモデルが置換の完了前に隠れて見えなくなる問題を直し、置換の確定後に切り替えるようにしました。
- 同じEntityに有効なRigid BodyやMesh Colliderを複数設定している場合、公開前確認で停止するようにしました。Rigid Bodyは1つにまとめ、Mesh Colliderは子Entityへ分けてください。
- 同じEntityへMesh Colliderを重複して追加できないようにしました。
- Play開始時に子Entityの暗黙の当たり判定が親子で重ならないようにしました。
- 当たり判定用のモデルを描画のインスタンシング対象から外し、表示の不整合を直しました。
