# XRift Studio v0.9.27

- glTFマテリアルとギミックをそれぞれ50種類に拡充しました。Emissiveは7種類、テクスチャ付きのマテリアル見本は32種類です。
- 花器・ボトル・布・宝石などの専用モデル12個とテクスチャ46枚を追加しました。同じ形状を左右に並べ、反射・透過・凹凸の違いを比較できます。
- カタログの分類・検索・件数表示を整え、「Emissive / 発光」と「テクスチャ付き」の絞り込みを追加しました。詳細の見本はドラッグで回転、ホイールで拡大できます。
- ギミックに操作・編集手順を追加しました。シーンへ追加した後、Playで扉・照明・音・パーティクルなどの動作を確認できます。
- テクスチャ付きの見本やMCPのマテリアルプリセットを追加すると、必要な画像をプロジェクトのAssetsへ取り込みます。
- 素材の追加中に別の編集が行われた場合、古い状態で上書きしないようにしました。
