# XRift Studio v0.9.27

- glTF マテリアルとギミックをそれぞれ 50 種類に増やしました。Emissive は 7 種類、テクスチャ付きのマテリアル見本は 32 種類あります。
- 花器・ボトル・布・宝石などの専用モデル 12 点とテクスチャ 46 枚を追加しました。同じ形状を左右に並べて、反射・透過・凹凸の違いを見比べられます。
- カタログの分類・検索・件数表示を整え、「Emissive / 発光」と「テクスチャ付き」の絞り込みを追加しました。詳細の見本はドラッグで回転、ホイールで拡大できます。
- ギミックに操作・編集手順を追加しました。シーンに追加した後、Play で扉・照明・音・パーティクルなどの動作を確認できます。
- テクスチャ付きの見本や MCP のマテリアルプリセットを追加すると、必要な画像もプロジェクトの Assets に取り込まれます。
- 素材の追加中に別の編集が行われても、古い状態で上書きされないようにしました。
