# XRift Studio v0.9.25

## 今回の更新

- プロジェクトの複製、ZIP 形式での書き出し・取り込み、Git リポジトリからの取り込みに対応しました。
- Skybox を 33 種類、水のプリセットを 21 種類に増やしました。見た目をプレビューしながら選べます。
- Image Component で画像を板として配置できるようになりました。マテリアルでは頂点カラーと、RGBA のチャンネルを選べる Opacity マップに対応しました。
- 同梱している作例モデル 32 点を更新しました。
- AI 連携で、プロジェクトの作成、開く操作、公開に対応しました。
- 画面名を「ビジュアルエディター」「コードエディター」、実行・終了ボタンを「Play」「Stop」に統一し、作成から公開までの日本語案内も整理しました。
- 紹介サイトと使い方ガイドの表記をそろえました。ガイドのトップページを簡潔にし、紹介サイトに戻るリンクも追加しています。
- 公開用ランタイムで不足していた依存関係を補いました。コードエディターへの書き出しでは依存パッケージの取得を再試行できるようにし、バックアップが正しく残るよう修正しています。
- 新規プロジェクト名を入力するときに、先頭文字が自動で大文字にならない設定を追加しました。

## ダウンロード

Windows は `.exe` または `.msi`、macOS は `.dmg`（Apple Silicon・Intel 共通）、Linux は `.deb`・`.rpm`・`.AppImage` を選んでください。

[紹介サイト](https://webxr-jp.github.io/xrift-studio/) · [使い方ガイド](https://webxr-jp.github.io/xrift-studio/guide/)

XRift Studio は、XRift 公式とは無関係の有志製ツールです。
