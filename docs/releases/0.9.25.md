# XRift Studio v0.9.25

## 今回の更新

- プロジェクトの複製、ZIPへの書き出し・取り込み、Gitリポジトリからの取り込みに対応しました。
- Skyboxを33種類、水のプリセットを21種類へ拡充しました。見た目をプレビューして選べます。
- Image Componentで画像を板として配置できるようになりました。マテリアルでは頂点カラーと、RGBAのチャンネルを選べるOpacityマップに対応しました。
- 同梱の作例モデル32点を更新しました。
- AI連携で、プロジェクトの作成・開く・公開の操作に対応しました。
- 画面名を「ビジュアルエディター」「コードエディター」、実行・終了ボタンを「Play」「Stop」に統一しました。作成から公開までの日本語の案内も整理しました。
- 紹介サイトと使い方ガイドの表記を揃えました。ガイドのトップを簡潔にし、紹介サイトへ戻るリンクを追加しました。
- 公開用ランタイムの依存関係の不足を修正しました。コードエディターへの書き出しでは、依存パッケージの取得を再試行できるようにし、バックアップの保持も修正しました。
- 新規プロジェクト名の入力時に、先頭文字が自動で大文字になるのを防ぐ設定を追加しました。

## ダウンロード

Windowsは `.exe` または `.msi`、macOSは `.dmg`（Apple Silicon・Intel共通）、Linuxは `.deb`・`.rpm`・`.AppImage` を選んでください。

[紹介サイト](https://webxr-jp.github.io/xrift-studio/) · [使い方ガイド](https://webxr-jp.github.io/xrift-studio/guide/)

XRift Studioは、XRift公式とは無関係の有志製ツールです。
