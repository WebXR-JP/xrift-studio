# XRift Studio v0.9.31

- Vehicle（乗り物）とSeat（座席）を、「外部から追加 → XRift公式コンポーネント」のカードからシーンへ追加できるようにしました。デザイン付きの車体や椅子を、操作に必要な設定と一緒に配置し、そのままWorld Playで運転・着席を試せます。VehicleはW/Sで前後に進み、A/Dで旋回、Spaceで降車でき、速度・旋回速度・座面の高さはInspectorから変更できます。
- デスクトップ版の初回起動は、セットアップを完了してからプロジェクト一覧へ進む流れにしました。新しいワールドは「空のワールド」を初期選択とし、床・ライト・開始位置が入った状態で制作を始められます。
- 自動保存を基本とする操作に統一しました。シーンに加えてScript・GLSL・コードエディターの変更も自動保存し、保存待ち・保存中・保存済み・保存エラーを画面で確認できます。通常の編集で保存ボタンを押す必要はありません。
- 利用ガイドに、セットアップ、新規ワールド作成、素材の配置、マテリアル調整、Playなどの実画面画像を追加しました。操作する設定欄を拡大して表示し、保存・再開の手順も自動保存を前提に書き直しました。
- エディターの読み込みエラー画面で重複していた見出しを整理し、セットアップの状態に合う戻り先を表示するようにしました。再読み込みとヘルプへの案内も見直しました。
