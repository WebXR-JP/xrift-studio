# XRift Studio v0.9.31

- Vehicle（乗り物）と Seat（座席）を、「外部から追加 → XRift公式コンポーネント」のカードからシーンに追加できるようになりました。車体や椅子が操作に必要な設定ごと配置され、そのまま World Play で運転や着席を試せます。Vehicle は W / S で前後進、A / D で旋回、Space で降車でき、速度・旋回速度・座面の高さは Inspector から変更できます。
- デスクトップ版の初回起動では、セットアップを完了してからプロジェクト一覧に進む流れにしました。新しいワールドは「空のワールド」を初期選択とし、床・ライト・開始位置が入った状態から制作を始められます。
- 自動保存を基本とする操作に統一しました。シーンに加えて Script・GLSL・コードエディターの変更も自動で保存され、保存待ち・保存中・保存済み・保存エラーの状態を画面上で確認できます。通常の編集で保存ボタンを押す必要はありません。
- 利用ガイドに、セットアップ、新規ワールド作成、素材の配置、マテリアル調整、Play などの実際の画面スクリーンショットを追加しました。操作する設定欄を拡大表示し、保存・再開の手順も自動保存を前提に書き直しています。
- エディターの読み込みエラー画面で重複していた見出しを整理し、セットアップの状態に合った戻り先を表示するようにしました。再読み込みとヘルプへの案内も見直しています。
