# XRift Studio v1.0.4

- Open BrushのGLBで、`OilPaint (Instance)`などのブラシ名を認識できず、通常のマテリアルで表示される不具合を修正しました。
- 頂点カラーを含むOpen Brushモデルで、ブラシシェーダーの読み込みに失敗する不具合を修正しました。編集画面と公開先に同じ修正を適用します。
- Open Brushの第2 UVと旧形式のブラシ用UVをシェーダーへ渡す処理を修正しました。GLBに埋め込まれた画像を保持し、各メッシュに対応するブラシを適用します。
- Web版をサブディレクトリで開いたときに、Open Brushのシェーダーとテクスチャを読み込めない不具合を修正しました。ブラウザ公開用runtimeも、編集画面と同じブラシローダーに更新しました。
- Open BrushのGLBに埋め込まれた画像をTexture Assetとして取り込み、マテリアルとブラシシェーダーの参照を保持するようにしました。
