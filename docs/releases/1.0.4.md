# XRift Studio v1.0.4

- Open Brush の GLB で `OilPaint (Instance)` などのブラシ名を認識できず、通常のマテリアルとして表示されてしまう不具合を修正しました。
- 頂点カラーを含む Open Brush モデルで、ブラシシェーダーの読み込みに失敗する不具合を修正しました。編集画面と公開先の両方に同じ修正を適用しています。
- Open Brush の第 2 UV と旧形式のブラシ用 UV をシェーダーに渡す処理を修正しました。GLB に埋め込まれた画像をそのまま残し、各メッシュに対応するブラシが適用されます。
- Web 版をサブディレクトリで開いたときに、Open Brush のシェーダーとテクスチャを読み込めない不具合を修正しました。ブラウザ公開用ランタイムも、編集画面と同じブラシローダーに更新しています。
- Open Brush の GLB に埋め込まれた画像を Texture Asset として取り込み、マテリアルとブラシシェーダーからの参照が切れないようにしました。
