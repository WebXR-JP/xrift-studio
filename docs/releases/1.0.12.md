# XRift Studio v1.0.12

- 制作チャットで、UIKit を使った角丸と余白のある空間 UI を作れるようになりました。日本語フォントの取り込みに対応し、文字の読み込みが終わらない問題や一部の文字が崩れる問題も修正しています。
- Text の背景に Border Radius を追加しました。コードで作る Text では、文字の太さ・整列・行間・字間も指定できます。編集画面・Play・公開先で共通の描画処理を使います。
- Hierarchy や Scene View の Entity を右クリックして「チャットに送る」「AIで作り替える…」を選べるようになりました。対象を添付して制作チャットを開き、入力中の下書きを残したまま仕上げの希望を入力できます。
- 制作方法を「AIにおまかせ」「素材ストア中心」「Blenderで制作」から選べるようになりました。自動制作では、外部素材・コード・UIKit・Blender を用途に合わせて使い分ける方針を整えています。
- ワールド制作ガイドを日本語化し、形や素材の仕上げ、読む距離、Skybox・IBL・照明の選び方と確認方法を追加しました。AI から Ambient Light の有効・無効も変更できます。
