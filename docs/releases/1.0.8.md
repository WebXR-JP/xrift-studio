# XRift Studio v1.0.8

- 制作チャットで `/goal` に続けて目標を送ると、保存済みの結果と最新のSceneを見直しながら、制作を続けられるようになりました。停止しても保存済みの変更は残ります。
- Blenderを使うモデル制作では、独立したモデルを最大2件並行して作り、完成したものからSceneへ反映します。曲線、回転面、角の丸み、UVにも対応しました。
- SkyboxとMaterialの選択肢を最大12候補に増やし、実際の素材のサムネイルで比較できるようになりました。制作予定と履歴にも素材のプレビューを表示します。
- Materialを変更する依頼で、指定したEntityへの割り当てとScene全体への一括適用を使い分けられるようになりました。全体への適用も、依頼単位でまとめて戻せます。
- 次の依頼の候補が、指定した対象やScene全体など、直前の依頼の範囲を引き継ぐように改善しました。
