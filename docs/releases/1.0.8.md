# XRift Studio v1.0.8

- 制作チャットで `/goal` に続けて目標を送ると、保存済みの結果と最新の Scene を見直しながら制作を続けられるようになりました。途中で停止しても保存済みの変更はそのまま残ります。
- Blender を使ったモデル制作では、独立したモデルを最大 2 件並行して作り、完成したものから順に Scene に反映するようにしました。曲線、回転面、角の丸み、UV にも対応しています。
- Skybox と Material の選択肢を最大 12 候補に増やし、実際の素材のサムネイルで見比べられるようにしました。制作予定と履歴にも素材のプレビューを表示します。
- Material を変更する依頼で、指定した Entity への割り当てと Scene 全体への一括適用を使い分けられるようになりました。全体への適用も、依頼単位でまとめて元に戻せます。
- 次の依頼候補が、指定した対象や Scene 全体など、直前の依頼の範囲を引き継ぐように改善しました。
