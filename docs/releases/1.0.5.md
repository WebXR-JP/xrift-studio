# XRift Studio v1.0.5

- Editor内の制作チャットからChatGPTに接続し、現在のSceneと会話履歴をもとに編集を依頼できるようになりました。Planを確認してから反映でき、途中で停止しても保存済みの編集は残ります。
- 制作チャットでモデル、マテリアル、音声を検索して取り込み、Sceneへ設定できるようになりました。モデルを設定するときは、Entityの配置と既存のComponentsを保持します。
- ChatGPT接続の復元とモデル選択を改善しました。Sceneや作品の切替、Plan作成後の手動編集を検出し、古い依頼が別のSceneや新しい編集内容を上書きしないようにしました。
- ワールドへのXRift Itemの配置と、ブラウザからのワールド・アイテム公開に対応しました。公開結果が不明なときの重複送信を防ぎ、Script・Graphの保存を待ってから公開を進めます。
- XRift CLI 0.25.0、SDK 0.2.0、world-components 0.57.1に対応しました。MToonの頂点色による描画エラーを修正し、編集・Play・公開用Runtimeへ同じ修正を適用しました。
- Hierarchyのドラッグが途中で止まる問題、狭い画面でAssetsの見出しと検索操作が重なる問題、自動画質へ戻したときの判定、音声やCanvas終了時の例外を修正しました。
- 起動中の読み込み状況と、読み込みに失敗したときの再表示操作を追加しました。ガイドの更新で編集中のEditorが再読み込みされる問題も修正しました。
- 素材カタログにAI LOWPOLY PROPSを追加し、制作から公開・更新・招待までを学べる29教材のコースと利用ガイドを整えました。
