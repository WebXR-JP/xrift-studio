# XRift Studio v1.0.5

- エディター内の制作チャットから ChatGPT に接続し、現在の Scene と会話履歴をもとに編集を依頼できるようになりました。Plan を確認してから反映でき、途中で停止しても保存済みの変更はそのまま残ります。
- 制作チャットからモデル・マテリアル・音声を検索して取り込み、Scene に設定できるようになりました。モデルを差し替えても、Entity の配置や既存の Components は維持されます。
- ChatGPT 接続の復元とモデル選択を改善しました。Scene や作品の切り替え、Plan 作成後の手動編集を検出し、古い依頼が別の Scene や新しい編集内容を上書きしないようにしています。
- ワールドへの XRift Item の配置と、ブラウザからのワールド・アイテム公開に対応しました。公開結果が不明なときの重複送信を防ぎ、Script や Graph の保存を待ってから公開を進めます。
- XRift CLI 0.25.0、SDK 0.2.0、world-components 0.57.1 に対応しました。MToon の頂点カラーによる描画エラーを修正し、編集・Play・公開用ランタイムのすべてに同じ修正を適用しています。
- Hierarchy のドラッグが途中で止まる問題、狭い画面で Assets の見出しと検索欄が重なる問題、自動画質に戻したときの判定、音声や Canvas 終了時の例外を修正しました。
- 起動中の読み込み状況の表示と、読み込みに失敗したときの再表示ボタンを追加しました。ガイドの更新によって編集中のエディターが再読み込みされてしまう問題も修正しています。
- 素材カタログに AI LOWPOLY PROPS を追加し、制作から公開・更新・招待までを学べる 29 教材のコースと利用ガイドを整えました。
