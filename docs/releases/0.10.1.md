# XRift Studio v0.10.1

- 上部の「素材を追加」から、基本形状・ライト・XRift のギミックなどをカテゴリと検索で選べるようにしました。名前や用途で探せて、使えない候補にはその理由が表示されます。
- Entity の新規作成と、既存 Entity への Component 追加を分けました。Component の追加は Inspector から、選択中 Entity の編集は Scene と Hierarchy 共通の右クリックメニューから行えます。
- Hierarchy で選んだ Entity と必要な素材を `.xriftstudio` 形式で書き出し、別のワールドやアイテムに追加できるようになりました。書き出す種類で「アイテム」を選ぶと、独立したアイテムとして開けます。
- 同じウィンドウ・タブ内の別プロジェクトに、素材ごとコピーして貼り付けられるようになりました。コピー完了の表示が出てからプロジェクトを切り替えてください。
- モデルの読み込み後に当たり判定を作り直すようにしました。「当たり判定に追加」で設定した形状が物理空間に登録されるまで Play を開始せず、解除した判定が次の Play に残らないようにしています。
- 既存の Mesh Collider がある場合は作り直さずに再利用し、摩擦・反発・Trigger の設定が別の Rigid Body で上書きされないようにしました。
