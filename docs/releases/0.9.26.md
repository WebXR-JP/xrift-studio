# XRift Studio v0.9.26

## 今回の更新

- 使い方ガイドを作り直し、実際の画面画像を加えました。アプリ内の案内と紹介サイトから同じ内容を確認できます。
- ビジュアルエディターのオブジェクト作成メニューを整理し、Hierarchyとシーン上で同じ項目を選べるようにしました。
- Assetsの一覧を見直し、実際のフォルダーだけを表示して、ファイルサイズを読みやすくしました。
- Componentの一覧では、重複するSpawn Pointと削除できないTransformを追加候補から除外しました。
- Component名の英語表記を各画面で統一し、メニューがパネルの背面に隠れる問題を修正しました。

## ダウンロード

Windowsは `.exe` または `.msi`、macOSは `.dmg`（Apple Silicon・Intel共通）、Linuxは `.deb`・`.rpm`・`.AppImage` を選んでください。

[紹介サイト](https://webxr-jp.github.io/xrift-studio/) · [使い方ガイド](https://webxr-jp.github.io/xrift-studio/guide/)

XRift Studioは、XRift公式とは無関係の有志製ツールです。
