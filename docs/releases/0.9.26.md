# XRift Studio v0.9.26

## 今回の更新

- 使い方ガイドを刷新し、実際の画面スクリーンショットを追加しました。アプリ内のヘルプと紹介サイトの両方から同じ内容を確認できます。
- ビジュアルエディターのオブジェクト作成メニューを整理し、Hierarchy とシーン上のどちらからも同じ項目を選べるようにしました。
- Assets の一覧を見直し、実在するフォルダーだけを表示するようにしたほか、ファイルサイズも読みやすく整えました。
- Component 一覧の追加候補から、重複する Spawn Point と削除できない Transform を除外しました。
- Component 名の英語表記を各画面で統一し、メニューがパネルの背面に隠れてしまう問題を修正しました。

## ダウンロード

Windows は `.exe` または `.msi`、macOS は `.dmg`（Apple Silicon・Intel 共通）、Linux は `.deb`・`.rpm`・`.AppImage` を選んでください。

[紹介サイト](https://webxr-jp.github.io/xrift-studio/) · [使い方ガイド](https://webxr-jp.github.io/xrift-studio/guide/)

XRift Studio は、XRift 公式とは無関係の有志製ツールです。
