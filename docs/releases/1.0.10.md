# XRift Studio v1.0.10

- 制作チャットの実行基盤を見直し、依頼に合わせて必要な操作を選びながらワールドやモデルの制作を進められるようにしました。保存状態・Scene の内容・描画画像を確認して完成条件を判定します。
- 制作中に追加の指示を送れるようになりました。「今の制作に反映」と「終了後に実行」から選べます。反映されなかった指示は入力欄に戻して再送できます。
- 会話の詳細な履歴を端末内に保存し、過去の応答から別案のチャットを始められるようになりました。この操作で現在の Scene は変わりません。
- 信頼する提供元の追加機能を、バージョンを指定して登録できるようになりました。登録したプログラムは Studio と同じ OS 権限で動作します。Plan では使用しません。
- 回答・制作プラン・質問・進捗・エラーの説明を読みやすく整えました。通常の応答が完了しただけなのに、制作に失敗したように表示されてしまう問題も修正しています。
- 開発時と配布版で制作に必要な実行ファイルを準備する処理を見直し、認証情報と会話履歴の保存も引き継げるようにしました。
