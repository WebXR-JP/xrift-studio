# XRift Studio v1.0.17

- 初期セットアップと推奨 CLI を `@xrift/cli` 0.26.0 に更新しました。旧版からの更新を案内し、より新しい安定版が入っている場合はそのまま維持します。
- ボーン付きモデルの再描画時に、脚などのパーツが離れてしまう不具合を修正しました。
- `.blend` ファイルを Assets に取り込み、編集元としてプロジェクト内に保存できるようになりました。インストール済みの Blender で編集し、再取り込みすると配置を崩さずに更新できます。
- AI が Blender で作ったモデルも編集元を保存するようにしました。パーツごとに編集元を管理し、公開時にはそこから生成して Studio で確認済みの GLB を使います。
