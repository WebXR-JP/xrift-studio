# XRift Studio v1.0.9

- ChatGPTとMCPの制作手順を揃え、家や街、公園など、依頼の範囲に合わせてワールド全体の構成と細部を作るように改善しました。初期状態の床や箱に用途を合わせず、新しい構成から制作できます。
- ワールド制作が1回の処理で打ち切られる問題を修正しました。保存したSceneの全景と入口からの見え方を確認し、依頼の完成条件に沿って修正を続けます。
- React Three Fiber（R3F）のコードを原本として保存し、続きの依頼で読み直して編集できるようになりました。手動で編集した部分を保ちながら更新し、同じ内容の再適用では不要な変更を作りません。
- 素材の検索と制作を整理し、重複したコード生成や確認を減らしました。思考の既定値を低くし、利用者が選んだ設定は引き継ぎます。
- 停止、再試行、保存、完成確認の扱いを改善し、古いSceneの確認結果で制作完了と判定しないようにしました。
- Blenderモデルの形状・材質の検証と、R3Fの押し出し形状の表示を改善しました。制作スキルも、ワールド制作に必要な内容へ整理しました。
