# XRift Studio v1.0.9

- ChatGPT と MCP の制作手順をそろえ、家や街、公園など依頼の規模に合わせてワールド全体の構成と細部を作るように改善しました。初期状態の床や箱にとらわれず、新しい構成から制作できます。
- ワールド制作が 1 回の処理で打ち切られてしまう問題を修正しました。保存した Scene の全景と入口からの見え方を確認しながら、依頼の完成条件に沿って修正を続けます。
- React Three Fiber（R3F）のコードを元データとして保存し、続きの依頼で読み直して編集できるようになりました。手動で編集した部分を残したまま更新でき、同じ内容の再適用では不要な変更を作りません。
- 素材の検索と制作の流れを整理し、重複したコード生成や確認を減らしました。思考量の既定値を低くし、利用者が選んだ設定はそのまま引き継ぎます。
- 停止・再試行・保存・完成確認の扱いを改善し、古い Scene の確認結果で制作完了と判定されないようにしました。
- Blender モデルの形状・材質の検証と、R3F の押し出し形状の表示を改善しました。制作スキルも、ワールド制作に必要な内容に整理しています。
