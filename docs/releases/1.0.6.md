# XRift Studio v1.0.6

- OpenBrushモデルを含むワールドの公開で、ビルドが型エラーにより失敗する問題を修正しました。
- 制作チャットで、処理中に次の依頼を送信待ちへ追加できるようになりました。Enterで送信、Shift+Enterで改行でき、日本語の変換確定では送信しません。
- ChatGPTが最新のSceneを読み直して制作を続けられるようにしました。手動編集と保存済みの制作結果を保持し、Planの対象が変わった場合は内容を再確認できます。
- 導入済みのBlenderを使って、制作チャットからモデルを作成できるようになりました。出力したGLBは通常のモデル素材としてAssetsへ取り込みます。
- 素材サイトに「素材庫」を追加しました。GLBモデル、アニメーション入りモデル、PNG画像・マスクを選び、デスクトップ版とブラウザ版から取り込めます。
- 外部ストアのGLBを元のファイルのまま保存し、GLBのダウンロードと取り込みの固定容量上限をなくしました。ambientCGの正規配信先への転送でダウンロードが失敗する問題も修正しました。
