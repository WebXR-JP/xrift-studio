# XRift Studio v1.0.6

- Open Brush モデルを含むワールドを公開するときに、ビルドが型エラーで失敗する問題を修正しました。
- 制作チャットで処理中に次の依頼を送信待ちに追加できるようになりました。Enter で送信、Shift+Enter で改行でき、日本語の変換確定では送信されません。
- ChatGPT が最新の Scene を読み直して制作を続けられるようにしました。手動編集や保存済みの制作結果を残したまま作業を続けられ、Plan の対象が変わった場合は内容を再確認できます。
- インストール済みの Blender を使って、制作チャットからモデルを作成できるようになりました。出力した GLB は通常のモデル素材として Assets に取り込まれます。
- 素材サイトに「素材庫」を追加しました。GLB モデル、アニメーション入りモデル、PNG 画像・マスクを選び、デスクトップ版とブラウザ版の両方から取り込めます。
- 外部ストアの GLB を元のファイルのまま保存するようにし、ダウンロードと取り込みの固定容量上限をなくしました。ambientCG の正規配信先への転送でダウンロードが失敗する問題も修正しています。
