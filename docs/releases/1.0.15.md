# XRift Studio v1.0.15

- 制作チャットが、木やベンチなど繰り返し配置するオブジェクトをプレハブとして再利用するようになりました。元の Entity を編集してプレハブに反映すると、すべての配置をまとめて変更できます。
- プレハブの 1 つだけを変えたいとき、AI がその配置を通常の Entity に展開して編集できるようになりました。元の Entity を削除してしまった場合も、配置済みのプレハブから復元できます。
- 元の Entity の変更がプレハブに未反映の場合、AI に未反映の状態と次の操作を伝えるようにしました。配置したプレハブも性能分析の対象に含まれます。
- AI による素材の配置で、位置・回転・大きさをまとめて指定できるようになりました。
