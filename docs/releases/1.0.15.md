# XRift Studio v1.0.15

- 制作チャットが、木やベンチなど繰り返し置くものをプレハブとして再利用するようになりました。元のEntityを編集してプレハブに反映すると、すべての配置をまとめて変更できます。
- プレハブの一つだけを変えたいとき、AIがその配置を通常のEntityに展開して編集できるようになりました。元のEntityを削除してしまった場合も、配置から復元できます。
- 元のEntityの変更がプレハブに未反映の場合、AIに未反映の状態と次の操作を伝えるようにしました。配置したプレハブも性能分析の対象に含めます。
- AIによる素材の配置で、位置・回転・大きさをまとめて指定できるようになりました。
