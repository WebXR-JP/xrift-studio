# XRift Studio v1.0.19

- 公式 Components を 0.64.0 に更新しました。編集・Play・公開のすべてで同じバージョンを使います。
- 公式の Seat に対応しました。Inspector で既存の Entity に追加すると、その Entity を座れる場所にできます。「XRift公式コンポーネント → Seat」からは座面付きの見本を追加できます。Play 中はクリックで座り、Space で降ります。
- Grabbable で掴んだオブジェクトの動きと置いた位置を、同じインスタンスの全員に共有するようになりました。Inspector で Sync をオフにすると、自分の画面だけで動きます。
- 制作チャットと MCP の AI に、既存のモデルや作品の品質を高める手順を加えました。気になる箇所が見える視点で問題を再現してから修正し、同じ視点で撮影した修正前後の画像を比べて確認します。直した箇所と残る課題も報告します。
