# XRift Studio v1.0.19

- 公式Componentsを0.64.0へ更新しました。編集、Play、公開で同じ版を使います。
- 公式のSeatに対応しました。Inspectorで既存のEntityに追加すると、そのEntityを座れる場所にできます。「XRift公式コンポーネント → Seat」では座面付きの見本を追加できます。Playではクリックで座り、Spaceで降ります。
- Grabbableで掴んだ物の動きと置いた位置を、同じインスタンスの全員に共有するようになりました。InspectorでSyncをオフにすると、自分の画面だけで動きます。
- 制作チャットとMCPのAIに、既存のモデルや作品の品質を上げる手順を加えました。気になる箇所が見える視点で問題を再現してから直し、同じ視点で撮った修正前後の画像を比べます。直した箇所と残る課題も報告します。
