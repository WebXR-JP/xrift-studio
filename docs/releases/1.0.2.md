# XRift Studio v1.0.2

- 新しいワールドの初期構成を Plane・Box・Light・SpawnPoint の最小構成にそろえました。Plane の当たり判定の説明も整理しています。
- テクスチャ取り込みの既定設定を見直し、元のサイズと形式のまま取り込むようにしました。Skybox に使う画像も同じ設定で取り込めます。
- テクスチャを選び直したときに、読み込み済みの Map が失われてしまう不具合を修正しました。
- MToon でモデルの頂点カラーをそのまま使えるようにし、設定から有効・無効を切り替えられるようにしました。
- 外部素材カタログの一覧を最後まで表示できるようにしました。音蔵の音源は SFX と BGM で絞り込めます。
- 録画停止時の処理と、録画ファイルをフォルダーで表示する操作を修正しました。ファイル操作や外部リンクを開く処理も改善しています。
- OS ごとのターミナル起動を修正し、VS Code を開けなかったときにエラーを通知するようにしました。
- Assets の右クリックメニューをカーソル付近に表示するようにし、スマートフォン表示でのパネル操作ボタンのサイズをそろえました。
- 設定項目の日本語説明と Node Graph の用語を整理し、利用ガイドに録画と GLSL 編集の手順を追加しました。
