# XRift Studio v1.0.2

- 新しいワールドをPlane、Box、Light、SpawnPointの最小構成にそろえました。Planeの当たり判定の説明も整理しました。
- テクスチャ取り込みの既定設定で、画像の元のサイズと形式を保持するようにしました。Skyboxに使う画像も同じ設定で取り込めます。
- テクスチャを再選択したときに、読み込み済みのMapが失われる不具合を修正しました。
- MToonでモデルの頂点カラーを保持し、設定から使用の有無を切り替えられるようにしました。
- 外部素材カタログの一覧を最後まで表示できるようにしました。音蔵の音源はSFXとBGMで絞り込めます。
- 録画停止時の処理と、録画ファイルをフォルダーで表示する操作を修正しました。ファイル操作と外部リンクを開く処理も改善しました。
- OSごとのターミナル起動を修正し、VS Codeを開けなかった場合に失敗を通知するようにしました。
- Assetsの右クリックメニューをカーソル付近に表示するようにし、スマートフォンのパネル操作ボタンの寸法をそろえました。
- 設定の日本語説明とNode Graphの用語を整理し、利用ガイドに録画とGLSL編集の手順を追加しました。
