# XRift Studio v0.10.4

- ビジュアルエディターの Assets を整理し、グリッド表示で素材名をアイコンの下に出すようにしました。フォルダーへの移動、複数選択した素材の削除、ノードグラフを開く導線も改善しています。
- Hierarchy と Scene の右クリックメニューを整理し、Entity の作成・編集や選択中 Entity の削除を行いやすくしました。複数選択時の回転・拡縮とギズモ表示も修正しています。
- ライトの向き、Power、投影テクスチャ、影の解像度や範囲を Inspector から設定できるようになりました。シーン全体の Shadow Map も選択できます。
- MCP のマテリアル編集で、PBR の各値、テクスチャの UV 変換、対応する `KHR_materials_*` 拡張を設定できるようになりました。
- 公開したモデルで一部のノードが欠ける問題を修正しました。既存ワールドの更新とアップロード対象の判定も直し、同梱する CLI と公式 World テンプレートを更新しています。
- 録画の入口とエディターの操作表示を整理し、シーンのグリッドが移動スナップ設定に合うようにしました。
