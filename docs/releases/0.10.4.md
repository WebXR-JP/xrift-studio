# XRift Studio v0.10.4

- ビジュアルエディターのAssetsを整理し、グリッドで素材名をアイコンの下に表示するようにしました。フォルダーへの移動、複数選択した素材の削除、ノードグラフを開く入口も改善しました。
- HierarchyとSceneの右クリック操作を整理し、Entityの作成・編集、選択中のEntityの削除を行いやすくしました。複数選択時の回転・拡縮とギズモの表示も修正しました。
- ライトの向き、Power、投影テクスチャ、影の解像度や範囲をInspectorで設定できるようにしました。シーン全体のShadow Mapも選択できます。
- MCPのマテリアル編集でPBR値、テクスチャのUV変換、対応する`KHR_materials_*`拡張を設定できるようにしました。
- 公開したモデルで一部のノードが欠ける問題を修正しました。既存ワールドの更新とアップロード対象の判定も修正し、同梱するCLIと公式Worldテンプレートを更新しました。
- 録画の入口とエディターの操作表示を整理し、シーンのグリッドが移動スナップ設定に沿うようにしました。
