# XRift Studio v1.0.0

- XRift Studioをv1.0.0としてリリースしました。ビジュアルエディターでのワールド・アイテム制作、Playでの動作確認、XRiftへの公開を利用できます。
- macOS向けにHomebrewでの配布を追加しました。Apple SiliconとIntelの両方で使えるUniversal版をインストール・更新できます。
- 通常リリースの公開後にHomebrewの配布定義を生成し、更新PRを作る処理を追加しました。定義のURL・SHA-256・公開状態を検証し、旧版への巻き戻りを防ぎます。

## Homebrewでインストールする

```bash
brew tap webxr-jp/xrift-studio https://github.com/WebXR-JP/xrift-studio.git
brew install --cask webxr-jp/xrift-studio/xrift-studio
```

配布定義の更新PRがマージされると、Homebrewからv1.0.0を取得できます。既に導入済みの場合は`brew update`の後に`brew upgrade --cask --greedy webxr-jp/xrift-studio/xrift-studio`を実行してください。

XRift StudioはXRift公式とは無関係の有志製ツールです。保存した作品は更新前にファイルへ書き出してバックアップしてください。macOSで開発元の確認が表示される場合は、[インストールガイド](https://github.com/WebXR-JP/xrift-studio/blob/main/docs/guide/installation-problems.md#macosで開けない)を参照してください。
