# XRift Studio v1.0.0

- XRift Studio を v1.0.0 としてリリースしました。ビジュアルエディターでのワールド・アイテム制作、Play での動作確認、XRift への公開を利用できます。
- macOS 向けに Homebrew での配布を追加しました。Apple Silicon と Intel の両方で使える Universal 版をインストール・更新できます。
- 通常リリースの公開後に Homebrew の配布定義を生成し、更新 PR を作成する処理を追加しました。定義の URL・SHA-256・公開状態を検証し、古いバージョンに戻ってしまうのを防ぎます。

## Homebrew でインストールする

```bash
brew tap webxr-jp/xrift-studio https://github.com/WebXR-JP/xrift-studio.git
brew install --cask webxr-jp/xrift-studio/xrift-studio
```

配布定義の更新 PR がマージされると、Homebrew から v1.0.0 を取得できます。すでに導入済みの場合は `brew update` の後に `brew upgrade --cask --greedy webxr-jp/xrift-studio/xrift-studio` を実行してください。

XRift Studio は XRift 公式とは無関係の有志製ツールです。保存した作品は更新前にファイルへ書き出してバックアップしてください。macOS で開発元の確認が表示される場合は、[インストールガイド](https://github.com/WebXR-JP/xrift-studio/blob/main/docs/guide/installation-problems.md#macosで開けない)を参照してください。
