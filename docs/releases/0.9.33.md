# XRift Studio v0.9.33

- Seat・Vehicleのローカル動作確認を、公式の `@xrift/world-components` 0.53.0の処理へ移行しました。World Playで着席・操縦・視点追従を確認でき、SpaceまたはEで降車できます。
- 着席中のテレポートと、Stop・座席削除時の着席解除に対応しました。フォーカスやポインターロックが外れたときは、押下中のキーを解除して操縦が続かないようにしました。
- エディター、Classic出力、公開ステージングの公式Component依存を0.53.0に揃えました。
- `.xriftstudio` ファイルをOSから開いたときに、Studioへ取り込む導線を追加しました。
