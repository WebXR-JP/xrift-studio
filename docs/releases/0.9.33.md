# XRift Studio v0.9.33

- Seat と Vehicle のローカル動作確認を、公式の `@xrift/world-components` 0.53.0 の処理に切り替えました。World Play で着席・操縦・視点追従を確認でき、Space または E で降車できます。
- 着席中のテレポートと、Stop や座席削除時の着席解除に対応しました。フォーカスやポインターロックが外れたときは押されているキー入力をリセットし、操縦が続いてしまうのを防ぎます。
- エディター、Classic 出力、公開ステージングの公式 Component 依存バージョンを 0.53.0 にそろえました。
- `.xriftstudio` ファイルを OS から直接開いたときに、Studio に取り込める導線を追加しました。
