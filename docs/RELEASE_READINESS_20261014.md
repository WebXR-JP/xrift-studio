## 実機確認と残る確認

Windows の Tauri 実機で隔離した検証用プロジェクトを開き、制作チャット、Scene と Inspector の同時表示、左下の入口、MCP 操作、エラーログを確認しました。既存作品を検証用に変更していません。

本人による接続完了（実際の OAuth）、実際のクラウド推論、Studio 再起動後の接続復元はいずれも未確認で、本人の接続操作待ちです。モックの結果や合成データの検証を実際の認証成功としては扱っていません。macOS・Linux の実機は未検証で、CI に 3 OS の Rust 確認と必要な依存を設定しています。

ブラウザからの公開では World と Item を扱います。Script を含むプロジェクトは、プロジェクトを書き出してデスクトップ版から公開する経路を維持しています。

報告された「を」の字形不足は、UIKit が選択フォントの字形を取得できないときの警告です。公式 Component には日本語フォントの読み込みがあり、元作品のどの部品・フォントで不足したかは未確認です。「aaaaaa」の保存データを読み取り、外部 Item の参照までは確認しましたが、完全な音声 URL とフォント情報は保存されていません。作品の変更や開き直しは行っていません。音声の終了処理修正による disconnect 例外の防止と、字形不足・音声 404 の解消は別に確認する必要があります。

XRift への実際の公開、`main` への Push・マージ、インストーラーの作成・配布は行っていません。ガイド本文と目次は更新しましたが、既存のガイド画像・動画は今回更新していません。
