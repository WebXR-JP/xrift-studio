# 提供元の検証結果

対象: `xrift-studio-sky-shaders@3`（33 プリセット / 11 カテゴリ）。

実行環境は Chromium 144.0.7559.96 / Linux / WebGL2 / SwiftShader です。TypeScript のトランスパイルにはこの作業環境のツールを使っています。Playwright Python 経由で、同梱の `webgl-checks.cjs` と同じ検査関数をブラウザ内で実行しました。

| 項目 | 結果 |
| --- | --- |
| カタログ整合性 | 2,237 件のアサーション / エラーなし |
| 33 プリセット × 3 品質のコンパイル・実際の描画 | 99 / エラーなし |
| 6 方向（水平 4 方向・真上・真下） | 198 / エラーなし |
| 公開パラメーターの最小・最大、黒・白 | 980 / エラーなし |
| 上記の非数値・無限大検査 | 1,277 / 検出なし |
| 露出 0 で黒になること | 33 / エラーなし |
| 新規シェーダーの速度 0・瞬き 0 での静止 | 24 / エラーなし |
| UI に露出するパラメーターの有効性 | WebGL の active uniforms と照合 / エラーなし |
| 変更した TypeScript / TSX の構文検査 | 8 ファイル / エラーなし |
| 既存フィクスチャの登録漏れ検査 | 104 スイート登録済み |

数値検査は 96×60 で行い、サムネイルは標準品質 640×400 で別途生成して最終画像も確認しました。これらは実機 GPU での速度測定ではなく、RGB 画像への出力を含む WebGL2 の検証です。数値検査はフラグメントの色出力を対象としており、各演算の途中値をすべて追跡するものではありません。

この環境ではアプリの依存パッケージを取得できなかったため、アプリ全体の型検査、React / R3F 統合、Tauri ビルド、全フィクスチャの実行、WebXR / Quest 実機、MCP・World 出力を通した E2E 検証は未実施です。フィクスチャの「登録確認」と「実行」を混同しないよう注意してください。

`verify-webgl.mjs` は、利用者の開発環境にある `@playwright/test` で同じブラウザ内テストを実行するための再現用ランナーです。この Node ランナー自体は依存パッケージ未取得のため、この環境では実行していません。

`main` 取り込み時の再検証と Three.js / R3F での確認結果は、[Skybox Shader Library](../SKY_SHADERS.md#main取り込み時の検証2026-09-07)に記録しています。ストアのサムネイルは取り込み時に Three.js で再生成しました。
