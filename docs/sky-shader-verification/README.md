# 提供元の検証結果

対象: xrift-studio-sky-shaders@3（33プリセット / 11カテゴリ）。

実行環境はChromium 144.0.7559.96 / Linux / WebGL2 / SwiftShaderです。TypeScriptのトランスパイルにはこの作業環境のツールを使っています。Playwright Python経由で、同梱の`webgl-checks.cjs`と同じ検査関数をブラウザ内で実行しました。

| 項目 | 結果 |
|---|---|
| カタログ整合性 | 2,237 assertions / エラーなし |
| 33プリセット × 3品質のコンパイル・実描画 | 99 / エラーなし |
| 6方向（水平4方向・真上・真下） | 198 / エラーなし |
| 公開パラメーターの最小・最大、黒・白 | 980 / エラーなし |
| 上記の非数値・無限大検査 | 1,277 / 検出なし |
| 露出0で黒になること | 33 / エラーなし |
| 新規シェーダーの速度0・瞬き0の静止 | 24 / エラーなし |
| UIに露出するパラメーターの有効性 | WebGL active uniformsとの照合 / エラーなし |
| 変更したTypeScript/TSXの構文検査 | 8ファイル / エラーなし |
| 既存fixtureの登録漏れ検査 | 104 suites registered |

数値検査は96×60で行い、サムネイルは標準品質640×400で別途生成しました。最終画像も確認しています。これらは実機GPUの速度測定ではなく、RGB画像への出力を含むWebGL2の検証です。数値検査はフラグメントの色出力を対象とし、各演算の途中値をすべて追跡するものではありません。

アプリの依存パッケージをこの環境では取得できなかったため、アプリ全体の型検査、React/R3F統合、Tauriビルド、全fixtureの実行、WebXR/Quest実機、MCP・World出力を通したE2E検証は未実施です。fixtureの「登録確認」と「実行」を混同しないでください。

`verify-webgl.mjs`は利用者の開発環境にある`@playwright/test`で同じブラウザ内テストを実行する再現用ランナーです。このNodeランナー自体は依存パッケージ未取得のため、この環境では実行していません。

main取り込み時の再検証とThree.js/R3Fの確認は[Skybox Shader Library](../SKY_SHADERS.md#main取り込み時の検証2026-09-07)に記録しています。ストアのサムネイルは取り込み時にThree.jsで再生成しました。
