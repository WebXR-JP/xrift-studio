# 地形エディター仕様

地形の編集には多くの操作が必要になる。他のコンポーネントと同じ設定パネルでは操作しにくいため、専用エディターに分ける設計を示す。

この文書は設計を記録したもの。「実装済み」と明記した部分以外は未実装である。

## なぜ専用にするのか

地形はブラシを選び、地面を繰り返し操作して編集する。通常の設定パネルでは、次の問題がある。

- ブラシの半径・強さ・種類を変えるたびに、地面から右パネルへ視線を移す必要がある。
- 高さ、草、穴、マテリアルが同じ縦長のリストに混在し、編集中の項目が分かりにくい。
- 地形の編集中も他のオブジェクトを選択できるため、誤って別の物を動かすことがある。

## 全体の形

地形を選択して「地形を編集」に入ると、専用モードへ遷移する。

- シーンは地形だけを操作対象にする。他のオブジェクトのギズモと選択を止める
- 左下にツールバー（モード切替）を出す。右にはそのモード専用のパネルだけを出す
- Escapeまたは「編集を終了」で通常のEditorへ戻る。戻り先は常に画面へ残す

### ツールバーの見せ方

Unityの地形設定に合わせる。モードはアイコンのタブとして横一列に並べる。選択中のモードだけが押された状態になる。選んだモードの設定だけを下へ出す。使わない設定は出さない。「操作」のドロップダウンから選ぶ形は使わない。いま何が有効なのかが読めないためである。

操作の意味をアイコンだけで示さない。各タブには読めるラベルを添える。`title`も付ける。形モードの中の筆（盛る・削る・ならす・高さを揃える・スタンプ）も同じ扱いにする。アイコン付きのボタン列にする。ドロップダウンでは、いま選んでいる筆が一覧の中に見えないためである。

モードは4つである。同時に有効なのは常に1つである。いま何を触っているのかを画面が示す。

| モード | 触るもの | 主な操作 |
| --- | --- | --- |
| 形 (Sculpt) | 高さフィールド | 盛る / 削る / 高さを揃える / ならす / スタンプ |
| 穴 (Hole) | セルマスク | 開ける / 塞ぐ |
| 草 (Grass) | 草の層 | 層の追加・削除、密度・高さ帯・傾斜上限の調整、塗り足し / 消し |
| 表面 (Surface) | マテリアル | 地形マテリアルの割り当てと繰り返し |

## 形モード

### ブラシ

既存の`TerrainBrushOperation`をそのまま使う。追加するのは操作の速さだけである。

- 半径と強さはカーソル上で直接変える。`[` `]`で半径を変える。`Shift` + ドラッグで強さを変える。数値欄はパネルにも置く。地面から目を離さずに済む経路を主にする
- ブラシ円はシーンに常時表示する。半径と落ち方が見えていないと、どこが変わるか予測できない
- `Ctrl`を押している間は逆操作にする（盛る↔削る、開ける↔塞ぐ）。持ち替えを挟まない

ブラシを押してから離すまでを、元に戻すの1件にまとめる。既存の`handleTerrainStrokeStart`がこの区切りを管理している。専用モードでも同じ扱いにする。

### 高さを揃える

`flatten`は現在「ブラシ中心の高さ」へ揃える。この動作に基準高さの取得を足す。`Alt` + クリックでその地点の高さを取得する。以降はその高さへ揃える。道や広場を作るときに、同じ高さを繰り返し狙う必要がなくなる。

## 草モード

草はルールに従って配置する。特定の場所だけ草を除外するには、ルール配置に加えて塗り操作が必要になる。

### マスク

`TerrainGrassLayer`へ任意の`mask`を足す。

```
mask?: number[]   // 0..1、Terrain の resolution と同じ並び
```

- 省略時は全サンプルを1として扱う。既存の層はそのまま動作し、塗り操作を行ったときに配列を作る。
- 解像度は高さフィールドと同じにする。解像度が異なると、地形を編集したときに各サンプルを対応付けられない。
- `serialization.ts`の許可キーへ足す。`generateTerrainGrassInstances`の候補判定へも同時に足す。片方だけでは、保存した時点でシーンが読めなくなる

配置側は`hash(seed, index, 5) < maskAt(localX, localZ)`を候補の採否へ加える。この条件であれば、密度の安定性（増やしても既存が動かない）を保てる。

- ブラシで足す / 消す。強さはマスク値の増減量である
- いま編集中の層だけを塗る。複数層を同時に塗ると、何をしたのか後から読めない
- 編集中の層をシーンで強調表示する。他層は薄く出す

### 層のパネル

草はUnityの地形Layersと同じく、レイヤーとして上から順に並べる。選択できる層は常に1つで、塗り操作はその層にだけ適用する。

層の一覧表示、追加、削除、並べ替えを用意する。各層は種類・密度・高さ帯・傾斜上限を持つ。選択中の層は一覧の中で見て分かるようにする。塗り・消しはその選択に従う。層ごとにボタンを置く。「どの層を塗っているのか」を毎回選ばせ直さない配置にする。

実際に置かれた本数と、密度が要求した本数は常に表示する。上限で丸めたときはその旨を出す。何も出さずに切り捨てない。

### MCP から草を扱う

草を設定パネルからしか操作できなかった時期は、AIが草のない地形を作っていた。MCPにもパネルと同じ単位の操作を用意する。草の配列全体を渡す方式では、要求の一部を間違えるだけで調整済みの層を置き換えるおそれがあるため、層ごとのtoolに分ける。

| Tool | 対応する操作 |
| --- | --- |
| `list_terrain_grass_types` | 種類カタログ、プリセット、密度・傾斜・高さ帯・上限の一覧 |
| `apply_terrain_grass_preset` | 「セットを適用」。層を積むのではなく置き換える |
| `add_terrain_grass_layer` | 「レイヤーを追加」。appearanceは同時に渡せる |
| `update_terrain_grass_layer` | 種類・密度・高さ帯・傾斜上限・seed・appearanceの変更と、`index`による並べ替え |
| `delete_terrain_grass_layer` | 層の削除 |
| `paint_terrain_grass` | 塗り足し / 消し。層を1つ指定する |

`appearance`の各項目へ`null`を渡すと、その上書きだけが消える。`patch.appearance`自体へ`null`を渡すと、種類の値へ全部戻る。省略は「今の値をそのまま」である。この3つを混同せずに使い分ける。`patch.mask`へ`null`を渡すと、塗りだけを戻す。

`get_terrain`は層ごとに、解決後の色とこの地形で実際に置かれる本数を返す。上限で丸めた層は`clampedByInstanceLimit`で分かる。設定と同じく、黙って切り捨てない。

## 表面モード

地形マテリアルは現在ひとつである。ここへ高さと傾斜による混合を入れる。

- 低い所 / 高い所 / 急斜面に別のマテリアルを割り当てる。境界をぼかす
- 実装は地形専用のシェーダーになる。水面と同じくプリセット付きのカスタムシェーダーとして配る形にする。既存の公開経路に乗るためである

これは草より重い作業である。草のマスクを先に済ませてから着手する。

## 性能

### 距離カリングと LOD

草は現在、全インスタンスを常に描いている。広い地形では処理が追いつかなくなる。

- 距離カリング: 既定40mである。層ごとに設定できるようにする
- LOD: 近距離は交差カードにする。遠距離は1枚へ落とす
- 実装はInstancedMeshを距離帯ごとに分ける形にする。1つのメッシュの中でカードを減らすことはできない

`TERRAIN_GRASS_MAX_INSTANCES`は実装済みである。ただしまだUIへ出していない。草モードのパネルで「上限に達したので丸めた」ことを示す。

## 公開への反映

この節は未実装時点の設計を記録している。現在の実装状況は、冒頭の「現状（確認済み）」と末尾の「実装順」を参照する。

`runtime.json`へ載せるのは種類id、密度、高さ帯、傾斜上限、seed、マスクだけである。GLSLもインスタンス座標も載せない。公開物のサイズは密度に比例しなくなる。

ランタイム側で同じ配置を再生成する必要がある。Studio側と生成アルゴリズムが一致していないと、動作確認と公開後で草の位置がずれる。

一致のさせ方は2案ある。

1. 生成ワールドへアルゴリズムを直接埋め込む。出力されたコードがアルゴリズムそのものを含む。このため、二重管理が起きない
2. ランタイムパッケージへ実装を置き、fixtureでTS実装と突き合わせる

1を採用する。2ではアルゴリズムを2箇所で管理するため、差が生じる可能性がある。1なら埋め込んだ関数をfixture内で評価し、TS実装と同じ入力から同じ出力が得られることを直接確認できる。

## 実装順

1. 草のマスク。データ、配置側の判定、塗り操作を用意し、専用モードで使う（実装済み）
2. モード制のパネル — アイコンタブでの形 / 穴 / 草の切り替えと、草のレイヤー選択。設定の中で先に形にする（実装済み）
3. 専用モードの枠 — シーン側の地形以外の選択停止、戻り先
4. 形モードの操作改善 — カーソル上での半径・強さ、常時ブラシ円、高さの吸い取り
5. 距離カリングとLOD — 広い地形が実用になる
6. 公開への反映 — 上記の埋め込み方式とfixture（実装済み）
7. 表面モード — 高さ・傾斜によるマテリアル混合

## 注意

- シーンdocumentのスキーマへ追加するときは、`serialization.ts`の許可キーとMCPの対応ツールを同時に更新する。片方を忘れると、保存した時点でシーンが読めなくなる
- 草の配置に手を入れるときは、密度を上げても既存のbladeが動かない性質を壊さない。`terrain-grass.fixture.ts`が固定している
- 専用モードへ入っている間も、動作確認への遷移と保存は塞がないこと
