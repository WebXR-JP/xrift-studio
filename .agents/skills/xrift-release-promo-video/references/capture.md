# 実画面の収録と座標

対象コミットの実アプリを使う。ブラウザ・Tauri の起動と検証は [xrift-studio-verify](../../xrift-studio-verify/SKILL.md) の該当箇所を参照する。

- 同じウィンドウサイズ・倍率で操作前、操作中、操作後の結果を撮る。変化を示す必要がない場面は静止画を使う。動きが主題なら録画する。
- 素材のカーソルを非表示にし、後から描くポインターと重ねない。通知、個人情報、未公開作品を画面から除く。
- `dev/release-promo/<slug>/public/source/` に素材を置く。storyboard の `sourceNotes` に日時・バージョン・実機かプレビューか・viewport・DPR・行った操作を記録する。
- 収録のための公開・アップロード・削除・リセットは `AGENT.md` の意思決定に従う。行っていない操作を行ったように見せない。

座標は素材左上を `(0, 0)`、右下を `(1, 1)` とする。DOM が取得できれば同じ viewport で要素の矩形を取得し、中心の X を viewport 幅、Y を高さで割る。画像から測る場合は素材ピクセルの位置を素材の幅・高さで割る。ポインター、ズーム、注釈に同じ座標を使い、静止画で一致を確認する。

個人情報が写った場合は撮り直すか、storyboard の `redactions` に `x, y, width, height, mode, reason` を指定する。mode は `blur` または `block`。元素材を不用意に共有せず、書き出した画像で伏せた範囲を確認する。

録画素材は可変フレームレートによる書き出し失敗を避けるため、各動画のディレクトリで次を実行する。

```bash
node ../_kit/scripts/prepare-footage.mjs
```

素材を固定フレームレートへ変換し音声を落として置換するため、元音声を使う場合は先に別途保存する。記録は `public/source/prepared.json`。再処理には `--force` を使う。背景をぼかして使うだけなら動画ではなく静止画を切り出す。

動画の `source` は `src`, `startFrom`, `playbackRate` を指定できる。素材音声は既定で無音。使う場合だけ `volume` を指定し、BGM と重ならないか確認する。
