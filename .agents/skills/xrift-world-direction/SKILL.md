# XRift ワールドの制作工程

## このスキルの目的

これは支援型のハーネスである。子どもが大きく育つ環境を整えるのと同じで、伸びる力を縛らず、
伸びを妨げるものだけを取り除く。具体的には次の 2 つのためにある。

1. 時間を溶かす罠 (ツールの偏りに流される、見ずに直し続ける) を避ける。
2. 許可を何度も求めずに、1 本のワールドを最後まで作り切る。

何を作るか、どの品質にするか、何を入れて何を入れないか、Terrain・草・ポストエフェクト・外部
素材・重いモデルを使うかは、依頼を読んでモデルが決める。「高品質のワールドが欲しい」と言われ
たら、重くなる手段も含めて選んでよい。「軽く」と言われたら削る。完成の条件も設計図の中で自分で
決める。ここにあるのは、どちらの場合にも効く順番と、罠の気づき方と、確かめ方だけである。

## 自律的に完成させる

- 最初に設計図を書き、聞かずに決めた前提をそこに書いて進む。途中で止まって許可を求めない。
  ユーザーは最初の報告の設計図を読んで、違えば途中で直す。
- ユーザーにしかできないこと (Script の承認、ログイン、公開) だけ依頼する。依頼したら待つ間に
  他の工程を進める。
- 完了報告は 1 通にまとめる。設計図、2 枚のキャプチャのパス、metrics、聞かずに決めた前提、
  やり残しと理由、完成の条件を満たした根拠。

## 設計図

書式は `references/blueprint-template.md`。品質の水準、場所と用途、雰囲気、床、主役、動きと
反応、入れないもの、自分で決めた予算、完成の条件、聞かずに決めた前提。テーマの指定が無ければ、
依頼の文脈 (用途、人数、雰囲気の言葉) から最も合うものを 1 つ決めて書く。案は 1 つ。候補を
並べてユーザーに選ばせない。

## 工程 (順番は罠を避けるためのもの)

### 0. 設計図 (ツール呼び出し 0 回)

ツール一覧を見る前に書く。一覧の偏り (Terrain と草に 14 本、床を作るプリミティブに 1 本) に
床の種類を決めさせないため。

### 1. 土台

`get_editor_context` と `list_entities` でスターターの床、太陽、スポーンを確認し、設計図の床と
違うなら消すか差し替える。床と大きな構造を設計図に合わせて作る。

### 2. 主役

設計図の主役を、装飾より先に作る。素材の調達先は `references/asset-sourcing.md` に並列で
並べてある。順番は無く、設計図と品質の水準で選ぶ。動くもの、繰り返すもの、反応するものは
Script で作れる (`references/scripting-patterns.md`)。

### 3. 光と空

空、環境光、フォグは `update_scene_settings` で同時に決める。ポストエフェクトを使うかは設計図の
品質の水準から決め、使うなら有効前後を `capture_scene_view` で比べる。WebGL では見る全員の
描画と弱い端末の負荷に効くためで、使うこと自体は自由である。

### 4. 設計図の残り

設計図に書いた残りの要素 (小物、音、仕掛け、動き) を作る。何を入れるかは設計図が決める。

### 5. 確かめる

1. `set_scene_view_camera` でスポーン位置・目の高さから主役を向き、`capture_scene_view`。
2. `set_scene_view_camera { preset: "iso" }` で俯瞰し、`capture_scene_view`。
3. `capture_scene_debug { action: "metrics" }` を設計図の予算と照らす。
4. 2 枚のフレームを設計図の「完成の条件」と照らし、根拠を完了報告に書く。数値と document は
   「何が映るはずか」しか言わない。何が映っているかを言うのはフレームだけ。

## ハマりやすい罠

| 罠 | なぜ起きる | 気づき方と抜け方 |
| --- | --- | --- |
| 既定に流される (草原の Terrain、木のレシピの複製、草) | ツール一覧と preset が自然物に偏っている | 設計図に床の種類を書いたか。書いた床と違う道具を呼んでいないか |
| 見ずに直し続ける (草の密度や色、同じ Entity の位置、同じ Material) | 1 回の変更で絵が変わるので進んだ気になる | 同じ分類の書き込みが撮影を挟まず 3 回続くと Studio が戻り値に `harness` の警告を付ける。撮って欠陥を 1 つ直し、無ければ確定して次へ |
| 主役が無いまま装飾が増える | 埋める方が決めるより簡単 | 最初の 1 枚に主役が写るか |
| 空だけ変えて光が昼のまま | 空と光が別の tool | 空、環境光、フォグを同時に決める |
| ポストエフェクトで誤魔化す | 一度に全体の印象が変わる | 有効前後のキャプチャを比べる。差が無ければ切る |
| 既定の灰色 Material のまま出荷する、y = 0 のまま置いて浮く・沈む | 既定値のまま進める | 俯瞰のキャプチャと `get_entity_bounds` / `sample_terrain_point` |
| 重い写真スキャンをそのまま入れる | 見た目は良いが数百万三角形のものがある | `search_external_assets` の `polycount` を予算と照らす |
| Script の承認待ちで止まる | 承認はユーザーにしかできない | 1 回だけ依頼して、待つ間に他の工程を進める |
| Blender の往復が終わらない | 要件が曖昧 | 要件を単純にして 1 回で決める |
