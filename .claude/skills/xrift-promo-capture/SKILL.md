# リリース動画の実画面収録

この作業に必要な手順・コマンドは [workflow](references/workflow.md) の該当節を参照する。関連スキルは、担当する作業が必要になった場合だけ読む。実行の判断はリポジトリルートの `AGENT.md` に従う。

参照する節:

- Overview
- 撮る前に整える
- 何を撮るか
- 収録した動画は必ず整える
- 写ってはいけないものを伏せる
- 置き場所と記録
- 座標を取り出す
- 動画素材の指定
- やらないこと
