# Blenderで部屋とインテリアを作る

既存シーンと制作条件を確認し、依頼された範囲を編集してください。実行できる操作はリポジトリの`AGENT.md`に従います。日本語の説明では、配置の意図、操作、検証した結果を明確にしてください。

## 制作

作業用の`.blend`、テクスチャ、生成スクリプトは、Studioが管理するプロジェクトディレクトリと分けて保存してください。繰り返し生成する部屋では、寸法定数をまとめた`.py`を使います。小さな編集では、部屋全体を再生成する必要はありません。

再生成する対象は、自分が生成したコレクションに限ります。既存オブジェクトや全データブロックを一括削除しません。全体を新しく生成する場合は専用の`.blend`を用意し、既存の作業を保存してください。

部屋の寸法、開口部、通路、家具の配置を先に確認し、その後で細部を作ります。Studioで個別に編集する物は、名前を付けた別オブジェクトにしてください。ドアはヒンジ、家具は設置面など、用途に合うピボットを保ちます。

プレビュー用のライトとカメラは、書き出す対象から分けてください。色と照明は、最後にStudioの表示で確認します。

## 必要な資料と補助コード

| 対象 | 参照先 |
|---|---|
| 壁、床、取り付け部品の面の重なり | [zfighting.md](references/zfighting.md) |
| マテリアル、UV、形状、GLBの検査 | [blender-recipes.md](references/blender-recipes.md) |
| 取り込み、座標、表示の確認 | [xrift-import.md](references/xrift-import.md) |
| 部屋を生成するヘルパー | [room_lib.py](scripts/room_lib.py) |
| テクスチャの取得 | [fetch_polyhaven.py](scripts/fetch_polyhaven.py) |
| 静的な部屋の検査 | [validate_scene.py](scripts/validate_scene.py) |
| 同一平面の候補検出 | [find_coplanar.py](scripts/find_coplanar.py) |

補助スクリプトは、対象と前提を読んでから使ってください。検査では全メッシュを調べるため、専用の制作ファイルで実行します。

`validate_scene.py`の単位スケール、UV、マテリアル、モディファイアの検査は、静的な部屋の制作規約です。すべてのglTFに必要な条件ではありません。`find_coplanar.py`の候補には誤検出もあります。対象の面とStudioの表示を確認し、件数をゼロにするために意図した形状を変更しないでください。

## 書き出しと確認

1. 対象オブジェクト、親子関係、ピボット、実寸、マテリアルを確認し、対象だけを自己完結したGLBへ書き出してください。
2. 静的な部屋ではプレビュー用ライト・カメラと不要なアニメーションを除きます。依頼された動きは保ってください。
3. Editモードで取り込み、最新のrevisionを取得して配置します。再取り込みでは既存のassetIdを維持してください。
4. 既存の床との重なり、スポーン位置、生成されたコライダーを確認し、問題のある対象を修正します。
5. `capture_scene_view`で見た目を確認してください。動きと性能は、必要に応じてPlayと`capture_scene_debug`で調べます。診断のために変更した値は元に戻します。

完了時はassetId、entityId、検証結果、残っている問題を報告してください。素材は取得先の利用条件を確認し、取得元、作者、加工内容を記録します。
