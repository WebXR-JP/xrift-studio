# 実画面の収録と座標

対象コミットの実アプリを使ってください。ブラウザとTauriの起動・確認手順は、[xrift-studio-verify](../../xrift-studio-verify/SKILL.md)にあります。

- 同じウィンドウサイズ・倍率で操作前、操作中、操作後の結果を撮る。変化を示す必要がない場面は静止画を使う。動きが主題なら録画する。
- 素材のカーソルを非表示にし、後から描くポインターと重ねない。通知、個人情報、未公開作品を画面から除く。
- `dev/release-promo/<slug>/public/source/`に素材を置く。storyboardの`sourceNotes`に日時・バージョン・実機かプレビューか・viewport・DPR・行った操作を記録する。
- 収録のための公開・アップロード・削除・リセットは`AGENT.md`の意思決定に従う。行っていない操作を行ったように見せない。

座標は素材左上を`(0, 0)`、右下を`(1, 1)`とする。DOMが取得できれば同じviewportで要素の矩形を取得し、中心のXをviewport幅、Yを高さで割る。画像から測る場合は素材ピクセルの位置を素材の幅・高さで割る。ポインター、ズーム、注釈に同じ座標を使い、静止画で一致を確認する。

個人情報が写った場合は撮り直すか、storyboardの`redactions`に`x, y, width, height, mode, reason`を指定する。modeは`blur`または`block`。元素材を不用意に共有せず、書き出した画像で伏せた範囲を確認する。

録画素材は可変フレームレートによる書き出し失敗を避けるため、各動画のディレクトリで次を実行する。

```bash
node ../_kit/scripts/prepare-footage.mjs
```

この処理は、素材を固定フレームレートへ変換し、音声を除いて置き換えます。元の音声を使う場合は、先に別のファイルへ保存してください。処理記録は`public/source/prepared.json`に残ります。再処理には`--force`を使います。背景をぼかすだけなら、静止画を切り出してください。

動画の`source`は`src`, `startFrom`, `playbackRate`を指定できる。素材音声は既定で無音。使う場合だけ`volume`を指定し、BGMと重ならないか確認する。
