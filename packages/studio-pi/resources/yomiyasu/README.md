# 日本語の応答方針（Yomiyasu 由来）

提供を受けた Yomiyasu の `SKILL.md` とライセンス文を、原文のままこのディレクトリに保管しています（著作権者: nanaism、ライセンス: MIT）。Unicode のライセンスも同梱しています。

制作チャットでは、このスキルの文章方針を要約した `src/writing-guide.ts` をシステム指示に組み込んでいます。回答本文だけでなく、進捗メッセージ、制作プラン、確認質問と選択肢、完了条件、エラー案内など、モデルが出力するすべてのテキストにこの方針を適用しています（固定の画面文言はソースコード側で整えています）。

なお、元のスキルに含まれていた参照資料や Python の校正スクリプトは同梱していないため、自動校正ワークフロー自体は組み込んでいません。また、利用者の入力文や外部サービスのエラー原文を一律に書き換えたり、内部の思考過程を表示したりする機能ではありません。
