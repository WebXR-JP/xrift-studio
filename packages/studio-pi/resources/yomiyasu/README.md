# 日本語の応答方針

利用者が提供したYomiyasuのSKILL.mdとライセンスを原文のまま保持しています。著作権者はnanaism、ライセンスはMITです。Unicodeのライセンスも同梱します。

制作チャットは、このスキルの文章方針を要約した`src/writing-guide.ts`をシステム指示に組み込みます。外部パッケージの登録は不要で、Planでも適用します。文章の意味、確実さ、権限と条件を維持する方針です。回答、進捗、プラン、質問と選択肢、完成条件、エラー時の案内など、モデルが作るすべての表示文を対象にします。固定表示文はソース側で同じ方針に沿って整えます。利用者の入力や外部サービスのエラー原文は一律に書き換えません。内部の思考過程を表示する機能ではありません。

添付には参照資料とPythonの校正スクリプトが含まれないため、元スキルの校正ワークフロー全体は実装・実行していません。文章品質を自動で保証したり、校正済みと判定したりする機能ではありません。
